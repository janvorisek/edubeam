# ส่วนติดต่อผู้ใช้

<Edubeam /> มีสามส่วนหลัก: **แถบแอป** ด้านบน **หน้าจอแสดงผล** (viewer) ตรงกลางที่คุณใช้วาด และ **แถบด้านล่าง** ที่มีตารางสำหรับวัตถุแต่ละประเภท เมื่อรู้ว่าอะไรอยู่ตรงไหน ส่วนที่เหลือของคู่มือจะเข้าใจง่ายขึ้น

![ส่วนต่าง ๆ ของอินเทอร์เฟซ มีหมายเลขตามรายการด้านล่าง](/screenshots/th/ui-overview.webp)

1. **เมนู ☰**: เปิด บันทึก แชร์ และส่งออก ตัวอย่างและทัวร์แนะนำ
2. **ปุ่มบนแถบแอป**: ลบ Mesh และแชร์โมเดล
3. **เลิกทำ / ทำซ้ำ** สำหรับทุกการเปลี่ยนแปลงในโมเดล
4. **ปุ่มของโปรแกรมดู**: จัดกึ่งกลาง ปรับให้พอดีหน้าจอ และปุ่มเปิด/ปิดตัวเลือกการแสดงผล
5. **ตัวเลือกการแสดงผล**: เลือกว่าจะวาดผลลัพธ์และส่วนใดของโมเดล
6. **ตาข่าย การจับติด เส้นเล็ง และหน่วย**
7. **แท็บของแถบด้านล่าง**: โหนด องค์ประกอบ แรงกระทำ วัสดุ หน้าตัด ผลลัพธ์
8. **ตาราง** ของแท็บที่เปิดอยู่ ซึ่งแก้ไขได้ทุกค่า

::: tip ลองทัวร์
**☰ → พาชมแอป** จะชี้ส่วนต่าง ๆ เหล่านี้ในตัวแอปทีละส่วน
:::

## หน้าจอแสดงผล {#viewer}

พื้นที่วาด (canvas) คือที่ที่คุณวาดและตรวจดูโมเดล ส่วนอื่นของแอปทั้งหมดจะเปลี่ยนตามสิ่งที่คุณเลือกที่นี่

### ปุ่มบนพื้นที่วาด {#buttons-on-the-canvas}

- **มุมซ้ายบน:** **เลิกทำ** และ **ทำซ้ำ** (<kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>) ทุกการเปลี่ยนแปลงในโมเดล ทั้งการเพิ่ม แก้ไข ลาก ลบ และล้างโมเดล เลิกทำได้ทั้งหมด
- **มุมขวาบน:** **จัดเนื้อหาให้อยู่กึ่งกลาง** (<kbd>C</kbd>) **ปรับเนื้อหาให้พอดีกับหน้าจอ** (<kbd>F</kbd>) และปุ่ม ⚙ ที่แสดงหรือซ่อนตัวเลือกการแสดงผล บนหน้าจอสัมผัสยังมี **เลือกแบบกรอบ** ด้วย
- **มุมขวาล่าง:** **G** เปิด/ปิดตาข่าย **S** เปิด/ปิดการจับติดตาข่าย ปุ่มเส้นเล็งแสดงตำแหน่งตัวชี้บนไม้บรรทัด และ **ป้ายหน่วย** เปิดการตั้งค่าที่หน้า *ภาษาและภูมิภาค*

### ตัวเลือกการแสดงผล {#display-options}

![ปุ่มของโปรแกรมดูและตัวเลือกการแสดงผล](/screenshots/th/ui-display-settings.webp){.shot-lg}

ช่องทำเครื่องหมายสองแถว เปิดอยู่เป็นค่าเริ่มต้น:

- **ผลลัพธ์:** *รูปร่างที่เสียรูป*, *N (x)*, *V<sub>z</sub> (x)*, *M<sub>y</sub> (x)*, *แรงปฏิกิริยา* โดยรูปร่างที่เสียรูป M และแรงปฏิกิริยาติ๊กไว้ตั้งแต่เริ่มต้น
- **โมเดล:** *จุดรองรับ*, *แรงกระทำ*, *ป้ายโหนด*, *ป้ายองค์ประกอบ*

**การตั้งค่าเพิ่มเติม** เปิด [การตั้งค่า](/th/essentials/units-settings) แบบเต็มที่หน้า *การตั้งค่าโปรแกรมดู*

### การเลื่อนมุมมอง {#navigating}

| การกระทำ | เมาส์ | หน้าจอสัมผัส |
| --- | --- | --- |
| ซูม | ล้อเมาส์ (ซูมเข้าหาเคอร์เซอร์), <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | จีบนิ้ว |
| เลื่อนมุมมอง | ลากด้วยปุ่ม **กลางหรือขวา** (ดู *การตั้งค่า → การควบคุมและทางลัด*) | ลากด้วยนิ้วเดียว |
| พอดีหน้าจอ / จัดกึ่งกลาง | <kbd>F</kbd> / <kbd>C</kbd> หรือปุ่มที่มุมขวาบน | ปุ่มที่มุมขวาบน |

### การเลือกและการแก้ไข {#selecting-and-editing}

**คลิก** โหนด องค์ประกอบ แรงกระทำ หรือเส้นมิติเพื่อเลือก แผงจะเปิดขึ้นข้าง ๆ พร้อมรายละเอียดและการดำเนินการที่เกี่ยวข้อง: เพิ่มแรงกระทำ กำหนดจุดรองรับ แก้ไข แสดงเมทริกซ์ความแข็ง ลบ การคลิกโหนดยังสลับแถบด้านล่างไปที่แท็บโหนดด้วย

<div class="shots">

![โหนด: เพิ่มแรงกระทำ กำหนดจุดรองรับ กำหนดการกระจัด](/screenshots/th/ui-node-menu.webp)

![องค์ประกอบ: แก้ไข เพิ่มแรงกระทำ เมทริกซ์ความแข็ง](/screenshots/th/ui-element-menu.webp)

</div>

- **ลากบนพื้นที่วาดที่ว่าง** เพื่อวาดกรอบเลือก ทุกอย่างที่อยู่ข้างในจะถูกเลือก: โหนด องค์ประกอบ แรงกระทำบนองค์ประกอบเหล่านั้น และเส้นมิติ กด <kbd>Delete</kbd> เพื่อลบทั้งหมด หรือ <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd> เพื่อคัดลอกไปที่อื่น
- **ลากโหนด** เพื่อย้าย เมื่อเปิดการจับติด โหนดจะลงบนตาข่าย องค์ประกอบที่เชื่อมอยู่และแรงกระทำบนองค์ประกอบจะเคลื่อนตาม
- **ดับเบิลคลิกแรงกระทำ** เพื่อแก้ไข
- **ชี้เมาส์** ที่อะไรก็ได้เพื่อดู tooltip โหนดแสดงการกระจัดและมุมหมุน องค์ประกอบแสดงวัสดุและหน้าตัด แรงกระทำแสดงค่า บนหน้าจอสัมผัสให้แตะแทน รายละเอียดเดียวกันจะปรากฏในแผงการเลือก

![การชี้เมาส์ที่โหนดแสดงการกระจัดและมุมหมุน](/screenshots/th/ui-hover.webp){.shot-sm}

**คลิกขวาบนพื้นที่วาด** (หรือกดค้างบนหน้าจอสัมผัส) เพื่อเปิดเมนูพื้นที่วาด กด <kbd>Ctrl</kbd> ค้างไว้ขณะเลือก *เพิ่มโหนด* หรือ *เพิ่มองค์ประกอบ* เพื่อวางด้วยเมาส์แทนกล่องโต้ตอบ เมื่อเปิดเมนูบนองค์ประกอบ จะมี *ใส่ขนาดชิ้นส่วน* ให้เลือกด้วย

![เมนูพื้นที่วาด](/screenshots/th/ui-canvas-menu.webp){.shot-sm}

ทางลัดทั้งหมดอยู่ในหน้า [แป้นพิมพ์ เมาส์ และระบบสัมผัส](/th/reference/shortcuts)

### เมื่อคำนวณโมเดลไม่ได้ {#when-the-model-cannot-be-solved}

ข้อความจะปรากฏที่มุมซ้ายบนของหน้าจอแสดงผล:

- *ไม่มีการกำหนดวัสดุ* / *ไม่มีการกำหนดหน้าตัด* พร้อมปุ่ม **เพิ่มใหม่**
- ป้ายสีฟ้าเล็ก ๆ **ต้องมีจุดรองรับ** ขณะที่โมเดลยังสร้างไม่เสร็จ
- **ข้อความสีแดง** เมื่อมีบางอย่างผิดพลาด พร้อมปุ่ม **แสดงรายละเอียด** ที่แสดงรายการปัญหาทั้งหมด

เมื่อโครงสร้างยังเคลื่อนที่ได้ EduBeam จะแสดงเส้นประของโครงสร้างที่แกว่งไปมา และวงโหนดหรือจุดหมุนที่เป็นต้นเหตุ ชี้เมาส์ที่ข้อความเพื่อดูการเคลื่อนที่อีกครั้ง หรือใช้ปุ่มรูปตาเพื่อซ่อน

![โครงข้อแข็งที่มีจุดหมุนที่ B และ C เป็นกลไก: EduBeam แสดงว่ามันเคลื่อนที่อย่างไร](/screenshots/th/ui-mechanism.webp)

![แสดงรายละเอียดจะแสดงแต่ละปัญหาพร้อมคำแนะนำ](/screenshots/th/ui-diagnostics.webp){.shot-lg}

## แถบด้านล่าง {#bottom-bar}

มีหกแท็บ แต่ละแท็บมีแถบเครื่องมือและตารางที่แก้ไขได้ แท็บแสดงจำนวนวัตถุแต่ละประเภทในโมเดล ปุ่ม **?** ทางขวาอธิบายแท็บที่เปิดอยู่ และ **?** ข้างหัวคอลัมน์บางคอลัมน์ก็อธิบายคอลัมน์นั้น ลากแถบแท็บขึ้นหรือลงเพื่อปรับขนาดแถบ หรือย่อเก็บด้วยปุ่มทางขวา

| แท็บ | แถบเครื่องมือ | ตาราง |
| --- | --- | --- |
| **โหนด** | เพิ่มโหนด (กล่องโต้ตอบ), เพิ่มโหนด (เมาส์) | ชื่อ พิกัด **องศาความเป็นอิสระที่รองรับ** (สัญลักษณ์จุดรองรับ, Dx, Dz, Ry, มุมจุดรองรับ α) แรงกระทำ แก้ไข ลบ |
| **องค์ประกอบ** | เพิ่มองค์ประกอบ (กล่องโต้ตอบ), เพิ่มองค์ประกอบ (เมาส์) | ชื่อ ประเภท โหนด (พร้อมปุ่มสลับ) วัสดุ หน้าตัด **ข้อต่ออิสระปลาย** แรงกระทำ เมทริกซ์ความแข็ง ลบ |
| **แรงกระทำ** | เพิ่มแรงกระทำที่โหนด, เพิ่มแรงกระทำที่องค์ประกอบ | ประเภท เป้าหมาย ส่วนประกอบที่แก้ไขได้ แก้ไข ลบ |
| **วัสดุ** | เพิ่มวัสดุ, ไลบรารีวัสดุ | ชื่อ E, G, α<sub>T</sub> ลบ |
| **หน้าตัด** | เพิ่มหน้าตัด, ไลบรารีหน้าตัด, หน้าตัดรูปหลายเหลี่ยม | รูปร่าง ชื่อ A, I<sub>y</sub>, h, k แก้ไขรูปร่าง ลบ |
| **ผลลัพธ์** | ผลลัพธ์ที่โหนด, ผลลัพธ์ที่องค์ประกอบ, ส่งออก CSV, คัดลอก | การกระจัดและมุมหมุนของแต่ละโหนด หรือแรงปลายของแต่ละองค์ประกอบ |

แก้ไขเซลล์ได้ในที่: คลิก พิมพ์ แล้วกด <kbd>Enter</kbd> (หรือ <kbd>Esc</kbd> เพื่อออกจากเซลล์) ค่าต่าง ๆ แสดงและป้อนใน [หน่วยปัจจุบัน](/th/essentials/units-settings)

## แท็บเหนือหน้าจอแสดงผล {#tabs-above-the-viewer}

**โปรแกรมดู** แสดงพื้นที่วาด **การตั้งค่า** แสดงการตั้งค่าแบบเต็มจอ คุณจึงเปลี่ยนสีหรือหน่วยแล้วสลับกลับไปดูผลได้ ป้ายหน่วยและ *การตั้งค่าเพิ่มเติม* เปิดการตั้งค่าชุดเดียวกันเป็นกล่องโต้ตอบเหนือโมเดล

## หน้าต่างลอย {#floating-windows}

**เมทริกซ์ความแข็ง** (จากแผงขององค์ประกอบหรือตารางองค์ประกอบ) เปิดหน้าต่างแสดงเมทริกซ์ความแข็งขนาด 6 × 6 ขององค์ประกอบในพิกัดรวม **แก้ไข** ในเมนูพื้นที่วาดเปิดตารางของสิ่งที่เลือกอยู่ ลากหน้าต่างได้ที่แถบชื่อ และปิดด้วย ×
