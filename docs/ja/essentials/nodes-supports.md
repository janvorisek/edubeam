# 節点と支点

節点はモデルの点です。要素は節点どうしを結び、支点と節点荷重は節点に設定します。

## 座標 {#coordinates}

各節点は、現在の長さの単位で **X** 座標と **Z** 座標を持ちます。画面上で x 軸は右向き、**z 軸は下向き**です。そのため、地面から立ち上がる柱は `Z = 0` から `+3` ではなく `Z = −3` へ向かいます。グリッドの隅にある座標軸の記号が向きを示しています。鉛直軸を上向きにしたい場合は、設定で [y 上向きの座標軸](/ja/elements/conventions#y-up-axes)に切り替えてください。

## 節点の追加 {#adding-nodes}

| 方法 | 手順 |
| --- | --- |
| **ダイアログ** | *節点*タブ → 1 つ目の**節点を追加**ボタン、またはキャンバスを右クリック → *節点を追加*。X と Z を入力し、必要に応じて支点と支点の角度も入力します。 |
| **マウス** | *節点*タブ → 2 つ目の**節点を追加**ボタン（カーソルアイコン）、またはキャンバスのメニューで <kbd>Ctrl</kbd> を押しながら*節点を追加*を選びます。キャンバスをクリックするたびに節点が追加されます。<kbd>Esc</kbd> または**キャンセル**で終了します。 |
| **要素の描画中** | 要素のマウスモードでキャンバスの何もない所をクリックすると、節点が作成されて接続されます。 |
| **コピーと貼り付け** | 節点（と要素）を選択して <kbd>Ctrl</kbd>+<kbd>C</kbd>、<kbd>Ctrl</kbd>+<kbd>V</kbd> を押し、コピー先をクリックするか、オフセット Δx、Δz を入力して**貼り付け**を押します。 |

ラベルは自動で付けられ（`1`、`2`、… または `A`、`B` のような独自の付け方の続き）、表で名前を変更できます。

### スナップ {#snapping}

**グリッドにスナップ**（<kbd>S</kbd> または **S** チップ）がオンのとき、配置したりドラッグしたりした節点は**グリッドのスナップ間隔**の倍数の位置に置かれます。初期値は 0.1 m、米国単位では 0.5 ft です。*設定 → 表示設定 → グリッド*で変更できます。自由に配置したい場合はスナップをオフにするか、あとで表に正確な座標を入力してください。

### 既存の要素の上に節点を置く {#placing-a-node-on-an-existing-element}

節点を追加するときに要素の近くをクリックすると、EduBeam がどうしたいかを尋ねます。

- **構造物に接続**は要素を 2 つ（`1a` と `1b`）に分割します。外側の端のヒンジは保たれ、等分布荷重と台形分布荷重は 2 つの要素に分けられます。集中荷重と温度荷重は 1 つ目の要素に移ります。中間支点や荷重点を追加するいちばん速い方法です。
- **独立した節点を配置**は、要素に接続せずにその上に節点を作成します。

## 節点の編集 {#editing-nodes}

- **表：** ラベル、X、Z をその場で編集します。
- **ドラッグ：** ビューアで節点を移動します。タッチスクリーンでも、節点を押してドラッグすれば移動できます。どの移動も元に戻せます。
- **節点を編集ダイアログ：** 表の*操作*列の鉛筆アイコン。座標、支点、支点の角度を設定でき、支点記号のプレビューも表示されます。
- **削除：** 表の ×、節点のパネルの*削除*、または選択して <kbd>Delete</kbd>。節点を削除すると、その節点に接続された要素と荷重も削除されます。

## 支点 {#supports}

支点とは、拘束された自由度（DOF）の組み合わせです。各節点には 3 つの自由度があります。

| 自由度 | 意味 |
| --- | --- |
| **Dx** | x 方向（水平）の並進 |
| **Dz** | z 方向（鉛直）の並進 |
| **Ry** | y 軸まわりの回転（図の面内） |

いちばん速いのは**記号を選ぶ**方法です。記号は、節点のパネルの**支点条件**、節点の追加・編集ダイアログ、そして節点の表の*拘束自由度*列の先頭にある小さなメニューから選べます。`Dx`、`Dz`、`Ry` のボックスにチェックを入れても、自由度を 1 つずつ同じように設定できます。

![支点条件：記号を選ぶか自由度にチェックを入れ、支点の角度を設定します](/screenshots/ja/nodes-support-picker.webp){.shot-lg}

| 支点 | 拘束 | 動き | 反力 |
| --- | --- | --- | --- |
| **自由** | なし | すべて | なし |
| **ピン** | Dx + Dz | 回転 | R<sub>x</sub>、R<sub>z</sub> |
| **ローラー** | Dz | 水平移動、回転 | R<sub>z</sub> |
| **鉛直ローラー** | Dx | 鉛直移動、回転 | R<sub>x</sub> |
| **固定** | Dx + Dz + Ry | なし | R<sub>x</sub>、R<sub>z</sub>、M |
| **スライド固定** | Dz + Ry | 水平移動 | R<sub>z</sub>、M |
| **鉛直スライド固定** | Dx + Ry | 鉛直移動 | R<sub>x</sub>、M |
| **回転のみ拘束** | Ry | 水平・鉛直移動 | M |

拘束されたすべての自由度について、反力が計算され、描画されます。

::: tip トラスの節点
トラス材は、両端の**材端ヒンジ**を解放した梁要素です（[要素](/ja/essentials/elements#end-hinges)を参照）。トラスの支点には通常ピン（Dx + Dz）を使います。接続するすべての要素がヒンジ接合の節点は回転剛性を持ちませんが、EduBeam はそれを受け入れ、その回転角を 0 として表示します。
:::

### 傾斜支点 {#inclined-skewed-supports}

**節点の LCS 角度** α を度単位（−180…180）で設定します。節点のパネルの*支点条件*、節点の追加・編集ダイアログ、節点の表の α 欄で設定できます。節点の座標軸がその角度だけ回転し、支点の自由度は回転した方向に作用します。たとえば 30° の斜面上のローラーは、α = 30 として `Dz` を拘束します。記号もそれに応じて回転し、反力は回転した方向で表示されます。

### 安定性 {#stability}

ソルバーには合計で少なくとも **3 つの拘束自由度**が必要で、さらに支点とヒンジが構造物を固定できていなければなりません。支点が足りないうちは、ビューアに青い*支点が必要*チップが表示されます。支点の数は足りていても構造物を固定できない場合（すべて平行、または 1 点で交わる）や、ヒンジによって部材どうしが回転できてしまう場合は、赤いメッセージが問題を示し、破線で構造物の動き方が表示されます。[トラブルシューティング](/ja/reference/troubleshooting)をご覧ください。

## 節点荷重と支点沈下 {#nodal-loads-and-settlements}

力、モーメント、強制変位（支点沈下）は節点に与えます。[荷重](/ja/essentials/loads#nodal-loads)をご覧ください。

## 寸法線 {#dimension-lines}

キャンバスを右クリック → **寸法線を追加**で 2 点間に寸法線を描けます。要素を右クリック → **要素の寸法線**で、その要素に直接寸法を付けることもできます。端点は、節点の近くまでドラッグすると節点にスナップします。寸法線を選択して**編集**で座標を入力したり、**寸法線を反転**でラベルを反対側に移したりできます。寸法線は表示のためだけのもので、プロジェクトと一緒に保存され、共有リンクにも含まれます。
