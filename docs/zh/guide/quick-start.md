# 快速入门

大约十分钟内，你将建立一根承受均布荷载的钢制简支梁模型，读出支座反力、剪力和弯矩，并与教科书公式进行核对。

::: tip 跟着做
在另一个标签页中打开 [run.edubeam.app](https://run.edubeam.app/?lang=cn){target="_blank"}。如果已经加载了一个模型，请使用**清空结构**（应用栏中的垃圾桶图标）从空白开始——勾选*删除材料*和*删除截面*即可彻底清空。
:::

## 问题描述

<ExampleStructure />

一根 6 m 的简支梁（左端固定铰支座，右端可动铰支座）承受 12 kN/m 的均布荷载。材料：钢材，$E = 210\ \text{GPa}$，$G = 81\ \text{GPa}$。截面：IPE 200，$A = 28.5\ \text{cm}^2$，$I_y = 1943\ \text{cm}^4$，$h = 200\ \text{mm}$。

## 1. 检查单位

看一下视图右下角的单位标记（例如 `m · m² · kN · kNm · MPa`）。所有输入框和结果都使用这些单位。默认是米、kN、kNm 和 MPa，本教程也以此为准。如需更改，点击单位标记或打开**设置 → 语言与区域**。

## 2. 添加材料和截面

单元必须先有材料和截面才能存在，所以先创建它们。

1. 打开底部栏的**材料**标签页，点击**添加材料**。
2. 输入 `E = 210000` MPa、`G = 81000` MPa，密度保持默认，`α = 0.000012` 1/K。点击**添加材料**。
   *（也可以点击**材料库**并选择 **Steel (S235)**——它的数值正好与此相同。）*
3. 打开**截面**标签页，点击**添加截面**。
4. 输入 `面积 = 0.00285` m²、`Iy = 1.943e-5` m⁴、`高度 = 0.2` m、`剪切系数 = 1`。点击**添加截面**。

::: details 剪切系数为什么重要？
EduBeam 使用 Timoshenko 梁单元，其中包含剪切变形。`k` 是剪切修正系数（矩形截面 $k \approx 0.83$；若 $A$ 取全截面面积，工字形截面腹板约为 $0.4$–$0.5$）。取 `k = 1` 并使用全截面面积会略微*低估*剪切柔度；对本例这样的细长梁，挠度差异远小于 1 %。公式见[梁单元理论页](/zh/elements/beam)。
:::

## 3. 添加节点

1. 打开**节点**标签页，点击**添加节点**。输入 `X = 0`、`Z = 0` 并确认。该节点的标签为 `1`。
2. 再次点击**添加节点**，输入 `X = 6`、`Z = 0`。这是节点 `2`。

也可以用鼠标放置节点：选择**通过鼠标添加**（或按住 <kbd>Ctrl</kbd> 在画布上右键 → *添加节点*），然后在网格上点击。开启**吸附到网格**（<kbd>S</kbd>）后，点击位置会落在 0.1 m 的整数倍上。

## 4. 用单元连接节点

1. 打开**单元**标签页，点击**添加单元**。
2. 选择**起始节点** `1`、**终止节点** `2`。你刚创建的材料和截面已被预选。确认。

两个节点之间出现一条黑线。按 <kbd>F</kbd> 使其适配屏幕。

## 5. 添加支座

在**节点**标签页中，**受约束自由度**一列为每个节点提供三个复选框：`Dx`、`Dz`、`Ry`。

- 节点 `1`：勾选 **Dx** 和 **Dz** → 出现固定铰支座符号。
- 节点 `2`：仅勾选 **Dz** → 可动铰支座。

在视图中点击节点并选择**节点支座**，也能看到同样的复选框。所有支座类型见[节点与支座](/zh/essentials/nodes-supports)。

## 6. 添加荷载

1. 打开**荷载**标签页，点击**添加单元荷载**。
2. **荷载类型**：*均布荷载*。**单元**：`1`。
3. 输入 `fz = 12` kN/m，`fx` 保持为 `0`。确认。

正的 `fz` 指向 +z 方向，在屏幕上是**向下**的——因此正值就是重力方向的荷载。参见[符号约定](/zh/elements/conventions)。

## 7. 读取结果

荷载一添加，解答立即出现。打开视图设置面板（视图右上角的齿轮按钮）可以开关各个显示图层：

| 图层 | 你应该看到 |
| --- | --- |
| **支反力** | 节点 1 和 2 处各有一个 **36 kN** 的向上箭头。 |
| **V<sub>z</sub> (x)** | 从左端 **+36 kN** 到右端 **−36 kN** 的一条直线，在跨中穿过零点。 |
| **M<sub>y</sub> (x)** | 一条抛物线，极值 **54 kNm** 位于跨中。 |
| **变形图** | 对称的下垂。悬停在节点 `1` 上可读出它的转角：约 **0.0265 rad**。 |

底部栏的**结果**标签页给出具体数值：**节点结果**列出每个节点的 `Dx`、`Dz`、`Ry`，**单元结果**列出每个单元在局部坐标系中的端力。

如果图形看起来太大或太小，请在**设置 → 视图设置 → 尺寸**中拖动**结果缩放**滑块。

## 8. 手算校核

| 物理量 | 公式 | 手算值 | EduBeam |
| --- | --- | --- | --- |
| 支座反力 | $R = qL/2$ | 36 kN | 36 kN |
| 最大剪力 | $V = qL/2$ | 36 kN | 36 kN |
| 最大弯矩 | $M = qL^2/8$ | 54 kNm | 54 kNm |
| 端部转角 | $\varphi = qL^3/(24EI)$ | 0.02647 rad | 0.02647 rad |
| 跨中挠度 | $w = 5qL^4/(384EI)$ | 49.6 mm | 49.6 mm |

全部吻合。更多手算校核方法（悬臂梁、两端固支梁、桁架）见[手算校核](/zh/guide/verification)。

## 9. 动手试验

这正是 EduBeam 的价值所在。逐一尝试下面的操作，观察图形如何更新：

- **向右拖动节点 2**：弯矩随 $L^2$ 增长。
- **勾选节点 1 的 `Ry`** 使其成为固定端：跨中弯矩减小，支座处出现负弯矩。
- 在 *通过鼠标添加* 模式下点击梁上 `X = 3` 处**添加第三个节点**——选择**连接到结构**使梁被拆分——然后勾选它的 `Dz`，得到一根两跨连续梁。
- 在单元标签页中**勾选某个单元的端部铰接**，释放该端的弯矩。
- 按 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 可撤销任意步骤。

## 10. 保存或分享

- **分享模型**（应用栏）生成一个包含整个模型的 URL——可粘贴到电子邮件、聊天或课件中。
- **保存项目**（菜单 ☰，或 <kbd>Ctrl</kbd>+<kbd>S</kbd>）会下载一个 `project.json`，之后可用**打开项目**或把它拖到应用上重新打开。

模型还会保存在浏览器的本地存储中，因此刷新页面不会丢失。参见[导入、导出与分享](/zh/essentials/import-export)。
