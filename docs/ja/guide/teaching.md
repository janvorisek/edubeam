# EduBeam を使った授業

<Edubeam /> は講義室で生まれ、今でもそこで最も力を発揮します。プロジェクターに映したモデルは変更した瞬間に反応し、同じモデルをリンクひとつで学生全員のノートパソコンに届けられます。このページでは、教員がよく使う機能をまとめます。

## 講義で {#in-the-lecture}

- **後ろの席からも見えるようにする。** *設定 → 表示設定*で、**文字サイズ**を 18–20 px に、**支点のサイズ**を 130–150 % に上げます。大きなスクリーンで図が控えめに見える場合は、**結果の表示倍率**も上げましょう。
- **一度にひとつずつ見せる。** 表示オプションで、説明している量以外のチェックをすべて外し、ほかの量を 1 つずつ追加していきます。
- **その場でモデルを変える。** 支点をドラッグする、`Ry` にチェックを入れる、ヒンジを追加する。学生は原因と結果をすぐに目にでき、<kbd>Ctrl</kbd>+<kbd>Z</kbd> でいつでも戻れます。
- **不安定構造の説明はソルバーに任せる。** ヒンジを 1 つ多く解放すると、EduBeam は不安定構造の動きを破線で揺らして見せ、原因となるヒンジを丸で囲みます。安定性について話す絶好の機会です。
- **学生の言語と座標軸に合わせる。** 講義資料に合わせて、インターフェースの言語、SI 単位または米国慣用単位、z 下向きか y 上向きの座標軸を選びましょう。

![不安定構造を可視化：B と C のヒンジによってラーメンが水平に揺れます](/screenshots/ja/ui-mechanism.webp)

## 講義資料や課題で {#in-lecture-notes-and-assignments}

共有リンクにはモデル全体が含まれているので、リンクが使える場所ならどこでも機能します。PDF、スライド、LMS のページ、メールなどです。

1. モデルを作成し、**モデルを共有 → コピー**を押します。
2. リンクを資料に貼り付けます。古いバージョンの EduBeam で作ったリンクも引き続き機能するので、資料は何年たっても有効です。
3. リンクを開いた学生は、自分専用のコピーで自由に試せます。学生が何を変更しても、あなたやほかの学生には影響しません。

便利なリンクの種類：

| リンク | 開くもの |
| --- | --- |
| `https://run.edubeam.app/?model=…` | 編集可能な状態のモデル |
| `https://run.edubeam.app/?viewer=1&model=…` | `<iframe>` への埋め込み用の、[ビューアモード](/ja/essentials/import-export#embed-a-read-only-viewer)のモデル |
| `https://run.edubeam.app/?panel=examples` | 例題ギャラリー |
| `https://run.edubeam.app/?lang=ja` | 日本語版のアプリ（[ほかの言語コード](/ja/essentials/import-export#url-parameters)も使えます） |

::: warning リンクを開くと学生自身のモデルが置き換えられます
それまでのモデルは **☰ → 最近のモデル**に移って復元でき、その旨のメッセージも表示されます。それでも、授業のリンクを開く前に、大事な作業は**プロジェクトを保存**で保存しておくよう学生に伝えてください。
:::

## 学生が自分で確認できる課題 {#assignments-students-can-check-themselves}

EduBeam は、解き方を教えることなく、手計算に対するフィードバックをすぐに学生に返します。

- 反力、断面力、変位 1 つを手計算で求めさせ、そのあとモデルを作って比較させます。[手計算による結果の確認](/ja/guide/verification)に、すぐ使える公式があります。
- 結果が*なぜ*違うのかを問います：せん断変形、ヒンジの付け忘れ、グローバル座標系ではなくローカル座標系で与えた荷重など。
- 計算と一緒に共有リンクや `project.json` を提出させます。開けば、学生が何をモデル化したのかが正確にわかります。
- レポート用には、図を **SVG**（Word や LaTeX でも鮮明）で、結果を **CSV** でエクスポートできます。

## すぐ使える演習 {#ready-made-exercises}

- [例題](/ja/examples/)のページには 6 つのモデルがあり、それぞれに演習の案が付いています。
- [3 ヒンジラーメン](/ja/tutorials/three-hinged-frame)と[平面トラス](/ja/tutorials/truss)のチュートリアルは、手計算による確認まで含めた完全な解説付きの例題です。
- [クイックスタート](/ja/guide/quick-start)は、最初の演習の配布資料として使えます。所要時間は約 10 分です。

## 学生の最初の一歩 {#getting-students-started}

はじめて使う人には、2 つのガイド付きの選択肢があるようこそダイアログが表示されます。**ツアーを見る**（インターフェースの案内）と、**はじめての梁を描く**（マウスを使う 7 ステップのタスク）です。どちらも ☰ メニューにもあります。最初の演習の冒頭で「run.edubeam.app を開いて*はじめての梁を描く*を選んでください」と伝えるだけの教員も多くいます。

## オフラインと演習室のコンピューター {#offline-and-lab-computers}

EduBeam はプログレッシブ Web アプリ（PWA）です。一度読み込んだコンピューターでは、接続がなくても動作し続け、ブラウザがインストールを提案することもあります。モデルと設定はブラウザのプロファイルごとに保存されるので、共用の演習室のコンピューターでは、学生に作業をファイルかリンクとして保存させてください。
