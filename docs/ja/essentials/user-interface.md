# ユーザーインターフェース

<Edubeam /> は 3 つの領域からなります。上部の**アプリバー**、中央で描画を行う**ビューア**、そしてオブジェクトの種類ごとの表がある**下部バー**です。どこに何があるかを知っておけば、ガイドの残りの部分もすっと理解できます。

![インターフェースの各部。番号は下のリストに対応しています](/screenshots/ja/ui-overview.webp)

1. **☰ メニュー**：開く、保存、共有、エクスポート。例題とガイド付きツアー。
2. **アプリバーのボタン**：モデルをクリアとモデルを共有。
3. **元に戻す / やり直し**：モデルへのすべての変更に使えます。
4. **ビューアのボタン**：中央に表示、画面に合わせる、表示オプションの切り替え。
5. **表示オプション**：どの結果とモデルのどの部分を描くか。
6. **グリッド、スナップ、クロスヘア、単位。**
7. **下部バーのタブ**：節点、要素、荷重、材料、断面、結果。
8. 開いているタブの**表**：すべての値を編集できます。

::: tip ツアーを見てみましょう
**☰ → ツアーを見る**では、アプリの中でこれらの部分を 1 つずつ案内します。
:::

![ツアーを見る：表示オプションのステップ](/screenshots/ja/tour.webp)

## アプリバー {#app-bar}

| 操作 | 機能 |
| --- | --- |
| **☰ メニュー** | メインメニュー。下記を参照。 |
| **モデルをクリア** | 確認のあと、すべての節点、要素、荷重を削除します。2 つのチェックボックスで材料と断面も削除できます。<kbd>Ctrl</kbd>+<kbd>Z</kbd> でモデルを元に戻せ、「最近のモデル」にも残ります。 |
| **モデルを共有** | モデル全体を含むリンクの[共有ダイアログ](/ja/essentials/import-export#share-a-link)を開きます。 |
| **更新情報** | リリースノート。アップデート後に一度だけ自動でも開きます。 |
| **ドキュメント** / GitHub | このガイドとソースコード。 |

スマートフォンでは ☰ メニューとドキュメントしか収まらないため、それ以外はすべてメニューの中にあります。

### ☰ メニュー {#the-☰-menu}

![☰ メニュー](/screenshots/ja/ui-app-menu.webp){.shot-xs}

| 項目 | 機能 |
| --- | --- |
| **プロジェクトを開く** / **プロジェクトを保存** | `project.json` ファイルを開く、またはダウンロードします（<kbd>Ctrl</kbd>+<kbd>O</kbd> / <kbd>Ctrl</kbd>+<kbd>S</kbd>）。 |

メニューの下部には、アプリのバージョンとリリース日が表示されます。

## ビューア {#viewer}

キャンバスは、モデルを描いて確認する場所です。アプリのほかの部分はすべて、ここで選択したものに連動します。

### キャンバス上のボタン {#buttons-on-the-canvas}

- **左上：** **元に戻す**と**やり直し**（<kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>）。追加、編集、ドラッグ、削除、クリアなど、モデルへの変更はすべて元に戻せます。
- **右上：** **中央に表示**（<kbd>C</kbd>）、**画面に合わせる**（<kbd>F</kbd>）、そして表示オプションの表示・非表示を切り替える ⚙ ボタン。タッチスクリーンでは**矩形選択**もあります。
- **右下：** **G** でグリッド、**S** でグリッドへのスナップを切り替えます。クロスヘアのボタンはポインターの位置を定規に表示し、**単位チップ**は*言語と地域*のページで設定を開きます。

### 表示オプション {#display-options}

![ビューアのボタンと表示オプション](/screenshots/ja/ui-display-settings.webp){.shot-lg}

チェックボックスが 2 列あり、初期状態で開いています。

- **結果：** *変形図*、*N (x)*、*V<sub>z</sub> (x)*、*M<sub>y</sub> (x)*、*反力*。変形図、M、反力は初期状態でチェックが入っています。
- **モデル：** *支点*、*荷重*、*節点ラベル*、*要素ラベル*。

**その他の設定**を押すと、すべての[設定](/ja/essentials/units-settings)が*表示設定*のページで開きます。

### 画面操作 {#navigating}

| 操作 | マウス | タッチ |
| --- | --- | --- |
| ズーム | マウスホイール（カーソルに向かって）、<kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | ピンチ |
| パン | **中ボタンまたは右ボタン**でドラッグ（*設定 → 操作とショートカット*を参照） | 1 本指でドラッグ |
| 画面に合わせる / 中央に表示 | <kbd>F</kbd> / <kbd>C</kbd> または右上のボタン | 右上のボタン |

### 選択と編集 {#selecting-and-editing}

節点、要素、荷重、寸法線を**クリック**すると選択されます。その横にパネルが開き、詳細と、荷重の追加、支点の設定、編集、剛性マトリクスの表示、削除など、その対象に合った操作が表示されます。節点をクリックすると、下部バーも節点タブに切り替わります。

<div class="shots">

![節点：荷重の追加、支点の設定、強制変位の設定](/screenshots/ja/ui-node-menu.webp)

![要素：編集、荷重の追加、剛性マトリクス](/screenshots/ja/ui-element-menu.webp)

</div>

- **キャンバスの何もない所をドラッグ**すると、選択範囲の矩形を描けます。その中にある節点、要素、それらの荷重と寸法線がすべて選択されます。<kbd>Delete</kbd> でまとめて削除、<kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd> で別の場所にコピーできます。
- **節点をドラッグ**すると移動できます。スナップがオンならグリッド上に置かれます。接続された要素とその荷重も一緒に動きます。
- **荷重をダブルクリック**すると編集できます。
- 何にでも**マウスを重ねる**とツールチップが表示されます。節点は変位と回転角、要素は材料と断面、荷重はその値を表示します。タッチスクリーンではタップしてください。同じ詳細が選択パネルに表示されます。

![節点にマウスを重ねると、変位と回転角が表示されます](/screenshots/ja/ui-hover.webp){.shot-sm}

**キャンバスを右クリック**（タッチスクリーンでは長押し）すると、キャンバスのメニューが開きます。*節点を追加*や*要素を追加*を選ぶときに <kbd>Ctrl</kbd> を押したままにすると、ダイアログではなくマウスで配置できます。要素の上では、メニューに*要素の寸法線*も表示されます。

![キャンバスのメニュー](/screenshots/ja/ui-canvas-menu.webp){.shot-sm}

ショートカットの一覧は[キーボード・マウス・タッチ](/ja/reference/shortcuts)のページにあります。

### モデルを解析できないとき {#when-the-model-cannot-be-solved}

ビューアの左上にメッセージが表示されます。

- *材料が定義されていません* / *断面が定義されていません*：**新規追加**ボタン付き。
- モデルが単に未完成のうちは、小さな青い**支点が必要**チップ。
- 何かがおかしいときは**赤いメッセージ**。**詳細を表示**で問題がすべて一覧表示されます。

構造物がまだ動ける場合、EduBeam はその動きを破線で揺らして見せ、原因となる節点やヒンジを丸で囲みます。メッセージにマウスを重ねると動きをもう一度表示でき、目のボタンで非表示にできます。

![B と C にヒンジがあるラーメンは不安定構造：EduBeam がその動き方を示します](/screenshots/ja/ui-mechanism.webp)

![詳細を表示：問題ごとにヒント付きで一覧表示されます](/screenshots/ja/ui-diagnostics.webp){.shot-lg}

各メッセージの意味は[トラブルシューティング](/ja/reference/troubleshooting)で説明しています。

## 下部バー {#bottom-bar}

6 つのタブがあり、それぞれにツールバーと編集可能な表があります。タブには、モデル内のその種類のオブジェクトの数が表示されます。右側の **?** は開いているタブを説明し、一部の列見出しの横にある **?** もその列を説明します。タブの列を上下にドラッグするとバーの高さを変えられ、右側のボタンで最小化できます。

| タブ | ツールバー | 表 |
| --- | --- | --- |
| **節点** | 節点を追加（ダイアログ）、節点を追加（マウス） | ラベル、座標、**拘束自由度**（支点記号、Dx、Dz、Ry、支点の角度 α）、荷重、編集、削除 |
| **要素** | 要素を追加（ダイアログ）、要素を追加（マウス） | ラベル、種類、節点（入れ替えボタン付き）、材料、断面、**材端ヒンジ**、荷重、剛性マトリクス、削除 |
| **荷重** | 節点荷重を追加、要素荷重を追加 | 種類、対象、編集可能な成分、編集、削除 |
| **材料** | 材料を追加、材料ライブラリ | ラベル、E、G、α<sub>T</sub>、削除 |
| **断面** | 断面を追加、断面ライブラリ、多角形断面 | 形状、ラベル、A、I<sub>y</sub>、h、k、形状の編集、削除 |
| **結果** | 節点結果、要素結果、CSV をエクスポート、コピー | 節点ごとの変位と回転角、または要素ごとの材端力 |

セルはその場で編集できます。クリックして入力し、<kbd>Enter</kbd> を押します（<kbd>Esc</kbd> でセルを離れます）。値は[現在の単位](/ja/essentials/units-settings)で表示・入力されます。

## ビューアの上のタブ {#tabs-above-the-viewer}

**ビューア**はキャンバスを表示します。**設定**は設定を全画面で表示するので、色や単位を変えてからビューアに戻り、効果を確かめられます。単位チップと*その他の設定*は、同じ設定をモデルの上にダイアログとして開きます。

## フローティングウィンドウ {#floating-windows}

**剛性マトリクス**（要素のパネルまたは要素の表から開きます）は、グローバル座標系での要素の 6 × 6 剛性マトリクスをウィンドウに表示します。キャンバスのメニューの**編集**は、現在の選択内容の表を開きます。ウィンドウはタイトルバーをドラッグして移動し、× で閉じます。
