# Tastiera, mouse e touch

Le scorciatoie da tastiera funzionano quando la vista ha il focus. Vengono ignorate mentre scrivi in una cella di tabella o in una finestra di dialogo; fai prima clic nell'area di disegno.

## Tastiera {#keyboard}

| Scorciatoia | Azione |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Annulla |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Ripeti |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Salva progetto (scarica il JSON) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Apri progetto |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Esporta immagine |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Seleziona tutto |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copia la selezione (nodi, elementi e i loro carichi) |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Incolla: un'ombra della copia segue il cursore; fai clic per posizionarla, oppure digita uno spostamento Δx, Δz nel banner e premi **Incolla** |
| <kbd>Delete</kbd> | Elimina la selezione |
| <kbd>Esc</kbd> | Annulla la modalità mouse corrente, chiude il tour, svuota la selezione o esce da una cella di tabella |
| <kbd>Enter</kbd> | Conferma una cella di tabella |
| <kbd>F</kbd> | Adatta allo schermo |
| <kbd>C</kbd> | Centra il modello |
| <kbd>G</kbd> | Mostra/nascondi la griglia |
| <kbd>S</kbd> | Attiva/disattiva lo snap alla griglia |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Zoom avanti / indietro |

Su un Mac, usa <kbd>Cmd</kbd> dove è indicato <kbd>Ctrl</kbd>.

## Mouse {#mouse}

| Azione | Risultato |
| --- | --- |
| Clic | Seleziona un nodo, un elemento, un carico o una quota e ne apre il pannello |
| Trascinamento su un'area vuota | Rettangolo di selezione |
| Trascinamento di un nodo | Sposta il nodo (si aggancia alla griglia quando lo snap è attivo) |
| Clic in modalità mouse | Posiziona un nodo, oppure inizia o prosegue una polilinea di elementi |
| Doppio clic su un carico | Modifica il carico |
| Clic destro | Menu dell'area di disegno: Aggiungi nodo, Aggiungi elemento, Aggiungi quota, Quota l'elemento (sopra un elemento), Modifica, Copia, Incolla, Elimina |
| <kbd>Ctrl</kbd> (<kbd>Cmd</kbd> su Mac) + Aggiungi nodo / Aggiungi elemento nel menu dell'area di disegno | Posiziona con il mouse invece che da una finestra |
| Trascinamento con il tasto centrale o destro | Sposta la vista (vedi *Impostazioni → Comandi e scorciatoie*) |
| Rotellina | Zoom verso il cursore |
| Puntare un oggetto | Tooltip con spostamenti, proprietà o valori del carico |

Sul trackpad, lo scorrimento con due dita fa lo zoom. Per spostare la vista, fai clic e trascina con due dita (equivale a trascinare con il tasto destro).

## Touch {#touch}

| Gesto | Risultato |
| --- | --- |
| Tocco | Seleziona e mostra i dettagli e le azioni dell'oggetto |
| Tocco in modalità mouse | Posiziona un nodo o prosegue un elemento |
| Premi un nodo e trascina | Sposta il nodo |
| Trascinamento con un dito altrove | Sposta la vista |
| Avvicinare o allontanare due dita | Zoom |
| Tieni premuto nell'area di disegno | Menu dell'area di disegno |
| Pulsante **Selezione con riquadro** (in alto a destra), poi trascina | Rettangolo di selezione |

## Pannelli degli oggetti {#object-panels}

Il clic su un oggetto apre accanto a esso un pannello con i suoi dettagli e queste azioni:

| Oggetto | Azioni |
| --- | --- |
| Nodo | Aggiungi carico · Vincoli del nodo (simbolo del vincolo, Dx / Dz / Ry, angolo LCS nodale) · Imponi spostamento (su un nodo vincolato) · Elimina |
| Elemento | Modifica elemento (nodi e cerniere, materiale, sezione) · Aggiungi carico · Matrice di rigidezza · Elimina |
| Carico nodale o su elemento | Modifica carico · Elimina |
| Quota | Modifica (coordinate) · Inverti quota · Elimina |
