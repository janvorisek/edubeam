## โจทย์ {#the-problem}

![รูปทรง จุดรองรับ และแรงกระทำ](/screenshots/th/tut-truss-model.webp)

- ช่วงยาว 12 m แบ่งเป็นสามช่อง ช่องละ 4 m ลึก 3 m
- โหนดของคอร์ดล่าง 1–4 โหนดของคอร์ดบน 5 และ 6
- จุดรองรับแบบหมุดที่โหนด 1 และแบบล้อเลื่อนที่โหนด 4
- แรงกระทำ 30 kN สองแรงที่โหนด 2 และ 3 ของคอร์ดล่าง
- ชิ้นส่วนเหล็กมี $A = 20$ cm²

| โหนด | X [m] | Z [m] | จุดรองรับ | แรงกระทำ |
| --- | --- | --- | --- | --- |
| 1 | 0 | 0 | หมุด | |
| 2 | 4 | 0 | | `Fz = 30` kN |
| 3 | 8 | 0 | | `Fz = 30` kN |
| 4 | 12 | 0 | ล้อเลื่อน | |
| 5 | 4 | −3 | | |
| 6 | 8 | −3 | | |

ชิ้นส่วน: คอร์ดล่าง 1–2, 2–3, 3–4 คอร์ดบน 5–6 ชิ้นส่วนทแยงที่ปลาย 1–5 และ 6–4 ชิ้นส่วนแนวดิ่ง 2–5 และ 3–6 และชิ้นส่วนทแยงตรงกลาง 5–3

**เป็นดีเทอร์มิเนทหรือไม่?** $m + r = 9 + 3 = 12 = 2j$ เมื่อมีจุดต่อ $j = 6$ จุด จึงเป็นดีเทอร์มิเนท: แรงในชิ้นส่วนหาได้จากสมการสมดุลเพียงอย่างเดียว

## 1. วัสดุและหน้าตัด {#_1-material-and-section}

1. **ลบ Mesh** (ติ๊ก *ลบวัสดุ* และ *ลบหน้าตัด*)
2. *วัสดุ* → **ไลบรารีวัสดุ** → **Steel (S235)**
3. *หน้าตัด* → **เพิ่มหน้าตัด**: `พื้นที่ = 0.002`, `Iy = 1e-6`, `ความสูง = 0.1`, `สัมประสิทธิ์เฉือน = 1` สำหรับชิ้นส่วนที่มีจุดหมุนทั้งสองปลาย มีเพียงพื้นที่หน้าตัดเท่านั้นที่มีผล

## 2. วาดชิ้นส่วนพร้อมจุดหมุน {#_2-draw-the-bars-with-hinges}

ชิ้นส่วนโครงถักใน EduBeam คือองค์ประกอบคานที่ติ๊ก **จุดหมุนทั้งสองปลาย** เครื่องมือเมาส์ตั้งค่านี้ให้ได้:

1. แท็บ *องค์ประกอบ* → ปุ่ม **เพิ่มองค์ประกอบ** ปุ่มที่สอง (ไอคอนเคอร์เซอร์)
2. ในแถบประกาศที่ด้านบนของหน้าจอแสดงผล ติ๊ก **จุดหมุนที่จุดเริ่มต้น** และ **จุดหมุนที่จุดปลาย** ทุกชิ้นส่วนที่วาดจากนี้จะมีจุดหมุนทั้งสองปลาย
3. วาดเส้นรอบนอกเป็นเส้นต่อเนื่องเส้นเดียว: คลิก (0, 0), (4, −3), (8, −3), (12, 0) แล้วย้อนกลับตามคอร์ดล่าง: (8, 0), (4, 0), (0, 0) กด <kbd>Esc</kbd>
4. วาดชิ้นส่วนภายในทีละชิ้น กด <kbd>Esc</kbd> หลังวาดแต่ละชิ้น: (4, 0) → (4, −3), (4, −3) → (8, 0), (8, 0) → (8, −3)
5. กด <kbd>F</kbd> เพื่อปรับให้พอดีหน้าจอ

ตรวจสอบตาราง *องค์ประกอบ*: ต้องมีเก้าองค์ประกอบ แต่ละองค์ประกอบติ๊ก *ข้อต่ออิสระปลาย* ทั้งสองช่อง หมายเลขโหนดและองค์ประกอบของคุณอาจต่างจากรูป ซึ่งไม่เป็นปัญหา

## 3. จุดรองรับและแรงกระทำ {#_3-supports-and-loads}

1. คลิกโหนดที่ (0, 0) → **การรองรับโหนด** → **หมุด** คลิกโหนดที่ (12, 0) → **ล้อเลื่อน**
2. คลิกโหนดที่ (4, 0) → **เพิ่มแรงกระทำ** → `Fz = 30` kN ทำเช่นเดียวกันที่ (8, 0)

`Fz` ที่เป็นบวกชี้ลง จุดต่อของโครงถักหมุนได้อิสระ EduBeam ยอมรับโหนดที่ทุกชิ้นส่วนต่อแบบจุดหมุน และรายงานมุมหมุนของโหนดเหล่านั้นเป็น 0

## 4. ผลลัพธ์ {#_4-results}

ในตัวเลือกการแสดงผล ยกเลิกการติ๊ก **รูปร่างที่เสียรูป** และ **M<sub>y</sub> (x)** (โครงถักไม่มีการดัด) แล้วติ๊ก **N (x)**

## 5. ตรวจสอบด้วยการคำนวณมือ {#_5-check-by-hand}

**แรงปฏิกิริยา** แรงกระทำสมมาตร ดังนั้น $R_1 = R_4 = 30$ kN ทิศขึ้น และแรงปฏิกิริยาแนวนอนที่หมุดเป็นศูนย์

**จุดต่อ 1** (วิธีจุดต่อ) ชิ้นส่วนทแยงที่ปลาย 1–5 ยาว 5 m ($\sin\alpha = 3/5$, $\cos\alpha = 4/5$):

$$\sum F_z:\ N_{15} \cdot \tfrac{3}{5} = -30 \Rightarrow N_{15} = -50\ \text{kN} \qquad \sum F_x:\ N_{12} = -N_{15} \cdot \tfrac{4}{5} = 40\ \text{kN}$$

**จุดต่อ 2** ชิ้นส่วนแนวดิ่ง 2–5 เป็นชิ้นส่วนเดียวที่ส่งแรง 30 kN ขึ้นไปได้: $N_{25} = +30$ kN และ $N_{23} = N_{12} = 40$ kN

**ตัดหน้าตัดผ่านช่องกลาง** ตัดชิ้นส่วน 5–6, 5–3 และ 2–3 แล้วพิจารณาส่วนซ้าย:

- โมเมนต์รอบโหนด 3: $R_1 \cdot 8 - 30 \cdot 4 + N_{56} \cdot 3 = 0 \Rightarrow N_{56} = -40$ kN
- แรงแนวดิ่ง: แรงเฉือนในช่องคือ $R_1 - 30 = 0$ ชิ้นส่วนทแยง **5–3 จึงไม่รับแรงเลย**: $N_{53} = 0$

| ชิ้นส่วน | ค่าจากการคำนวณมือ | EduBeam |
| --- | --- | --- |
| คอร์ดล่าง 1–2, 2–3, 3–4 | +40 kN (แรงดึง) | 40 |
| คอร์ดบน 5–6 | −40 kN (แรงอัด) | −40 |
| ชิ้นส่วนทแยงที่ปลาย 1–5, 6–4 | −50 kN | −50 |
| ชิ้นส่วนแนวดิ่ง 2–5, 3–6 | +30 kN | 30 |
| ชิ้นส่วนทแยงตรงกลาง 5–3 | 0 | 0 |

การโก่งตัวของโหนด 2 คือ 2.29 mm (*ผลลัพธ์ → ผลลัพธ์ที่โหนด*) ลองคำนวณด้วยงานเสมือน $\delta = \sum N n L / (EA)$ เป็นแบบฝึกหัด

## 6. ทดลอง {#_6-experiment}

- **ย้ายแรงหนึ่งแรง** วางแรง 30 kN ทั้งสองแรงที่โหนด 2 ตอนนี้ชิ้นส่วนทแยงตรงกลางรับแรงแล้ว: เครื่องหมายอะไร และทำไม?
- **ลบชิ้นส่วนทแยงตรงกลาง** โครงถักจะกลายเป็นกลไก EduBeam จะวงจุดหมุนที่เป็นต้นเหตุ และแสดงว่าช่องนั้นเฉือนตัวอย่างไร
- **ยกเลิกการติ๊กจุดหมุนทั้งหมด** โครงถักจะกลายเป็นโครงข้อแข็งที่มีจุดต่อแบบแข็งเกร็ง ติ๊ก **M<sub>y</sub> (x)**: โมเมนต์ดัดเล็กมากเมื่อเทียบกับแรงตามแนวแกน นี่คือเหตุผลที่สมมติฐานจุดต่อแบบหมุดใช้ได้
- **ใช้หมุดที่จุดรองรับทั้งสองข้าง** แรงปฏิกิริยาที่เพิ่มขึ้นหนึ่งค่าทำให้เป็นอินดีเทอร์มิเนท และแรงในคอร์ดล่างจะขึ้นกับพื้นที่หน้าตัดของชิ้นส่วน
