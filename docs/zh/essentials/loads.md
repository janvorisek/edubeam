## 一句话说明符号约定 {#sign-convention-in-one-line}

整体坐标 **x** 指向右，整体坐标 **z** 指向**下**。因此正的 `Fz` 或 `fz` 是向下的重力型荷载，正的力矩 `My` 在屏幕上为逆时针。详见[坐标系与符号约定](/zh/elements/conventions)。使用 [y 向上的坐标轴](/zh/elements/conventions#y-up-axes)时，竖向分量的名称和符号会反转：重力是负的 `Fy`。

## 节点荷载 {#nodal-loads}

*荷载*标签页 → **添加节点荷载**，或点击节点 → **添加荷载**。选择**力/力矩**：

| 字段 | 含义 | 单位 |
| --- | --- | --- |
| `Fx` | 水平力（向右为正） | 力的单位 |
| `Fz` | 竖向力（向下为正） | 力的单位 |
| `My` | 绕 y 的力矩（逆时针为正） | 弯矩单位 |

![添加节点荷载。输入时预览会显示方向。](/screenshots/zh/loads-nodal.webp){.shot-md}

分量始终在**整体**坐标系中。一个节点可以承受多个节点荷载；它们相互叠加，并叠放显示。

### 位移约束（支座沉降） {#prescribed-displacements-support-settlements}

在同一对话框中选择**位移约束**，或点击有支座的节点 → **施加位移约束**。字段变为：

| 字段 | 含义 | 单位 |
| --- | --- | --- |
| `Dx` | 施加的水平位移 | 位移单位 |
| `Dz` | 施加的竖向位移（向下为正） | 位移单位 |
| `Ry` | 施加的转角 | rad |

只能为该节点上**受约束**的自由度输入数值，因为只有支座才能被移动。每个节点最多只有一个位移约束；请编辑它，而不是再添加一个。在静定结构中，沉降只产生位移而不产生内力；在超静定结构中两者都会产生。

## 单元荷载 {#element-loads}

*荷载*标签页 → **添加单元荷载**，或点击单元 → **添加荷载**。选择**荷载类型**；输入时对话框会实时预览荷载在单元上的样子。

### 均布荷载 {#uniformly-distributed-load}

| 字段 | 含义 | 单位 |
| --- | --- | --- |
| `fx` | 沿 x 的单位长度荷载 | 力 / 长度 |
| `fz` | 沿 z 的单位长度荷载 | 力 / 长度 |
| **LCS** | 勾选：`fx`、`fz` 沿单元局部坐标轴作用；不勾选：沿整体坐标轴作用 | – |

**LCS**（局部坐标系）默认勾选。对于从左向右画的水平单元，局部坐标轴与整体坐标轴相同，因此勾选与否没有区别。对于倾斜杆件则有区别：

- **垂直于杆件**的荷载（作用在斜梁上的风荷载）是**勾选** LCS 的 `fz`；
- 按杆件长度每米计的**竖向**荷载（自重）是**不勾选** LCS 的 `fz`；
- 按*水平*投影每米计的竖向荷载（雪荷载）无法直接输入。请先将其乘以 $\cos\alpha$（$\alpha$ 为杆件倾角），再作为竖向荷载输入。

### 梯形分布荷载 {#trapezoidal-load}

| 字段 | 含义 |
| --- | --- |
| `f1x`、`f1z` | **起始**节点处的集度 |
| `f2x`、`f2z` | **终止**节点处的集度 |

集度从单元起点到终点线性变化。三角形荷载即 `f1z = 0`。梯形分布荷载始终沿**单元局部坐标轴**作用（LCS 复选框被锁定）；对于水平单元，这与整体坐标相同。

### 集中荷载 {#concentrated-load}

作用在单元**沿长度方向**任意位置的集中力或力矩，无需额外节点。

| 字段 | 含义 |
| --- | --- |
| `Fx`、`Fz`、`My` | 力和力矩分量 |
| **距起始节点的荷载位置** | 距起始节点的距离，`0 ≤ a ≤ L` |
| **LCS** | 分量沿局部坐标轴 |

剪力图在荷载处突变 `Fz`，弯矩图在该处出现折点；该点的弯矩值会自动标注。集中的 `My` 则使弯矩图发生突变。

### 温度荷载 {#temperature-load}

| 字段 | 含义 |
| --- | --- |
| **ΔT<sub>c</sub>**，轴向温度变化 | 整个截面的均匀温度变化，产生伸长 $\alpha\,\Delta T_c\,L$ |
| **ΔT<sub>b</sub> − ΔT<sub>t</sub>**，温差 | 下缘纤维减上缘纤维，产生曲率 $\alpha\,(\Delta T_b - \Delta T_t)/h$ |

温度荷载使用材料的 **α** 和截面的**高度 h**。正的 `ΔTb − ΔTt`（下缘更热）使下缘纤维伸长，因此单元会像承受重力荷载的梁一样向下弯曲。在静定结构中，温度只产生位移；约束（固定端、连续性、多余杆件）会把它转化为内力。

## 编辑与删除荷载 {#editing-and-removing-loads}

- 每个荷载都是*荷载*标签页中的一行，可以在其中直接编辑分量和 LCS 标记。荷载也会以标记的形式出现在*节点*和*单元*表格中。
- 在视图中**双击**荷载，或点击它并选择**编辑荷载**，即可打开编辑对话框。
- 选中荷载并按 <kbd>Delete</kbd>，或使用表格中的 ×。
- 附着在节点或单元上的荷载会随之一起删除，复制粘贴时也会随之一起复制。

![荷载标签页：每个荷载一行，其分量可直接编辑](/screenshots/zh/loads-table.webp)

## 暂不支持的功能 {#what-is-not-available}

- **荷载工况和荷载组合。** 只有一个荷载工况。
- **自重。** 以不勾选 LCS 的均布荷载输入：$f_z = \rho\,g\,A$。对于 IPE 200，7850 × 9.81 × 0.00285 ≈ 0.22 kN/m。
- 倾斜杆件上**整体坐标系中的梯形分布荷载**。
