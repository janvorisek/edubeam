# คำถามที่พบบ่อย

## ทั่วไป {#general}

### EduBeam คืออะไร? {#what-is-edubeam}

โปรแกรมคำนวณคาน โครงข้อแข็ง และโครงถัก 2 มิติแบบโอเพนซอร์สที่ใช้ฟรีบนเบราว์เซอร์ สำหรับนักศึกษา ผู้สอน และวิศวกรที่ต้องการผลตอบกลับทันที ดู [บทนำ](/th/guide/introduction)

### ฟรีจริงไหม? ต้องมีบัญชีหรือเปล่า? {#is-it-really-free-do-i-need-an-account}

ฟรีจริง และไม่ต้องมีบัญชี เปิด [run.edubeam.app](https://run.edubeam.app/?lang=th) แล้วเริ่มสร้างโมเดลได้เลย ไม่มีบัญชี ไม่มีตัวติดตั้ง และไม่จำกัดการใช้งาน ซอร์สโค้ดอยู่บน [GitHub](https://github.com/janvorisek/edubeam)

### ใช้กับเบราว์เซอร์และอุปกรณ์ใดได้บ้าง? {#which-browsers-and-devices-work}

Chrome, Edge, Firefox หรือ Safari เวอร์ชันปัจจุบันทุกตัว แท็บเล็ตและโทรศัพท์ก็ใช้ได้: แตะเพื่อเลือกหรือวาง ลากโหนดเพื่อย้าย ลากที่อื่นเพื่อเลื่อนมุมมอง จีบนิ้วเพื่อซูม และกดค้างเพื่อเปิดเมนูพื้นที่วาด แต่เมาส์และแป้นพิมพ์ยังช่วยให้สร้างโมเดลได้เร็วกว่า ดู [แป้นพิมพ์ เมาส์ และระบบสัมผัส](/th/reference/shortcuts#touch)

### โมเดลหาย กู้คืนได้ไหม? {#i-lost-my-model-can-i-get-it-back}

น่าจะได้ การลบโมเดล หรือการเปิดลิงก์ ไฟล์ หรือตัวอย่างทับโมเดลเดิม จะเก็บโมเดลเดิมไว้ใน **☰ → โครงสร้างล่าสุด** (10 รายการล่าสุด) และ <kbd>Ctrl</kbd>+<kbd>Z</kbd> ยกเลิกการแทนที่ได้ ทั้งสองอย่างอยู่ในเบราว์เซอร์ของคุณเท่านั้น

### ใช้แบบออฟไลน์ได้ไหม? {#can-i-use-it-offline}

ได้ EduBeam เป็น progressive web app: เมื่อโหลดแล้วจะใช้งานต่อได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต และเบราว์เซอร์อาจเสนอให้ติดตั้ง เมื่อมีเวอร์ชันใหม่ จะมีกล่องโต้ตอบถามก่อนอัปเดต

### ข้อมูลของฉันเก็บไว้ที่ไหน? {#where-is-my-data-stored}

ในเบราว์เซอร์ของคุณเท่านั้น โมเดลไม่เคยถูกส่งไปยังเซิร์ฟเวอร์ ลิงก์แชร์ *คือ* ตัวโมเดลเอง ดู [นำเข้า ส่งออก และแชร์](/th/essentials/import-export)

## การสร้างโมเดล {#modelling}

### จะสร้างจุดรองรับแบบยึดแน่น / หมุด / ล้อเลื่อนอย่างไร? {#how-do-i-make-a-fixed-pinned-roller-support}

คลิกโหนด เปิด **จุดรองรับของโหนด** แล้วเลือกสัญลักษณ์: หมุด ล้อเลื่อน ยึดแน่น แบบเลื่อน และอื่น ๆ หรือติ๊ก DOF: **Dx + Dz + Ry** = ยึดแน่น **Dx + Dz** = หมุด **Dz** = ล้อเลื่อน ทุกรูปแบบอยู่ใน [โหนดและจุดรองรับ](/th/essentials/nodes-supports#supports)

### จะสร้างโครงถักอย่างไร? {#how-do-i-make-a-truss}

ใช้เอลิเมนต์คานแล้วติ๊ก **จุดหมุนที่ปลาย** ทั้งสองช่อง ของทุกชิ้นส่วนในแท็บ *เอลิเมนต์* หรือติ๊ก *จุดหมุนที่จุดเริ่มต้น* และ *จุดหมุนที่จุดปลาย* ในแถบประกาศก่อนวาดชิ้นส่วนด้วยเมาส์ ใส่แรงกระทำที่จุดต่อ [บทเรียนโครงถัก](/th/tutorials/truss) พาทำทีละขั้น

### จะใส่จุดหมุนในโครงข้อแข็งอย่างไร? {#how-do-i-put-a-hinge-in-a-frame}

ติ๊ก **จุดหมุนที่จุดปลาย** ของเอลิเมนต์ที่อยู่ด้านของจุดต่อที่ต้องการปลดโมเมนต์ การใส่จุดหมุนให้ *เอลิเมนต์เดียว* ที่จุดต่อจะปลดเฉพาะเอลิเมนต์นั้น

### จะเพิ่มจุดรองรับหรือแรงกระทำเป็นจุดตรงกลางคานอย่างไร? {#how-do-i-add-a-support-or-a-point-load-in-the-middle-of-a-beam}

เพิ่มโหนดบนคานด้วย *เพิ่มด้วยเมาส์* แล้วเลือก **เชื่อมต่อกับโครงสร้าง** คานจะถูกแบ่งเป็นสองส่วน ถ้าต้องการแค่แรงกระทำเป็นจุด ไม่ต้องเพิ่มโหนดเลย: ใช้แรงกระทำบนเอลิเมนต์แบบ **แรงกระทำเป็นจุด** พร้อมระบุตำแหน่ง

### ใส่น้ำหนักตัวเองได้ไหม? {#can-i-apply-self-weight}

ไม่ได้แบบอัตโนมัติ ให้ใส่เป็นแรงแผ่กระจายสม่ำเสมอ $f_z = \rho g A$

### สร้างจุดรองรับแบบเอียงได้ไหม? {#can-i-model-inclined-supports}

ได้ ให้กำหนด **มุมระบบพิกัดท้องถิ่นของโหนด** ที่โหนด แล้ว DOF ของโหนดจะถูกตีความในระบบที่หมุนแล้ว

### มีกรณีแรงกระทำหรือการจัดหมู่แรงกระทำไหม? {#are-there-load-cases-or-combinations}

ไม่มี มีเพียงกรณีแรงกระทำเดียว ให้สร้างโมเดลแต่ละกรณีแยกกันแล้วบันทึกหรือแชร์

### ทำไมแรงกระทำของฉันชี้ขึ้น? {#why-do-my-loads-point-up}

เพราะแกนรวม z ชี้ **ลง**: `Fz` ที่เป็นบวกมีทิศลง ดู [ข้อตกลง](/th/elements/conventions) ถ้าต้องการให้แกนดิ่งชี้ขึ้น ให้สลับไปใช้แกน y ชี้ขึ้นใน *การตั้งค่า → ภาษาและภูมิภาค → ระบบพิกัด*

## ผลลัพธ์ {#results}

### ทำไมไม่มีปุ่ม "คำนวณ"? {#why-is-there-no-solve-button}

โมเดลถูกคำนวณอัตโนมัติหลังทุกการเปลี่ยนแปลง ถ้าไม่มีผลลัพธ์แสดง แสดงว่ายังคำนวณโมเดลไม่ได้ [การแก้ปัญหา](/th/reference/troubleshooting) มีรายการสิ่งที่ต้องตรวจสอบ

### ทำไมการโก่งตัวต่างจากสูตรเล็กน้อย? {#why-does-my-deflection-differ-slightly-from-the-formula}

EduBeam ใช้คาน Timoshenko การโก่งตัวจึงรวมการเสียรูปเนื่องจากแรงเฉือน สำหรับชิ้นส่วนชะลูด ความต่างน้อยกว่า 1 % มาก รายละเอียดและการเปรียบเทียบพร้อมตัวอย่างอยู่ใน [ตรวจสอบผลลัพธ์ด้วยการคำนวณมือ](/th/guide/verification)

### ผลลัพธ์แม่นยำแค่ไหน? ต้องใช้เอลิเมนต์มากขึ้นไหม? {#how-accurate-are-the-results-do-i-need-more-elements}

สำหรับการวิเคราะห์สถิตเชิงเส้น เอลิเมนต์คานให้ผลแม่นตรงภายใต้แรงกระทำทุกประเภทที่รองรับ ชิ้นส่วนหนึ่งชิ้นจึงใช้เอลิเมนต์เดียวก็พอ ต้องเพิ่มโหนดเฉพาะที่ที่ต้องการจุดรองรับ จุดหมุน การเปลี่ยนหน้าตัด หรือโหนดสำหรับใส่แรงกระทำ

### แรงปฏิกิริยาแสดงอยู่ที่ไหน? {#where-are-the-reactions-listed}

บนหน้าจอแสดงผลเป็นลูกศรพร้อมค่า (**แรงปฏิกิริยา** ในตัวเลือกการแสดงผล เปิดเป็นค่าเริ่มต้น) และยังอยู่ในไฟล์จาก **ผลลัพธ์ → ส่งออก CSV** และใน **คัดลอก** ด้วย การกระจัดที่โหนดและแรงปลายของเอลิเมนต์อยู่ในแท็บ **ผลลัพธ์**

## ไฟล์และการแชร์ {#files-sharing}

### จะแชร์โมเดลอย่างไร? {#how-do-i-share-a-model}

**แชร์โมเดล** → **คัดลอก** ลิงก์บรรจุทั้งโมเดล ผู้รับจะได้สำเนาที่แก้ไขได้ของตัวเอง ไม่มีการทำงานร่วมกันแบบเรียลไทม์ ดูเพิ่มเติมที่ [สอนด้วย EduBeam](/th/guide/teaching)

### ฝังโมเดลในเว็บไซต์หรือสไลด์ได้ไหม? {#can-i-embed-a-model-on-my-website-or-in-slides}

ได้ เพิ่ม `&viewer=1` ต่อท้ายลิงก์แชร์แล้วใส่ใน `<iframe>` ดู [ฝังโปรแกรมดู](/th/essentials/import-export#embed-a-read-only-viewer)

### ส่งออกรูปภาพหรือตารางได้ไหม? {#can-i-export-images-or-tables}

ได้ **☰ → ส่งออกรูปภาพ** (<kbd>Ctrl</kbd>+<kbd>P</kbd>) บันทึกภาพวาดเป็น PNG หรือ SVG ตามขนาดหรือมาตราส่วนที่เลือก **ผลลัพธ์ → ส่งออก CSV** บันทึกตารางผลลัพธ์ทั้งสองตาราง และ **คัดลอก** วางลงคลิปบอร์ดสำหรับสเปรดชีต ดู [นำเข้า ส่งออก และแชร์](/th/essentials/import-export#export-an-image)

### สร้างโมเดลด้วยโปรแกรมได้ไหม? {#can-i-generate-models-programmatically}

ได้ ไฟล์โปรเจกต์เป็น JSON ธรรมดาในหน่วย SI (ดู [คำอธิบายรูปแบบไฟล์](/th/essentials/import-export#project-file-format)) และเปิดได้ด้วย *เปิดโปรเจกต์* หรือลากไฟล์มาวาง

### จะรายงานบั๊กหรือขอฟีเจอร์ใหม่อย่างไร? {#how-do-i-report-a-bug-or-request-a-feature}

เปิด issue บน [GitHub](https://github.com/janvorisek/edubeam/issues) และแนบลิงก์แชร์หรือไฟล์โปรเจกต์ที่ทำให้เกิดปัญหาซ้ำได้ ความช่วยเหลือแบบส่วนตัว: [support@edubeam.app](mailto:support@edubeam.app)
