# Teclado e mouse

Os atalhos de teclado funcionam enquanto a visualização tem o foco — são ignorados enquanto você digita em uma célula de tabela ou em um diálogo.

## Teclado

| Atalho | Ação |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Desfazer |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Refazer |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Salvar projeto (baixar JSON) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Abrir projeto |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Selecionar tudo |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copiar a seleção (nós, elementos, cargas) para a área de transferência do EduBeam |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Colar: um contorno da cópia segue o cursor; clique com o botão esquerdo para posicioná-la |
| <kbd>Delete</kbd> | Excluir a seleção |
| <kbd>Esc</kbd> | Cancelar o modo de mouse atual, limpar a seleção, sair de uma célula de tabela |
| <kbd>Enter</kbd> | Confirmar uma célula de tabela |
| <kbd>F</kbd> | Ajustar à tela |
| <kbd>C</kbd> | Centralizar |
| <kbd>G</kbd> | Alternar grade |
| <kbd>S</kbd> | Alternar encaixe na grade |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Aproximar / afastar |

No macOS use <kbd>Cmd</kbd> onde aparece <kbd>Ctrl</kbd>.

## Mouse

| Ação | Resultado |
| --- | --- |
| Clique esquerdo | Seleciona um nó / elemento / carga / cota e abre seu menu de contexto |
| Arrastar com botão esquerdo na tela vazia | Seleção por retângulo |
| Arrastar um nó com botão esquerdo | Move o nó (encaixa na grade se o encaixe estiver ativado) |
| Clique esquerdo no modo *Adicionar com o mouse* | Posiciona um nó, ou inicia / continua uma poligonal de elementos |
| Clique duplo em uma carga | Edita a carga |
| Clique direito na tela vazia | Menu da tela: Adicionar nó, Adicionar elemento, Adicionar cota, Editar, Copiar, Colar, Excluir |
| Arrastar com botão do meio ou direito | Panorâmica (configurável em *Configurações → Controles e atalhos*) |
| Roda | Zoom em direção ao cursor |
| Passar o mouse | Dica com deslocamentos / propriedades / valores de carga |

## Toque

| Gesto | Resultado |
| --- | --- |
| Toque | Selecionar |
| Arrastar com um dedo | Panorâmica |
| Pinça | Zoom |
| Pressionar e segurar um nó | Começar a movê-lo |

## Menus de contexto

Clicar em um objeto abre um pequeno menu ao lado dele:

| Objeto | Itens |
| --- | --- |
| Nó | Adicionar carga · Apoios do nó (Dx / Dz / Ry, Ângulo do SCL nodal) · Prescrever deslocamento (se apoiado) · Excluir |
| Elemento | Editar elemento (nós, material, seção) · Adicionar carga · Matriz de rigidez · Excluir |
| Carga nodal / de elemento | Editar carga · Excluir |
| Linha de cota | Editar (coordenadas) · Inverter cota · Excluir |
