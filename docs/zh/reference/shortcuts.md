# 键盘、鼠标与触控

键盘快捷键在视图获得焦点时有效。在表格单元格或对话框中输入时，快捷键会被忽略；请先点击画布。

## 键盘 {#keyboard}

| 快捷键 | 操作 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 撤销 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | 重做 |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | 保存项目（下载 JSON） |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | 打开项目 |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | 导出图像 |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | 全选 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | 复制所选对象（节点、单元及其荷载） |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | 粘贴：副本的虚影跟随光标移动；点击即可放置，或在横幅中输入偏移量 Δx、Δz 并点击**粘贴** |
| <kbd>Delete</kbd> | 删除所选对象 |
| <kbd>Esc</kbd> | 取消当前鼠标模式、关闭导览、清除选择，或离开表格单元格 |
| <kbd>Enter</kbd> | 确认表格单元格 |
| <kbd>F</kbd> | 适配屏幕 |
| <kbd>C</kbd> | 内容居中 |
| <kbd>G</kbd> | 切换网格 |
| <kbd>S</kbd> | 切换网格吸附 |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | 放大 / 缩小 |

在 Mac 上，凡是显示 <kbd>Ctrl</kbd> 的地方请使用 <kbd>Cmd</kbd>。

## 鼠标 {#mouse}

| 操作 | 结果 |
| --- | --- |
| 点击 | 选中节点、单元、荷载或尺寸标注，并打开其面板 |
| 在空白画布上拖动 | 选择框 |
| 拖动节点 | 移动节点（开启吸附时会吸附到网格） |
| 在鼠标模式下点击 | 放置节点，或开始、继续绘制单元折线 |
| 双击荷载 | 编辑荷载 |
| 右键 | 画布菜单：添加节点、添加单元、添加标注、标注单元（在单元上时）、编辑、复制、粘贴、删除 |
| 在画布菜单中按住 <kbd>Ctrl</kbd>（Mac 上为 <kbd>Cmd</kbd>）+ 添加节点 / 添加单元 | 用鼠标放置，而不是打开对话框 |
| 按住中键或右键拖动 | 平移（见*设置 → 控制与快捷键*） |
| 滚轮 | 朝光标方向缩放 |
| 指向对象 | 显示位移、属性或荷载数值的提示信息 |

在触控板上，双指滚动用于缩放。要平移，请用双指点按并拖动（相当于右键拖动）。

## 触控 {#touch}

| 手势 | 结果 |
| --- | --- |
| 轻点 | 选中，并显示对象的详细信息和操作 |
| 在鼠标模式下轻点 | 放置节点或继续绘制单元 |
| 按住节点并拖动 | 移动节点 |
| 在其他位置单指拖动 | 平移 |
| 双指捏合 | 缩放 |
| 在画布上长按 | 画布菜单 |
| 点击**框选**按钮（右上角），然后拖动 | 选择框 |

## 对象面板 {#object-panels}

点击对象会在其旁边打开一个面板，显示其详细信息和以下操作：

| 对象 | 操作 |
| --- | --- |
| 节点 | 添加荷载 · 节点支座（支座符号、Dx / Dz / Ry、节点局部坐标系角度） · 施加位移约束（在有支座的节点上） · 删除 |
| 单元 | 编辑单元（节点和铰接、材料、截面） · 添加荷载 · 刚度矩阵 · 删除 |
| 节点荷载或单元荷载 | 编辑荷载 · 删除 |
| 尺寸标注 | 编辑（坐标） · 翻转标注 · 删除 |
