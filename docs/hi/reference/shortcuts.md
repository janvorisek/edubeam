# कीबोर्ड, माउस और टच

कीबोर्ड शॉर्टकट तब काम करते हैं जब व्यूअर पर फ़ोकस हो। जब आप किसी तालिका सेल या संवाद में टाइप कर रहे हों, तो इन्हें अनदेखा किया जाता है; पहले कैनवास पर क्लिक करें।

## कीबोर्ड {#keyboard}

| शॉर्टकट | क्रिया |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | पूर्ववत करें (Undo) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | पुनः करें (Redo) |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | प्रोजेक्ट सहेजें (JSON डाउनलोड) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | प्रोजेक्ट खोलें |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | चित्र निर्यात करें |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | सब कुछ चुनें |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | चयन कॉपी करें (नोड, अवयव और उनके भार) |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | पेस्ट करें: प्रति की एक छाया कर्सर के साथ चलती है; उसे रखने के लिए क्लिक करें, या ऊपर की पट्टी में ऑफ़सेट Δx, Δz टाइप करके **Paste** दबाएँ |
| <kbd>Delete</kbd> | चयन हटाएँ |
| <kbd>Esc</kbd> | वर्तमान माउस मोड रद्द करें, भ्रमण बंद करें, चयन साफ़ करें, या तालिका सेल छोड़ें |
| <kbd>Enter</kbd> | तालिका सेल की पुष्टि करें |
| <kbd>F</kbd> | सामग्री को स्क्रीन पर फिट करें |
| <kbd>C</kbd> | सामग्री को केंद्र में लाएँ |
| <kbd>G</kbd> | ग्रिड चालू/बंद करें |
| <kbd>S</kbd> | ग्रिड पर स्नैप चालू/बंद करें |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | ज़ूम इन / आउट |

Mac पर, जहाँ <kbd>Ctrl</kbd> दिखाया गया है, वहाँ <kbd>Cmd</kbd> का उपयोग करें।

## माउस {#mouse}

| क्रिया | परिणाम |
| --- | --- |
| क्लिक | किसी नोड, अवयव, भार या विमा रेखा को चुनें और उसका पैनल खोलें |
| खाली कैनवास पर खींचना | चयन आयत |
| नोड खींचना | नोड खिसकाएँ (स्नैपिंग चालू होने पर ग्रिड पर स्नैप होता है) |
| माउस मोड में क्लिक | नोड रखें, या अवयव पॉलीलाइन शुरू करें या जारी रखें |
| भार पर डबल-क्लिक | भार संपादित करें |
| राइट-क्लिक | कैनवास मेनू: Add node, Add element, Add dimension, Dimension element (अवयव के ऊपर), Edit, Copy, Paste, Delete |
| कैनवास मेनू में <kbd>Ctrl</kbd> (Mac पर <kbd>Cmd</kbd>) + Add node / Add element | संवाद के बजाय माउस से रखें |
| मध्य या दाएँ बटन से खींचना | पैन (देखें *Settings → Controls & Shortcuts*) |
| व्हील | कर्सर की ओर ज़ूम |
| किसी वस्तु पर पॉइंटर ले जाना | विस्थापन, गुणधर्म या भार मानों वाला टूलटिप |

ट्रैकपैड पर दो उँगलियों से स्क्रॉल करने से ज़ूम होता है। पैन करने के लिए दो उँगलियों से क्लिक करके खींचें (दाएँ बटन से खींचना)।

## टच {#touch}

| इशारा | परिणाम |
| --- | --- |
| टैप | चुनें, और वस्तु का विवरण और क्रियाएँ दिखाएँ |
| माउस मोड में टैप | नोड रखें या अवयव जारी रखें |
| नोड को दबाकर खींचना | नोड खिसकाएँ |
| कहीं और एक उँगली से खींचना | पैन |
| पिंच | ज़ूम |
| कैनवास को दबाए रखना | कैनवास मेनू |
| **Box select** बटन (ऊपर दाएँ), फिर खींचना | चयन आयत |

## वस्तु पैनल {#object-panels}

किसी वस्तु पर क्लिक करने से उसके पास एक पैनल खुलता है, जिसमें उसका विवरण और ये क्रियाएँ होती हैं:

| वस्तु | क्रियाएँ |
| --- | --- |
| नोड | Add load · Node supports (आधार प्रतीक, Dx / Dz / Ry, नोडीय LCS कोण) · Prescribe displacement (आधार वाले नोड पर) · Delete |
| अवयव | Edit element (नोड और हिंज, सामग्री, अनुप्रस्थ काट) · Add load · Stiffness matrix · Delete |
| नोडीय या अवयव भार | Edit load · Delete |
| विमा रेखा | Edit (निर्देशांक) · Flip dimension · Delete |
