# Клавиатура и мышь

Сочетания клавиш работают, пока фокус находится в области просмотра; при вводе в ячейке таблицы или в диалоге они игнорируются.

## Клавиатура

| Сочетание | Действие |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Отменить |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Повторить |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Сохранить проект (скачать JSON) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Открыть проект |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Выделить всё |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Скопировать выделение (узлы, элементы, нагрузки) в буфер EduBeam |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Вставить: «призрак» копии следует за курсором; левый щелчок размещает её |
| <kbd>Delete</kbd> | Удалить выделение |
| <kbd>Esc</kbd> | Отменить текущий режим мыши, снять выделение, выйти из ячейки таблицы |
| <kbd>Enter</kbd> | Подтвердить ячейку таблицы |
| <kbd>F</kbd> | Вписать в экран |
| <kbd>C</kbd> | Центрировать |
| <kbd>G</kbd> | Показать/скрыть сетку |
| <kbd>S</kbd> | Включить/выключить привязку к сетке |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Увеличить / уменьшить |

В macOS используйте <kbd>Cmd</kbd> там, где указано <kbd>Ctrl</kbd>.

## Мышь

| Действие | Результат |
| --- | --- |
| Левый щелчок | Выделить узел / элемент / нагрузку / размерную линию и открыть всплывающее меню |
| Протягивание левой кнопкой по пустому холсту | Выделение рамкой |
| Протягивание левой кнопкой за узел | Переместить узел (при включённой привязке — по сетке) |
| Левый щелчок в режиме *Добавить мышью* | Поставить узел либо начать / продолжить ломаную элементов |
| Двойной щелчок по нагрузке | Редактировать нагрузку |
| Правый щелчок по пустому холсту | Меню холста: Добавить узел, Добавить элемент, Добавить размер, Изменить, Копировать, Вставить, Удалить |
| Протягивание средней или правой кнопкой | Панорамирование (настраивается в *Настройки → Управление и горячие клавиши*) |
| Колесо | Масштабирование к курсору |
| Наведение | Подсказка с перемещениями / свойствами / значениями нагрузки |

## Сенсорный экран

| Жест | Результат |
| --- | --- |
| Касание | Выделить |
| Перетаскивание одним пальцем | Панорамирование |
| Щипок | Масштабирование |
| Долгое нажатие на узел | Начать перемещение |

## Всплывающие меню

Щелчок по объекту открывает рядом с ним небольшое меню:

| Объект | Пункты |
| --- | --- |
| Узел | Добавить нагрузку · Опоры узла (Dx / Dz / Ry, Угол локальной системы координат) · Задать перемещение (если узел опёрт) · Удалить |
| Элемент | Редактировать элемент (узлы, материал, сечение) · Добавить нагрузку · Матрица жёсткости · Удалить |
| Узловая нагрузка / нагрузка на элемент | Редактировать нагрузку · Удалить |
| Размерная линия | Изменить (координаты) · Развернуть размер · Удалить |
