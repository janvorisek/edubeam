# クイックスタート

約 10 分で、等分布荷重を受ける鋼製の単純梁をモデル化し、反力、せん断力、曲げモーメントを読み取って、教科書の公式と照らし合わせます。

::: tip 実際に操作しながら進めましょう
[run.edubeam.app](https://run.edubeam.app/?lang=ja){target="_blank"} を別のタブで開いてください。すでにモデルがある場合は、アプリバーの**モデルをクリア**で空の状態から始めます。*材料を削除*と*断面を削除*にもチェックを入れると、完全にまっさらな状態になります。クリアは <kbd>Ctrl</kbd>+<kbd>Z</kbd> で元に戻せ、前のモデルは **☰ → 最近のモデル**に残ります。

画面のヒントを見ながら手を動かして覚えたい場合は、**☰ → はじめての梁を描く**で、同じような梁をマウスで作る手順を案内します。
:::

## 問題 {#the-problem}

<ExampleStructure />

スパン 6 m の単純梁（左端がピン、右端がローラー）に 12 kN/m の等分布荷重が作用します。材料：鋼、$E = 210\ \text{GPa}$、$G = 81\ \text{GPa}$。断面：IPE 200、$A = 28.5\ \text{cm}^2$、$I_y = 1943\ \text{cm}^4$、$h = 200\ \text{mm}$。

## 1. 単位を確認する {#_1-check-the-units}

ビューアの右下にある単位チップには、すべての入力欄と結果で使われる単位が表示されます。このチュートリアルでは SI の初期設定（m、kN、kNm、MPa）を前提とします。

![グリッド（G）、スナップ（S）、クロスヘアの切替ボタンと単位チップ](/screenshots/ja/ui-grid-units.webp){.shot-sm}

`ft · kip · kip·ft · ksi` と表示されている場合は、チップをクリックして**単位系 → SI（メートル法）** を選んでください。

## 2. 材料と断面を追加する {#_2-add-the-material-and-cross-section}

要素には材料と断面が必要なので、先にこれらを作成します。

1. 下部バーの**材料**タブを開き、**材料を追加**をクリックします。
2. `E = 210000` MPa と `G = 81000` MPa を入力します。密度と `α = 0.000012` 1/K はそのままにします。**材料を追加**をクリックします。

<div class="shots">

![材料を追加：E と G を入力するか…](/screenshots/ja/qs-material.webp)

![…材料ライブラリから Steel (S235) を選びます](/screenshots/ja/qs-material-library.webp)

</div>

3. **断面**タブを開き、**断面を追加**をクリックします。
4. `断面積 = 0.00285` m²、`Iy = 1.943e-5` m⁴、`高さ = 0.2` m、`せん断補正係数 = 1` を入力します。**断面を追加**をクリックします。

![断面を追加。ライブラリから選んだり、多角形形状を描いたりすることもできます。](/screenshots/ja/qs-cross-section.webp){.shot-md}

::: details せん断補正係数はなぜ重要？
EduBeam はせん断変形を考慮する Timoshenko 梁要素を使います。`k` はせん断補正係数で、長方形では $k \approx 0.83$、I 形断面で $A$ に全断面積を使う場合は約 $0.4$–$0.5$ です。全断面積で `k = 1` とすると、せん断変形をわずかに*小さく*見積もることになります。この梁のように細長い梁では、たわみの差は 1 % を大きく下回ります。式は[梁の理論のページ](/ja/elements/beam)をご覧ください。
:::

## 3. 節点を追加する {#_3-add-the-nodes}

1. **節点**タブを開きます。**節点を追加**ボタンが 2 つあり、1 つ目はダイアログを開き、2 つ目（カーソルアイコン付き）はマウスで節点を配置します。1 つ目をクリックします。
2. `X = 0`、`Z = 0` を入力して**節点を追加**をクリックします。この節点のラベルは `1` です。
3. 2 つ目の節点を `X = 6`、`Z = 0` に追加します。これが節点 `2` です。

![節点を追加ダイアログでは、支点もその場で設定できます](/screenshots/ja/qs-node.webp){.shot-md}

マウスのボタンを使う場合は、キャンバスをクリックするたびに節点が配置されます。**グリッドにスナップ**（<kbd>S</kbd>）がオンなら、クリック位置はグリッド間隔（初期値 0.1 m）に揃います。

## 4. 要素でつなぐ {#_4-connect-them-with-an-element}

1. **要素**タブを開き、1 つ目の**要素を追加**ボタンをクリックします。
2. **始端節点**に `1`、**終端節点**に `2` を選びます。材料と断面はすでに選択されています。**要素を追加**をクリックします。

![要素を追加：両端の節点、必要に応じて材端ヒンジ、材料と断面](/screenshots/ja/qs-element.webp){.shot-md}

節点の間に線が表示されます。<kbd>F</kbd> を押すと画面に合わせて表示されます。

## 5. 支点を追加する {#_5-add-the-supports}

**節点**タブの**拘束自由度**列には、節点ごとに支点記号の選択ボタンと 3 つのチェックボックス（`Dx`、`Dz`、`Ry`）があります。

- 節点 `1`：**ピン**の記号を選ぶか、**Dx** と **Dz** にチェックを入れます。
- 節点 `2`：**ローラー**を選ぶか、**Dz** だけにチェックを入れます。

![節点の表の支点：節点 1 はピン、節点 2 はローラー](/screenshots/ja/qs-supports.webp)

ビューアで節点をクリックし、**支点条件**を選んで設定することもできます。支点の種類はすべて[節点と支点](/ja/essentials/nodes-supports#supports)に載っています。

## 6. 荷重を追加する {#_6-add-the-load}

1. **荷重**タブを開き、**要素荷重を追加**をクリックします。
2. **荷重の種類**：*等分布荷重*。**要素**：`1`。
3. `fz = 12` kN/m を入力し、`fx = 0` はそのままにします。**要素荷重を追加**をクリックします。

![ダイアログでは要素上の荷重をプレビューできます](/screenshots/ja/qs-load.webp){.shot-md}

正の `fz` は +z 方向、つまり画面上で**下向き**なので、正の値が重力方向の荷重になります。[符号規約](/ja/elements/conventions)をご覧ください。

## 7. 結果を読む {#_7-read-the-results}

荷重を追加するとすぐに解が表示されます。ビューア右上の表示パネルで、各図の表示・非表示を切り替えます。**変形図**、**M<sub>y</sub>(x)**、**反力**は初期状態でオンです。**V<sub>z</sub>(x)** にチェックを入れると、せん断力も表示されます。

![せん断力（緑）、曲げモーメント（赤）、反力（紫）と変形図](/screenshots/ja/qs-results.webp)

| 表示 | 見えるはずのもの |
| --- | --- |
| **反力** | 節点 1 と 2 に、上向きの **36 kN** の矢印が 2 本。 |
| **V<sub>z</sub>(x)** | 左端の **+36 kN** から右端の **−36 kN** までの直線で、スパン中央で 0 になります。 |
| **M<sub>y</sub>(x)** | スパン中央で極値 **54 kNm** をとる放物線。 |
| **変形図** | 左右対称のたわみ。節点 `1` にマウスを重ねると回転角が読めます：**2.6469 · 10⁻² rad**。 |

数値は下部バーの**結果**タブにあります。**節点結果**には各節点の `Dx`、`Dz`、`Ry` が、**要素結果**には各要素のローカル座標系での材端力が表示されます。

図が大きすぎたり小さすぎたりする場合は、**設定 → 表示設定 → サイズ**の**結果の表示倍率**を変更してください。

## 8. 手計算で確認する {#_8-check-by-hand}

| 量 | 式 | 手計算 | EduBeam |
| --- | --- | --- | --- |
| 反力 | $R = qL/2$ | 36 kN | 36 kN |
| 最大せん断力 | $V = qL/2$ | 36 kN | 36 kN |
| 最大曲げモーメント | $M = qL^2/8$ | 54 kNm | 54 kNm |
| 材端の回転角 | $\varphi = qL^3/(24EI)$ | 0.02647 rad | 0.02647 rad |
| 中央のたわみ（曲げ） | $w = 5qL^4/(384EI)$ | 49.63 mm | |
| 中央のたわみ（せん断） | $w_s = qL^2/(8kGA)$ | 0.23 mm | |
| 中央のたわみ（合計） | 合計 | 49.86 mm | 49.86 mm |

スパン中央には節点がないので、そこでのたわみを読むには節点を 1 つ追加します。2 つ目の**節点を追加**ボタンを選び、梁の `X = 3` の位置をクリックして**構造物に接続**を選びます。梁が 2 つに分割され、**結果**で新しい節点の `Dz` が 49.86 mm と読めます。要素は厳密なので、分割しても結果は変わりません。

すべて一致しました。ほかの手計算による確認方法（片持ち梁、両端固定梁、トラス、温度荷重）は[手計算による結果の確認](/ja/guide/verification)にあります。

## 9. いろいろ試す {#_9-experiment}

ここからが EduBeam の本領です。次の操作を試して、図がどう変わるかを見てみましょう。

- **節点 2 を右へドラッグ**：モーメントは $L^2$ に比例して大きくなります。
- **節点 1 の `Ry` にチェック**を入れて固定にする：スパン中央のモーメントが小さくなり、支点に負の曲げモーメント（上側引張）が生じます。
- 先ほど追加した**中央の節点の `Dz` にチェック**を入れると、2 径間連続梁になります。
- 要素タブで要素の**材端ヒンジにチェック**を入れると、片端のモーメントが解放されます。
- どの操作も <kbd>Ctrl</kbd>+<kbd>Z</kbd> で元に戻せます。

## 10. 保存・共有する {#_10-save-or-share}

- **モデルを共有**（アプリバーまたは ☰ メニュー）では、モデル全体を含むリンクが得られます。メール、チャット、スライドに貼り付けられます。
- **☰ → プロジェクトを保存**（<kbd>Ctrl</kbd>+<kbd>S</kbd>）で `project.json` がダウンロードされます。後で**プロジェクトを開く**から開くか、アプリにドロップして開けます。
- **☰ → 画像をエクスポート**（<kbd>Ctrl</kbd>+<kbd>P</kbd>）で、レポート用に図を PNG または SVG で保存できます。

モデルはブラウザにも保存されるので、ページを再読み込みしても失われません。[インポート・エクスポート・共有](/ja/essentials/import-export)をご覧ください。
