# 示例

下面的每张卡片都是一个已求解的实时模型。点击即可在 <Edubeam /> 中打开，所有设置都已就绪可供编辑——然后拖动节点、修改荷载或勾选一个铰，观察内力图随之变化。

## 建议练习

- **超静定梁** —— 取消固定端的 `Ry` 勾选，使其成为简支梁。跨中弯矩增大了多少？
- **悬臂梁** —— 把端部挠度与 $FL^3/3EI$ 比较（参见[手算校核](/zh/guide/verification)）；然后在*截面*标签页中把 $I_y$ 减半。
- **Pratt 桁架** —— 去掉一根斜杆。桁架还能站住吗？哪些杆件承受的轴力最大？
- **三跨连续梁** —— 在跨中节点添加 `Dz` 支座；观察支座上方的负弯矩。
- **门式刚架** —— 勾选横梁两端的端部铰接来模拟梁柱铰接连接，或者把右侧支座改为固定铰支座而不是可动铰支座。
- **温度荷载** —— 约束两个支座的 `Dx`，观察轴力的出现。
