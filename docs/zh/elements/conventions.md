# 坐标系与符号约定

<Edubeam /> 中大多数"错误"的结果其实都是符号约定带来的意外。下面的所有内容都是求解器实际使用的约定。

## 整体坐标轴

- **x** —— 水平，向**右**为正。
- **z** —— 竖向，在屏幕上向**下**为正。
- **y** —— 平面外轴（在右手系中指向观察者）。转角和力矩都绕 y 轴。

网格角落的坐标轴指示器显示 x（红色）和 z（绿色）。因此，若柱底在 `Z = 0`，一根 3 m 高柱子顶部的节点为 `Z = −3`。

## 自由度

每个节点有 `Dx`、`Dz`（平动）和 `Ry`（转动）。正的 `Dz` 是向下的位移；正的 `Ry` 在屏幕上是**逆时针**转动。同样的符号适用于位移约束和报告的节点结果。

## 荷载

| 荷载 | 正方向 |
| --- | --- |
| `Fx`、`fx`、`f1x`… | +x（向右；开启局部坐标系时沿单元局部 x 轴） |
| `Fz`、`fz`、`f1z`… | +z（**向下**；开启局部坐标系时沿局部 z 轴） |
| `My` | 屏幕上逆时针 |
| `ΔTs` | 升温（伸长） |
| `ΔTb − ΔTt` | 下缘纤维比上缘热 |

因此，重力荷载是**正的** `fz`，把左柱向右推的风荷载是正的 `fx`。

## 单元局部坐标轴

局部 **x** 轴从起始节点指向终止节点；局部 **z** 轴与它垂直，由整体坐标轴旋转单元角度 $\alpha$ 得到。对于从左向右绘制的水平单元，局部与整体坐标轴重合。在*单元*表格中使用**交换节点顺序**可以反转方向。

## 内力

| 物理量 | 正值含义 |
| --- | --- |
| **N** | 拉力 |
| **V<sub>z</sub>** | 梁理论中的常用符号：承受重力荷载的简支梁，V 在左支座为正，在右支座为负 |
| **M<sub>y</sub>** | **下侧受拉** —— 下缘（+z）纤维受拉。承受重力荷载的简支梁跨中弯矩为正；端部受集中荷载的悬臂梁在根部弯矩为负（上侧受拉） |

## 端力（单元结果表）

`X12, Z12, M12` 在起始节点处作用于单元，`X21, Z21, M21` 在终止节点处作用于单元，均在**局部**坐标系中，正方向与局部坐标轴和 `My` 相同。它们是节点作用在单元上的力，即 $\mathbf{f} = \mathbf{K}_l\,\mathbf{u}_l - \mathbf{f}_{eq}$，其中 $\mathbf{f}_{eq}$ 是单元荷载的等效节点荷载。在一个节点相交的所有单元的端力之和与该处的节点荷载和支座反力平衡。

## 支座反力

每个被约束的自由度都有一个支座反力，并在节点的坐标系中报告（如果设置了节点局部坐标系角度，则按该角度旋转）。视图中的反力箭头指向支座推动结构的方向。

## 单位

求解器内部使用 SI 单位（m、N、Pa、rad、K）。显示单位只影响你输入和读取的内容；更改它们永远不会改变模型。
