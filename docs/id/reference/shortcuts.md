# Keyboard, mouse & sentuh

Pintasan keyboard berfungsi saat tampilan sedang aktif (fokus). Pintasan diabaikan saat Anda mengetik di sel tabel atau dialog; klik kanvas terlebih dahulu.

## Keyboard {#keyboard}

| Pintasan | Aksi |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Urungkan |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Ulangi |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Simpan proyek (unduh JSON) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Buka proyek |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Ekspor gambar |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Pilih semua |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Salin seleksi (joint, elemen, dan bebannya) |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Tempel: bayangan salinan mengikuti kursor; klik untuk menempatkannya, atau ketik pergeseran Δx, Δz di banner dan tekan **Tempel** |
| <kbd>Delete</kbd> | Hapus seleksi |
| <kbd>Esc</kbd> | Batalkan mode mouse yang aktif, tutup tur, kosongkan seleksi, atau keluar dari sel tabel |
| <kbd>Enter</kbd> | Konfirmasi sel tabel |
| <kbd>F</kbd> | Sesuaikan dengan layar |
| <kbd>C</kbd> | Pusatkan model |
| <kbd>G</kbd> | Tampilkan/sembunyikan grid |
| <kbd>S</kbd> | Aktifkan/nonaktifkan snap ke grid |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Perbesar / perkecil |

Di Mac, gunakan <kbd>Cmd</kbd> di tempat <kbd>Ctrl</kbd>.

## Mouse {#mouse}

| Aksi | Hasil |
| --- | --- |
| Klik | Memilih joint, elemen, beban, atau garis dimensi dan membuka panelnya |
| Seret di kanvas kosong | Persegi panjang seleksi |
| Seret joint | Memindahkan joint (menempel ke grid saat snap aktif) |
| Klik dalam mode mouse | Menempatkan joint, atau memulai atau melanjutkan polyline elemen |
| Klik ganda beban | Mengedit beban |
| Klik kanan | Menu kanvas: Tambah joint, Tambah elemen, Tambah dimensi, Dimensi elemen (di atas elemen), Edit, Salin, Tempel, Hapus |
| <kbd>Ctrl</kbd> (<kbd>Cmd</kbd> di Mac) + Tambah joint / Tambah elemen di menu kanvas | Menempatkan dengan mouse alih-alih dialog |
| Seret dengan tombol tengah atau kanan | Geser tampilan (lihat *Pengaturan → Kontrol & Pintasan*) |
| Roda | Zoom ke arah kursor |
| Arahkan kursor ke objek | Tooltip berisi perpindahan, properti, atau nilai beban |

Pada trackpad, menggulir dengan dua jari melakukan zoom. Untuk menggeser tampilan, klik dan seret dengan dua jari (seperti menyeret dengan tombol kanan).

## Sentuh {#touch}

| Gerakan | Hasil |
| --- | --- |
| Ketuk | Memilih, dan menampilkan detail serta aksi objek |
| Ketuk dalam mode mouse | Menempatkan joint atau melanjutkan elemen |
| Tekan joint lalu seret | Memindahkan joint |
| Seret satu jari di tempat lain | Geser tampilan |
| Cubit | Zoom |
| Tekan lama di kanvas | Menu kanvas |
| Tombol **Pilih dengan kotak** (kanan atas), lalu seret | Persegi panjang seleksi |

## Panel objek {#object-panels}

Mengklik objek membuka panel di sampingnya berisi detail dan aksi berikut:

| Objek | Aksi |
| --- | --- |
| Joint | Tambah beban · Tumpuan joint (simbol tumpuan, Dx / Dz / Ry, sudut LCS joint) · Tetapkan perpindahan (pada joint bertumpuan) · Hapus |
| Elemen | Edit elemen (joint dan sendi, material, penampang) · Tambah beban · Matriks kekakuan · Hapus |
| Beban joint atau beban elemen | Edit beban · Hapus |
| Garis dimensi | Edit (koordinat) · Balik dimensi · Hapus |
