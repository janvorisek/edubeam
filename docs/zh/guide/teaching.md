# 用 EduBeam 教学

<Edubeam /> 诞生于讲堂，而讲堂至今仍是它最能发挥作用的地方：投影仪上的模型在你修改的瞬间就做出反应，同一个模型还能通过一个链接出现在每位学生的笔记本电脑上。本页汇总了教师最常用的功能。

## 课堂上 {#in-the-lecture}

- **让最后一排也看得清。** 在*设置 → 视图设置*中，把**字号**调到 18–20 px，把**支座大小**调到 130–150 %。如果内力图在大屏幕上显得太小，请调大**结果缩放**。
- **一次只展示一样东西。** 在显示选项中取消勾选除当前所讲物理量之外的所有内容，然后再逐一加上其他内容。
- **现场修改模型。** 拖动支座、勾选 `Ry`、添加铰接。学生能立刻看到因果关系，<kbd>Ctrl</kbd>+<kbd>Z</kbd> 则可以随时退回。
- **让求解器来解释机构。** 多释放一个铰，EduBeam 就会让机构的虚线轮廓摆动起来，并圈出出问题的铰。这正是讨论稳定性的好时机。
- **使用学生的语言和坐标轴。** 选择界面语言、国际单位制或美制单位，以及 z 向下或 y 向上的坐标轴，与你的课程讲义保持一致。

## 讲义和作业中 {#in-lecture-notes-and-assignments}

分享链接包含整个模型，因此凡是能放链接的地方都能用：PDF、幻灯片、教学平台页面、电子邮件。

1. 建好模型，点击**分享模型 → 复制**。
2. 把链接粘贴到讲义中。旧版 EduBeam 生成的链接依然有效，因此讲义可以年复一年地使用。
3. 打开链接的学生会得到一份属于自己的副本，可以随意尝试。他们的任何修改都不会影响到你或其他学生。

常用的链接形式：

| 链接 | 打开的内容 |
| --- | --- |
| `https://run.edubeam.app/?model=…` | 模型，可直接编辑 |
| `https://run.edubeam.app/?viewer=1&model=…` | [查看器模式](/zh/essentials/import-export#embed-a-read-only-viewer)下的模型，用于嵌入 `<iframe>` |
| `https://run.edubeam.app/?panel=examples` | 示例库 |
| `https://run.edubeam.app/?lang=cn` | 中文界面的应用（或任何[其他语言代码](/zh/essentials/import-export#url-parameters)） |

::: warning 打开链接会替换学生自己的模型
他们原来的模型会进入 **☰ → 最近的结构**，可以恢复，界面上也会有消息提示。尽管如此，还是请提醒学生：在打开课堂链接之前，先用**保存项目**保存重要的工作。
:::

## 学生可以自行核对的作业 {#assignments-students-can-check-themselves}

EduBeam 能为学生的手算结果提供即时反馈，同时不会泄露解题方法：

- 要求学生手算支反力、内力和一个位移，然后让他们建立模型进行比较。[手算校核结果](/zh/guide/verification)中有现成的公式。
- 让学生解释结果*为什么*不同：剪切变形、漏掉的铰、荷载用了局部坐标而不是整体坐标。
- 要求学生在提交计算书时附上分享链接或 `project.json`。你可以打开它，准确看到他们建的是什么模型。
- 写报告时，学生可以把图形导出为 **SVG**（在 Word 和 LaTeX 中保持清晰），把结果导出为 **CSV**。

## 现成的练习 {#ready-made-exercises}

- [示例](/zh/examples/)页面有六个模型，每个都附有建议练习。
- [三铰刚架](/zh/tutorials/three-hinged-frame)和[平面桁架](/zh/tutorials/truss)教程是带手算核对的完整算例。
- [快速入门](/zh/guide/quick-start)可以用作第一次上机课的讲义：大约需要十分钟。

## 帮助学生入门 {#getting-students-started}

新用户会看到一个欢迎对话框，其中有两个引导选项：**带我看看**（界面导览）和**绘制第一根梁**（用鼠标完成的七步任务）。两者也都在 ☰ 菜单中。许多教师在第一次上机课开始时只说一句：“打开 run.edubeam.app，选择*绘制第一根梁*。”

## 离线使用与机房电脑 {#offline-and-lab-computers}

EduBeam 是一个渐进式网页应用（PWA）。电脑加载过一次之后，断网也能继续使用，浏览器还可能提示安装它。模型和设置按浏览器配置文件分别保存，因此在共用的机房电脑上，学生应把工作保存为文件或链接。
