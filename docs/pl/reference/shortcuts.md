# Klawiatura, mysz i dotyk

Skróty klawiaturowe działają, gdy widok jest aktywny. Są ignorowane podczas wpisywania w komórce tabeli lub w oknie dialogowym; najpierw kliknij płótno.

## Klawiatura {#keyboard}

| Skrót | Działanie |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Cofnij |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Ponów |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Zapisz projekt (pobierz JSON) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Otwórz projekt |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Eksportuj obraz |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Zaznacz wszystko |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Kopiuj zaznaczenie (węzły, elementy i ich obciążenia) |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Wklej: półprzezroczysta kopia podąża za kursorem; kliknij, aby ją umieścić, albo wpisz przesunięcie Δx, Δz na pasku u góry i naciśnij **Wklej** |
| <kbd>Delete</kbd> | Usuń zaznaczenie |
| <kbd>Esc</kbd> | Anuluj bieżący tryb myszy, zamknij przewodnik, wyczyść zaznaczenie lub opuść komórkę tabeli |
| <kbd>Enter</kbd> | Zatwierdź komórkę tabeli |
| <kbd>F</kbd> | Dopasuj do ekranu |
| <kbd>C</kbd> | Wyśrodkuj widok |
| <kbd>G</kbd> | Włącz/wyłącz siatkę |
| <kbd>S</kbd> | Włącz/wyłącz przyciąganie do siatki |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Powiększ / pomniejsz |

Na Macu używaj <kbd>Cmd</kbd> wszędzie tam, gdzie podano <kbd>Ctrl</kbd>.

## Mysz {#mouse}

| Czynność | Wynik |
| --- | --- |
| Kliknięcie | Zaznacza węzeł, element, obciążenie lub linię wymiarową i otwiera jego panel |
| Przeciągnięcie po pustym płótnie | Prostokąt zaznaczenia |
| Przeciągnięcie węzła | Przesuwa węzeł (przy włączonym przyciąganiu trafia w siatkę) |
| Kliknięcie w trybie myszy | Wstawia węzeł albo zaczyna lub kontynuuje linię łamaną elementów |
| Dwukrotne kliknięcie obciążenia | Edycja obciążenia |
| Prawy przycisk | Menu płótna: Dodaj węzeł, Dodaj element, Dodaj wymiar, Wymiaruj element (nad elementem), Edytuj, Kopiuj, Wklej, Usuń |
| <kbd>Ctrl</kbd> (<kbd>Cmd</kbd> na Macu) + Dodaj węzeł / Dodaj element w menu płótna | Wstawianie myszą zamiast przez okno dialogowe |
| Przeciąganie środkowym lub prawym przyciskiem | Przesuwanie widoku (zobacz *Ustawienia → Sterowanie i skróty*) |
| Kółko | Powiększanie w stronę kursora |
| Najechanie na obiekt | Podpowiedź z przemieszczeniami, właściwościami lub wartościami obciążenia |

Na gładziku przewijanie dwoma palcami powiększa widok. Aby przesunąć widok, kliknij i przeciągnij dwoma palcami (odpowiednik przeciągania prawym przyciskiem).

## Dotyk {#touch}

| Gest | Wynik |
| --- | --- |
| Stuknięcie | Zaznacza obiekt i pokazuje jego szczegóły i akcje |
| Stuknięcie w trybie myszy | Wstawia węzeł lub kontynuuje element |
| Dotknięcie węzła i przeciągnięcie | Przesuwa węzeł |
| Przeciągnięcie jednym palcem w innym miejscu | Przesuwanie widoku |
| Rozsunięcie / zsunięcie palców | Powiększanie |
| Przytrzymanie palca na płótnie | Menu płótna |
| Przycisk **Zaznaczanie prostokątem** (prawy górny róg), potem przeciągnięcie | Prostokąt zaznaczenia |

## Panele obiektów {#object-panels}

Kliknięcie obiektu otwiera obok niego panel z jego szczegółami i następującymi akcjami:

| Obiekt | Akcje |
| --- | --- |
| Węzeł | Dodaj obciążenie · Podpory węzła (symbol podpory, Dx / Dz / Ry, kąt lokalnego układu węzła) · Zadaj przemieszczenie (w podpartym węźle) · Usuń |
| Element | Edytuj element (węzły i przeguby, materiał, przekrój) · Dodaj obciążenie · Macierz sztywności · Usuń |
| Obciążenie węzłowe lub elementu | Edytuj obciążenie · Usuń |
| Linia wymiarowa | Edytuj (współrzędne) · Odwróć wymiar · Usuń |
