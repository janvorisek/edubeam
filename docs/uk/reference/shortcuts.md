# Клавіатура, миша та сенсорний екран

Гарячі клавіші працюють, коли фокус у вікні перегляду. Вони ігноруються, поки ви вводите текст у клітинці таблиці чи в діалозі; спершу клацніть полотно.

## Клавіатура {#keyboard}

| Комбінація | Дія |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Скасувати |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Повторити |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Зберегти проєкт (завантажити JSON) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Відкрити проєкт |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Експорт зображення |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Виділити все |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Копіювати виділення (вузли, елементи та їхні навантаження) |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Вставити: напівпрозора копія рухається за курсором; клацніть, щоб її розмістити, або введіть зсув Δx, Δz на панелі вгорі й натисніть **Вставити** |
| <kbd>Delete</kbd> | Видалити виділення |
| <kbd>Esc</kbd> | Скасувати поточний режим миші, закрити огляд, зняти виділення або вийти з клітинки таблиці |
| <kbd>Enter</kbd> | Підтвердити значення в клітинці таблиці |
| <kbd>F</kbd> | Вмістити на екран |
| <kbd>C</kbd> | Центрувати вміст |
| <kbd>G</kbd> | Показати/сховати сітку |
| <kbd>S</kbd> | Увімкнути/вимкнути прив'язку до сітки |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Збільшити / зменшити масштаб |

На Mac використовуйте <kbd>Cmd</kbd> там, де вказано <kbd>Ctrl</kbd>.

## Миша {#mouse}

| Дія | Результат |
| --- | --- |
| Клацання | Вибрати вузол, елемент, навантаження чи розмірну лінію й відкрити його панель |
| Перетягування по порожньому полотну | Прямокутник виділення |
| Перетягування вузла | Перемістити вузол (прив'язується до сітки, коли прив'язку ввімкнено) |
| Клацання в режимі миші | Розмістити вузол або почати чи продовжити ламану з елементів |
| Подвійне клацання по навантаженню | Редагувати навантаження |
| Клацання правою кнопкою | Меню полотна: Додати вузол, Додати елемент, Додати розмір, Проставити розмір елемента (над елементом), Редагувати, Копіювати, Вставити, Видалити |
| <kbd>Ctrl</kbd> (<kbd>Cmd</kbd> на Mac) + Додати вузол / Додати елемент у меню полотна | Розмістити мишею замість діалогу |
| Перетягування середньою або правою кнопкою | Панорамування (див. *Налаштування → Керування та гарячі клавіші*) |
| Колесо | Масштабування в бік курсора |
| Наведення на об'єкт | Підказка з переміщеннями, властивостями чи значеннями навантаження |

На тачпаді прокручування двома пальцями змінює масштаб. Щоб панорамувати, клацніть і перетягніть двома пальцями (перетягування правою кнопкою).

## Сенсорний екран {#touch}

| Жест | Результат |
| --- | --- |
| Дотик | Вибрати й показати відомості та дії для об'єкта |
| Дотик у режимі миші | Розмістити вузол або продовжити елемент |
| Натиснути на вузол і перетягнути | Перемістити вузол |
| Перетягування одним пальцем в іншому місці | Панорамування |
| Зведення / розведення пальців | Масштабування |
| Натиснути й утримувати полотно | Меню полотна |
| Кнопка **Виділення рамкою** (угорі праворуч), потім перетягування | Прямокутник виділення |

## Панелі об'єктів {#object-panels}

Клацання по об'єкту відкриває поруч із ним панель із відомостями та такими діями:

| Об'єкт | Дії |
| --- | --- |
| Вузол | Додати навантаження · Опори вузла (умовне позначення опори, Dx / Dz / Ry, кут локальної системи координат вузла) · Задати переміщення (для вузла з опорою) · Видалити |
| Елемент | Редагувати елемент (вузли й шарніри, матеріал, переріз) · Додати навантаження · Матриця жорсткості · Видалити |
| Вузлове навантаження або навантаження на елемент | Редагувати навантаження · Видалити |
| Розмірна лінія | Редагувати (координати) · Змінити напрям розміру · Видалити |
