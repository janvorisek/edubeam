# यूज़र इंटरफ़ेस

<Edubeam /> में तीन क्षेत्र हैं। जान लें कि क्या कहाँ है, तो बाकी दस्तावेज़ीकरण अपने आप समझ में आएगा।

::: tip इंटरफ़ेस की भाषा
ऐप का इंटरफ़ेस अभी हिन्दी में नहीं है; सभी बटन, टैब और सेटिंग्स के नाम अंग्रेज़ी में ठीक वैसे ही दिए गए हैं जैसे वे ऐप में दिखते हैं।
:::

## व्यूअर

कैनवास वह जगह है जहाँ आप मॉडल बनाते और जाँचते हैं। ऐप की बाकी हर चीज़ यहाँ के चयन को दर्शाती है।

### ओवरले बटन

- **ऊपर-बाएँ:** **Undo** / **Redo** (पूर्ववत / पुनः करें; <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> भी)। मॉडल का हर बदलाव—जोड़ना, संपादित करना, खींचना, हटाना—पूर्ववत किया जा सकता है।
- **ऊपर-दाएँ:** **Center content** (<kbd>C</kbd>), **Fit content to screen** (<kbd>F</kbd>) और **प्रदर्शन सेटिंग्स** टॉगल ⚙।
- **नीचे-दाएँ:** **G** ग्रिड को टॉगल करता है, **S** ग्रिड-स्नैप को; **इकाइयों की चिप** सक्रिय इकाइयाँ दिखाती है और क्लिक करने पर सेटिंग्स खोलती है।

### प्रदर्शन सेटिंग्स पैनल

⚙ बटन से खोलें। चेकबॉक्स की दो पंक्तियाँ:

- **Results:** *Deformed shape*, *N (x)*, *V<sub>z</sub> (x)*, *M<sub>y</sub> (x)*, *Reactions*।
- **Model:** *Supports*, *Loads*, *Node labels*, *Element labels*।

**More settings** पूरा [सेटिंग्स संवाद](/hi/essentials/units-settings) खोलता है।

### नेविगेशन

| क्रिया | माउस / टच |
| --- | --- |
| ज़ूम | माउस व्हील (कर्सर की ओर ज़ूम), <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd>; टच स्क्रीन पर पिंच |
| पैन | **मध्य या दायाँ** माउस बटन दबाकर खींचें (*Settings → Controls & Shortcuts* में बदला जा सकता है); टच पर एक उँगली से खींचें |
| फिट / केंद्रित | <kbd>F</kbd> / <kbd>C</kbd> या ऊपर-दाएँ के बटन |

### चयन और संपादन

- किसी नोड, अवयव, भार या विमा रेखा (dimension line) को चुनने के लिए उस पर **क्लिक** करें। निचली पट्टी संबंधित टैब पर चली जाती है और चयन के पास एक छोटा **पॉपओवर मेनू** दिखता है, जिसमें उस वस्तु के लिए उपलब्ध क्रियाएँ होती हैं (जैसे *Add load*, *Node supports*, *Edit element*, *Stiffness matrix*, *Delete*)।
- चयन आयत बनाने के लिए **खाली कैनवास पर खींचें**। उसके भीतर की हर चीज़—नोड, अवयव, उनके भार और विमा रेखाएँ—चयनित हो जाती है। सब हटाने के लिए <kbd>Delete</kbd> दबाएँ, कहीं और कॉपी-पेस्ट करने के लिए <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd>।
- नोड को खिसकाने के लिए **उसे खींचें**। स्नैप चालू हो तो वह ग्रिड पर बैठता है। जुड़े अवयव और उनके भार साथ चलते हैं।
- भार को संपादित करने के लिए **उस पर डबल-क्लिक** करें।
- टूलटिप के लिए किसी भी चीज़ पर **होवर** करें: नोड अपने विस्थापन और घूर्णन दिखाते हैं, अवयव अपनी सामग्री और अनुप्रस्थ काट, भार अपने घटक।
- कैनवास मेनू के लिए **खाली कैनवास पर राइट-क्लिक** करें: *Add node*, *Add element*, *Add dimension*, *Edit* (वर्तमान चयन की तालिका खोलता है), *Copy*, *Paste*, *Delete*। *Add node* / *Add element* चुनते समय <kbd>Ctrl</kbd> दबाए रखें ताकि वे संवाद की बजाय माउस से रखे जाएँ।

सभी शॉर्टकट [कीबोर्ड और माउस](/hi/reference/shortcuts) पृष्ठ पर सूचीबद्ध हैं।

### चेतावनियाँ

कुछ गलत होने पर व्यूअर के ऊपर-बाएँ संदेश दिखते हैं: *No materials defined* / *No cross sections defined* (एक **Add new** बटन के साथ) या *Model has N error(s)*, जिसके **Show details** बटन से हर समस्या की सूची मिलती है। ये संदेश अभी अंग्रेज़ी में ही दिखते हैं। देखें [समस्या निवारण](/hi/reference/troubleshooting)।

## निचली पट्टी

छह टैब, हर एक में एक गिनती बैज, एक टूलबार और एक संपादन योग्य तालिका। आकार बदलने के लिए पट्टी के ऊपर के विभाजक को खींचें, या दाईं ओर के बटन से उसे छोटा करें।

| टैब | टूलबार | तालिका |
| --- | --- | --- |
| **Nodes** | Add node (संवाद), Add using mouse | लेबल, X, Z, **Supported DOFs** चेकबॉक्स, नोड पर भार, हटाएँ |
| **Elements** | Add element (संवाद), Add using mouse | लेबल, प्रकार, प्रारंभिक/अंतिम नोड (+ *Swap nodes*), सामग्री, अनुप्रस्थ काट, **End hinges**, अवयव पर भार, दृढ़ता मैट्रिक्स, हटाएँ |
| **Loads** | Add nodal load, Add element load | प्रकार, लक्ष्य, संपादन योग्य घटक, हटाएँ |
| **Materials** | Add material, Material library | लेबल, E, G, α<sub>T</sub>, हटाएँ |
| **Cross sections** | Add cross section, Section library | लेबल, A, I<sub>y</sub>, h, k, हटाएँ |
| **Results** | Nodal results / Element results स्विच | प्रति नोड विस्थापन और घूर्णन, या प्रति अवयव सिरा-बल |

कोशिकाएँ वहीं संपादित होती हैं—क्लिक करें, टाइप करें, <kbd>Enter</kbd> दबाएँ (या कोशिका छोड़ने के लिए <kbd>Esc</kbd>)। मान [वर्तमान इकाइयों](/hi/essentials/units-settings) में दिखाए और दर्ज किए जाते हैं।

## व्यूअर के ऊपर के टैब

**Viewer** टैब हमेशा मौजूद रहता है। सेटिंग्स खोलने पर उसके बगल में एक बंद करने योग्य **Settings** टैब जुड़ जाता है, ताकि आप मॉडल देखते हुए रंग या इकाइयाँ समायोजित कर सकें।

## तैरते विजेट

कुछ क्रियाएँ व्यूअर के ऊपर खींचने योग्य विंडो खोलती हैं: **Stiffness matrix** (अवयव के पॉपओवर या तालिका पंक्ति से) अवयव की 6 × 6 दृढ़ता मैट्रिक्स स्थानीय और वैश्विक निर्देशांकों में दिखाती है; कैनवास मेनू का **Edit** वर्तमान चयन की तालिका खोलता है। इन्हें × से बंद करें।
