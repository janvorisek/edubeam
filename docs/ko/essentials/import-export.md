# 가져오기, 내보내기 및 공유

<Edubeam />의 모든 작업은 브라우저 안에서 이루어집니다. 서버에 업로드되는 것은 없습니다. 공유 링크에는 말 그대로 모델이 담겨 있습니다.

## 프로젝트 저장 {#save-a-project}

**☰ → 프로젝트 저장** 또는 <kbd>Ctrl</kbd>+<kbd>S</kbd>를 누르면 `project.json`을 내려받습니다. 이 파일에는 절점, 요소, 재료, 단면(다각형 형상 포함), 하중, 치수선과 파일을 작성한 앱 버전이 들어 있습니다. 파일 이름은 자유롭게 바꿔도 됩니다.

## 프로젝트 열기 {#open-a-project}

- **☰ → 프로젝트 열기** 또는 <kbd>Ctrl</kbd>+<kbd>O</kbd>를 누른 뒤 `.json` 파일을 고르거나,
- **파일을 앱 창의 아무 곳에나 끌어다 놓습니다**.

프로젝트를 열면 재료와 단면을 포함한 현재 모델이 대체됩니다. 이전 모델은 사라지지 않습니다. <kbd>Ctrl</kbd>+<kbd>Z</kbd>로 되돌릴 수 있고, [최근 구조물](#recent-structures)에도 보관됩니다. EduBeam 프로젝트가 아닌 파일은 메시지와 함께 거부되며, 사용자의 모델은 그대로 유지됩니다.

이전 버전의 EduBeam에서 만든 프로젝트 파일도 모두 현재 버전에서 열립니다.

## 링크 공유 {#share-a-link}

**모델 공유**(앱 바 또는 ☰ 메뉴)는 *URL로 모델 공유* 대화 상자를 엽니다.

![공유 대화 상자](/screenshots/ko/share.webp){.shot-lg}

- **복사**는 링크를 클립보드에 복사합니다. 입력란 안을 클릭해도 같습니다.
- **링크 열기**는 링크를 새 탭에서 열어 받는 사람이 무엇을 보게 될지 확인할 수 있게 합니다.
- **시스템 공유 창으로 공유**는 브라우저가 지원하는 경우 기기의 공유 시트로 링크를 넘깁니다.
- **짧은 링크**는 같은 모델을 약 절반의 글자 수로 씁니다. 2026년 10월 이후로 업데이트되지 않은 <Edubeam />은 업데이트하기 전까지 이 링크를 읽을 수 없으므로, 링크가 어디서나 바로 열려야 한다면 끈 상태로 두십시오.

링크의 형식은 `https://run.edubeam.app/?model=…`이며 모델 전체가 인코딩되어 있습니다. 링크를 연 사람은 각자 편집할 수 있는 사본을 받고, 편집 내용은 원본으로 동기화되지 **않습니다**. 따라서 모델이 바뀌면 새 링크를 보내십시오. 모델이 아주 크면 링크도 아주 길어지므로 그럴 때는 JSON 파일을 공유하십시오.

누군가 링크를 열면 그 사람이 작업하던 이전 모델은 최근 구조물로 옮겨지고, 어디서 찾을 수 있는지 메시지로 알려 줍니다.

이전 버전에서 만든 링크도 계속 작동합니다. 작년 강의 노트의 링크는 오늘도 같은 모델을 엽니다.

## 이미지 내보내기 {#export-an-image}

**☰ → 이미지 내보내기** 또는 <kbd>Ctrl</kbd>+<kbd>P</kbd>로 이미지 내보내기를 엽니다.

![이미지 내보내기: 레이어, 영역, 크기를 고른 다음 다운로드하거나 복사합니다](/screenshots/ko/export-image.webp)

- **레이어**: 위쪽의 칩으로 그릴 항목을 뷰어와 별개로 고릅니다. 변형 형상, N, V, M, 반력, 지점, 하중, 절점 및 요소 이름이 있습니다.
- **영역**: 화면 비율(16:9, 4:3, 3:2, 1:1), **전체 맞춤**, 또는 그림 위에 사각형을 드래그하는 **영역…** 중에서 고릅니다. 미리보기의 가장자리를 드래그할 수도 있습니다.
- **크기**: 픽셀 단위의 너비와 높이, 또는 종이에 축척대로 그릴 때 쓰는 1 : 50 같은 **축척**. **다이어그램 높이**는 이미지 속 결과 다이어그램의 크기를 정합니다. **투명 배경**은 흰색 배경을 뺍니다.
- **PNG 다운로드**, **SVG 다운로드** 또는 **클립보드에 복사**.

SVG는 어떤 크기에서도 선명하며 Word, Inkscape, Overleaf의 LaTeX에서 쓸 수 있으므로 보고서와 학위 논문에 가장 좋습니다.

## 결과 내보내기 {#export-the-results}

**결과 → CSV 내보내기**는 반력을 포함한 두 결과 표를 내려받고, **복사**는 스프레드시트에 붙여 넣을 수 있도록 클립보드에 넣습니다. [CSV 내보내기와 복사](/ko/essentials/results#export-csv-and-copy)를 참고하십시오.

## 최근 구조물 {#recent-structures}

**☰ → 최근 구조물**에는 지웠거나 링크, 파일, 예제, 첫 번째 보 과제로 대체된 최근 모델 10개가 보관됩니다. 각 항목에는 썸네일, 대체된 이유, 크기가 표시됩니다. **복원**을 누르면 모델을 되돌리고, 그때 작업하던 모델은 다시 목록에 들어가며, <kbd>Ctrl</kbd>+<kbd>Z</kbd>로 복원을 취소할 수 있습니다.

![최근 구조물](/screenshots/ko/recent.webp){.shot-lg}

이 목록은 현재 브라우저에만 저장됩니다.

**☰ → 예제**는 미리 만들어진 교육용 모델 갤러리를 엽니다. 예제를 열면 현재 모델이 대체되며, <kbd>Ctrl</kbd>+<kbd>Z</kbd>로 되돌릴 수 있습니다. 같은 모델과 연습 문제가 이 사용 설명서의 [예제](/ko/examples/) 페이지에 있습니다.

![예제 갤러리](/screenshots/ko/examples.webp){.shot-lg}

## 뷰어 삽입 {#embed-a-read-only-viewer}

공유 링크에 `&viewer=1`을 붙이면 모델이 **뷰어 모드**로 열립니다. 앱 바, 하단 바, 탭, 실행 취소와 다시 실행, 그리드 칩, 좌표축 표시가 숨겨지고 캔버스, 화면 맞춤과 가운데 맞춤 버튼, 표시 옵션만 남습니다. 이 URL을 `<iframe>`에 넣으면 확대/축소할 수 있는 실시간 모델을 강의 노트나 웹 페이지에 삽입할 수 있습니다.

```html
<iframe src="https://run.edubeam.app/?viewer=1&model=…" width="100%" height="400"></iframe>
```

![뷰어 모드의 3힌지 라멘](/screenshots/ko/viewer-mode.webp){.shot-lg}

뷰어 모드는 보기용이지만 잠겨 있지는 않습니다. 방문자는 여전히 절점을 드래그하고 다이어그램을 전환할 수 있습니다. 뷰어 링크를 열어도 일반 링크와 마찬가지로 그 브라우저에 있던 방문자의 모델이 대체됩니다(최근 구조물로 옮겨짐).

## URL 매개변수 {#url-parameters}

| 매개변수 | 효과 |
| --- | --- |
| `model=<data>` | 인코딩된 모델을 불러와 화면에 맞춥니다. |
| `viewer=1` | 뷰어 모드(위 참고). |
| `lang=<code>` | 인터페이스 언어를 바꿉니다: `en`, `cs`, `de`, `fr`, `es`, `pt`, `pl`, `cn`, `th`, `uk`, `ru`, `tr`, `hi`, `vi`, `it`, `id`, `ja`, `ko`. |
| `panel=examples` | 예제 갤러리를 바로 엽니다. |

EduBeam은 매개변수를 읽은 뒤 주소 표시줄에서 지웁니다.

## 자동 저장 {#automatic-persistence}

현재 모델과 설정은 변경할 때마다 브라우저의 로컬 스토리지에 저장되고, 브라우저를 닫았다가 다시 와도 복원됩니다. 이는 편의 기능일 뿐 백업이 아닙니다. 한 기기의 한 브라우저 프로필에만 속하며, 사이트 데이터를 지우면 사라집니다. 중요한 작업은 프로젝트 파일로 저장하십시오.

## 프로젝트 파일 형식 {#project-file-format}

`project.json`은 사람이 읽을 수 있는 일반 JSON입니다.

```json
{
  "edubeam": true,
  "version": "1.3.1",
  "domain": {
    "materials": [{ "label": "1", "e": 210000000000, "g": 81000000000, "alpha": 0.000012, "d": 7850 }],
    "crossSections": [{ "label": "1", "a": 0.00285, "iy": 1.943e-5, "h": 0.2, "k": 1 }],
    "nodes": [
      { "label": "1", "coords": [0, 0, 0], "bcs": [0, 2] },
      { "label": "2", "coords": [6, 0, 0], "bcs": [2] }
    ],
    "elements": [{ "label": "1", "nodes": ["1", "2"], "mat": "1", "cs": "1", "hinges": [false, false] }],
    "loadCases": [
      {
        "label": "1",
        "nodalLoads": [],
        "elementLoads": [{ "type": "udl", "target": "1", "lcs": false, "values": [0, 12000] }],
        "prescribedBC": []
      }
    ]
  },
  "dimensions": []
}
```

빠른 시작의 보입니다. 표시 단위와 관계없이 모든 값은 **SI 단위**(m, N, Pa, rad)입니다. 좌표는 `[x, y, z]`이며 y는 항상 0입니다. 경계 조건과 하중 성분은 자유도 번호 `0 = Dx`, `2 = Dz`, `4 = Ry`를 씁니다.

| 요소 하중 `type` | 값 |
| --- | --- |
| `udl` | `values: [fx, fz]`, N/m |
| `trapezoidal` | `startValues: [f1x, f1z]`, `endValues: [f2x, f2z]`, N/m, 국부 좌표축 |
| `concentrated` | `values: [Fx, Fz, My, a]`, N, N·m, 시작 절점으로부터의 거리 m |
| `temperature` | `values: [ΔTc, ΔTb, ΔTt]`, K; 온도 기울기는 ΔTb − ΔTt |

절점 하중은 `{ "target": "2", "values": { "0": Fx, "2": Fz, "4": My } }`, 강제 변위는 `{ "target": "2", "prescribedValues": { "0": Dx, "2": Dz, "4": Ry } }`이며, 세 성분을 모두 지정해야 합니다. 앱이 작성한 파일에는 `date`, `commit`, 절점 `lcs`, 다각형 `shape`도 들어 있습니다.

형식이 단순하므로 스크립트나 스프레드시트로 모델을 생성한 뒤 **프로젝트 열기**로 열 수 있습니다.
