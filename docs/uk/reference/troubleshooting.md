# Усунення несправностей

## Результати не відображаються {#no-results-are-drawn}

Результати з'являються лише тоді, коли модель можна розрахувати. Перевірте в такому порядку:

1. **Прочитайте повідомлення в лівому верхньому куті вікна перегляду.**
   - *Матеріали не визначено.* / *Перерізи не визначено.*: додайте їх кнопкою **Додати**.
   - Синій чип **Потрібні опори**: модель просто не завершена. Додайте опори. Наведіть курсор на чип, щоб побачити у вигляді пунктирного контуру, як конструкція ще може рухатися.
   - **Червоне повідомлення**: щось не так. Воно називає проблему або, коли їх кілька, показує *Помилок у моделі: N*. Натисніть **Показати деталі** й виправте кожен пункт (див. таблицю нижче). Відповідні вузли чи шарніри обведено на полотні.
   - **Жовте повідомлення**: попередження. Модель однаково розраховано; їх можна сховати.
2. **Чи достатньо опор?** Розв'язувачу потрібно щонайменше три закріплені ступені вільності, і опори мають утримувати конструкцію. Балка на двох шарнірно-рухомих опорах (Dz + Dz) має лише два й зісковзує. Додайте десь `Dx` або `Ry` на одній з опор.
3. **Чи з'єднано елементи?** Два вузли з однаковими координатами — це все одно два окремі вузли. Видаліть зайвий і з'єднайте заново або розміщуйте вузли на елементах за допомогою **З'єднати з конструкцією**.
4. **Забагато шарнірів?** Шарніри на обох кінцях колони або квадрат із шарнірно з'єднаних стрижнів без розкосу утворюють механізм. EduBeam обводить шарніри й показує рух.
5. **Нульова жорсткість?** `E`, `A` чи `Iy`, випадково введені як 0 або в неправильних одиницях, дають частині конструкції змогу рухатися майже без опору. EduBeam повідомляє про це як про *нестійкість*.

## Повідомлення {#messages}

**Показати деталі** відкриває діалог із заголовком *Неможливо розрахувати модель* (помилки), *Модель ще не готова до розрахунку* (ще потрібні опори) або *Попередження моделі*. Його посилання **Усунення несправностей** веде сюди.

### Залишилося додати {#still-needed}

| Повідомлення | Значення / виправлення |
| --- | --- |
| *Конструкції потрібні опори, інакше її не можна розрахувати.* | Загалом менше трьох закріплених ступенів вільності. Додайте опори. |
| *Окрема частина конструкції (вузли …) має менше ніж 3 закріплені ступені вільності й може вільно переміщуватися.* | Модель складається з частин, і одна з них «плаває». З'єднайте її або закріпіть. |

### Помилки {#errors}

| Повідомлення | Значення / виправлення |
| --- | --- |
| *Конструкція має достатньо опор, але вони її не утримують: вона все ще може …* | Усі опори паралельні або їхні лінії дії перетинаються в одній точці. Пунктирний контур показує рух; змініть напрям однієї з опор. Якщо зачеплено лише одну частину, те саме повідомлення називає *окрему частину*. |
| *Опори утримують конструкцію, але вона все одно є механізмом: її стрижні можуть повертатися навколо шарнірів у вузлі …* | Шарніри дають стрижням змогу повертатися один відносно одного, як у рамі із шарнірами вгорі обох колон або в шарнірному квадраті без розкосу. Приберіть шарнір або додайте стрижень чи опору. |
| *Конструкція нестійка, практично без опору можливі: …* | Майже механізм або жорсткість, близька до нуля. Перевірте опори, шарніри та значення `E`, `A` і `Iy`. |
| *Конструкція є механізмом: матриця жорсткості вироджена.* | Щось може вільно рухатися, і перевірки вище цього не виявили. Перевірте, що кожна частина утримується щонайменше трьома в'язями і що шарніри не залишають стрижень вільним до повороту. |
| *Елемент … посилається на відсутній вузол / матеріал / переріз …* | Об'єкт, на який є посилання, видалено, зазвичай у вручну відредагованому файлі JSON. Призначте інший у таблиці *Елементи*. |
| *Елемент … має посилатися рівно на 2 вузли.* | Пошкоджений елемент в імпортованому файлі. Видаліть його й створіть заново. |
| *Вузлове навантаження / Задане переміщення #n посилається на відсутній вузол …* | Видаліть навантаження або призначте йому вузол. |
| *Навантаження на елемент #n посилається на відсутній елемент …* | Видаліть навантаження. |
| *Розрахунок не вдався через внутрішню неузгодженість моделі…* | Загальна помилка. Скасуйте останній крок або збережіть файл і [повідомте про неї](https://github.com/janvorisek/edubeam/issues). |

### Попередження {#warnings}

Модель однаково розраховано, але перевірте таке:

| Повідомлення | Значення / виправлення |
| --- | --- |
| *Вузол … не з'єднаний із жодним елементом і не враховується в розрахунку.* | Зайвий вузол. Видаліть його або приєднайте. |
| *Вузол … має опору, але до нього не приєднано жодного елемента, тож опора нічого не сприймає.* | Опора на зайвому вузлі. |
| *Елемент … посилається на той самий вузол на обох кінцях.* | Елемент нульової довжини. Видаліть його. |
| *Вузлове навантаження / Задане переміщення #n містить некоректні значення.* | Компонент, що не є числом. Відредагуйте навантаження. |

## Результати виглядають неправильно {#results-look-wrong}

| Симптом | Імовірна причина |
| --- | --- |
| Навантаження діють угору | Глобальна вісь **z спрямована вниз**, тож додатне `Fz`/`fz` діє вниз. Від'ємні значення спрямовані вгору. Див. [правила знаків](/uk/elements/conventions). З осями y вгору — навпаки. |
| Прогин у 1000 разів завеликий чи замалий | Плутанина з одиницями: `E` введено в Pa, коли одиниця MPa, або `Iy` у cm⁴, коли одиниця m⁴. Перевірте чип одиниць у правому нижньому куті вікна перегляду. |
| Прогин трохи більший, ніж за формулою з підручника | Деформація зсуву Тимошенка. Збільште коефіцієнт зсуву перерізу або використайте гнучкіший стрижень, щоб наблизитися до значень Ейлера–Бернуллі. Див. [Перевірка результатів вручну](/uk/guide/verification). |
| Знак здається «неправильним» | Визначайте знак за підписами, а не за боком епюри. Додатний M — розтяг знизу. Кінцеві зусилля в *Результати по елементах* відповідають локальним осям елемента, а не правилу знаків N-V-M. |
| Дві однакові колони мають протилежні знаки поперечної сили | Знак V відповідає напряму кожного елемента. Поміняйте вузли одного з них, щоб порівняти. |
| Числа на кшталт `4 · 10¹` | Науковий формат чисел. Виберіть *Автоматичний* у *Налаштування → Мова та локаль → Формат чисел*. |
| Епюри величезні чи крихітні | Суто візуальне. Налаштуйте **Масштаб результатів** у *Налаштування → Налаштування перегляду*. |
| Навантаження в локальних координатах спрямоване не туди | Локальна вісь x елемента йде від його *початкового* до *кінцевого* вузла. Поміняйте вузли або змініть знак. |
| Навантаження на похилий стрижень не таке, як очікувалося | **LCS** типово позначено, тож `fz` діє перпендикулярно до стрижня. Зніміть позначку для вертикального навантаження. |
| Температурне навантаження нічого не робить | Статично визначувана конструкція під дією температури деформується вільно, без внутрішніх зусиль. Перевірте, що α ≠ 0 і, для градієнта, що задано висоту перерізу h. |

## Проблеми з інтерфейсом {#interface-issues}

| Симптом | Виправлення |
| --- | --- |
| Гарячі клавіші не працюють | Спершу клацніть полотно: клавіші ігноруються, поки фокус у текстовому полі. |
| Не вдається панорамувати | Типово панорамування виконується середньою або правою кнопкою миші; змініть це в *Налаштування → Керування та гарячі клавіші*. На тачпаді прокручування двома пальцями змінює масштаб; щоб панорамувати, клацніть і перетягніть двома пальцями. |
| Моя модель зникла | Відкриття посилання, файлу чи прикладу, а також очищення зберігають стару модель: **☰ → Нещодавні моделі** або <kbd>Ctrl</kbd>+<kbd>Z</kbd>. |
| Неправильна мова | *Налаштування → Мова та локаль* або додайте `?lang=uk` до адреси. |
| Зміни налаштувань не зберігаються | Локальне сховище заблоковано (приватне вікно, суворий режим конфіденційності). Воно потрібне для налаштувань, автозбереження й Нещодавніх моделей. |

## Повідомлення про помилку {#reporting-a-bug}

Створіть [issue на GitHub](https://github.com/janvorisek/edubeam/issues), вказавши браузер і ОС, що ви очікували, і, найкорисніше, **посилання** або **файл проєкту**, на якому проблема відтворюється.
