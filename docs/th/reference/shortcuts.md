# แป้นพิมพ์ เมาส์ และระบบสัมผัส

แป้นพิมพ์ลัดทำงานเมื่อหน้าจอแสดงผลได้รับโฟกัส และจะไม่ทำงานขณะคุณพิมพ์ในเซลล์ตารางหรือกล่องโต้ตอบ ให้คลิกบนพื้นที่วาดก่อน

## แป้นพิมพ์ {#keyboard}

| ทางลัด | การทำงาน |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | เลิกทำ |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | ทำซ้ำ |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | บันทึกโปรเจกต์ (ดาวน์โหลด JSON) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | เปิดโปรเจกต์ |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | ส่งออกรูปภาพ |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | เลือกทั้งหมด |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | คัดลอกสิ่งที่เลือก (โหนด เอลิเมนต์ และแรงกระทำบนสิ่งเหล่านั้น) |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | วาง: เงาของสำเนาจะเคลื่อนตามเคอร์เซอร์ คลิกเพื่อวาง หรือพิมพ์ระยะเลื่อน Δx, Δz ในแถบประกาศแล้วกด **วาง** |
| <kbd>Delete</kbd> | ลบสิ่งที่เลือก |
| <kbd>Esc</kbd> | ยกเลิกโหมดเมาส์ปัจจุบัน ปิดทัวร์ ล้างการเลือก หรือออกจากเซลล์ตาราง |
| <kbd>Enter</kbd> | ยืนยันค่าในเซลล์ตาราง |
| <kbd>F</kbd> | ปรับเนื้อหาให้พอดีกับหน้าจอ |
| <kbd>C</kbd> | จัดเนื้อหาให้อยู่กึ่งกลาง |
| <kbd>G</kbd> | เปิด/ปิดกริด |
| <kbd>S</kbd> | เปิด/ปิดการสแนปกับกริด |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | ซูมเข้า / ซูมออก |

บน Mac ให้ใช้ <kbd>Cmd</kbd> แทน <kbd>Ctrl</kbd>

## เมาส์ {#mouse}

| การกระทำ | ผลลัพธ์ |
| --- | --- |
| คลิก | เลือกโหนด เอลิเมนต์ แรงกระทำ หรือเส้นบอกขนาด และเปิดแผงของสิ่งนั้น |
| ลากบนพื้นที่วาดที่ว่าง | กรอบเลือก |
| ลากโหนด | ย้ายโหนด (สแนปกับกริดเมื่อเปิดการสแนป) |
| คลิกในโหมดเมาส์ | วางโหนด หรือเริ่มหรือต่อเส้นต่อเนื่องของเอลิเมนต์ |
| ดับเบิลคลิกแรงกระทำ | แก้ไขแรงกระทำ |
| คลิกขวา | เมนูพื้นที่วาด: เพิ่มโหนด เพิ่มเอลิเมนต์ เพิ่มเส้นบอกขนาด บอกขนาดเอลิเมนต์ (เมื่ออยู่บนเอลิเมนต์) แก้ไข คัดลอก วาง ลบ |
| <kbd>Ctrl</kbd> (<kbd>Cmd</kbd> บน Mac) + เพิ่มโหนด / เพิ่มเอลิเมนต์ ในเมนูพื้นที่วาด | วางด้วยเมาส์แทนกล่องโต้ตอบ |
| ลากด้วยปุ่มกลางหรือปุ่มขวา | เลื่อนมุมมอง (ดู *การตั้งค่า → การควบคุมและทางลัด*) |
| ล้อเมาส์ | ซูมเข้าหาเคอร์เซอร์ |
| ชี้ที่วัตถุ | Tooltip แสดงการกระจัด คุณสมบัติ หรือค่าแรงกระทำ |

บนทัชแพด การเลื่อนด้วยสองนิ้วจะซูม ถ้าต้องการเลื่อนมุมมอง ให้คลิกแล้วลากด้วยสองนิ้ว (เท่ากับการลากด้วยปุ่มขวา)

## ระบบสัมผัส {#touch}

| ท่าทาง | ผลลัพธ์ |
| --- | --- |
| แตะ | เลือก และแสดงรายละเอียดกับการดำเนินการของวัตถุ |
| แตะในโหมดเมาส์ | วางโหนดหรือต่อเอลิเมนต์ |
| กดที่โหนดแล้วลาก | ย้ายโหนด |
| ลากนิ้วเดียวที่ตำแหน่งอื่น | เลื่อนมุมมอง |
| จีบนิ้ว | ซูม |
| กดค้างบนพื้นที่วาด | เมนูพื้นที่วาด |
| ปุ่ม **เลือกแบบกรอบ** (มุมขวาบน) แล้วลาก | กรอบเลือก |

## แผงของวัตถุ {#object-panels}

การคลิกวัตถุจะเปิดแผงข้าง ๆ พร้อมรายละเอียดและการดำเนินการต่อไปนี้:

| วัตถุ | การดำเนินการ |
| --- | --- |
| โหนด | เพิ่มแรงกระทำ · จุดรองรับของโหนด (สัญลักษณ์จุดรองรับ, Dx / Dz / Ry, มุมระบบพิกัดท้องถิ่นของโหนด) · กำหนดการกระจัด (บนโหนดที่มีจุดรองรับ) · ลบ |
| เอลิเมนต์ | แก้ไขเอลิเมนต์ (โหนดและจุดหมุน วัสดุ หน้าตัด) · เพิ่มแรงกระทำ · เมทริกซ์ความแข็ง · ลบ |
| แรงกระทำที่โหนดหรือที่เอลิเมนต์ | แก้ไขแรงกระทำ · ลบ |
| เส้นบอกขนาด | แก้ไข (พิกัด) · กลับด้านเส้นบอกขนาด · ลบ |
