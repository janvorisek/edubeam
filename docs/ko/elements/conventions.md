# 좌표계 및 부호 규약

<Edubeam />에서 "틀린" 결과처럼 보이는 것은 대부분 부호 규약 때문에 생긴 오해입니다. 아래 내용은 모두 솔버가 실제로 쓰는 규약입니다.

## 전체 좌표축 {#global-axes}

- **x** — 수평, **오른쪽**이 양.
- **z** — 연직, 화면에서 **아래**가 양.
- **y** — 면외 축(오른손 좌표계에서 보는 사람 쪽을 향함). 회전과 모멘트는 y축에 대한 것입니다.

그리드 모서리의 좌표축 표시는 x(빨간색)와 z(녹색)를 보여 줍니다. 따라서 하단이 `Z = 0`인 3 m 기둥의 꼭대기 절점은 `Z = −3`입니다.

## 자유도 {#degrees-of-freedom}

각 절점에는 `Dx`, `Dz`(이동)와 `Ry`(회전)가 있습니다. 양의 `Dz`는 아래 방향 변위이고, 양의 `Ry`는 화면에서 **반시계 방향** 회전입니다. 강제변위와 절점 결과에도 같은 부호가 적용됩니다.

## 하중 {#loads}

| 하중 | 양의 방향 |
| --- | --- |
| `Fx`, `fx`, `f1x`… | +x(오른쪽, LCS가 켜져 있으면 요소의 국부 x 방향) |
| `Fz`, `fz`, `f1z`… | +z(**아래**, LCS가 켜져 있으면 국부 z 방향) |
| `My` | 화면에서 반시계 방향 |
| `ΔTc` | 가열(신장) |
| `ΔTb − ΔTt` | 하연이 상연보다 따뜻함 |

따라서 중력 하중은 **양의** `fz`이고, 왼쪽 기둥을 오른쪽으로 미는 풍하중은 양의 `fx`입니다.

## 요소 국부 좌표축 {#element-local-axes}

국부 **x**축은 시작 절점에서 끝 절점으로 향하고, 국부 **z**축은 그에 수직이며 전체 좌표축을 요소 각도 $\alpha$만큼 회전해 얻습니다. 왼쪽에서 오른쪽으로 그린 수평 요소에서는 국부 좌표축과 전체 좌표축이 일치합니다. 방향을 뒤집으려면 *요소* 표에서 **절점 교환**을 쓰세요.

## 부재력 {#internal-forces}

| 물리량 | 양의 의미 |
| --- | --- |
| **N** | 인장 |
| **V<sub>z</sub>** | 보 이론의 일반적인 부호: 중력 하중을 받는 단순보에서 V는 왼쪽 지점에서 양, 오른쪽 지점에서 음 |
| **M<sub>y</sub>** | **아래로 처지는 휨(정모멘트)** — 하연(+z 쪽)이 인장. 중력 하중을 받는 단순보는 경간 중앙 모멘트가 양이고, 자유단 하중을 받는 캔틸레버는 고정단에서 음의 모멘트(부모멘트)를 가집니다 |

## 단부력(요소 결과 표) {#end-forces-element-results-table}

`X12, Z12, M12`는 시작 절점에서, `X21, Z21, M21`은 끝 절점에서 요소에 작용하며, **국부** 좌표계 기준이고 양의 방향은 국부 좌표축 및 `My`와 같습니다. 이 값은 절점이 요소에 가하는 힘, 즉 $\mathbf{f} = \mathbf{K}_l\,\mathbf{u}_l - \mathbf{f}_{eq}$이며, 여기서 $\mathbf{f}_{eq}$는 요소하중의 등가 절점하중입니다. 한 절점에 모이는 모든 요소의 단부력을 합하면 그 절점의 절점하중 및 반력과 평형을 이룹니다.

## 반력 {#reactions}

반력은 구속된 모든 자유도에 존재하며, 절점 좌표계(절점 좌표계 각도가 설정되어 있으면 그만큼 회전된 좌표계)로 표시됩니다. 뷰어의 반력 화살표는 지점이 구조물을 미는 방향을 가리킵니다.

## y 위 좌표축 {#y-up-axes}

**설정 → 좌표계 → x 오른쪽, y 위**를 고르면 입력하고 읽는 모든 값이 교과서 좌표계로 바뀝니다. **x**는 오른쪽, **y**는 위, **z**는 보는 사람 쪽입니다. 모델, 저장된 파일, 그림은 그대로이며 숫자와 이름만 바뀝니다.

| 물리량 | z 아래(기본값) | y 위 |
| --- | --- | --- |
| 연직 좌표 | `Z` | `Y`, 부호 반대 |
| 연직 하중, 변위, 반력, 단부력 | `Fz`, `fz`, `Dz`, `Z12`… | `Fy`, `fy`, `Dy`, `Y12`…, 부호 반대 |
| 회전과 모멘트 | `Ry`, `My` | `Rz`, `Mz`, 부호 같음(반시계 방향이 양) |
| 지점 각도 α | 시계 방향으로 측정 | 반시계 방향으로 측정, 부호 반대 |
| 부재력 N, V, M | | 변화 없음, 다이어그램도 같은 방식으로 그려짐 |

따라서 중력 하중은 **음의** `fy`이고, 3 m 기둥의 꼭대기는 `Y = 3`입니다.

## 단위 {#units}

솔버는 내부적으로 SI 단위(m, N, Pa, rad, K)로 계산합니다. 표시 단위는 입력하고 읽는 값에만 영향을 주며, 단위를 바꿔도 모델은 절대 바뀌지 않습니다.
