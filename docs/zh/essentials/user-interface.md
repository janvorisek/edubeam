# 用户界面

<Edubeam /> 分为三个区域。弄清楚每样东西在哪里，文档的其余部分就容易理解了。

```
┌──────────────────────────────────────────────────────────────┐
│ ☰  edubeam        🗑 清空结构   🔗 分享模型     更新内容      │  ← 应用栏
├──────────────────────────────────────────────────────────────┤
│ 视图 | 设置                                                  │  ← 标签页
│ ↶ ↷                                        ⌖  ⤢  ⚙            │
│                                                              │
│                     画布（模型）                [显示         │  ← 视图
│                                                   开关]      │
│                                       G  S  m·kN·kNm·MPa     │
├──────────────────────────────────────────────────────────────┤
│ 节点 | 单元 | 荷载 | 材料 | 截面 | 结果                       │  ← 底部栏
│ [添加节点] [通过鼠标添加]           对象表格 …               │
└──────────────────────────────────────────────────────────────┘
```

## 应用栏

| 控件 | 作用 |
| --- | --- |
| **☰ 菜单** | **打开项目**、**保存项目**、**分享模型**、**清空结构**，以及应用版本号。 |
| **清空结构** 🗑 | 确认后删除所有节点、单元和荷载。两个复选框可以同时删除材料和截面。不可撤销。 |
| **分享模型** 🔗 | 打开[分享对话框](/zh/essentials/import-export#分享链接)，其中的 URL 编码了整个模型。 |
| **更新内容** | 版本更新说明。 |
| **文档** / GitHub | 指向本站点和源代码的链接。 |

在[查看器模式](/zh/essentials/import-export#嵌入只读查看器)下应用栏是隐藏的。

## 视图

画布是你绘制和查看模型的地方。应用中的其他所有部分都跟随你在这里的选择。

### 悬浮按钮

- **左上角：** **撤销** / **重做**（也可用 <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>）。模型的每一次更改——添加、编辑、拖动、删除——都可以撤销。
- **右上角：** **居中显示**（<kbd>C</kbd>）、**适配屏幕**（<kbd>F</kbd>）以及**显示设置**开关 ⚙。
- **右下角：** **G** 切换网格，**S** 切换吸附到网格；**单位标记**显示当前单位，点击可打开设置。

### 显示设置面板

用 ⚙ 按钮打开。两行复选框：

- **结果：** *变形图*、*N (x)*、*V<sub>z</sub> (x)*、*M<sub>y</sub> (x)*、*支反力*。
- **模型：** *支座*、*荷载*、*节点标签*、*单元标签*。

**更多设置**打开完整的[设置对话框](/zh/essentials/units-settings)。

### 导航

| 操作 | 鼠标 / 触摸 |
| --- | --- |
| 缩放 | 鼠标滚轮（朝光标位置缩放）、<kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd>；触摸屏上双指捏合 |
| 平移 | 用**中键或右键**拖动（可在 *设置 → 控制与快捷键* 中配置）；触摸屏上单指拖动 |
| 适配 / 居中 | <kbd>F</kbd> / <kbd>C</kbd> 或右上角的按钮 |

### 选择与编辑

- **点击**节点、单元、荷载或尺寸标注即可选中。底部栏会跳到对应的标签页，同时选中对象旁边会出现一个小的**弹出菜单**，列出该对象可用的操作（例如 *添加荷载*、*节点支座*、*编辑单元*、*刚度矩阵*、*删除*）。
- **在空白画布上拖动**可绘制选择框。框内的所有内容——节点、单元、它们的荷载以及尺寸标注——都会被选中。按 <kbd>Delete</kbd> 全部删除，按 <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd> 复制并粘贴到别处。
- **拖动节点**可移动它。开启吸附后它会落在网格上。相连的单元及其荷载会跟随移动。
- **双击荷载**可编辑它。
- **悬停**在任何对象上可显示提示：节点显示位移和转角，单元显示材料和截面，荷载显示分量。
- **在空白画布上右键**打开画布菜单：*添加节点*、*添加单元*、*添加标注*、*编辑*（打开当前选择的表格）、*复制*、*粘贴*、*删除*。选择 *添加节点* / *添加单元* 时按住 <kbd>Ctrl</kbd>，可以用鼠标放置而不是通过对话框。

所有快捷键列在[键盘与鼠标](/zh/reference/shortcuts)页面。

### 提示消息

出现问题时，视图左上角会显示消息：*尚未定义材料。* / *尚未定义截面。*（带有**新增**按钮），或 *Model has N error(s)*，并带有一个 **Show details** 按钮列出每个问题（求解器消息目前仅以英文显示）。参见[故障排除](/zh/reference/troubleshooting)。

## 底部栏

六个标签页，每个都带有数量徽标、工具栏和可编辑的表格。拖动底部栏上方的分隔线可以调整高度，或用右侧的按钮将其最小化。

| 标签页 | 工具栏 | 表格 |
| --- | --- | --- |
| **节点** | 添加节点（对话框）、通过鼠标添加 | 标签、X、Z、**受约束自由度**复选框、节点上的荷载、删除 |
| **单元** | 添加单元（对话框）、通过鼠标添加 | 标签、类型、起始/终止节点（+ *交换节点顺序*）、材料、截面、**端部铰接**、单元上的荷载、刚度矩阵、删除 |
| **荷载** | 添加节点荷载、添加单元荷载 | 类型、作用位置、可编辑的分量、删除 |
| **材料** | 添加材料、材料库 | 标签、E、G、α<sub>T</sub>、删除 |
| **截面** | 添加截面、截面库 | 标签、A、I<sub>y</sub>、h、k、删除 |
| **结果** | 节点结果 / 单元结果切换 | 每个节点的位移与转角，或每个单元的端力 |

单元格可以就地编辑——点击、输入、按 <kbd>Enter</kbd>（或按 <kbd>Esc</kbd> 离开单元格）。数值按[当前单位](/zh/essentials/units-settings)显示和输入。

## 视图上方的标签页

**视图**标签页始终存在。打开设置会在它旁边添加一个可关闭的**设置**标签页，这样你可以一边看着模型一边调整颜色或单位。

## 浮动窗口

某些操作会在视图之上打开可拖动的窗口：**刚度矩阵**（来自单元的弹出菜单或表格行）显示该单元在局部和整体坐标系下的 6 × 6 刚度矩阵；画布菜单上的**编辑**打开当前选择的表格。用 × 关闭它们。
