# Интерфейс

В <Edubeam /> три зоны. Разберитесь, что где находится, — и остальная документация станет понятной.

```
┌──────────────────────────────────────────────────────────────────┐
│ ☰  edubeam    🗑 Очистить модель  🔗 Поделиться моделью  Что нового?│  ← Верхняя панель
├──────────────────────────────────────────────────────────────────┤
│ Вид | Настройки                                                  │  ← Вкладки
│ ↶ ↷                                            ⌖  ⤢  ⚙            │
│                                                                  │
│                     холст (модель)                  [переключатели│  ← Область просмотра
│                                                      отображения] │
│                                           G  S  m·kN·kNm·MPa     │
├──────────────────────────────────────────────────────────────────┤
│ Узлы | Элементы | Нагрузки | Материалы | Сечения | Результаты     │  ← Нижняя панель
│ [Добавить узел] [Добавить мышью]        таблица объектов …       │
└──────────────────────────────────────────────────────────────────┘
```

## Верхняя панель

| Элемент | Назначение |
| --- | --- |
| **Меню ☰** | **Открыть проект**, **Сохранить проект**, **Поделиться моделью**, **Очистить модель**, а также версия приложения. |
| **Очистить модель** 🗑 | После подтверждения удаляет все узлы, элементы и нагрузки. Два флажка позволяют удалить также материалы и сечения. Отменить нельзя. |
| **Поделиться моделью** 🔗 | Открывает [диалог обмена](/ru/essentials/import-export#ссылка-на-модель) с URL, в который закодирована вся модель. |
| **Что нового?** | Список изменений по версиям. |
| **Документация** / GitHub | Ссылки на этот сайт и на исходный код. |

В [режиме просмотра](/ru/essentials/import-export#встраивание-просмотра-только-для-чтения) верхняя панель скрыта.

## Область просмотра

Холст — это место, где вы рисуете и изучаете модель. Всё остальное в приложении отражает то, что здесь выделено.

### Кнопки поверх холста

- **Слева вверху:** **Отменить** / **Повторить** (также <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>). Любое изменение модели — добавление, правка, перетаскивание, удаление — можно отменить.
- **Справа вверху:** **Центрировать** (<kbd>C</kbd>), **Вписать в экран** (<kbd>F</kbd>) и переключатель **настроек отображения** ⚙.
- **Справа внизу:** **G** включает сетку, **S** — привязку к сетке; **плашка единиц** показывает текущие единицы и по щелчку открывает настройки.

### Панель настроек отображения

Открывается кнопкой ⚙. Два ряда флажков:

- **Результаты:** *Деформированная форма*, *N (x)*, *V<sub>z</sub> (x)*, *M<sub>y</sub> (x)*, *Реакции*.
- **Модель:** *Опоры*, *Нагрузки*, *Метки узлов*, *Метки элементов*.

**Дополнительные настройки** открывают полный [диалог настроек](/ru/essentials/units-settings).

### Навигация

| Действие | Мышь / сенсорный экран |
| --- | --- |
| Масштаб | Колесо мыши (масштабирует к курсору), <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd>; щипок на сенсорном экране |
| Панорамирование | Перетаскивание **средней или правой** кнопкой мыши (настраивается в *Настройки → Управление и горячие клавиши*); перетаскивание одним пальцем на сенсорном экране |
| Вписать / центрировать | <kbd>F</kbd> / <kbd>C</kbd> или кнопки справа вверху |

### Выделение и редактирование

- **Щёлкните** узел, элемент, нагрузку или размерную линию, чтобы выделить. Нижняя панель переключится на соответствующую вкладку, а рядом с выделением появится небольшое **всплывающее меню** с доступными для объекта действиями (например, *Добавить нагрузку*, *Опоры узла*, *Редактировать элемент*, *Матрица жёсткости*, *Удалить*).
- **Протяните по пустому холсту**, чтобы нарисовать прямоугольник выделения. Всё внутри — узлы, элементы, их нагрузки и размерные линии — выделяется. Нажмите <kbd>Delete</kbd>, чтобы удалить всё выделенное, <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd>, чтобы скопировать и вставить в другом месте.
- **Перетащите узел**, чтобы переместить его. При включённой привязке он встанет на сетку. Присоединённые элементы и их нагрузки следуют за ним.
- **Двойной щелчок по нагрузке** открывает её редактирование.
- **Наведите курсор** на любой объект, чтобы увидеть подсказку: узлы показывают перемещения и угол поворота, элементы — материал и сечение, нагрузки — свои компоненты.
- **Щёлкните правой кнопкой по пустому холсту**, чтобы открыть меню холста: *Добавить узел*, *Добавить элемент*, *Добавить размер*, *Изменить* (открывает таблицу текущего выделения), *Копировать*, *Вставить*, *Удалить*. Удерживайте <kbd>Ctrl</kbd> при выборе *Добавить узел* / *Добавить элемент*, чтобы разместить их мышью вместо диалога.

Все сочетания клавиш перечислены на странице [Клавиатура и мышь](/ru/reference/shortcuts).

### Предупреждения

Когда что-то не так, в левом верхнем углу области просмотра появляются сообщения: *Материалы не определены.* / *Сечения не определены.* (с кнопкой **Добавить**) или *Model has N error(s)* с кнопкой **Show details**, открывающей список всех проблем. Сообщения решателя пока показываются только на английском. См. [Решение проблем](/ru/reference/troubleshooting).

## Нижняя панель

Шесть вкладок, у каждой — счётчик, панель инструментов и редактируемая таблица. Перетащите разделитель над панелью, чтобы изменить её высоту, или сверните её кнопкой справа.

| Вкладка | Панель инструментов | Таблица |
| --- | --- | --- |
| **Узлы** | Добавить узел (диалог), Добавить мышью | Метка, X, Z, флажки **Закреплённые степени свободы**, нагрузки в узле, удаление |
| **Элементы** | Добавить элемент (диалог), Добавить мышью | Метка, тип, начальный/конечный узел (+ *Поменять порядок узлов*), материал, сечение, **Концевые шарниры**, нагрузки на элементе, матрица жёсткости, удаление |
| **Нагрузки** | Добавить узловую нагрузку, Добавить нагрузку на элемент | Тип, точка приложения, редактируемые компоненты, удаление |
| **Материалы** | Добавить материал, Библиотека материалов | Метка, E, G, α<sub>T</sub>, удаление |
| **Сечения** | Добавить сечение, Библиотека сечений | Метка, A, I<sub>y</sub>, h, k, удаление |
| **Результаты** | Переключатель Узловые результаты / Результаты по элементам | Перемещения и углы поворота по узлам либо концевые усилия по элементам |

Ячейки редактируются на месте: щёлкните, введите значение, нажмите <kbd>Enter</kbd> (или <kbd>Esc</kbd>, чтобы выйти из ячейки). Значения показываются и вводятся в [текущих единицах](/ru/essentials/units-settings).

## Вкладки над областью просмотра

Вкладка **Вид** есть всегда. При открытии настроек рядом появляется закрываемая вкладка **Настройки**, так что цвета или единицы можно менять, глядя на модель.

## Плавающие окна

Некоторые действия открывают перетаскиваемые окна поверх области просмотра: **Матрица жёсткости** (из всплывающего меню элемента или строки таблицы) показывает матрицу жёсткости элемента 6 × 6 в локальных и глобальных координатах; **Изменить** в меню холста открывает таблицу текущего выделения. Закрываются крестиком ×.
