# 座標系と符号規約

<Edubeam /> で「間違って」見える結果のほとんどは、実は符号規約の思い違いです。以下は、ソルバーが実際に使っている規約です。

## グローバル座標軸 {#global-axes}

- **x** — 水平方向、**右向き**が正。
- **z** — 鉛直方向、画面上で**下向き**が正。
- **y** — 面外方向の軸（右手系では見ている人の方を向きます）。回転とモーメントは y 軸まわりです。

グリッドの隅にある座標軸の記号は、x（赤）と z（緑）を示しています。したがって、柱脚が `Z = 0` にある高さ 3 m の柱の頂部の節点は `Z = −3` です。

## 自由度 {#degrees-of-freedom}

各節点は `Dx`、`Dz`（並進）と `Ry`（回転）を持ちます。正の `Dz` は下向きの変位、正の `Ry` は画面上で**反時計回り**の回転です。強制変位と、表示される節点結果にも同じ符号が適用されます。

## 荷重 {#loads}

| 荷重 | 正の向き |
| --- | --- |
| `Fx`、`fx`、`f1x`… | +x（右向き。LCS がオンなら要素のローカル x 軸の向き） |
| `Fz`、`fz`、`f1z`… | +z（**下向き**。LCS がオンならローカル z 軸の向き） |
| `My` | 画面上で反時計回り |
| `ΔTc` | 温度上昇（伸び） |
| `ΔTb − ΔTt` | 下縁が上縁より高温 |

したがって、重力荷重は**正の** `fz`、左の柱を右へ押す風荷重は正の `fx` です。

## 要素のローカル座標軸 {#element-local-axes}

ローカル **x** 軸は始端節点から終端節点へ向かい、ローカル **z** 軸はそれに垂直で、グローバル座標軸を要素の角度 $\alpha$ だけ回転させたものです。左から右へ描いた水平な要素では、ローカル座標軸とグローバル座標軸が一致します。向きを逆にするには、*要素*の表の**節点を入れ替え**を使います。

## 断面力 {#internal-forces}

| 量 | 正の意味 |
| --- | --- |
| **N** | 引張 |
| **V<sub>z</sub>** | 梁理論で一般的な符号。重力荷重を受ける単純梁では、V は左の支点で正、右の支点で負 |
| **M<sub>y</sub>** | **下側引張** — 下縁（+z 側）が引張。重力荷重を受ける単純梁ではスパン中央のモーメントが正、先端荷重を受ける片持ち梁では固定端のモーメントが負（上側引張） |

## 材端力（要素結果の表） {#end-forces-element-results-table}

`X12, Z12, M12` は始端節点で、`X21, Z21, M21` は終端節点で要素に作用し、**ローカル**座標系で、ローカル座標軸および `My` と同じ向きを正とします。これらは節点が要素に及ぼす力、つまり $\mathbf{f} = \mathbf{K}_l\,\mathbf{u}_l - \mathbf{f}_{eq}$ です。ここで $\mathbf{f}_{eq}$ は要素荷重の等価節点荷重です。ある節点に集まるすべての要素の材端力の和は、その節点の節点荷重および反力とつり合います。

## 反力 {#reactions}

反力は拘束されたすべての自由度について存在し、節点の座標系（節点の LCS 角度が設定されていれば、その分だけ回転した座標系）で表示されます。ビューアの反力の矢印は、支点が構造物を押す向きを指しています。

## y 上向きの座標軸 {#y-up-axes}

**設定 → 座標系 → x 右向き、y 上向き**を選ぶと、入力するものと読み取るものすべてが教科書の座標系に切り替わります。**x** は右向き、**y** は上向き、**z** は見ている人の方を向きます。モデル、保存されるファイル、図は変わらず、数値と名前だけが変わります。

| 量 | z 下向き（初期値） | y 上向き |
| --- | --- | --- |
| 鉛直座標 | `Z` | `Y`、符号は逆 |
| 鉛直方向の荷重、変位、反力、材端力 | `Fz`、`fz`、`Dz`、`Z12`… | `Fy`、`fy`、`Dy`、`Y12`…、符号は逆 |
| 回転とモーメント | `Ry`、`My` | `Rz`、`Mz`、符号は同じ（反時計回りが正） |
| 支点の角度 α | 時計回りに測る | 反時計回りに測る、符号は逆 |
| 断面力 N、V、M | | 変わらず、図も同じように描かれる |

したがって、重力荷重は**負の** `fy` で、高さ 3 m の柱の頂部は `Y = 3` です。

## 単位 {#units}

ソルバーは内部では SI（m、N、Pa、rad、K）で計算します。表示単位が影響するのは、入力するものと読み取るものだけです。表示単位を変えても、モデルは決して変わりません。
