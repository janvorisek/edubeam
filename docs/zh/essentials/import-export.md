# 导入、导出与分享

<Edubeam /> 中的一切都在你的浏览器里完成。没有任何内容上传到服务器——分享链接本身就包含了整个模型。

## 保存项目

**☰ 菜单 → 保存项目**或 <kbd>Ctrl</kbd>+<kbd>S</kbd> 会下载 `project.json`。它包含节点、单元、材料、截面、荷载、尺寸标注以及写入它的应用版本。文件名可以随意更改。

## 打开项目

- **☰ 菜单 → 打开项目**或 <kbd>Ctrl</kbd>+<kbd>O</kbd>，然后选择一个 `.json` 文件，或者
- **把文件拖到应用窗口的任意位置**。

打开会替换当前模型（包括材料和截面）。如果想保留当前模型，请先**保存项目**。

## 分享链接

**分享模型**（应用栏中的 🔗，或 ☰ 菜单）会打开 *通过 URL 分享模型* 对话框：

- **复制链接** —— 把链接复制到剪贴板（或点击输入框内部）。
- **打开链接** —— 在新标签页中打开，以便查看接收者将看到的内容。
- **通过系统分享对话框** —— 在手机和平板上，把链接交给操作系统的分享面板。

链接的形式为 `https://run.edubeam.app/?model=…`，编码了整个模型（节点、单元、属性、荷载）。打开它的人会得到一份可在本地编辑的精确副本；编辑**不会**同步回来——模型更改后请发送新链接。非常大的模型会产生非常长的链接；这种情况下请改为分享 JSON 文件。

## 嵌入只读查看器

在分享链接后追加 `&viewer=1`（或在任意应用 URL 后追加 `?viewer=1`）即可以**查看器模式**打开模型：应用栏、底部栏、撤销/重做和设置面板都被隐藏，只保留带有当前模型的画布。把该 URL 放进 `<iframe>` 中，就能在讲义或网页中嵌入一个可缩放的实时模型：

```html
<iframe src="https://run.edubeam.app/?viewer=1&model=…" width="100%" height="400"></iframe>
```

[示例](/zh/examples/)页面就是这样构建的——每张卡片都是一个带 `?model=` 参数的链接。

## URL 参数

| 参数 | 作用 |
| --- | --- |
| `model=<数据>` | 加载编码的模型，使其适配屏幕，然后从地址栏中移除该参数。 |
| `lang=<代码>` | 切换界面语言（`en`、`cs`、`de`、`fr`、`es`、`pt`、`pl`、`cn`、`th`、`uk`、`ru`）。 |
| `viewer=1` | 只读查看器模式（见上文）。 |

## 自动持久化

当前模型和你的设置会在每次更改后保存到浏览器的本地存储中，并在你回来时恢复——即使关闭了浏览器也是如此。这是一种便利而不是备份：它绑定在一台设备上的一个浏览器配置文件中，清除站点数据就会删除它。重要的工作请保存为项目文件。

## 项目文件格式

`project.json` 是简单、可读的 JSON：

```json
{
  "edubeam": true,
  "version": "1.0.6",
  "domain": {
    "materials": [ { "label": "1", "e": 210000000000, "g": 81000000000, "alpha": 0.000012, "d": 7850 } ],
    "crossSections": [ { "label": "1", "a": 0.00285, "iy": 1.943e-5, "h": 0.2, "k": 1 } ],
    "nodes": [ { "label": "1", "coords": [0, 0, 0], "bcs": [0, 2] }, … ],
    "elements": [ { "label": "1", "nodes": ["1", "2"], "mat": "1", "cs": "1", "hinges": [false, false] } ],
    "loadCases": [ … ]
  }
}
```

无论显示单位如何，所有数值都以 **SI 单位**（m、N、Pa、rad）存储。边界条件使用自由度编号 `0 = Dx`、`2 = Dz`、`4 = Ry`。由于格式简单，你可以用脚本或电子表格生成模型，再用**打开项目**打开它们。该格式没有作为稳定 API 进行版本管理，因此如果你要基于它做自动化，请检查 `version` 字段。
