# Klavye, fare ve dokunmatik

Klavye kısayolları, odak görüntüleyicideyken çalışır. Bir tablo hücresine veya bir pencereye yazarken dikkate alınmazlar; önce tuvale tıklayın.

## Klavye {#keyboard}

| Kısayol | İşlem |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Geri al |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Yinele |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Projeyi kaydet (JSON indirir) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Proje aç |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Görüntüyü dışa aktar |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Her şeyi seç |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Seçimi kopyala (düğümler, elemanlar ve yükleri) |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Yapıştır: kopyanın silik bir görüntüsü imleci izler; yerleştirmek için tıklayın ya da şeritte bir Δx, Δz kayması girip **Yapıştır** düğmesine basın |
| <kbd>Delete</kbd> | Seçimi sil |
| <kbd>Esc</kbd> | Geçerli fare modunu iptal et, turu kapat, seçimi temizle veya tablo hücresinden çık |
| <kbd>Enter</kbd> | Tablo hücresini onayla |
| <kbd>F</kbd> | Modeli ekrana sığdır |
| <kbd>C</kbd> | Modeli ortala |
| <kbd>G</kbd> | Izgarayı aç/kapat |
| <kbd>S</kbd> | Izgaraya yaslamayı aç/kapat |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Yakınlaştır / uzaklaştır |

Mac'te <kbd>Ctrl</kbd> yazan yerlerde <kbd>Cmd</kbd> kullanın.

## Fare {#mouse}

| İşlem | Sonuç |
| --- | --- |
| Tıklama | Bir düğümü, elemanı, yükü veya ölçü çizgisini seçer ve panelini açar |
| Boş tuvalde sürükleme | Seçim dikdörtgeni |
| Düğümü sürükleme | Düğümü taşır (yaslama açıksa ızgaraya yaslanır) |
| Fare modunda tıklama | Bir düğüm yerleştirir ya da bir eleman zincirini başlatır veya sürdürür |
| Yüke çift tıklama | Yükü düzenler |
| Sağ tıklama | Tuval menüsü: Düğüm ekle, Eleman ekle, Ölçü ekle, Elemanı ölçülendir (bir elemanın üzerindeyken), Düzenle, Kopyala, Yapıştır, Sil |
| Tuval menüsünde <kbd>Ctrl</kbd> (Mac'te <kbd>Cmd</kbd>) + Düğüm ekle / Eleman ekle | Pencere yerine fareyle yerleştirir |
| Orta veya sağ tuşla sürükleme | Kaydırma (bkz. *Ayarlar → Kontroller ve kısayollar*) |
| Tekerlek | İmlece doğru yakınlaştırır |
| İmleci bir nesnenin üzerine getirme | Yer değiştirmeleri, özellikleri veya yük değerlerini gösteren bilgi kutusu |

Dokunmatik yüzeyde (trackpad) iki parmakla kaydırmak yakınlaştırır. Görünümü kaydırmak için iki parmakla tıklayıp sürükleyin (sağ tuşla sürüklemeye karşılık gelir).

## Dokunmatik {#touch}

| Hareket | Sonuç |
| --- | --- |
| Dokunma | Seçer ve nesnenin ayrıntılarını ve işlemlerini gösterir |
| Fare modunda dokunma | Bir düğüm yerleştirir veya bir elemanı sürdürür |
| Düğüme basıp sürükleme | Düğümü taşır |
| Başka bir yerde tek parmakla sürükleme | Kaydırma |
| İki parmakla sıkıştırma | Yakınlaştırma |
| Tuvale basılı tutma | Tuval menüsü |
| **Dikdörtgenle seç** düğmesi (sağ üstte), ardından sürükleme | Seçim dikdörtgeni |

## Nesne panelleri {#object-panels}

Bir nesneye tıklamak, yanında ayrıntılarını ve şu işlemleri içeren bir panel açar:

| Nesne | İşlemler |
| --- | --- |
| Düğüm | Yük ekle · Düğüm mesnetleri (mesnet sembolü, Dx / Dz / Ry, düğüm yerel eksen açısı) · Yer değiştirme öngör (mesnetli bir düğümde) · Sil |
| Eleman | Elemanı düzenle (düğümler ve mafsallar, malzeme, kesit) · Yük ekle · Rijitlik matrisi · Sil |
| Düğüm veya eleman yükü | Yükü düzenle · Sil |
| Ölçü çizgisi | Düzenle (koordinatlar) · Ölçü çizgisini ters çevir · Sil |
