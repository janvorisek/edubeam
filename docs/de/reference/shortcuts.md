# Tastatur & Maus

Tastenkürzel wirken, solange die Ansicht den Fokus hat – während Sie in einer Tabellenzelle oder einem Dialog tippen, werden sie ignoriert.

## Tastatur

| Kürzel | Aktion |
| --- | --- |
| <kbd>Strg</kbd>+<kbd>Z</kbd> | Rückgängig |
| <kbd>Strg</kbd>+<kbd>Umschalt</kbd>+<kbd>Z</kbd> | Wiederholen |
| <kbd>Strg</kbd>+<kbd>S</kbd> | Projekt speichern (JSON herunterladen) |
| <kbd>Strg</kbd>+<kbd>O</kbd> | Projekt öffnen |
| <kbd>Strg</kbd>+<kbd>A</kbd> | Alles auswählen |
| <kbd>Strg</kbd>+<kbd>C</kbd> | Auswahl (Knoten, Elemente, Lasten) in die EduBeam-Zwischenablage kopieren |
| <kbd>Strg</kbd>+<kbd>V</kbd> | Einfügen: eine Kontur der Kopie folgt dem Cursor; Linksklick platziert sie |
| <kbd>Entf</kbd> | Auswahl löschen |
| <kbd>Esc</kbd> | Aktuellen Mausmodus abbrechen, Auswahl aufheben, Tabellenzelle verlassen |
| <kbd>Enter</kbd> | Tabellenzelle bestätigen |
| <kbd>F</kbd> | An Bildschirm anpassen |
| <kbd>C</kbd> | Zentrieren |
| <kbd>G</kbd> | Raster ein/aus |
| <kbd>S</kbd> | Am Raster ausrichten ein/aus |
| <kbd>Strg</kbd>+<kbd>=</kbd> / <kbd>Strg</kbd>+<kbd>-</kbd> | Vergrößern / Verkleinern |

Unter macOS verwenden Sie <kbd>Cmd</kbd> statt <kbd>Strg</kbd>.

## Maus

| Aktion | Ergebnis |
| --- | --- |
| Linksklick | Knoten / Element / Last / Bemaßungslinie auswählen und Kontextmenü öffnen |
| Ziehen mit links auf leerer Fläche | Rechteckauswahl |
| Ziehen mit links an einem Knoten | Knoten verschieben (mit Rasterfang, falls aktiv) |
| Linksklick im Modus *Per Maus hinzufügen* | Knoten setzen bzw. Polygonzug von Elementen beginnen / fortsetzen |
| Doppelklick auf eine Last | Last bearbeiten |
| Rechtsklick auf leere Fläche | Menü der Zeichenfläche: Knoten hinzufügen, Element hinzufügen, Bemaßung hinzufügen, Bearbeiten, Kopieren, Einfügen, Löschen |
| Ziehen mit mittlerer oder rechter Taste | Verschieben (einstellbar unter *Einstellungen → Steuerung & Tastenkürzel*) |
| Mausrad | Zoom zum Cursor |
| Mauszeiger | Tooltip mit Verschiebungen / Eigenschaften / Lastwerten |

## Touch

| Geste | Ergebnis |
| --- | --- |
| Tippen | Auswählen |
| Ziehen mit einem Finger | Verschieben |
| Pinch | Zoom |
| Knoten lange drücken | Verschieben des Knotens beginnen |

## Kontextmenüs

Ein Klick auf ein Objekt öffnet daneben ein kleines Menü:

| Objekt | Einträge |
| --- | --- |
| Knoten | Last hinzufügen · Knotenlagerung (Dx / Dz / Ry, Knoten-LKS-Winkel) · Verschiebung vorgeben (falls gelagert) · Löschen |
| Element | Element bearbeiten (Knoten, Material, Querschnitt) · Last hinzufügen · Steifigkeitsmatrix · Löschen |
| Knoten- / Elementlast | Last bearbeiten · Löschen |
| Bemaßungslinie | Bearbeiten (Koordinaten) · Bemaßung umkehren · Löschen |
