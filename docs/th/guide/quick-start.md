# เริ่มต้นใช้งานด่วน

ในเวลาประมาณสิบนาที คุณจะสร้างโมเดลคานเหล็กช่วงเดียวแบบรองรับธรรมดาที่รับแรงแผ่กระจายสม่ำเสมอ อ่านค่าแรงปฏิกิริยา แรงเฉือน และโมเมนต์ดัด แล้วตรวจสอบกับสูตรในตำรา

::: tip ทำตามไปพร้อมกัน
เปิด [run.edubeam.app](https://run.edubeam.app/?lang=th){target="_blank"} ในแท็บที่สอง ถ้ามีโมเดลอยู่แล้ว ให้กด **ล้างโมเดล** ในแถบด้านบนเพื่อเริ่มจากหน้าว่าง และติ๊ก *ลบวัสดุ* กับ *ลบหน้าตัด* เพื่อเริ่มใหม่ทั้งหมด การลบย้อนกลับได้ด้วย <kbd>Ctrl</kbd>+<kbd>Z</kbd> และโมเดลเดิมยังอยู่ใน **☰ → โครงสร้างล่าสุด**

ชอบเรียนรู้ด้วยการลงมือทำพร้อมคำแนะนำบนจอ? **☰ → วาดคานแรกของคุณ** จะพาคุณวาดคานลักษณะคล้ายกันด้วยเมาส์ทีละขั้น
:::

## โจทย์ {#the-problem}

<ExampleStructure />

คานช่วงเดียวแบบรองรับธรรมดายาว 6 m (ซ้ายเป็นหมุด ขวาเป็นล้อเลื่อน) รับแรงแผ่กระจายสม่ำเสมอ 12 kN/m วัสดุ: เหล็ก $E = 210\ \text{GPa}$, $G = 81\ \text{GPa}$ หน้าตัด: IPE 200, $A = 28.5\ \text{cm}^2$, $I_y = 1943\ \text{cm}^4$, $h = 200\ \text{mm}$

## 1. ตรวจสอบหน่วย {#_1-check-the-units}

ป้ายหน่วยที่มุมขวาล่างของหน้าจอแสดงผลบอกหน่วยที่ทุกช่องป้อนข้อมูลและผลลัพธ์ใช้ บทเรียนนี้ใช้หน่วย SI เริ่มต้น: เมตร kN kNm และ MPa

![ปุ่มเปิด/ปิดกริด (G) การสแนป (S) และเส้นเล็ง พร้อมป้ายหน่วย](/screenshots/th/ui-grid-units.webp){.shot-sm}

ถ้าเห็น `ft · kip · kip·ft · ksi` ให้คลิกที่ป้ายแล้วเลือก **ระบบหน่วย → SI (เมตริก)**

## 2. เพิ่มวัสดุและหน้าตัด {#_2-add-the-material-and-cross-section}

เอลิเมนต์ต้องมีวัสดุและหน้าตัด จึงต้องสร้างสองอย่างนี้ก่อน

1. เปิดแท็บ **วัสดุ** ในแถบด้านล่าง แล้วคลิก **เพิ่มวัสดุ**
2. ใส่ `E = 210000` MPa และ `G = 81000` MPa ปล่อยความหนาแน่นและ `α = 0.000012` 1/K ไว้ตามเดิม คลิก **เพิ่มวัสดุ**

<div class="shots">

![เพิ่มวัสดุ: พิมพ์ค่า E และ G…](/screenshots/th/qs-material.webp)

![…หรือเลือก Steel (S235) จากไลบรารีวัสดุ](/screenshots/th/qs-material-library.webp)

</div>

3. เปิดแท็บ **หน้าตัด** แล้วคลิก **เพิ่มหน้าตัด**
4. ใส่ `พื้นที่ = 0.00285` m², `Iy = 1.943e-5` m⁴, `ความสูง = 0.2` m และ `สัมประสิทธิ์เฉือน = 1` คลิก **เพิ่มหน้าตัด**

![เพิ่มหน้าตัด หรือเลือกจากไลบรารี หรือวาดเป็นรูปหลายเหลี่ยม](/screenshots/th/qs-cross-section.webp){.shot-md}

::: details ทำไมสัมประสิทธิ์เฉือนจึงสำคัญ?
EduBeam ใช้เอลิเมนต์คาน Timoshenko ซึ่งคิดการเสียรูปเนื่องจากแรงเฉือนด้วย `k` คือตัวคูณปรับแก้แรงเฉือน (shear correction factor): $k \approx 0.83$ สำหรับหน้าตัดสี่เหลี่ยมผืนผ้า และประมาณ $0.4$–$0.5$ สำหรับหน้าตัดรูป I เมื่อ $A$ คือพื้นที่หน้าตัดทั้งหมด การตั้ง `k = 1` กับพื้นที่ทั้งหมดจะประเมินความยืดหยุ่นต่อแรงเฉือน *ต่ำไป* เล็กน้อย สำหรับคานชะลูดอย่างคานนี้ การโก่งตัวต่างกันน้อยกว่า 1 % มาก ดูสูตรได้ที่ [หน้าทฤษฎีคาน](/th/elements/beam)
:::

## 3. เพิ่มโหนด {#_3-add-the-nodes}

1. เปิดแท็บ **โหนด** ในแท็บนี้มีปุ่ม **เพิ่มโหนด** สองปุ่ม: ปุ่มแรกเปิดกล่องโต้ตอบ ปุ่มที่สอง (ที่มีไอคอนเคอร์เซอร์) ใช้วางโหนดด้วยเมาส์ คลิกปุ่มแรก
2. ใส่ `X = 0`, `Z = 0` แล้วคลิก **เพิ่มโหนด** โหนดจะได้หมายเลข `1`
3. เพิ่มโหนดที่สองที่ `X = 6`, `Z = 0` นี่คือโหนด `2`

![กล่องโต้ตอบเพิ่มโหนดกำหนดจุดรองรับได้ทันทีด้วย](/screenshots/th/qs-node.webp){.shot-md}

ถ้าใช้ปุ่มเมาส์แทน การคลิกบนพื้นที่วาดแต่ละครั้งจะวางโหนดหนึ่งโหนด เมื่อเปิด **สแนปกับกริด** (<kbd>S</kbd>) ตำแหน่งที่คลิกจะลงบนระยะกริด (ค่าเริ่มต้น 0.1 m)

## 4. เชื่อมโหนดด้วยเอลิเมนต์ {#_4-connect-them-with-an-element}

1. เปิดแท็บ **เอลิเมนต์** แล้วคลิกปุ่ม **เพิ่มเอลิเมนต์** ปุ่มแรก
2. เลือก **โหนดเริ่มต้น** `1` และ **โหนดปลาย** `2` วัสดุและหน้าตัดของคุณถูกเลือกไว้แล้ว คลิก **เพิ่มเอลิเมนต์**

![เพิ่มเอลิเมนต์: โหนดปลายทั้งสอง จุดหมุนที่ปลาย (ไม่บังคับ) วัสดุ และหน้าตัด](/screenshots/th/qs-element.webp){.shot-md}

เส้นจะปรากฏระหว่างโหนด กด <kbd>F</kbd> เพื่อปรับให้พอดีกับหน้าจอ

## 5. เพิ่มจุดรองรับ {#_5-add-the-supports}

ในแท็บ **โหนด** คอลัมน์ **องศาความเป็นอิสระที่รองรับ** มีตัวเลือกสัญลักษณ์จุดรองรับและช่องทำเครื่องหมายสามช่องต่อโหนด: `Dx`, `Dz`, `Ry`

- โหนด `1`: เลือกสัญลักษณ์ **หมุด** หรือติ๊ก **Dx** และ **Dz**
- โหนด `2`: เลือก **ล้อเลื่อน** หรือติ๊ก **Dz** อย่างเดียว

![จุดรองรับในตารางโหนด: โหนด 1 เป็นหมุด โหนด 2 เป็นล้อเลื่อน](/screenshots/th/qs-supports.webp)

คุณยังคลิกโหนดบนหน้าจอแสดงผลแล้วเลือก **จุดรองรับของโหนด** ได้ด้วย หน้า [โหนดและจุดรองรับ](/th/essentials/nodes-supports#supports) อธิบายจุดรองรับทุกประเภท

## 6. เพิ่มแรงกระทำ {#_6-add-the-load}

1. เปิดแท็บ **แรงกระทำ** แล้วคลิก **เพิ่มแรงกระทำบนเอลิเมนต์**
2. **ประเภทแรงกระทำ**: *แรงแผ่กระจายสม่ำเสมอ* **เอลิเมนต์**: `1`
3. ใส่ `fz = 12` kN/m และปล่อย `fx = 0` ไว้ คลิก **เพิ่มแรงกระทำบนเอลิเมนต์**

![กล่องโต้ตอบแสดงตัวอย่างแรงกระทำบนเอลิเมนต์](/screenshots/th/qs-load.webp){.shot-md}

`fz` ที่เป็นบวกชี้ไปทาง +z ซึ่งคือ **ลง** บนหน้าจอ ค่าบวกจึงเป็นแรงตามแรงโน้มถ่วง ดู [ข้อตกลงเรื่องเครื่องหมาย](/th/elements/conventions)

## 7. อ่านผลลัพธ์ {#_7-read-the-results}

ผลการคำนวณปรากฏทันทีที่เพิ่มแรงกระทำ แผงการแสดงผลที่มุมขวาบนของหน้าจอแสดงผลใช้เปิดและปิดแผนภาพ **รูปร่างที่เสียรูป**, **M<sub>y</sub>(x)** และ **แรงปฏิกิริยา** เปิดอยู่เป็นค่าเริ่มต้น ติ๊ก **V<sub>z</sub>(x)** เพื่อแสดงแรงเฉือนเพิ่ม

![แรงเฉือน (สีเขียว) โมเมนต์ดัด (สีแดง) แรงปฏิกิริยา (สีม่วง) และรูปร่างที่เสียรูป](/screenshots/th/qs-results.webp)

| สิ่งที่แสดง | สิ่งที่คุณควรเห็น |
| --- | --- |
| **แรงปฏิกิริยา** | ลูกศรชี้ขึ้นขนาด **36 kN** สองอันที่โหนด 1 และ 2 |
| **V<sub>z</sub>(x)** | เส้นตรงจาก **+36 kN** ทางซ้ายถึง **−36 kN** ทางขวา ตัดศูนย์ที่กึ่งกลางช่วง |
| **M<sub>y</sub>(x)** | พาราโบลาที่มีค่าสูงสุด **54 kNm** ที่กึ่งกลางช่วง |
| **รูปร่างที่เสียรูป** | การแอ่นตัวลงแบบสมมาตร ชี้เมาส์ที่โหนด `1` เพื่ออ่านมุมหมุน: **2.6469 · 10⁻² rad** |

แท็บ **ผลลัพธ์** ในแถบด้านล่างแสดงค่าตัวเลข **ผลลัพธ์ที่โหนด** แสดง `Dx`, `Dz`, `Ry` ของแต่ละโหนด **ผลลัพธ์ที่เอลิเมนต์** แสดงแรงปลายของแต่ละเอลิเมนต์ในระบบพิกัดท้องถิ่นของเอลิเมนต์นั้น

ถ้าแผนภาพดูใหญ่หรือเล็กเกินไป ให้เปลี่ยน **ขนาดผลลัพธ์** ใน **การตั้งค่า → การตั้งค่าโปรแกรมดู → ขนาด**

## 8. ตรวจสอบด้วยการคำนวณมือ {#_8-check-by-hand}

| ปริมาณ | สูตร | ค่าจากการคำนวณมือ | EduBeam |
| --- | --- | --- | --- |
| แรงปฏิกิริยา | $R = qL/2$ | 36 kN | 36 kN |
| แรงเฉือนสูงสุด | $V = qL/2$ | 36 kN | 36 kN |
| โมเมนต์สูงสุด | $M = qL^2/8$ | 54 kNm | 54 kNm |
| มุมหมุนที่ปลาย | $\varphi = qL^3/(24EI)$ | 0.02647 rad | 0.02647 rad |
| การโก่งตัวที่กึ่งกลางช่วง (จากการดัด) | $w = 5qL^4/(384EI)$ | 49.63 mm | |
| การโก่งตัวที่กึ่งกลางช่วง (จากแรงเฉือน) | $w_s = qL^2/(8kGA)$ | 0.23 mm | |
| การโก่งตัวที่กึ่งกลางช่วง (รวม) | ผลรวม | 49.86 mm | 49.86 mm |

ที่กึ่งกลางช่วงไม่มีโหนด ถ้าต้องการอ่านการโก่งตัวที่ตำแหน่งนั้นให้เพิ่มโหนดหนึ่งโหนด: เลือกปุ่ม **เพิ่มโหนด** ปุ่มที่สอง คลิกบนคานที่ `X = 3` แล้วเลือก **เชื่อมต่อกับโครงสร้าง** คานจะถูกแบ่งเป็นสองเอลิเมนต์ และค่า `Dz` ของโหนดใหม่ใน **ผลลัพธ์** จะเป็น 49.86 mm การแบ่งเอลิเมนต์ไม่เปลี่ยนผลลัพธ์ใด ๆ เพราะเอลิเมนต์ให้ผลแม่นตรง

ทุกค่าตรงกัน สูตรตรวจสอบด้วยมือเพิ่มเติม (คานยื่น คานยึดแน่นสองปลาย โครงถัก อุณหภูมิ) อยู่ใน [ตรวจสอบผลลัพธ์ด้วยการคำนวณมือ](/th/guide/verification)

## 9. ทดลอง {#_9-experiment}

นี่คือจุดที่ EduBeam แสดงความสามารถ ลองทำทีละข้อแล้วดูแผนภาพเปลี่ยนตาม:

- **ลากโหนด 2** ไปทางขวา: โมเมนต์เพิ่มขึ้นตาม $L^2$
- **ติ๊ก `Ry` ที่โหนด 1** เพื่อให้เป็นจุดรองรับแบบยึดแน่น: โมเมนต์ที่กึ่งกลางช่วงลดลง และเกิดโมเมนต์ลบที่จุดรองรับ
- **ติ๊ก `Dz` ที่โหนดกึ่งกลางช่วง** ที่เพิ่งเพิ่ม เพื่อให้เป็นคานต่อเนื่องสองช่วง
- **ติ๊กจุดหมุนที่ปลาย** ของเอลิเมนต์ในแท็บเอลิเมนต์ เพื่อปลดโมเมนต์ที่ปลายด้านหนึ่ง
- กด <kbd>Ctrl</kbd>+<kbd>Z</kbd> เพื่อเลิกทำขั้นใดก็ได้

## 10. บันทึกหรือแชร์ {#_10-save-or-share}

- **แชร์โมเดล** (ในแถบด้านบนหรือเมนู ☰) ให้ลิงก์ที่บรรจุทั้งโมเดล วางในอีเมล แชต หรือสไลด์ได้
- **☰ → บันทึกโปรเจกต์** (<kbd>Ctrl</kbd>+<kbd>S</kbd>) ดาวน์โหลดไฟล์ `project.json` ที่เปิดภายหลังได้ด้วย **เปิดโปรเจกต์** หรือลากไฟล์มาวางบนแอป
- **☰ → ส่งออกรูปภาพ** (<kbd>Ctrl</kbd>+<kbd>P</kbd>) บันทึกภาพวาดเป็น PNG หรือ SVG สำหรับใส่ในรายงาน

โมเดลของคุณยังถูกเก็บไว้ในเบราว์เซอร์ด้วย การโหลดหน้าใหม่จึงไม่ทำให้โมเดลหาย ดู [นำเข้า ส่งออก และแชร์](/th/essentials/import-export)
