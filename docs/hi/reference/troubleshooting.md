# समस्या निवारण

## कोई परिणाम नहीं बनता {#no-results-are-drawn}

परिणाम तभी दिखते हैं जब मॉडल हल किया जा सकता हो। इस क्रम में जाँचें:

1. **व्यूअर के ऊपर-बाएँ का संदेश पढ़ें।** (ऐप के संदेश अंग्रेज़ी में दिखते हैं।)
   - *No materials defined* / *No cross sections defined*: **Add new** बटन से एक जोड़ें।
   - एक नीली **Needs supports** चिप: मॉडल बस अधूरा है। आधार जोड़ें। डैश वाली रूपरेखा के रूप में यह देखने के लिए कि संरचना अब भी कैसे हिल सकती है, चिप पर पॉइंटर ले जाएँ।
   - एक **लाल संदेश**: कुछ गलत है। यह समस्या का नाम बताता है, या कई समस्याएँ होने पर *Errors in the model: N* पढ़ता है। **Show details** पर क्लिक करें और हर आइटम ठीक करें (नीचे की तालिका देखें)। संबंधित नोडों या हिंजों पर कैनवास पर घेरा बना होता है।
   - एक **पीला संदेश**: चेतावनियाँ। मॉडल फिर भी हल हो गया; आप इन्हें छिपा सकते हैं।
2. **पर्याप्त आधार?** सॉल्वर को कम से कम तीन अवरुद्ध DOFs चाहिए, और आधारों को संरचना को थामे रखना चाहिए। दो रोलरों (Dz + Dz) पर रखे बीम में केवल दो हैं और वह सरक जाता है। कहीं एक `Dx` जोड़ें, या किसी आधार पर एक `Ry`।
3. **क्या अवयव जुड़े हुए हैं?** एक ही निर्देशांकों पर दो नोड फिर भी दो अलग नोड हैं। फ़ालतू वाले को हटाएँ और फिर से जोड़ें, या **Connect to structure** से अवयवों पर नोड रखें।
4. **बहुत अधिक हिंज?** किसी स्तंभ के दोनों सिरों पर हिंज, या बिना विकर्ण के कीलित जोड़ वाली छड़ों का वर्ग, एक यंत्र बनाते हैं। EduBeam हिंजों पर घेरा बनाता है और गति दिखाता है।
5. **शून्य कठोरता?** गलती से 0 के रूप में, या गलत इकाई में दर्ज `E`, `A` या `Iy` संरचना के किसी भाग को लगभग बिना प्रतिरोध के हिलने देता है। EduBeam इसे *unstable* (अस्थिर) के रूप में रिपोर्ट करता है।

## संदेश {#messages}

**Show details** एक संवाद खोलता है जिसका शीर्षक *Cannot solve model* (त्रुटियाँ), *Not ready to solve yet* (अभी आधार चाहिए) या *Model warnings* होता है। उसका **Troubleshooting** लिंक यहाँ लाता है।

### अभी आवश्यक {#still-needed}

| संदेश | अर्थ / समाधान |
| --- | --- |
| *The structure needs supports before it can be solved.* | कुल मिलाकर तीन से कम अवरुद्ध DOFs। आधार जोड़ें। |
| *A separate part of the structure (nodes …) has fewer than 3 restrained DOFs and can move freely.* | मॉडल टुकड़ों में है और एक टुकड़ा तैर रहा है। उसे जोड़ें, या आधार दें। |

### त्रुटियाँ {#errors}

| संदेश | अर्थ / समाधान |
| --- | --- |
| *Structure has enough supports but they do not hold it: it can still …* | सभी आधार समानांतर हैं, या उनकी क्रिया रेखाएँ एक बिंदु पर मिलती हैं। डैश वाली रूपरेखा गति दिखाती है; किसी एक आधार की दिशा बदलें। यदि केवल एक टुकड़ा प्रभावित है, तो यही संदेश एक *separate part* (अलग भाग) का नाम बताता है। |
| *The supports hold the structure, but it is still a mechanism: its members can turn about the hinges at node …* | हिंज सदस्यों को एक-दूसरे के सापेक्ष घूमने देते हैं, जैसे दोनों स्तंभों के शीर्ष पर हिंज वाले फ्रेम में या बिना विकर्ण वाले कीलित जोड़ के वर्ग में। एक हिंज हटाएँ, या एक सदस्य या आधार जोड़ें। |
| *Structure is unstable: node … moves practically without resistance.* | लगभग एक यंत्र, या शून्य के निकट कठोरता। आधार, हिंज, और `E`, `A` तथा `Iy` के मान जाँचें। |
| *Structure is a mechanism: the stiffness matrix is singular.* | कुछ ऐसा मुक्त रूप से हिल सकता है जिसे ऊपर की जाँचें नहीं पकड़ पाईं। जाँचें कि हर भाग कम से कम तीन अवरोधों से थामा गया है और हिंज किसी सदस्य को घूमने के लिए मुक्त नहीं छोड़ते। |
| *Element … references missing node / material / cross section …* | संदर्भित वस्तु हटा दी गई थी, प्रायः हाथ से संपादित JSON फ़ाइल में। *Elements* तालिका में उसे फिर से निर्दिष्ट करें। |
| *Element … must reference exactly 2 nodes.* | आयात की गई फ़ाइल में एक टूटा हुआ अवयव। उसे हटाकर फिर से बनाएँ। |
| *Nodal load / Prescribed displacement #n references missing node …* | भार हटाएँ या उसे एक नोड दें। |
| *Element load #n references missing element …* | भार हटाएँ। |
| *Solver failed due to an internal model inconsistency…* | एक सामान्य विफलता। अंतिम चरण पूर्ववत करें, या फ़ाइल सहेजकर [उसकी रिपोर्ट करें](https://github.com/janvorisek/edubeam/issues)। |

### चेतावनियाँ {#warnings}

मॉडल फिर भी हल होता है, लेकिन इन्हें जाँचें:

| संदेश | अर्थ / समाधान |
| --- | --- |
| *Node … is not connected to any element and is ignored by the solver.* | एक फ़ालतू नोड। उसे हटाएँ, या जोड़ें। |
| *Node … is supported but no element connects to it, so the support carries nothing.* | किसी फ़ालतू नोड पर आधार। |
| *Element … references the same node at both ends.* | शून्य लंबाई का अवयव। उसे हटाएँ। |
| *Nodal load / Prescribed displacement #n contains invalid values.* | कोई घटक जो संख्या नहीं है। भार संपादित करें। |

## परिणाम गलत दिखते हैं {#results-look-wrong}

| लक्षण | संभावित कारण |
| --- | --- |
| भार ऊपर की ओर कार्य करते हैं | वैश्विक **z नीचे की ओर** है, इसलिए धनात्मक `Fz`/`fz` नीचे की ओर है। ऋणात्मक मान ऊपर की ओर इंगित करते हैं। देखें [परिपाटी](/hi/elements/conventions)। y-ऊपर अक्षों के साथ यह उल्टा है। |
| विक्षेप 1000× बहुत बड़ा या बहुत छोटा है | इकाइयों की गड़बड़ी: इकाई MPa होते हुए `E` Pa में दर्ज किया गया, या इकाई m⁴ होते हुए `Iy` cm⁴ में। व्यूअर के नीचे-दाएँ इकाइयों की चिप जाँचें। |
| विक्षेप पाठ्यपुस्तक के सूत्र से थोड़ा बड़ा है | Timoshenko अपरूपण विरूपण। Euler–Bernoulli मानों के निकट पहुँचने के लिए अनुप्रस्थ काट का अपरूपण गुणांक बढ़ाएँ, या पतला सदस्य उपयोग करें। देखें [परिणामों की हाथ से जाँच](/hi/guide/verification)। |
| कोई चिह्न "गलत" लगता है | चिह्न लेबलों से पढ़ें, आरेख की ओर से नहीं। धनात्मक M सैगिंग है। *Element results* में सिरा-बल अवयव के स्थानीय अक्षों के अनुसार होते हैं, N-V-M परिपाटी के अनुसार नहीं। |
| दो एक जैसे स्तंभ विपरीत अपरूपण चिह्न दिखाते हैं | V का चिह्न हर अवयव की दिशा के अनुसार होता है। तुलना के लिए किसी एक के नोड आपस में बदलें। |
| `4 · 10¹` जैसी संख्याएँ | वैज्ञानिक संख्या प्रारूप। *Settings → Language & Locale → Number format* में *Automatic* चुनें। |
| आरेख बहुत बड़े या बहुत छोटे हैं | पूरी तरह दृश्य। *Settings → Viewer settings* में **Results scale** समायोजित करें। |
| स्थानीय निर्देशांक वाला भार गलत दिशा में है | अवयव का स्थानीय x उसके *प्रारंभिक* से *अंतिम* नोड की ओर चलता है। नोड आपस में बदलें, या चिह्न उलटें। |
| झुके हुए सदस्य का भार ठीक नहीं है | **LCS** डिफ़ॉल्ट रूप से टिक है, इसलिए `fz` सदस्य के लंबवत कार्य करता है। ऊर्ध्वाधर भार के लिए इसे अनटिक करें। |
| तापीय भार का कोई प्रभाव नहीं | निर्धार्य संरचना तापमान के अधीन बिना आंतरिक बलों के मुक्त रूप से विरूपित होती है। जाँचें कि α ≠ 0 है और, प्रवणता के लिए, कि अनुप्रस्थ काट की ऊँचाई h सेट है। |

## इंटरफ़ेस समस्याएँ {#interface-issues}

| लक्षण | समाधान |
| --- | --- |
| शॉर्टकट कुछ नहीं करते | पहले कैनवास पर क्लिक करें: जब किसी टेक्स्ट फ़ील्ड पर फ़ोकस होता है, तो कुंजियाँ अनदेखी की जाती हैं। |
| पैन नहीं हो पाता | पैन डिफ़ॉल्ट रूप से माउस के मध्य या दाएँ बटन से होता है; इसे *Settings → Controls & Shortcuts* में बदलें। ट्रैकपैड पर दो उँगलियों से स्क्रॉल करने से ज़ूम होता है; पैन करने के लिए दो उँगलियों से क्लिक करके खींचें। |
| मेरा मॉडल गायब हो गया | लिंक, फ़ाइल या उदाहरण खोलने पर, और साफ़ करने पर, पुराना मॉडल रखा जाता है: **☰ → Recent structures**, या <kbd>Ctrl</kbd>+<kbd>Z</kbd>। |
| गलत भाषा | *Settings → Language & Locale*, या पते में `?lang=en` जोड़ें। |
| सेटिंग्स के बदलाव टिकते नहीं | लोकल स्टोरेज अवरुद्ध है (निजी विंडो, सख्त गोपनीयता मोड)। सेटिंग्स, स्वतः सहेजना और Recent structures को इसकी आवश्यकता होती है। |

## बग की रिपोर्ट करना {#reporting-a-bug}

अपने ब्राउज़र और OS, आपने क्या अपेक्षा की थी, और सबसे उपयोगी, समस्या को दोहराने वाले **साझा लिंक** या **प्रोजेक्ट फ़ाइल** के साथ एक [GitHub issue](https://github.com/janvorisek/edubeam/issues) खोलें।
