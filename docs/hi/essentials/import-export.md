# आयात, निर्यात और साझाकरण

<Edubeam /> में सब कुछ आपके ब्राउज़र में होता है। कुछ भी सर्वर पर अपलोड नहीं होता—साझा लिंक में सचमुच पूरा मॉडल समाया होता है।

## प्रोजेक्ट सहेजें

**☰ मेनू → Save project** या <kbd>Ctrl</kbd>+<kbd>S</kbd> `project.json` डाउनलोड करता है। इसमें नोड, अवयव, सामग्री, अनुप्रस्थ काट, भार, विमा रेखाएँ और उसे लिखने वाले ऐप का संस्करण होता है। फाइल का नाम आप स्वतंत्र रूप से बदल सकते हैं।

## प्रोजेक्ट खोलें

- **☰ मेनू → Open project** या <kbd>Ctrl</kbd>+<kbd>O</kbd>, फिर कोई `.json` फाइल चुनें, या
- **फाइल को ऐप विंडो पर कहीं भी खींचकर छोड़ें**।

खोलने पर वर्तमान मॉडल (सामग्री और अनुप्रस्थ काट सहित) बदल जाता है। उसे रखना हो तो पहले **Save project** करें।

## लिंक साझा करें

**Share model** (ऐप बार में 🔗, या ☰ मेनू) *Share model via URL* संवाद खोलता है:

- **Copy link** — लिंक क्लिपबोर्ड पर कॉपी करता है (या फ़ील्ड के भीतर क्लिक करें)।
- **Open link** — उसे नए टैब में खोलता है ताकि आप देख सकें कि प्राप्तकर्ता को क्या दिखेगा।
- **Share via system dialog** — फ़ोन और टैबलेट पर लिंक को OS की शेयर शीट को सौंपता है।

लिंक का रूप `https://run.edubeam.app/?model=…` है और यह पूरे मॉडल (नोड, अवयव, गुण, भार) को एन्कोड करता है। जो भी इसे खोलता है उसे स्थानीय रूप से संपादित करने के लिए एक सटीक प्रति मिलती है; संपादन वापस **समकालिक नहीं** होते—मॉडल बदलने पर नया लिंक भेजें। बहुत बड़े मॉडल से बहुत लंबे लिंक बनते हैं; उनके लिए JSON फाइल साझा करें।

## रीड-ओनली व्यूअर एम्बेड करें

साझा लिंक में `&viewer=1` (या किसी भी ऐप URL में `?viewer=1`) जोड़कर मॉडल को **व्यूअर मोड** में खोलें: ऐप बार, निचली पट्टी, पूर्ववत/पुनः करें और सेटिंग्स पैनल छिप जाते हैं और केवल वर्तमान मॉडल वाला कैनवास रहता है। व्याख्यान नोट्स या वेब पेज में लाइव, ज़ूम करने योग्य मॉडल एम्बेड करने के लिए उस URL को `<iframe>` में रखें:

```html
<iframe src="https://run.edubeam.app/?viewer=1&model=…" width="100%" height="400"></iframe>
```

[उदाहरण](/hi/examples/) पृष्ठ इसी तरह बना है—हर कार्ड `?model=` पैरामीटर वाला एक लिंक है।

## URL पैरामीटर

| पैरामीटर | प्रभाव |
| --- | --- |
| `model=<data>` | एन्कोड किया मॉडल लोड करें, उसे स्क्रीन पर फिट करें, फिर पता-पट्टी से पैरामीटर हटा दें। |
| `lang=<code>` | इंटरफ़ेस की भाषा बदलें (`en`, `cs`, `de`, `fr`, `es`, `pt`, `pl`, `cn`, `th`, `uk`, `ru`)। |
| `viewer=1` | केवल-पढ़ने योग्य व्यूअर मोड (ऊपर देखें)। |

## स्वतः संरक्षण

वर्तमान मॉडल और आपकी सेटिंग्स हर बदलाव के बाद ब्राउज़र के लोकल स्टोरेज में सहेजी जाती हैं और लौटने पर—ब्राउज़र बंद करने के बाद भी—बहाल होती हैं। यह सुविधा है, बैकअप नहीं: यह एक डिवाइस के एक ब्राउज़र प्रोफ़ाइल से बँधी है, और साइट डेटा साफ़ करने पर मिट जाती है। महत्वपूर्ण काम को प्रोजेक्ट फाइल के रूप में सहेजें।

## प्रोजेक्ट फाइल प्रारूप

`project.json` सादा, पढ़ने योग्य JSON है:

```json
{
  "edubeam": true,
  "version": "1.0.6",
  "domain": {
    "materials": [ { "label": "1", "e": 210000000000, "g": 81000000000, "alpha": 0.000012, "d": 7850 } ],
    "crossSections": [ { "label": "1", "a": 0.00285, "iy": 1.943e-5, "h": 0.2, "k": 1 } ],
    "nodes": [ { "label": "1", "coords": [0, 0, 0], "bcs": [0, 2] }, … ],
    "elements": [ { "label": "1", "nodes": ["1", "2"], "mat": "1", "cs": "1", "hinges": [false, false] } ],
    "loadCases": [ … ]
  }
}
```

प्रदर्शन इकाइयों की परवाह किए बिना सभी मान **SI इकाइयों** (m, N, Pa, rad) में संग्रहित हैं। सीमा शर्तें DOF आईडी `0 = Dx`, `2 = Dz`, `4 = Ry` का उपयोग करती हैं। प्रारूप सरल है, इसलिए आप स्क्रिप्ट या स्प्रेडशीट से मॉडल बनाकर उन्हें **Open project** से खोल सकते हैं। प्रारूप को स्थिर API के रूप में संस्करणित नहीं किया गया है, इसलिए इस पर स्वचालन करते समय `version` फ़ील्ड जाँचें।
