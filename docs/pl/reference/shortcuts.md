# Klawiatura i mysz

Skróty klawiaturowe działają, gdy widok ma fokus — są ignorowane podczas pisania w komórce tabeli lub w oknie dialogowym.

## Klawiatura

| Skrót | Działanie |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Cofnij |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Ponów |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Zapisz projekt (pobierz JSON) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Otwórz projekt |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Zaznacz wszystko |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Skopiuj zaznaczenie (węzły, elementy, obciążenia) do schowka EduBeam |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Wklej: zarys kopii podąża za kursorem; kliknij lewym przyciskiem, aby ją umieścić |
| <kbd>Delete</kbd> | Usuń zaznaczenie |
| <kbd>Esc</kbd> | Anuluj bieżący tryb myszy, wyczyść zaznaczenie, opuść komórkę tabeli |
| <kbd>Enter</kbd> | Zatwierdź komórkę tabeli |
| <kbd>F</kbd> | Dopasuj zawartość do ekranu |
| <kbd>C</kbd> | Wyśrodkuj zawartość |
| <kbd>G</kbd> | Przełącz siatkę |
| <kbd>S</kbd> | Przełącz przyciąganie do siatki |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Powiększ / pomniejsz |

Na macOS używaj <kbd>Cmd</kbd> tam, gdzie podano <kbd>Ctrl</kbd>.

## Mysz

| Czynność | Rezultat |
| --- | --- |
| Kliknięcie lewym przyciskiem | Zaznacz węzeł / element / obciążenie / linię wymiarową i otwórz jego menu podręczne |
| Przeciąganie lewym przyciskiem po pustym płótnie | Zaznaczanie prostokątem |
| Przeciąganie lewym przyciskiem węzła | Przesuń węzeł (przyciąga się do siatki, gdy przyciąganie jest włączone) |
| Kliknięcie lewym przyciskiem w trybie *Dodaj myszą* | Umieść węzeł albo rozpocznij / kontynuuj łamaną elementów |
| Dwukrotne kliknięcie obciążenia | Edytuj obciążenie |
| Kliknięcie prawym przyciskiem pustego płótna | Menu płótna: Dodaj węzeł, Dodaj element, Dodaj wymiar, Edytuj, Kopiuj, Wklej, Usuń |
| Przeciąganie środkowym lub prawym przyciskiem | Przesuwanie widoku (do zmiany w *Ustawienia → Sterowanie i skróty*) |
| Kółko | Powiększanie w kierunku kursora |
| Najechanie | Podpowiedź z przemieszczeniami / właściwościami / wartościami obciążeń |

## Dotyk

| Gest | Rezultat |
| --- | --- |
| Stuknięcie | Zaznacz |
| Przeciąganie jednym palcem | Przesuwanie widoku |
| Szczypanie | Powiększanie |
| Przytrzymanie węzła | Rozpocznij przesuwanie |

## Menu podręczne

Kliknięcie obiektu otwiera obok niego małe menu:

| Obiekt | Pozycje |
| --- | --- |
| Węzeł | Dodaj obciążenie · Podpory węzła (Dx / Dz / Ry, Kąt lokalnego układu) · Zadaj przemieszczenie (jeśli węzeł jest podparty) · Usuń |
| Element | Edytuj element (węzły, materiał, przekrój) · Dodaj obciążenie · Macierz sztywności · Usuń |
| Obciążenie węzłowe / elementu | Edytuj obciążenie · Usuń |
| Linia wymiarowa | Edytuj (współrzędne) · Odwróć wymiar · Usuń |
