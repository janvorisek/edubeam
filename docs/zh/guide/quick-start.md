# 快速入门

大约十分钟内，你将建立一根承受均布荷载的钢制简支梁模型，读取支反力、剪力和弯矩，并与教科书公式进行核对。

::: tip 跟着做
在另一个标签页中打开 [run.edubeam.app](https://run.edubeam.app/?lang=cn){target="_blank"}。如果已经有模型，请使用应用栏中的**清空结构**从空白开始；勾选*删除材料*和*删除截面*即可彻底重新开始。清空可以用 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 撤销，旧模型也会保留在 **☰ → 最近的结构**中。

更喜欢在屏幕提示下边做边学？**☰ → 绘制第一根梁**会带你用鼠标完成一根类似的梁。
:::

## 问题描述 {#the-problem}

<ExampleStructure />

一根 6 m 的简支梁（左端固定铰支座，右端滑动铰支座）承受 12 kN/m 的均布荷载。材料：钢材，$E = 210\ \text{GPa}$，$G = 81\ \text{GPa}$。截面：IPE 200，$A = 28.5\ \text{cm}^2$，$I_y = 1943\ \text{cm}^4$，$h = 200\ \text{mm}$。

## 1. 检查单位 {#_1-check-the-units}

视图右下角的单位标记显示了所有输入框和结果所用的单位。本教程采用国际单位制的默认设置：米、kN、kNm 和 MPa。

![网格 (G)、吸附 (S) 和十字准线开关，以及单位标记](/screenshots/zh/ui-grid-units.webp){.shot-sm}

如果看到的是 `ft · kip · kip·ft · ksi`，请点击该标记并选择**单位制 → 国际单位制（公制）**。

## 2. 添加材料和截面 {#_2-add-the-material-and-cross-section}

单元需要材料和截面，所以先创建它们。

1. 打开底部栏的**材料**标签页，点击**添加材料**。
2. 输入 `E = 210000` MPa 和 `G = 81000` MPa。密度和 `α = 0.000012` 1/K 保持不变。点击**添加材料**。

<div class="shots">

![添加材料：输入 E 和 G……](/screenshots/zh/qs-material.webp)

![……或从材料库中选择 Steel (S235)](/screenshots/zh/qs-material-library.webp)

</div>

3. 打开**截面**标签页，点击**添加截面**。
4. 输入 `面积 = 0.00285` m²、`Iy = 1.943e-5` m⁴、`高度 = 0.2` m 和 `剪切系数 = 1`。点击**添加截面**。

![添加截面。也可以从库中选择，或绘制多边形形状。](/screenshots/zh/qs-cross-section.webp){.shot-md}

::: details 剪切系数为什么重要？
EduBeam 使用 Timoshenko 梁单元，其中包含剪切变形。`k` 是剪切修正系数：矩形截面 $k \approx 0.83$；若 $A$ 取全截面面积，工字形截面约为 $0.4$–$0.5$。取 `k = 1` 并使用全截面面积会略微*低估*剪切柔度。对本例这样的细长梁，挠度差异远小于 1 %。公式见[梁单元理论页](/zh/elements/beam)。
:::

## 3. 添加节点 {#_3-add-the-nodes}

1. 打开**节点**标签页。这里有两个**添加节点**按钮：第一个打开对话框，第二个（带光标图标）用鼠标放置节点。点击第一个。
2. 输入 `X = 0`、`Z = 0`，点击**添加节点**。该节点的标签为 `1`。
3. 在 `X = 6`、`Z = 0` 处添加第二个节点。这是节点 `2`。

![添加节点对话框也可以直接设置支座](/screenshots/zh/qs-node.webp){.shot-md}

如果改用鼠标按钮，每次在画布上点击都会放置一个节点。开启**吸附到网格**（<kbd>S</kbd>）后，点击位置会落在网格步长上（默认 0.1 m）。

## 4. 用单元连接节点 {#_4-connect-them-with-an-element}

1. 打开**单元**标签页，点击第一个**添加单元**按钮。
2. 选择**起始节点** `1` 和**终止节点** `2`。你的材料和截面已被选中。点击**添加单元**。

![添加单元：两个端节点、可选的端部铰接、材料和截面](/screenshots/zh/qs-element.webp){.shot-md}

两个节点之间出现一条线。按 <kbd>F</kbd> 使其适配屏幕。

## 5. 添加支座 {#_5-add-the-supports}

在**节点**标签页中，**受约束自由度**一列为每个节点提供一个支座符号选择器和三个复选框：`Dx`、`Dz`、`Ry`。

- 节点 `1`：选择**固定铰支座**符号，或勾选 **Dx** 和 **Dz**。
- 节点 `2`：选择**滑动铰支座**，或仅勾选 **Dz**。

![节点表格中的支座：节点 1 为固定铰支座，节点 2 为滑动铰支座](/screenshots/zh/qs-supports.webp)

也可以在视图中点击节点并选择**节点支座**。[节点与支座](/zh/essentials/nodes-supports#supports)列出了所有支座类型。

## 6. 添加荷载 {#_6-add-the-load}

1. 打开**荷载**标签页，点击**添加单元荷载**。
2. **荷载类型**：*均布荷载*。**单元**：`1`。
3. 输入 `fz = 12` kN/m，`fx = 0` 保持不变。点击**添加单元荷载**。

![对话框会在单元上预览荷载](/screenshots/zh/qs-load.webp){.shot-md}

正的 `fz` 指向 +z 方向，在屏幕上是**向下**，因此正值就是重力荷载。见[符号约定](/zh/elements/conventions)。

## 7. 读取结果 {#_7-read-the-results}

荷载一添加，结果就出现了。视图右上角的显示面板用于打开或关闭各种内力图。**变形图**、**M<sub>y</sub>(x)** 和**支反力**默认开启。勾选 **V<sub>z</sub>(x)** 可以加上剪力图。

![剪力（绿色）、弯矩（红色）、支反力（紫色）和变形图](/screenshots/zh/qs-results.webp)

| 图形 | 你应该看到的 |
| --- | --- |
| **支反力** | 节点 1 和节点 2 处各有一个 **36 kN** 的向上箭头。 |
| **V<sub>z</sub>(x)** | 一条直线，从左端的 **+36 kN** 到右端的 **−36 kN**，在跨中过零。 |
| **M<sub>y</sub>(x)** | 一条抛物线，跨中极值为 **54 kNm**。 |
| **变形图** | 对称的下垂。指向节点 `1` 可读出其转角：**2.6469 · 10⁻² rad**。 |

底部栏的**结果**标签页给出具体数值。**节点结果**列出每个节点的 `Dx`、`Dz`、`Ry`。**单元结果**列出每个单元在其局部坐标系中的端力。

如果内力图显得过大或过小，请在**设置 → 视图设置 → 尺寸**中修改**结果缩放**。

## 8. 手算核对 {#_8-check-by-hand}

| 物理量 | 公式 | 手算值 | EduBeam |
| --- | --- | --- | --- |
| 支反力 | $R = qL/2$ | 36 kN | 36 kN |
| 最大剪力 | $V = qL/2$ | 36 kN | 36 kN |
| 最大弯矩 | $M = qL^2/8$ | 54 kNm | 54 kNm |
| 端部转角 | $\varphi = qL^3/(24EI)$ | 0.02647 rad | 0.02647 rad |
| 跨中挠度（弯曲） | $w = 5qL^4/(384EI)$ | 49.63 mm | |
| 跨中挠度（剪切） | $w_s = qL^2/(8kGA)$ | 0.23 mm | |
| 跨中挠度（总计） | 两者之和 | 49.86 mm | 49.86 mm |

跨中没有节点，因此要读取那里的挠度，需要加一个节点：选择第二个**添加节点**按钮，在梁上 `X = 3` 处点击，然后选择**连接到结构**。梁被拆分为两段，新节点在**结果**中的 `Dz` 为 49.86 mm。拆分不会改变任何结果，因为单元是精确的。

全部吻合。更多手算校核方法（悬臂梁、两端固定梁、桁架、温度荷载）见[手算校核结果](/zh/guide/verification)。

## 9. 动手试试 {#_9-experiment}

这正是 EduBeam 的价值所在。逐一尝试下面的操作，观察内力图的变化：

- 向右**拖动节点 2**：弯矩按 $L^2$ 增大。
- **勾选节点 1 的 `Ry`** 使其固定：跨中弯矩减小，支座处出现负弯矩。
- 在刚添加的跨中节点处**勾选 `Dz`**，得到一根两跨连续梁。
- 在单元标签页中为某个单元**勾选端部铰接**，释放一端的弯矩。
- 按 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 可撤销任何一步。

## 10. 保存或分享 {#_10-save-or-share}

- **分享模型**（在应用栏或 ☰ 菜单中）会给出一个包含整个模型的链接。可以把它粘贴到电子邮件、聊天或幻灯片中。
- **☰ → 保存项目**（<kbd>Ctrl</kbd>+<kbd>S</kbd>）会下载一个 `project.json`，之后可以用**打开项目**或直接把它拖到应用上来打开。
- **☰ → 导出图像**（<kbd>Ctrl</kbd>+<kbd>P</kbd>）将图形保存为 PNG 或 SVG，用于报告。

模型也会保存在浏览器中，因此重新加载页面不会丢失。见[导入、导出与分享](/zh/essentials/import-export)。
