# การแก้ปัญหา

## ไม่มีผลลัพธ์แสดง {#no-results-are-drawn}

ผลลัพธ์จะแสดงเฉพาะเมื่อคำนวณโมเดลได้ ให้ตรวจสอบตามลำดับนี้:

1. **อ่านข้อความที่มุมซ้ายบนของหน้าจอแสดงผล**
   - *ไม่มีการกำหนดวัสดุ* / *ไม่มีการกำหนดหน้าตัด*: เพิ่มด้วยปุ่ม **เพิ่มใหม่**
   - ป้ายสีฟ้า **ต้องมีจุดรองรับ**: โมเดลแค่ยังสร้างไม่เสร็จ ให้เพิ่มจุดรองรับ ชี้เมาส์ที่ป้ายเพื่อดูเส้นประที่แสดงว่าโครงสร้างยังเคลื่อนที่ได้อย่างไร
   - **ข้อความสีแดง**: มีบางอย่างผิดพลาด ข้อความจะบอกปัญหา หรือแสดงเป็น *โมเดลมีข้อผิดพลาด N รายการ* เมื่อมีหลายปัญหา คลิก **แสดงรายละเอียด** แล้วแก้ทีละรายการ (ดูตารางด้านล่าง) โหนดหรือจุดหมุนที่เกี่ยวข้องจะถูกวงไว้บนพื้นที่วาด
   - **ข้อความสีเหลือง**: คำเตือน โมเดลยังคำนวณได้ และคุณซ่อนคำเตือนได้
2. **จุดรองรับพอหรือไม่?** ตัวคำนวณต้องการ DOF ที่ถูกยึดอย่างน้อยสามรายการ และจุดรองรับต้องยึดโครงสร้างไว้ได้ คานบนล้อเลื่อนสองตัว (Dz + Dz) มีเพียงสองรายการและจะเลื่อนหลุดไป ให้เพิ่ม `Dx` ที่ใดที่หนึ่ง หรือ `Ry` ที่จุดรองรับหนึ่งจุด
3. **องค์ประกอบเชื่อมต่อกันหรือไม่?** โหนดสองโหนดที่มีพิกัดเดียวกันยังเป็นสองโหนดแยกกัน ลบโหนดที่เกินแล้วเชื่อมใหม่ หรือวางโหนดบนองค์ประกอบด้วย **เชื่อมต่อกับโครงสร้าง**
4. **จุดหมุนมากเกินไปหรือไม่?** จุดหมุนที่ปลายทั้งสองของเสา หรือสี่เหลี่ยมของชิ้นส่วนที่ต่อแบบหมุดโดยไม่มีชิ้นส่วนทแยง จะเกิดเป็นกลไก EduBeam จะวงจุดหมุนเหล่านั้นและแสดงการเคลื่อนที่
5. **ความแข็งเกร็งเป็นศูนย์หรือไม่?** `E`, `A` หรือ `Iy` ที่ใส่เป็น 0 โดยไม่ตั้งใจ หรือใส่ผิดหน่วย ทำให้บางส่วนของโครงสร้างเคลื่อนที่ได้โดยแทบไม่มีความต้านทาน EduBeam จะรายงานว่า *ไม่เสถียร*

## ข้อความ {#messages}

**แสดงรายละเอียด** เปิดกล่องโต้ตอบที่มีชื่อ *ไม่สามารถแก้โมเดลได้* (ข้อผิดพลาด) *ยังไม่พร้อมคำนวณ* (ยังต้องมีจุดรองรับ) หรือ *คำเตือนของโมเดล* ลิงก์ **การแก้ปัญหา** ในกล่องนั้นพามาที่หน้านี้

### สิ่งที่ยังขาด {#still-needed}

| ข้อความ | ความหมาย / วิธีแก้ |
| --- | --- |
| *โครงสร้างต้องมีจุดรองรับจึงจะคำนวณได้* | DOF ที่ถูกยึดรวมกันน้อยกว่าสามรายการ ให้เพิ่มจุดรองรับ |
| *ส่วนที่แยกออกของโครงสร้าง (โหนด …) มีองศาความเป็นอิสระที่ถูกยึดน้อยกว่า 3 รายการ และสามารถเคลื่อนที่ได้อย่างอิสระ* | โมเดลแยกเป็นหลายส่วนและมีส่วนหนึ่งลอยอยู่ ให้เชื่อมต่อหรือใส่จุดรองรับให้ส่วนนั้น |

### ข้อผิดพลาด {#errors}

| ข้อความ | ความหมาย / วิธีแก้ |
| --- | --- |
| *โครงสร้างมีจุดรองรับเพียงพอ แต่จุดรองรับไม่สามารถยึดโครงสร้างไว้ได้: โครงสร้างยังสามารถ…* | จุดรองรับขนานกันทั้งหมด หรือแนวแรงตัดกันที่จุดเดียว เส้นประแสดงการเคลื่อนที่ ให้เปลี่ยนทิศของจุดรองรับหนึ่งจุด ถ้าปัญหาเกิดกับเพียงส่วนเดียว ข้อความเดียวกันจะระบุเป็น *ส่วนที่แยกออก* |
| *จุดรองรับยึดโครงสร้างไว้ได้ แต่โครงสร้างยังเป็นกลไก: ชิ้นส่วนหมุนรอบบานพับที่โหนด …* | จุดหมุนทำให้ชิ้นส่วนหมุนสัมพัทธ์กันได้ เช่น โครงข้อแข็งที่มีจุดหมุนที่ยอดเสาทั้งสองต้น หรือสี่เหลี่ยมที่ต่อแบบหมุดโดยไม่มีชิ้นส่วนทแยง ให้เอาจุดหมุนออก หรือเพิ่มชิ้นส่วนหรือจุดรองรับ |
| *โครงสร้างไม่เสถียร: โหนด … เคลื่อนที่ได้โดยแทบไม่มีความต้านทาน* | เกือบเป็นกลไก หรือความแข็งเกร็งเกือบเป็นศูนย์ ตรวจสอบจุดรองรับ จุดหมุน และค่า `E`, `A` และ `Iy` |
| *โครงสร้างเป็นกลไก: เมทริกซ์ความแข็งเป็นเมทริกซ์เอกฐาน* | มีบางส่วนเคลื่อนที่ได้อิสระโดยที่การตรวจสอบข้างต้นจับไม่ได้ ตรวจสอบว่าทุกส่วนถูกยึดด้วยการยึดอย่างน้อยสามรายการ และจุดหมุนไม่ทำให้ชิ้นส่วนใดหมุนได้อย่างอิสระ |
| *องค์ประกอบ … อ้างอิงโหนด / วัสดุ / หน้าตัด … ที่ไม่มีอยู่* | วัตถุที่อ้างอิงถูกลบไปแล้ว มักเกิดจากการแก้ไขไฟล์ JSON ด้วยมือ ให้กำหนดใหม่ในตาราง *องค์ประกอบ* |
| *องค์ประกอบ … ต้องอ้างอิงโหนดจำนวน 2 โหนดพอดี* | องค์ประกอบที่เสียหายในไฟล์ที่นำเข้า ให้ลบแล้วสร้างใหม่ |
| *แรงกระทำที่โหนด / การให้ค่าการกระจัด #n อ้างอิงโหนด … ที่ไม่มีอยู่* | ลบแรงกระทำนั้น หรือกำหนดโหนดให้ |
| *แรงกระทำที่องค์ประกอบ #n อ้างอิงองค์ประกอบ … ที่ไม่มีอยู่* | ลบแรงกระทำนั้น |
| *การคำนวณล้มเหลวเนื่องจากความไม่สอดคล้องภายในโมเดล…* | ความผิดพลาดทั่วไป ให้เลิกทำขั้นล่าสุด หรือบันทึกไฟล์แล้ว [รายงานปัญหา](https://github.com/janvorisek/edubeam/issues) |

### คำเตือน {#warnings}

โมเดลยังคำนวณได้ แต่ควรตรวจสอบรายการเหล่านี้:

| ข้อความ | ความหมาย / วิธีแก้ |
| --- | --- |
| *โหนด … ไม่ได้เชื่อมต่อกับองค์ประกอบใด และจะถูกละเว้นในการคำนวณ* | โหนดที่หลงเหลือ ให้ลบหรือเชื่อมต่อ |
| *โหนด … มีจุดรองรับ แต่ไม่มีองค์ประกอบใดเชื่อมต่อ จุดรองรับจึงไม่ได้รับแรงใดๆ* | จุดรองรับบนโหนดที่หลงเหลือ |
| *องค์ประกอบ … อ้างอิงโหนดเดียวกันที่ปลายทั้งสองด้าน* | องค์ประกอบที่มีความยาวเป็นศูนย์ ให้ลบออก |
| *แรงกระทำที่โหนด / การให้ค่าการกระจัด #n มีค่าที่ไม่ถูกต้อง* | มีส่วนประกอบที่ไม่ใช่ตัวเลข ให้แก้ไขแรงกระทำ |

## ผลลัพธ์ดูผิดปกติ {#results-look-wrong}

| อาการ | สาเหตุที่เป็นไปได้ |
| --- | --- |
| แรงกระทำมีทิศขึ้น | แกนรวม **z ชี้ลง** `Fz`/`fz` ที่เป็นบวกจึงมีทิศลง ค่าลบมีทิศขึ้น ดู [ข้อตกลง](/th/elements/conventions) ถ้าใช้แกน y ชี้ขึ้นจะกลับกัน |
| การโก่งตัวมากหรือน้อยไป 1000 เท่า | ใช้หน่วยสับสน: ใส่ `E` เป็น Pa ขณะที่หน่วยเป็น MPa หรือใส่ `Iy` เป็น cm⁴ ขณะที่หน่วยเป็น m⁴ ตรวจสอบป้ายหน่วยที่มุมขวาล่างของหน้าจอแสดงผล |
| การโก่งตัวมากกว่าสูตรในตำราเล็กน้อย | การเสียรูปเนื่องจากแรงเฉือนของ Timoshenko เพิ่มสัมประสิทธิ์เฉือนของหน้าตัด หรือใช้ชิ้นส่วนชะลูด เพื่อให้ใกล้ค่าตาม Euler–Bernoulli ดู [ตรวจสอบผลลัพธ์ด้วยการคำนวณมือ](/th/guide/verification) |
| เครื่องหมายดู "ผิด" | อ่านเครื่องหมายจากป้าย ไม่ใช่จากด้านที่วาดแผนภาพ M ที่เป็นบวกคือโมเมนต์บวก (เส้นใยล่างรับแรงดึง) แรงปลายใน *ผลลัพธ์ที่องค์ประกอบ* เป็นไปตามแกนท้องถิ่นขององค์ประกอบ ไม่ใช่ข้อตกลง N-V-M |
| เสาสองต้นที่เหมือนกันมีเครื่องหมายแรงเฉือนตรงข้ามกัน | เครื่องหมายของ V เป็นไปตามทิศของแต่ละองค์ประกอบ สลับโหนดของต้นหนึ่งเพื่อเปรียบเทียบ |
| ตัวเลขอย่าง `4 · 10¹` | รูปแบบตัวเลขแบบวิทยาศาสตร์ เลือก *อัตโนมัติ* ใน *การตั้งค่า → ภาษาและภูมิภาค → รูปแบบตัวเลข* |
| แผนภาพใหญ่หรือเล็กมาก | เป็นเรื่องการแสดงผลเท่านั้น ปรับ **ขนาดผลลัพธ์** ใน *การตั้งค่า → การตั้งค่าโปรแกรมดู* |
| แรงกระทำในพิกัดท้องถิ่นชี้ผิดทาง | แกน x ท้องถิ่นขององค์ประกอบวิ่งจากโหนด *เริ่มต้น* ไปยังโหนด *ปลาย* ให้สลับโหนดหรือกลับเครื่องหมาย |
| แรงกระทำบนชิ้นส่วนเอียงไม่ถูกต้อง | **LCS** ติ๊กไว้เป็นค่าเริ่มต้น `fz` จึงกระทำตั้งฉากกับชิ้นส่วน ยกเลิกการติ๊กถ้าต้องการแรงแนวดิ่ง |
| แรงกระทำเนื่องจากอุณหภูมิไม่มีผล | โครงสร้างดีเทอร์มิเนทเสียรูปได้อย่างอิสระภายใต้อุณหภูมิโดยไม่เกิดแรงภายใน ตรวจสอบว่า α ≠ 0 และสำหรับผลต่างอุณหภูมิ ตรวจว่าได้กำหนดความสูงหน้าตัด h แล้ว |

## ปัญหาของอินเทอร์เฟซ {#interface-issues}

| อาการ | วิธีแก้ |
| --- | --- |
| ทางลัดไม่ทำงาน | คลิกบนพื้นที่วาดก่อน: แป้นพิมพ์จะไม่ทำงานขณะช่องข้อความได้รับโฟกัส |
| เลื่อนมุมมองไม่ได้ | ค่าเริ่มต้นใช้ปุ่มกลางหรือปุ่มขวาของเมาส์ในการเลื่อน เปลี่ยนได้ใน *การตั้งค่า → การควบคุมและทางลัด* บนทัชแพด การเลื่อนด้วยสองนิ้วจะซูม ให้คลิกแล้วลากด้วยสองนิ้วเพื่อเลื่อนมุมมอง |
| โมเดลของฉันหายไป | การเปิดลิงก์ ไฟล์ หรือตัวอย่าง และการลบ Mesh จะเก็บโมเดลเดิมไว้: **☰ → โครงสร้างล่าสุด** หรือ <kbd>Ctrl</kbd>+<kbd>Z</kbd> |
| ภาษาไม่ถูกต้อง | *การตั้งค่า → ภาษาและภูมิภาค* หรือเพิ่ม `?lang=th` ต่อท้ายที่อยู่ |
| การตั้งค่าที่เปลี่ยนไม่ถูกเก็บไว้ | local storage ถูกบล็อก (หน้าต่างส่วนตัว โหมดความเป็นส่วนตัวแบบเข้มงวด) การตั้งค่า การบันทึกอัตโนมัติ และโครงสร้างล่าสุดต้องใช้ local storage |

## การรายงานบั๊ก {#reporting-a-bug}

เปิด [issue บน GitHub](https://github.com/janvorisek/edubeam/issues) ระบุเบราว์เซอร์และระบบปฏิบัติการ สิ่งที่คุณคาดหวัง และที่มีประโยชน์ที่สุดคือ **ลิงก์แชร์** หรือ **ไฟล์โปรเจกต์** ที่ทำให้เกิดปัญหาซ้ำได้
