# Інтерфейс користувача

<Edubeam /> має три зони. Дізнайтеся, що де розташовано, — і решта документації стане зрозумілою.

```
┌──────────────────────────────────────────────────────────────────┐
│ ☰  edubeam   🗑 Очистити модель  🔗 Поділитися моделлю  Що нового? │  ← Панель застосунку
├──────────────────────────────────────────────────────────────────┤
│ Вигляд | Налаштування                                            │  ← Вкладки
│ ↶ ↷                                            ⌖  ⤢  ⚙            │
│                                                                  │
│                     полотно (модель)              [перемикачі    │  ← Вікно перегляду
│                                                     відображення]│
│                                           G  S  m·kN·kNm·MPa     │
├──────────────────────────────────────────────────────────────────┤
│ Вузли | Елементи | Навантаження | Матеріали | Перерізи | Результати│  ← Нижня панель
│ [Додати вузол] [Додати мишею]        таблиця об'єктів …          │
└──────────────────────────────────────────────────────────────────┘
```

## Панель застосунку

| Елемент керування | Що робить |
| --- | --- |
| **Меню ☰** | **Відкрити проєкт**, **Зберегти проєкт**, **Поділитися моделлю**, **Очистити модель**, а також версія застосунку. |
| **Очистити модель** 🗑 | Видаляє всі вузли, елементи й навантаження після підтвердження. Два прапорці дають змогу видалити також матеріали та перерізи. Дію не можна скасувати. |
| **Поділитися моделлю** 🔗 | Відкриває [діалог обміну](/uk/essentials/import-export#поділитися-посиланням) з URL, що кодує всю модель. |
| **Що нового?** | Примітки до випусків. |
| **Документація** / GitHub | Посилання на цей сайт і на вихідний код. |

У [режимі перегляду](/uk/essentials/import-export#вбудувати-перегляд-лише-для-читання) панель застосунку прихована.

## Вікно перегляду

Полотно — це місце, де ви креслите й досліджуєте модель. Усе інше в застосунку відображає те, що ви тут вибрали.

### Кнопки поверх полотна

- **Угорі ліворуч:** **Скасувати** / **Повторити** (також <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>). Кожну зміну моделі — додавання, редагування, перетягування, видалення — можна скасувати.
- **Угорі праворуч:** **Центрувати вміст** (<kbd>C</kbd>), **Вписати вміст в екран** (<kbd>F</kbd>) і перемикач **налаштувань відображення** ⚙.
- **Унизу праворуч:** **G** вмикає/вимикає сітку, **S** — прив'язку до сітки; **чип одиниць** показує активні одиниці й відкриває налаштування при клацанні.

### Панель налаштувань відображення

Відкривається кнопкою ⚙. Два ряди прапорців:

- **Результати:** *Деформована форма*, *N (x)*, *V<sub>z</sub> (x)*, *M<sub>y</sub> (x)*, *Реакції*.
- **Модель:** *Опори*, *Навантаження*, *Мітки вузлів*, *Мітки елементів*.

**Додаткові налаштування** відкривають повний [діалог налаштувань](/uk/essentials/units-settings).

### Навігація

| Дія | Миша / сенсорний екран |
| --- | --- |
| Масштабування | Колесо миші (масштабує в бік курсора), <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd>; щипок на сенсорних екранах |
| Панорамування | Перетягування **середньою або правою** кнопкою миші (налаштовується в *Налаштування → Керування та гарячі клавіші*); перетягування одним пальцем на сенсорному екрані |
| Вписати / центрувати | <kbd>F</kbd> / <kbd>C</kbd> або кнопки у правому верхньому куті |

### Вибір і редагування

- **Клацніть** вузол, елемент, навантаження чи розмірну лінію, щоб вибрати. Нижня панель перемикається на відповідну вкладку, а поруч із виділенням з'являється невелике **спливне меню** з доступними для цього об'єкта діями (наприклад, *Додати навантаження*, *Опори вузла*, *Редагувати елемент*, *Матриця жорсткості*, *Видалити*).
- **Потягніть по порожньому полотну**, щоб окреслити прямокутник виділення. Виділяється все всередині — вузли, елементи, їхні навантаження та розмірні лінії. Натисніть <kbd>Delete</kbd>, щоб видалити все це, або <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd>, щоб скопіювати й вставити в іншому місці.
- **Перетягніть вузол**, щоб перемістити його. З увімкненою прив'язкою він стає на сітку. Приєднані елементи та їхні навантаження рухаються разом із ним.
- **Двічі клацніть навантаження**, щоб відредагувати його.
- **Наведіть курсор** на будь-що, щоб побачити підказку: вузли показують переміщення й кут повороту, елементи — матеріал і переріз, навантаження — свої компоненти.
- **Клацніть правою кнопкою на порожньому полотні**, щоб відкрити меню полотна: *Додати вузол*, *Додати елемент*, *Додати розмір*, *Редагувати* (відкриває таблицю поточного виділення), *Копіювати*, *Вставити*, *Видалити*. Утримуйте <kbd>Ctrl</kbd>, вибираючи *Додати вузол* / *Додати елемент*, щоб розміщувати їх мишею замість діалогу.

Усі гарячі клавіші перелічено на сторінці [Клавіатура та миша](/uk/reference/shortcuts).

### Сповіщення

Коли щось не так, у лівому верхньому куті вікна перегляду з'являються повідомлення: *Матеріали не визначено.* / *Перерізи не визначено.* (з кнопкою **Додати**) або *Model has N error(s)* з кнопкою **Show details**, яка перелічує всі проблеми (повідомлення розв'язувача наразі показуються англійською). Див. [Усунення проблем](/uk/reference/troubleshooting).

## Нижня панель

Шість вкладок, кожна з лічильником, панеллю інструментів і редагованою таблицею. Тягніть роздільник над панеллю, щоб змінити її розмір, або згорніть її кнопкою праворуч.

| Вкладка | Панель інструментів | Таблиця |
| --- | --- | --- |
| **Вузли** | Додати вузол (діалог), Додати мишею | Мітка, X, Z, прапорці **Закріплені ступені вільності**, навантаження на вузол, видалення |
| **Елементи** | Додати елемент (діалог), Додати мишею | Мітка, тип, початковий/кінцевий вузол (+ *Поміняти порядок вузлів*), матеріал, переріз, **Кінцеві шарніри**, навантаження на елемент, матриця жорсткості, видалення |
| **Навантаження** | Додати вузлове навантаження, Додати навантаження на елемент | Тип, точка прикладання, редаговані компоненти, видалення |
| **Матеріали** | Додати матеріал, Бібліотека матеріалів | Мітка, E, G, α<sub>T</sub>, видалення |
| **Перерізи** | Додати переріз, Бібліотека перерізів | Мітка, A, I<sub>y</sub>, h, k, видалення |
| **Результати** | Перемикач Вузлові результати / Результати по елементах | Переміщення й кути повороту для кожного вузла або кінцеві зусилля для кожного елемента |

Комірки редагуються на місці — клацніть, введіть значення, натисніть <kbd>Enter</kbd> (або <kbd>Esc</kbd>, щоб вийти з комірки). Значення показуються та вводяться в [поточних одиницях](/uk/essentials/units-settings).

## Вкладки над вікном перегляду

Вкладка **Вигляд** присутня завжди. Відкриття налаштувань додає поруч закривану вкладку **Налаштування**, тож можна змінювати кольори чи одиниці, дивлячись на модель.

## Плаваючі вікна

Деякі дії відкривають перетягувані вікна поверх вікна перегляду: **Матриця жорсткості** (зі спливного меню елемента або рядка таблиці) показує матрицю жорсткості елемента 6 × 6 у локальних і глобальних координатах; **Редагувати** в меню полотна відкриває таблицю поточного виділення. Закривайте їх хрестиком ×.
