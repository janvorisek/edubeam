# Tastatur, Maus & Touch

Tastenkürzel funktionieren, solange die Ansicht den Fokus hat. Während Sie in einer Tabellenzelle oder einem Dialog tippen, werden sie ignoriert; klicken Sie zuerst auf die Zeichenfläche.

## Tastatur {#keyboard}

| Tastenkürzel | Aktion |
| --- | --- |
| <kbd>Strg</kbd>+<kbd>Z</kbd> | Rückgängig |
| <kbd>Strg</kbd>+<kbd>Umschalt</kbd>+<kbd>Z</kbd> | Wiederholen |
| <kbd>Strg</kbd>+<kbd>S</kbd> | Projekt speichern (JSON herunterladen) |
| <kbd>Strg</kbd>+<kbd>O</kbd> | Projekt öffnen |
| <kbd>Strg</kbd>+<kbd>P</kbd> | Bild exportieren |
| <kbd>Strg</kbd>+<kbd>A</kbd> | Alles auswählen |
| <kbd>Strg</kbd>+<kbd>C</kbd> | Auswahl kopieren (Knoten, Elemente und ihre Lasten) |
| <kbd>Strg</kbd>+<kbd>V</kbd> | Einfügen: Ein Schattenbild der Kopie folgt dem Cursor; klicken Sie, um es zu platzieren, oder geben Sie im Banner einen Versatz Δx, Δz ein und drücken Sie **Einfügen** |
| <kbd>Entf</kbd> | Auswahl löschen |
| <kbd>Esc</kbd> | Aktuellen Mausmodus abbrechen, den Rundgang schließen, die Auswahl aufheben oder eine Tabellenzelle verlassen |
| <kbd>Enter</kbd> | Tabellenzelle bestätigen |
| <kbd>F</kbd> | Inhalt an Bildschirm anpassen |
| <kbd>C</kbd> | Inhalt zentrieren |
| <kbd>G</kbd> | Raster ein/aus |
| <kbd>S</kbd> | Am Raster ausrichten ein/aus |
| <kbd>Strg</kbd>+<kbd>=</kbd> / <kbd>Strg</kbd>+<kbd>-</kbd> | Vergrößern / verkleinern |

Auf einem Mac verwenden Sie <kbd>Cmd</kbd>, wo <kbd>Strg</kbd> angegeben ist.

## Maus {#mouse}

| Aktion | Ergebnis |
| --- | --- |
| Klick | Einen Knoten, ein Element, eine Last oder eine Bemaßungslinie auswählen und das zugehörige Panel öffnen |
| Ziehen auf leerer Zeichenfläche | Auswahlrechteck |
| Einen Knoten ziehen | Den Knoten verschieben (rastet bei aktivem Fangen am Raster ein) |
| Klick im Mausmodus | Einen Knoten setzen oder einen Polygonzug aus Elementen beginnen oder fortsetzen |
| Doppelklick auf eine Last | Die Last bearbeiten |
| Rechtsklick | Menü der Zeichenfläche: Knoten hinzufügen, Element hinzufügen, Bemaßung hinzufügen, Element … bemaßen (über einem Element), Bearbeiten, Kopieren, Einfügen, Löschen |
| <kbd>Strg</kbd> (<kbd>Cmd</kbd> auf einem Mac) + Knoten hinzufügen / Element hinzufügen im Menü der Zeichenfläche | Mit der Maus statt per Dialog platzieren |
| Ziehen mit mittlerer oder rechter Taste | Verschieben (siehe *Einstellungen → Steuerung & Tastenkürzel*) |
| Mausrad | Zum Cursor hin zoomen |
| Auf ein Objekt zeigen | Tooltip mit Verschiebungen, Eigenschaften oder Lastwerten |

Auf einem Trackpad zoomt das Scrollen mit zwei Fingern. Zum Verschieben klicken und ziehen Sie mit zwei Fingern (entspricht Ziehen mit der rechten Taste).

## Touch {#touch}

| Geste | Ergebnis |
| --- | --- |
| Tippen | Auswählen und die Details und Aktionen des Objekts anzeigen |
| Tippen im Mausmodus | Einen Knoten setzen oder ein Element fortsetzen |
| Einen Knoten drücken und ziehen | Den Knoten verschieben |
| Ziehen mit einem Finger an anderer Stelle | Ansicht verschieben |
| Zwei Finger auseinander- oder zusammenziehen | Zoomen |
| Zeichenfläche gedrückt halten | Menü der Zeichenfläche |
| Schaltfläche **Rechteckauswahl** (oben rechts), dann ziehen | Auswahlrechteck |

## Objektpanels {#object-panels}

Ein Klick auf ein Objekt öffnet daneben ein Panel mit seinen Details und diesen Aktionen:

| Objekt | Aktionen |
| --- | --- |
| Knoten | Last hinzufügen · Knotenlagerung (Lagersymbol, Dx / Dz / Ry, Knoten-LKS-Winkel) · Verschiebung vorgeben (an einem gelagerten Knoten) · Löschen |
| Element | Element bearbeiten (Knoten und Gelenke, Material, Querschnitt) · Last hinzufügen · Steifigkeitsmatrix · Löschen |
| Knoten- oder Elementlast | Last bearbeiten · Löschen |
| Bemaßungslinie | Bearbeiten (Koordinaten) · Bemaßung umkehren · Löschen |
