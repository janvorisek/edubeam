# Клавіатура та миша

Гарячі клавіші працюють, коли фокус у вікні перегляду, — вони ігноруються, поки ви вводите текст у комірці таблиці чи діалозі.

## Клавіатура

| Комбінація | Дія |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Скасувати |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Повторити |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Зберегти проєкт (завантажити JSON) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Відкрити проєкт |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Виділити все |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Скопіювати виділення (вузли, елементи, навантаження) у буфер обміну EduBeam |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Вставити: контур копії рухається за курсором; клацніть лівою кнопкою, щоб розмістити |
| <kbd>Delete</kbd> | Видалити виділення |
| <kbd>Esc</kbd> | Скасувати поточний режим миші, зняти виділення, вийти з комірки таблиці |
| <kbd>Enter</kbd> | Підтвердити комірку таблиці |
| <kbd>F</kbd> | Вписати вміст в екран |
| <kbd>C</kbd> | Центрувати вміст |
| <kbd>G</kbd> | Увімкнути/вимкнути сітку |
| <kbd>S</kbd> | Увімкнути/вимкнути прив'язку до сітки |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Збільшити / зменшити масштаб |

На macOS використовуйте <kbd>Cmd</kbd> там, де вказано <kbd>Ctrl</kbd>.

## Миша

| Дія | Результат |
| --- | --- |
| Клацання лівою кнопкою | Вибрати вузол / елемент / навантаження / розмірну лінію та відкрити спливне меню |
| Перетягування лівою кнопкою по порожньому полотну | Виділення прямокутником |
| Перетягування лівою кнопкою вузла | Перемістити вузол (прив'язується до сітки, якщо прив'язка ввімкнена) |
| Клацання лівою кнопкою в режимі *Додати мишею* | Поставити вузол або почати / продовжити ламану елементів |
| Подвійне клацання навантаження | Редагувати навантаження |
| Клацання правою кнопкою на порожньому полотні | Меню полотна: Додати вузол, Додати елемент, Додати розмір, Редагувати, Копіювати, Вставити, Видалити |
| Перетягування середньою або правою кнопкою | Панорамування (налаштовується в *Налаштування → Керування та гарячі клавіші*) |
| Колесо | Масштабування в бік курсора |
| Наведення | Підказка з переміщеннями / властивостями / значеннями навантаження |

## Сенсорний екран

| Жест | Результат |
| --- | --- |
| Дотик | Вибрати |
| Перетягування одним пальцем | Панорамування |
| Щипок | Масштабування |
| Довге натискання на вузол | Почати його переміщення |

## Спливні меню

Клацання по об'єкту відкриває поруч невелике меню:

| Об'єкт | Пункти |
| --- | --- |
| Вузол | Додати навантаження · Опори вузла (Dx / Dz / Ry, Кут локальної системи координат) · Задати переміщення (якщо є опора) · Видалити |
| Елемент | Редагувати елемент (вузли, матеріал, переріз) · Додати навантаження · Матриця жорсткості · Видалити |
| Вузлове навантаження / навантаження на елемент | Редагувати навантаження · Видалити |
| Розмірна лінія | Редагувати (координати) · Змінити напрям розміру · Видалити |
