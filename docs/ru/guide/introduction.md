# Введение

<Edubeam /> — это бесплатный браузерный инструмент для **расчёта плоских стержневых систем**: балок, рам и ферм. Вы рисуете конструкцию, задаёте опоры и нагрузки, а конечно-элементный решатель пересчитывает всё в тот же момент, когда вы что-то меняете. Ни кнопки «Рассчитать», ни установки, ни учётной записи.

[Запустите EduBeam](https://run.edubeam.app/?lang=ru){target="_blank"} в новой вкладке и следуйте [быстрому старту](/ru/guide/quick-start).

## Что умеет EduBeam

| Область | Возможности |
| --- | --- |
| **Конструкции** | Плоские (x–z) балки, неразрезные балки, рамы и фермы из узлов и 2D-элементов балки Тимошенко. Концевые шарниры превращают любой стержень в стержень фермы. |
| **Опоры** | Любая комбинация закреплённых степеней свободы `Dx`, `Dz`, `Ry` в узле → жёсткая заделка, шарнирно-неподвижная, шарнирно-подвижная опора, скользящая заделка… Наклонные опоры через угол локальной системы координат узла. |
| **Нагрузки** | Узловые силы и моменты, заданные перемещения (осадки опор), равномерно распределённые и трапециевидные погонные нагрузки (в глобальных или локальных осях), сосредоточенные нагрузки в любой точке стержня, равномерный и неравномерный нагрев. |
| **Результаты** | Деформированная форма, продольная сила **N**, поперечная сила **V<sub>z</sub>**, изгибающий момент **M<sub>y</sub>**, опорные реакции, перемещения узлов, концевые усилия элементов и матрицы жёсткости каждого элемента. |
| **Расчёт** | Линейный статический расчёт для одного случая нагружения. Результаты точны для линейной модели (сгущать сетку не нужно). |
| **Файлы** | Сохранение и открытие проектов в JSON, передача всей модели в виде URL, встраивание просмотра только для чтения. Всё остаётся на вашем устройстве. |
| **Единицы** | Независимо выбираемые единицы длины, площади, момента инерции сечения, массы, силы, момента и напряжения (метрические и британские). |

## Чего EduBeam (пока) не умеет

Знание ограничений заранее экономит время:

- **Только 2D** — никакой работы из плоскости, никаких пространственных рам.
- **Только линейная статика** — нет расчёта по деформированной схеме (P–Δ), устойчивости, динамики, пластичности.
- **Один случай нагружения** — нет сочетаний нагрузок и огибающих. Моделируйте каждый случай отдельно (сохраняйте его как отдельный файл или ссылку).
- **Нет собственного веса** — при необходимости задайте его как распределённую нагрузку.
- **Нет проверок по нормам** — EduBeam даёт внутренние усилия и перемещения; проверка по нормам остаётся за вами.

Если вам не хватает какой-то функции, [создайте issue](https://github.com/janvorisek/edubeam/issues).

## Для кого это?

- **Студентам**, изучающим строительную механику и сопротивление материалов, которым нужна мгновенная проверка ручного расчёта. См. [Проверка результатов вручную](/ru/guide/verification).
- **Преподавателям**, показывающим, как опоры, шарниры и нагрузки меняют внутренние усилия — вживую, на проекторе, на любом из 11 языков.
- **Инженерам**, которым нужна быстрая проверка перед запуском «тяжёлого» настольного пакета.

## Языки

Интерфейс доступен на английском, чешском, немецком, испанском, французском, польском, португальском, русском, украинском, тайском и китайском языках. EduBeam выбирает язык по настройкам браузера; изменить его можно в **Настройки → Язык и локаль** или открыв приложение с параметром `?lang=`, например [run.edubeam.app/?lang=ru](https://run.edubeam.app/?lang=ru){target="_blank"}.
