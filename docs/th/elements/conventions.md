# ระบบพิกัดและข้อตกลงเรื่องเครื่องหมาย

ผลลัพธ์ที่ดู "ผิด" ส่วนใหญ่ใน <Edubeam /> ที่จริงแล้วเป็นเรื่องข้อตกลงเครื่องหมายที่ไม่คาดคิด ทุกอย่างด้านล่างคือสิ่งที่ตัวคำนวณใช้จริง

## แกนรวม {#global-axes}

- **x** — แนวนอน บวกไปทาง **ขวา**
- **z** — แนวดิ่ง บวกทิศ **ลง** บนหน้าจอ
- **y** — แกนตั้งฉากกับระนาบ (ชี้เข้าหาผู้ดูในระบบมือขวา) มุมหมุนและโมเมนต์คิดรอบแกน y

สัญลักษณ์แกนที่มุมกริดแสดง x (สีแดง) และ z (สีเขียว) โหนดที่ยอดเสาสูง 3 m จึงมี `Z = −3` ถ้าฐานอยู่ที่ `Z = 0`

## องศาความเป็นอิสระ {#degrees-of-freedom}

แต่ละโหนดมี `Dx`, `Dz` (การเลื่อน) และ `Ry` (การหมุน) `Dz` ที่เป็นบวกคือการกระจัดทิศลง `Ry` ที่เป็นบวกคือการหมุน **ทวนเข็มนาฬิกา** บนหน้าจอ เครื่องหมายเดียวกันนี้ใช้กับการกระจัดที่กำหนดและผลลัพธ์ที่โหนดที่รายงาน

## แรงกระทำ {#loads}

| แรงกระทำ | ทิศที่เป็นบวก |
| --- | --- |
| `Fx`, `fx`, `f1x`… | +x (ไปทางขวา หรือตามแกน x ท้องถิ่นของเอลิเมนต์เมื่อเปิด LCS) |
| `Fz`, `fz`, `f1z`… | +z (**ลง** หรือตามแกน z ท้องถิ่นเมื่อเปิด LCS) |
| `My` | ทวนเข็มนาฬิกาบนหน้าจอ |
| `ΔTc` | อุณหภูมิเพิ่มขึ้น (ยืดออก) |
| `ΔTb − ΔTt` | เส้นใยล่างร้อนกว่าเส้นใยบน |

แรงโน้มถ่วงจึงเป็น `fz` ที่ **เป็นบวก** และแรงลมที่ดันเสาด้านซ้ายไปทางขวาคือ `fx` ที่เป็นบวก

## แกนท้องถิ่นของเอลิเมนต์ {#element-local-axes}

แกน **x** ท้องถิ่นวิ่งจากโหนดเริ่มต้นไปยังโหนดปลาย แกน **z** ท้องถิ่นตั้งฉากกับแกน x ได้จากการหมุนแกนรวมด้วยมุมของเอลิเมนต์ $\alpha$ สำหรับเอลิเมนต์แนวนอนที่วาดจากซ้ายไปขวา แกนท้องถิ่นและแกนรวมจะตรงกัน ใช้ **สลับโหนด** ในตาราง *เอลิเมนต์* เพื่อกลับทิศ

## แรงภายใน {#internal-forces}

| ปริมาณ | ค่าบวกหมายถึง |
| --- | --- |
| **N** | แรงดึง |
| **V<sub>z</sub>** | เครื่องหมายตามทฤษฎีคานทั่วไป: คานช่วงเดียวแบบรองรับธรรมดาที่รับแรงโน้มถ่วง V เป็นบวกที่จุดรองรับซ้ายและเป็นลบที่จุดรองรับขวา |
| **M<sub>y</sub>** | **โมเมนต์บวก** — เส้นใยล่าง (+z) รับแรงดึง คานช่วงเดียวแบบรองรับธรรมดาที่รับแรงโน้มถ่วงมีโมเมนต์บวกที่กึ่งกลางช่วง ส่วนคานยื่นที่รับแรงที่ปลายมีโมเมนต์ลบที่โคนคาน |

## แรงปลาย (ตารางผลลัพธ์ที่เอลิเมนต์) {#end-forces-element-results-table}

`X12, Z12, M12` กระทำต่อเอลิเมนต์ที่โหนดเริ่มต้น `X21, Z21, M21` ที่โหนดปลาย ในระบบ **ท้องถิ่น** โดยมีทิศบวกเหมือนแกนท้องถิ่นและ `My` ค่าเหล่านี้คือแรงที่โหนดกระทำต่อเอลิเมนต์ คือ $\mathbf{f} = \mathbf{K}_l\,\mathbf{u}_l - \mathbf{f}_{eq}$ โดย $\mathbf{f}_{eq}$ คือแรงกระทำที่โหนดเทียบเท่าของแรงกระทำบนเอลิเมนต์ ผลรวมของแรงปลายของทุกเอลิเมนต์ที่มาบรรจบกันที่โหนดจะสมดุลกับแรงกระทำที่โหนดและแรงปฏิกิริยาที่โหนดนั้น

## แรงปฏิกิริยา {#reactions}

แรงปฏิกิริยามีสำหรับทุก DOF ที่ถูกยึด และรายงานในระบบพิกัดของโหนด (หมุนตามมุมระบบพิกัดท้องถิ่นของโหนดถ้ากำหนดไว้) ลูกศรแรงปฏิกิริยาบนหน้าจอแสดงผลชี้ในทิศที่จุดรองรับดันโครงสร้าง

## แกน y ชี้ขึ้น {#y-up-axes}

**การตั้งค่า → ระบบพิกัด → x ไปทางขวา, y ชี้ขึ้น** สลับทุกสิ่งที่คุณพิมพ์และอ่านไปเป็นระบบแบบในตำรา: **x** ไปทางขวา **y** ชี้ขึ้น และ **z** ชี้เข้าหาผู้ดู โมเดล ไฟล์ที่บันทึก และภาพวาดยังเหมือนเดิม มีเพียงตัวเลขและชื่อที่เปลี่ยน:

| ปริมาณ | z ชี้ลง (ค่าเริ่มต้น) | y ชี้ขึ้น |
| --- | --- | --- |
| พิกัดแนวดิ่ง | `Z` | `Y` เครื่องหมายตรงข้าม |
| แรงกระทำ การกระจัด แรงปฏิกิริยา และแรงปลายในแนวดิ่ง | `Fz`, `fz`, `Dz`, `Z12`… | `Fy`, `fy`, `Dy`, `Y12`… เครื่องหมายตรงข้าม |
| มุมหมุนและโมเมนต์ | `Ry`, `My` | `Rz`, `Mz` เครื่องหมายเดิม (ทวนเข็มนาฬิกาเป็นบวก) |
| มุมจุดรองรับ α | วัดตามเข็มนาฬิกา | วัดทวนเข็มนาฬิกา เครื่องหมายตรงข้าม |
| แรงภายใน N, V, M | | ไม่เปลี่ยน แผนภาพวาดแบบเดิม |

แรงโน้มถ่วงจึงเป็น `fy` ที่ **เป็นลบ** และยอดเสาสูง 3 m มี `Y = 3`

## หน่วย {#units}

ภายในตัวคำนวณใช้หน่วย SI (m, N, Pa, rad, K) หน่วยที่แสดงมีผลเฉพาะกับสิ่งที่คุณพิมพ์และอ่าน การเปลี่ยนหน่วยไม่เคยเปลี่ยนโมเดล
