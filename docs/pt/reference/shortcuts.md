# Teclado, mouse e toque

Os atalhos de teclado funcionam enquanto a visualização tem o foco. Eles são ignorados enquanto você digita em uma célula de tabela ou em um diálogo; clique na tela primeiro.

## Teclado {#keyboard}

| Atalho | Ação |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Desfazer |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Refazer |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Salvar projeto (baixar JSON) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Abrir projeto |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Exportar imagem |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Selecionar tudo |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copiar a seleção (nós, elementos e suas cargas) |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Colar: um contorno da cópia segue o cursor; clique para posicioná-la, ou digite um deslocamento Δx, Δz na faixa e pressione **Colar** |
| <kbd>Delete</kbd> | Excluir a seleção |
| <kbd>Esc</kbd> | Cancelar o modo de mouse atual, fechar o tour, limpar a seleção ou sair de uma célula de tabela |
| <kbd>Enter</kbd> | Confirmar uma célula de tabela |
| <kbd>F</kbd> | Ajustar conteúdo à tela |
| <kbd>C</kbd> | Centralizar conteúdo |
| <kbd>G</kbd> | Ligar/desligar a grade |
| <kbd>S</kbd> | Ligar/desligar o encaixe na grade |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Aproximar / afastar |

Em um Mac, use <kbd>Cmd</kbd> onde aparece <kbd>Ctrl</kbd>.

## Mouse {#mouse}

| Ação | Resultado |
| --- | --- |
| Clique | Seleciona um nó, elemento, carga ou linha de cota e abre seu painel |
| Arrastar na tela vazia | Retângulo de seleção |
| Arrastar um nó | Move o nó (encaixa na grade quando o encaixe está ativado) |
| Clique no modo de mouse | Posiciona um nó, ou inicia ou continua uma poligonal de elementos |
| Clique duplo em uma carga | Edita a carga |
| Clique com o botão direito | Menu da tela: Adicionar nó, Adicionar elemento, Adicionar cota, Cotar o elemento (sobre um elemento), Editar, Copiar, Colar, Excluir |
| <kbd>Ctrl</kbd> (<kbd>Cmd</kbd> em um Mac) + Adicionar nó / Adicionar elemento no menu da tela | Posiciona com o mouse em vez de por um diálogo |
| Arrastar com o botão do meio ou direito | Panorâmica (veja *Configurações → Controles e atalhos*) |
| Roda | Zoom em direção ao cursor |
| Apontar para um objeto | Dica com deslocamentos, propriedades ou valores de carga |

Em um trackpad, a rolagem com dois dedos aplica zoom. Para a panorâmica, clique e arraste com dois dedos (equivale a arrastar com o botão direito).

## Toque {#touch}

| Gesto | Resultado |
| --- | --- |
| Toque | Seleciona e mostra os detalhes e as ações do objeto |
| Toque no modo de mouse | Posiciona um nó ou continua um elemento |
| Pressionar um nó e arrastar | Move o nó |
| Arrastar com um dedo em outro lugar | Panorâmica |
| Pinça | Zoom |
| Tocar e segurar a tela | Menu da tela |
| Botão **Seleção por retângulo** (canto superior direito), depois arrastar | Retângulo de seleção |

## Painéis dos objetos {#object-panels}

Clicar em um objeto abre um painel ao lado dele com seus detalhes e estas ações:

| Objeto | Ações |
| --- | --- |
| Nó | Adicionar carga · Apoios do nó (símbolo do apoio, Dx / Dz / Ry, ângulo do SCL nodal) · Prescrever deslocamento (em um nó com apoio) · Excluir |
| Elemento | Editar elemento (nós e rótulas, material, seção) · Adicionar carga · Matriz de rigidez · Excluir |
| Carga nodal ou de elemento | Editar carga · Excluir |
| Linha de cota | Editar (coordenadas) · Inverter cota · Excluir |
