# 例題

下のカードはすべて、解析済みのライブなモデルです。クリックすると、すべて設定済みの編集可能な状態で <Edubeam /> に開きます。節点をドラッグしたり、荷重を変えたり、ヒンジにチェックを入れたりして、図がどう追従するかを見てみましょう。

<br>

<FeatureStructures />

同じモデルはアプリの **☰ → 例題**にもあり、[run.edubeam.app/?panel=examples](https://run.edubeam.app/?panel=examples&lang=ja){target="_blank"} を開くとギャラリーが直接表示されます。

## 演習の案 {#suggested-exercises}

- **不静定梁**：固定端の `Ry` のチェックを外して単純梁にします。スパン中央のモーメントはどれだけ大きくなるでしょうか？
- **片持ち梁**：先端のたわみを $FL^3/3EI$ と比べ（[手計算による結果の確認](/ja/guide/verification)を参照）、次に*断面*タブで $I_y$ を半分にしてみましょう。
- **プラットトラス**：この例題の節点は剛接合です。すべての部材の両端の材端ヒンジにチェックを入れて本当のトラスにし、軸力を比べてみましょう。次に斜材を 1 本取り除くと、トラスはまだ立っているでしょうか？
- **3 径間連続梁**：この梁は両端だけで支持されています。内側の節点 B と C の `Dz` にチェックを入れて連続梁にし、支点の上に負の曲げモーメント（上側引張）が現れる様子を見てみましょう。
- **門形ラーメン**：梁の両端の材端ヒンジにチェックを入れて柱梁接合部をピン接合にするか、右の支点をローラーではなくピンにしてみましょう。
- **温度荷重**：両方の支点で `Dx` を拘束し、軸力が生じる様子を見てみましょう。
