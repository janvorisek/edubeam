# 문제 해결

## 결과가 그려지지 않을 때 {#no-results-are-drawn}

결과는 모델을 해석할 수 있을 때만 나타납니다. 다음 순서로 확인하십시오.

1. **뷰어 왼쪽 위의 메시지를 읽습니다.**
   - *정의된 재료가 없습니다* / *정의된 단면이 없습니다*: **새로 추가** 버튼으로 추가하십시오.
   - 파란색 **지점 필요** 칩: 모델이 단지 아직 완성되지 않았을 뿐입니다. 지점을 추가하십시오. 칩에 포인터를 올리면 구조물이 아직 어떻게 움직일 수 있는지 점선 윤곽으로 보여 줍니다.
   - **빨간색 메시지**: 무언가 잘못되었습니다. 문제를 알려 주거나, 문제가 여러 개면 *모델 오류: N*이라고 표시됩니다. **자세히 보기**를 클릭하고 항목을 하나씩 고치십시오(아래 표 참고). 관련된 절점이나 힌지는 캔버스에 원으로 표시됩니다.
   - **노란색 메시지**: 경고입니다. 모델은 그래도 해석되었으며, 경고를 숨길 수 있습니다.
2. **지점이 충분한가요?** 솔버에는 구속된 자유도가 3개 이상 필요하고, 지점이 구조물을 붙잡아야 합니다. 롤러 두 개(Dz + Dz) 위의 보는 구속이 두 개뿐이어서 미끄러져 버립니다. 어딘가에 `Dx`를 추가하거나 한 지점에 `Ry`를 추가하십시오.
3. **요소가 연결되어 있나요?** 같은 좌표에 있는 두 절점도 여전히 별개의 절점입니다. 남는 절점을 삭제하고 다시 연결하거나, **구조물에 연결**로 요소 위에 절점을 배치하십시오.
4. **힌지가 너무 많은가요?** 기둥 양 끝의 힌지나, 사재 없이 핀으로 연결된 사각형 부재는 메커니즘을 만듭니다. EduBeam이 힌지에 원을 그리고 움직임을 보여 줍니다.
5. **강성이 0인가요?** `E`, `A`, `Iy`를 실수로 0이나 잘못된 단위로 입력하면 구조물의 일부가 거의 저항 없이 움직입니다. EduBeam은 이를 *불안정*으로 알려 줍니다.

## 메시지 {#messages}

**자세히 보기**는 *모델을 해석할 수 없습니다*(오류), *아직 해석할 수 없습니다*(지점이 아직 필요함), 또는 *모델 경고*라는 제목의 대화 상자를 엽니다. 그 안의 **문제 해결** 링크가 이 페이지로 연결됩니다.

### 아직 필요 {#still-needed}

| 메시지 | 의미 / 해결 방법 |
| --- | --- |
| *구조물을 해석하려면 먼저 지점이 필요합니다.* | 구속된 자유도가 전체적으로 3개 미만입니다. 지점을 추가하십시오. |
| *구조물의 분리된 부분(절점 …)은 구속된 자유도가 3개 미만이어서 자유롭게 움직일 수 있습니다.* | 모델이 여러 조각으로 나뉘어 있고 그중 한 조각이 떠 있습니다. 연결하거나 지점을 주십시오. |

### 오류 {#errors}

| 메시지 | 의미 / 해결 방법 |
| --- | --- |
| *지점 수는 충분하지만 구조물을 고정하지 못합니다. 구조물이 여전히 … 수 있습니다.* | 지점이 모두 평행하거나, 지점 반력의 작용선이 한 점에서 만납니다. 점선 윤곽이 움직임을 보여 줍니다. 지점 하나의 방향을 바꾸십시오. 한 조각에만 해당하면 같은 메시지가 *분리된 부분*을 알려 줍니다. |
| *지점은 구조물을 고정하지만, 구조물은 여전히 메커니즘입니다. 절점 …의 힌지를 중심으로 부재가 회전할 수 있습니다.* | 두 기둥의 꼭대기에 힌지가 있는 라멘이나 사재 없이 핀으로 연결된 사각형처럼, 힌지 때문에 부재끼리 서로 돌아갈 수 있습니다. 힌지를 제거하거나 부재나 지점을 추가하십시오. |
| *구조물이 불안정합니다. 다음 자유도가 거의 저항 없이 움직입니다: 절점 …* | 거의 메커니즘이거나 강성이 0에 가깝습니다. 지점, 힌지, `E`, `A`, `Iy` 값을 확인하십시오. |
| *구조물이 메커니즘입니다. 강성 행렬이 특이 행렬입니다.* | 위의 검사에서 잡히지 않은 무언가가 자유롭게 움직일 수 있습니다. 모든 부분이 3개 이상의 구속으로 고정되어 있는지, 힌지 때문에 부재가 자유롭게 회전하지 않는지 확인하십시오. |
| *요소 …에서 참조하는 절점 / 재료 / 단면 …이(가) 없습니다.* | 참조된 객체가 삭제되었습니다. 대개 손으로 편집한 JSON 파일에서 생깁니다. *요소* 표에서 다시 지정하십시오. |
| *요소 …은(는) 정확히 2개의 절점을 참조해야 합니다.* | 가져온 파일의 요소가 손상되었습니다. 삭제하고 다시 만드십시오. |
| *절점 하중 / 강제 변위 #n에서 참조하는 절점 …이(가) 없습니다.* | 하중을 삭제하거나 절점을 지정하십시오. |
| *요소 하중 #n에서 참조하는 요소 …이(가) 없습니다.* | 하중을 삭제하십시오. |
| *모델 내부의 불일치로 해석에 실패했습니다…* | 일반적인 오류입니다. 마지막 단계를 실행 취소하거나, 파일을 저장해 [신고해 주십시오](https://github.com/janvorisek/edubeam/issues). |

### 경고 {#warnings}

모델은 그래도 해석되지만 다음을 확인하십시오.

| 메시지 | 의미 / 해결 방법 |
| --- | --- |
| *절점 …은(는) 어떤 요소에도 연결되어 있지 않아 해석에서 무시됩니다.* | 남는 절점입니다. 삭제하거나 연결하십시오. |
| *절점 …에 지점이 있지만 연결된 요소가 없어 지점이 아무것도 지지하지 않습니다.* | 남는 절점에 지점이 있습니다. |
| *요소 …의 양 끝이 같은 절점을 참조합니다.* | 길이가 0인 요소입니다. 삭제하십시오. |
| *절점 하중 / 강제 변위 #n에 잘못된 값이 있습니다.* | 숫자가 아닌 성분이 있습니다. 하중을 편집하십시오. |

## 결과가 이상해 보일 때 {#results-look-wrong}

| 증상 | 가능한 원인 |
| --- | --- |
| 하중이 위로 작용함 | 전체 **z축은 아래를 향하므로** 양의 `Fz`/`fz`는 아래 방향입니다. 음수 값이 위를 향합니다. [부호 규약](/ko/elements/conventions)을 참고하십시오. y 위 좌표축에서는 반대입니다. |
| 처짐이 1000배 크거나 작음 | 단위 혼동입니다. 단위가 MPa인데 `E`를 Pa로 입력했거나, 단위가 m⁴인데 `Iy`를 cm⁴로 입력한 경우입니다. 뷰어 오른쪽 아래의 단위 칩을 확인하십시오. |
| 처짐이 교과서 공식보다 약간 큼 | Timoshenko 전단 변형 때문입니다. Euler–Bernoulli 값에 가까워지려면 단면의 전단 보정계수를 키우거나 세장한 부재를 쓰십시오. [손 계산으로 결과 검증](/ko/guide/verification)을 참고하십시오. |
| 부호가 "틀려" 보임 | 부호는 다이어그램이 그려진 쪽이 아니라 레이블에서 읽으십시오. 양의 M은 아래로 처지는 휨입니다. *요소 결과*의 단부력은 N-V-M 규약이 아니라 요소의 국부 좌표축을 따릅니다. |
| 똑같은 두 기둥의 전단력 부호가 반대 | V의 부호는 각 요소의 방향을 따릅니다. 비교하려면 한 기둥의 절점 순서를 바꾸십시오. |
| `4 · 10¹` 같은 숫자 | 과학적 표기 형식입니다. *설정 → 언어 및 지역 → 숫자 형식*에서 *자동*을 고르십시오. |
| 다이어그램이 너무 크거나 작음 | 순전히 시각적인 문제입니다. *설정 → 뷰어 설정*에서 **결과 배율**을 조정하십시오. |
| 국부 좌표계 하중이 엉뚱한 방향을 향함 | 요소의 국부 x축은 *시작* 절점에서 *끝* 절점으로 향합니다. 절점 순서를 바꾸거나 부호를 뒤집으십시오. |
| 경사 부재의 하중이 이상함 | **LCS**가 기본으로 체크되어 있어 `fz`가 부재에 수직으로 작용합니다. 연직 하중을 주려면 체크를 해제하십시오. |
| 온도 하중이 아무 효과가 없음 | 정정 구조물은 온도에 의해 부재력 없이 자유롭게 변형됩니다. α ≠ 0인지, 온도 기울기의 경우 단면 높이 h가 설정되어 있는지 확인하십시오. |

## 인터페이스 문제 {#interface-issues}

| 증상 | 해결 방법 |
| --- | --- |
| 단축키가 작동하지 않음 | 먼저 캔버스를 클릭하십시오. 텍스트 입력란에 포커스가 있으면 키 입력이 무시됩니다. |
| 화면을 이동할 수 없음 | 화면 이동은 기본적으로 마우스 가운데 또는 오른쪽 버튼을 씁니다. *설정 → 조작 및 단축키*에서 바꾸십시오. 트랙패드에서는 두 손가락 스크롤로 확대/축소하고, 두 손가락으로 클릭한 채 드래그하면 화면이 이동합니다. |
| 모델이 사라짐 | 링크, 파일, 예제를 열거나 구조물을 지워도 이전 모델은 보관됩니다. **☰ → 최근 구조물**을 보거나 <kbd>Ctrl</kbd>+<kbd>Z</kbd>를 누르십시오. |
| 언어가 다름 | *설정 → 언어 및 지역*에서 바꾸거나, 주소에 `?lang=en`을 붙이십시오. |
| 설정 변경이 유지되지 않음 | 로컬 스토리지가 차단되었습니다(시크릿 창, 엄격한 개인 정보 보호 모드). 설정, 자동 저장, 최근 구조물에는 로컬 스토리지가 필요합니다. |

## 버그 신고 {#reporting-a-bug}

브라우저와 OS, 기대했던 동작, 그리고 무엇보다 문제를 재현하는 **공유 링크**나 **프로젝트 파일**을 첨부해 [GitHub 이슈](https://github.com/janvorisek/edubeam/issues)를 등록해 주십시오.
