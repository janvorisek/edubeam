# บทเรียน: โครงข้อแข็งสามจุดหมุน

โครงข้อแข็งสามจุดหมุนเป็นโครงสร้างดีเทอร์มิเนท: สมการสมดุลสามสมการรวมกับเงื่อนไข $M = 0$ ที่จุดหมุนให้แรงปฏิกิริยาที่จุดรองรับครบทั้งสี่ค่า จึงเป็นโมเดลที่เหมาะมากสำหรับตรวจสอบทุกตัวเลขที่ EduBeam วาด ใช้เวลาประมาณ 15 นาที

## โจทย์ {#the-problem}

- เสาสองต้นสูง 4 m ฐานเป็นจุดรองรับแบบหมุดที่ A และ E ห่างกัน 8 m
- คานแนวนอน B–D อยู่ด้านบน มีจุดหมุนที่กึ่งกลางช่วง C
- แรงแผ่กระจายสม่ำเสมอ $q = 10$ kN/m ตลอดทั้งคาน
- เหล็ก ($E = 210$ GPa, $G = 81$ GPa) IPE 300 ($A = 53.8$ cm², $I_y = 8356$ cm⁴, $h = 300$ mm)

| โหนด | X [m] | Z [m] | จุดรองรับ |
| --- | --- | --- | --- |
| A | 0 | 0 | หมุด |
| B | 0 | −4 | |
| C | 4 | −4 | (จุดหมุนในคาน) |
| D | 8 | −4 | |
| E | 8 | 0 | หมุด |

อย่าลืมว่า **แกน z ชี้ลง** ยอดเสาจึงอยู่ที่ `Z = −4`

## 1. วัสดุและหน้าตัด {#_1-material-and-section}

1. **ล้างโมเดล** (ติ๊ก *ลบวัสดุ* และ *ลบหน้าตัด*)
2. *วัสดุ* → **ไลบรารีวัสดุ** → **Steel (S235)**
3. *หน้าตัด* → **เพิ่มหน้าตัด**: `พื้นที่ = 0.00538`, `Iy = 8.356e-5`, `ความสูง = 0.3`, `สัมประสิทธิ์เฉือน = 1`

หน้าตัดมีผลต่อการกระจัดเท่านั้น โครงข้อแข็งนี้เป็นดีเทอร์มิเนท แรงภายในจึงไม่ขึ้นกับ $E$, $A$ หรือ $I$ เลย

## 2. วาดโครงข้อแข็ง {#_2-draw-the-frame}

วิธีที่เร็วที่สุดคือวาดเป็นเส้นต่อเนื่องเส้นเดียวด้วยเมาส์:

1. ตรวจสอบว่าเปิด **สแนปกับกริด** อยู่ (ปุ่ม **S**)
2. แท็บ *เอลิเมนต์* → ปุ่ม **เพิ่มเอลิเมนต์** ปุ่มที่สอง (ไอคอนเคอร์เซอร์)
3. คลิกที่ (0, 0) แล้ว (0, −4), (4, −4), (8, −4) และ (8, 0) ใช้ไม้บรรทัดและเส้นเล็งช่วยหาตำแหน่ง การคลิกแต่ละครั้งจะเพิ่มโหนดและเชื่อมกับโหนดก่อนหน้า
4. กด <kbd>Esc</kbd> เพื่อจบ แล้วกด <kbd>F</kbd> เพื่อปรับโครงข้อแข็งให้พอดีกับหน้าจอ

ตอนนี้คุณมีห้าโหนดและสี่เอลิเมนต์ รูปในหน้านี้ตั้งชื่อโหนดเป็น A–E คุณเปลี่ยนชื่อโหนดของคุณในตาราง *โหนด* ได้ หรือจะใช้ 1–5 ต่อไปก็ได้ ตรวจสอบพิกัดในตารางและแก้ค่าที่ไม่ลงกริด

## 3. จุดรองรับและจุดหมุน {#_3-supports-and-the-hinge}

1. คลิกโหนด A เปิด **จุดรองรับของโหนด** แล้วเลือก **หมุด** ทำเช่นเดียวกันกับโหนด E
2. ในตาราง *เอลิเมนต์* หาเอลิเมนต์จาก B ถึง C แล้วติ๊กจุดหมุนที่ **ปลาย** (ช่องที่สองใน *จุดหมุนที่ปลาย*)

![ตารางเอลิเมนต์: จุดหมุนอยู่ที่ปลายของเอลิเมนต์ 2 ที่โหนด C](/screenshots/th/elements-table.webp)

::: tip จุดหมุนเดียว ไม่ใช่สอง
ใส่จุดหมุนที่ปลายของเอลิเมนต์ B–C ก็พอ: โมเมนต์ที่ C จะเป็นศูนย์ เพราะ C–D ไม่สามารถส่งโมเมนต์เข้าโหนดที่มีเพียง C–D ยึดไว้แบบแข็งเกร็งได้ ถ้าติ๊กที่จุดเริ่มต้นของ C–D ด้วยก็ไม่มีอะไรเปลี่ยน แต่ถ้าติ๊กจุดหมุนที่ B ด้วย โครงข้อแข็งจะกลายเป็นกลไก ลองดู: EduBeam จะแสดงว่ามันเคลื่อนที่อย่างไร
:::

## 4. แรงกระทำ {#_4-load}

*แรงกระทำ* → **เพิ่มแรงกระทำบนเอลิเมนต์** → *แรงแผ่กระจายสม่ำเสมอ* เอลิเมนต์ B–C, `fz = 10` kN/m ทำซ้ำกับเอลิเมนต์ C–D คานอยู่ในแนวนอน ช่อง LCS จึงไม่มีผลในกรณีนี้

## 6. ตรวจสอบด้วยการคำนวณมือ {#_6-check-by-hand}

**แรงปฏิกิริยาแนวดิ่ง** จากความสมมาตร ฐานแต่ละข้างรับแรงครึ่งหนึ่ง:

$$V_A = V_E = \frac{q \cdot 8}{2} = 40\ \text{kN}$$

**แรงปฏิกิริยาแนวนอน** หาโมเมนต์รอบจุดหมุน C ของโครงข้อแข็งครึ่งซ้าย โมเมนต์ที่จุดนั้นต้องเป็นศูนย์:

$$V_A \cdot 4 - H_A \cdot 4 - q \cdot 4 \cdot 2 = 0 \quad\Rightarrow\quad H_A = \frac{160 - 80}{4} = 20\ \text{kN}$$

ฐานทั้งสองข้างดันเข้าด้านในด้วยแรง 20 kN แรงดันแนวนอน (thrust) นี้เองที่ทำให้โครงข้อแข็งสามจุดหมุนมีประสิทธิภาพ

**แรงภายใน**

| ปริมาณ | สูตร | ค่าจากการคำนวณมือ | EduBeam |
| --- | --- | --- | --- |
| แรงปฏิกิริยาแนวดิ่ง | $qL/2$ | 40 kN | 40 kN |
| แรงปฏิกิริยาแนวนอน | จาก $M_C = 0$ | 20 kN | 20 kN |
| โมเมนต์ที่มุม B และ D | $H \cdot h$ | 80 kNm ดึงด้านนอก | −80 kNm |
| โมเมนต์ที่จุดหมุน C | | 0 | 0 |
| แรงตามแนวแกนในเสา | $-V_A$ | −40 kN | −40 kN |
| แรงตามแนวแกนในคาน | $-H_A$ | −20 kN | −20 kN |
| แรงเฉือนในเสา | $H_A$ | 20 kN | −20 kN (A–B), +20 kN (D–E) |
| แรงเฉือนในคานที่ B | $V_A$ | 40 kN | 40 kN |
| แรงเฉือนในคานที่ C | $V_A - 4q$ | 0 | 0 |
| แรงเฉือนในคานที่ D | $V_A - 8q$ | −40 kN | −40 kN |

เสาทั้งสองต้นมีเครื่องหมายแรงเฉือนตรงข้ามกัน แม้จะรับแรงเท่ากัน เพราะแกนท้องถิ่นของแต่ละเอลิเมนต์เป็นไปตามทิศของเอลิเมนต์นั้น: A–B วาดขึ้น ส่วน D–E วาดลง ถ้าสลับโหนดของเสาต้นหนึ่ง เครื่องหมายจะกลับ

ในคาน $M(x) = -80 + 40x - 5x^2$ kNm (x วัดจาก B) ซึ่งเป็นศูนย์ที่จุดหมุนและไม่เป็นบวกเลย: ทั้งคานรับโมเมนต์ลบ แรงเฉือน $V(x) = 40 - 10x$ ลดลงเป็นศูนย์พอดีที่ C ค่าสุดขีดของโมเมนต์จึงอยู่ที่จุดหมุนด้วย

**การกระจัด** จุดหมุน C ทรุดลง 43.1 mm (*ผลลัพธ์ → ผลลัพธ์ที่โหนด* ค่า `Dz` ของ C) ค่านี้มาจากการดัดของชิ้นส่วนทั้งสี่ และเป็นแบบฝึกหัดที่ดีสำหรับหลักงานเสมือน (principle of virtual work)

## 7. ทดลอง {#_7-experiment}

- **ยกเลิกการติ๊กจุดหมุน** ที่ C โครงข้อแข็งจะเป็นอินดีเทอร์มิเนทหนึ่งขั้น โมเมนต์ที่มุมลดลงและเกิดโมเมนต์บวกที่กึ่งกลางช่วง คราวนี้หน้าตัดมีผลแล้ว ลองใช้คานที่แข็งกว่า
- **ยึดฐานแน่น** (เลือกจุดรองรับแบบ **ยึดแน่น**) จะเกิดโมเมนต์ที่ A และ E
- **เพิ่มแรงแนวนอน**: แรงกระทำที่โหนด `Fx = 10` kN ที่ B โครงข้อแข็งจะเซ และแรงปฏิกิริยาไม่สมมาตรอีกต่อไป ตรวจสอบด้วยสมการสามสมการเดิมและ $M_C = 0$
- **ติ๊กจุดหมุนที่ B** ด้วย โครงข้อแข็งตอนนี้เป็นกลไก และ EduBeam จะแสดงภาพเคลื่อนไหวว่ามันเคลื่อนที่ได้อย่างไร
