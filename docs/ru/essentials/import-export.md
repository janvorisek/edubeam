# Импорт, экспорт и обмен

Всё в <Edubeam /> происходит в вашем браузере. На сервер ничего не отправляется — ссылка для обмена буквально содержит модель.

## Сохранение проекта

**Меню ☰ → Сохранить проект** или <kbd>Ctrl</kbd>+<kbd>S</kbd> скачивает файл `project.json`. В нём — узлы, элементы, материалы, сечения, нагрузки, размерные линии и версия приложения, которая его записала. Файл можно свободно переименовать.

## Открытие проекта

- **Меню ☰ → Открыть проект** или <kbd>Ctrl</kbd>+<kbd>O</kbd>, затем выберите файл `.json`, либо
- **перетащите файл в любое место окна приложения**.

Открытие заменяет текущую модель (включая материалы и сечения). Если хотите её сохранить, сначала нажмите **Сохранить проект**.

## Ссылка на модель

**Поделиться моделью** (🔗 в верхней панели или меню ☰) открывает диалог *Поделиться моделью по URL*:

- **Копировать ссылку** — копирует ссылку в буфер обмена (или щёлкните внутри поля).
- **Открыть ссылку** — открывает её в новой вкладке, чтобы проверить, что увидит получатель.
- **Поделиться через системный диалог** — на телефонах и планшетах передаёт ссылку системному меню «Поделиться».

Ссылка имеет вид `https://run.edubeam.app/?model=…` и кодирует всю модель (узлы, элементы, свойства, нагрузки). Тот, кто её откроет, получает точную копию для локального редактирования; правки **не** синхронизируются обратно — при изменении модели отправьте новую ссылку. Очень большие модели дают очень длинные ссылки; для них лучше передавать файл JSON.

## Встраивание просмотра только для чтения

Добавьте `&viewer=1` к ссылке на модель (или `?viewer=1` к любому URL приложения), чтобы открыть модель в **режиме просмотра**: верхняя панель, нижняя панель, отмена/повтор и панель настроек скрыты, остаётся только холст с текущей моделью. Вставьте такой URL в `<iframe>`, чтобы встроить живую масштабируемую модель в конспект лекции или веб-страницу:

```html
<iframe src="https://run.edubeam.app/?viewer=1&model=…" width="100%" height="400"></iframe>
```

Страница [Примеры](/ru/examples/) устроена именно так — каждая карточка является ссылкой с параметром `?model=`.

## Параметры URL

| Параметр | Действие |
| --- | --- |
| `model=<данные>` | Загружает закодированную модель, вписывает её в экран и убирает параметр из адресной строки. |
| `lang=<код>` | Переключает язык интерфейса (`en`, `cs`, `de`, `fr`, `es`, `pt`, `pl`, `cn`, `th`, `uk`, `ru`). |
| `viewer=1` | Режим просмотра только для чтения (см. выше). |

## Автоматическое сохранение

Текущая модель и ваши настройки сохраняются в локальное хранилище браузера после каждого изменения и восстанавливаются при возвращении — даже после закрытия браузера. Это удобство, а не резервная копия: оно привязано к одному профилю браузера на одном устройстве, и очистка данных сайта его удаляет. Важную работу сохраняйте как файл проекта.

## Формат проекта JSON

`project.json` — это простой, читаемый JSON:

```json
{
  "edubeam": true,
  "version": "1.0.6",
  "domain": {
    "materials": [ { "label": "1", "e": 210000000000, "g": 81000000000, "alpha": 0.000012, "d": 7850 } ],
    "crossSections": [ { "label": "1", "a": 0.00285, "iy": 1.943e-5, "h": 0.2, "k": 1 } ],
    "nodes": [ { "label": "1", "coords": [0, 0, 0], "bcs": [0, 2] }, … ],
    "elements": [ { "label": "1", "nodes": ["1", "2"], "mat": "1", "cs": "1", "hinges": [false, false] } ],
    "loadCases": [ … ]
  }
}
```

Все значения хранятся в **единицах СИ** (м, Н, Па, рад) независимо от единиц отображения. Граничные условия используют идентификаторы степеней свободы `0 = Dx`, `2 = Dz`, `4 = Ry`. Благодаря простоте формата модели можно генерировать скриптом или в электронной таблице и открывать через **Открыть проект**. Формат не является стабильным версионируемым API, поэтому при автоматизации проверяйте поле `version`.
