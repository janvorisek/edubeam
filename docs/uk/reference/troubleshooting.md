# Усунення проблем

## Результати не малюються

Результати з'являються лише тоді, коли модель можна розв'язати. Перевірте в такому порядку:

1. **Чи є червоне сповіщення у вікні перегляду?** *Матеріали не визначено.* / *Перерізи не визначено.* → додайте їх. *Model has N error(s)* → натисніть **Show details** і виправте кожен пункт (див. таблицю нижче). Повідомлення розв'язувача наразі показуються англійською.
2. **Достатньо опор?** Розв'язувачу потрібно щонайменше три закріплені ступені вільності *та* відсутність механізму. Балка на двох шарнірно-рухомих опорах (Dz + Dz) має лише два й ковзає геть; рама, у якій усі вузли шарнірні й немає в'язей, може бути механізмом навіть із багатьма опорами. Додайте `Dx` десь або `Ry` на одній з опор.
3. **Чи з'єднані елементи?** Два вузли з однаковими координатами — це все одно два окремі вузли. Видаліть зайвий і з'єднайте заново або ставте вузли на елементи через **З'єднати з конструкцією**.
4. **Шарніри всюди?** Вузол, усі елементи якого шарнірні й який не має опори `Ry`, має невизначений поворот. Зніміть один шарнір або закріпіть `Ry` у цьому вузлі.
5. **Абсурдні числа** (переміщення в мільйонах) означають, що конструкція майже механізм; EduBeam приховує такі результати. Шукайте відсутню опору або майже нульову жорсткість (`E`, `A` чи `Iy` випадково введено як 0 або в неправильній одиниці).

## Повідомлення про помилки

Повідомлення з **Show details** (діалог *Cannot solve model*); наразі вони показуються англійською:

| Повідомлення | Значення / виправлення |
| --- | --- |
| *Model needs at least 3 constrained DOFs to be stable in 2D analysis.* | Додавайте опори, доки загалом не буде закріплено щонайменше три ступені вільності. |
| *Element X references missing node / material / cross section Y.* | Об'єкт, на який є посилання, було видалено (зазвичай через відредагований вручну файл JSON). Призначте його заново в таблиці *Елементи*. |
| *Element X must reference exactly 2 nodes.* | Пошкоджений елемент в імпортованому файлі; видаліть і створіть заново. |
| *Nodal load / Prescribed displacement #n references missing node Y.* | Видаліть навантаження або перепризначте його. |
| *Element load #n references missing element Y.* | Видаліть навантаження. |
| *Solver failed due to an internal model inconsistency…* | Загальна помилка; скасуйте останній крок або збережіть файл і [повідомте про проблему](https://github.com/janvorisek/edubeam/issues). |

Попередження (діалог *Model warnings*) не зупиняють розрахунок: *Element X references the same node at both ends* (елемент нульової довжини — видаліть його) і *… contains invalid values* (навантаження з нечисловою компонентою — відредагуйте його).

## Результати виглядають неправильно

| Симптом | Імовірна причина |
| --- | --- |
| Навантаження діють угору | Глобальна **вісь z спрямована вниз**, тож додатне `Fz`/`fz` — це вниз. Від'ємні значення спрямовані вгору. Див. [правила знаків](/uk/elements/conventions). |
| Прогин у 1000 разів завеликий або замалий | Плутанина з одиницями — `E` введено в Па, коли одиниця МПа, або `Iy` у см⁴, коли одиниця м⁴. Перевірте чип одиниць у правому нижньому куті вікна перегляду. |
| Прогин трохи більший, ніж за формулою з підручника | Деформація зсуву за Тимошенком. Збільште коефіцієнт зсуву перерізу (або візьміть гнучкіший стрижень), щоб наблизитися до значень Ейлера–Бернуллі. Див. [Перевірка результатів вручну](/uk/guide/verification). |
| Епюра моментів на «неправильному» боці | Бік — лише умовність креслення; знак читайте з підписів: додатний означає розтяг нижніх волокон. |
| Епюри величезні / крихітні | Суто візуальне — відрегулюйте **Масштаб результатів** у *Налаштування → Налаштування перегляду*. |
| Навантаження в локальних координатах спрямоване не туди | Локальна вісь x елемента йде від *початкового* вузла до *кінцевого*. Скористайтеся **Поміняти порядок вузлів** або змініть знак. |
| Температурне навантаження нічого не дає | Статично визначувані системи вільно деформуються від температури без внутрішніх зусиль. Перевірте, що α ≠ 0, а для градієнтної частини — що задано висоту перерізу h. |

## Проблеми з інтерфейсом

| Симптом | Виправлення |
| --- | --- |
| Гарячі клавіші не працюють | Спершу клацніть по полотну — клавіші ігноруються, поки фокус у текстовому полі. |
| Не вдається панорамувати | Панорамування за замовчуванням виконується середньою/правою кнопкою миші; змініть це в *Налаштування → Керування та гарячі клавіші*. На тачпаді використовуйте два пальці або перемкніть налаштування на *Правої кнопки*. |
| Моя модель зникла після оновлення | Про оновлення, яке скидає сховище, спершу повідомляє діалог; скасуйте його та збережіть проєкт перед оновленням. |
| Неправильна мова | *Налаштування → Мова та локаль* або додайте `?lang=uk` до URL. |
| Зміни налаштувань не зберігаються | Локальне сховище заблоковано (приватне вікно, суворий режим приватності). Налаштуванням і автозбереженню воно потрібне. |

## Повідомити про помилку

Створіть [GitHub issue](https://github.com/janvorisek/edubeam/issues), вказавши браузер і ОС, очікуваний результат і — найкорисніше — **посилання для обміну** або **JSON проєкту**, що відтворює проблему.
