# Часті запитання

## Загальні

### Що таке EduBeam?

Безкоштовний браузерний розв'язувач із відкритим кодом для плоских балок, рам і ферм, призначений для студентів, викладачів та інженерів, яким потрібен миттєвий відгук. Див. [Вступ](/uk/guide/introduction).

### Він справді безкоштовний? Потрібен обліковий запис?

Так, і ні. Відкрийте [run.edubeam.app](https://run.edubeam.app/?lang=uk) і починайте моделювати. Жодних облікових записів, інсталяторів чи обмежень на використання. Вихідний код — на [GitHub](https://github.com/janvorisek/edubeam).

### Які браузери та пристрої підтримуються?

Будь-який актуальний Chrome, Edge, Firefox або Safari. Планшети й телефони працюють (дотик, перетягування для панорамування, щипок для масштабування, довге натискання для переміщення вузла), але з мишею та клавіатурою моделювати значно швидше.

### Чи можна працювати офлайн?

EduBeam — це прогресивний вебзастосунок: після завантаження він працює без з'єднання, і браузер може запропонувати встановити його. Коли доступна нова версія, діалог запитує дозвіл перед оновленням.

### Де зберігаються мої дані?

Лише у вашому браузері. Моделі ніколи не надсилаються на сервер; посилання для обміну *і є* моделлю. Див. [Імпорт, експорт та обмін](/uk/essentials/import-export).

## Моделювання

### Як зробити защемлення / шарнірно-нерухому / шарнірно-рухому опору?

Позначте прапорці ступенів вільності: **Dx + Dz + Ry** = защемлення, **Dx + Dz** = шарнірно-нерухома, **Dz** = шарнірно-рухома. Усі комбінації та їхні символи перелічено в розділі [Вузли та опори](/uk/essentials/nodes-supports#опори).

### Як зробити ферму?

Використовуйте балкові елементи й позначте **обидва кінцеві шарніри** для кожного стрижня у вкладці *Елементи*. Навантаження прикладайте у вузлах. Див. [Елементи](/uk/essentials/elements#кінцеві-шарніри).

### Як поставити шарнір у рамі?

Позначте **кінцевий шарнір** елемента з того боку вузла, де потрібно звільнити момент. Шарнір на *одному* елементі у вузлі звільняє лише цей елемент.

### Як додати опору або зосереджену силу посередині балки?

Додайте вузол на балці через *Додати мишею* й виберіть **З'єднати з конструкцією** — балка розділиться на дві. Для самої лише зосередженої сили вузол навіть не потрібен: скористайтеся навантаженням на елемент типу **Зосереджене навантаження** із заданим положенням.

### Чи можна прикласти власну вагу?

Не автоматично. Задайте її як рівномірно розподілене навантаження $f_z = \rho g A$.

### Чи можна моделювати похилі опори?

Так — задайте **Кут локальної системи координат** у вузлі; його ступені вільності тоді інтерпретуються в повернутій системі.

### Чи є випадки або комбінації навантажень?

Ні, лише один випадок навантаження. Моделюйте кожен випадок окремо та зберігайте або діліться ним.

### Чому мої навантаження спрямовані вгору?

Бо глобальна вісь z спрямована **вниз**: додатне `Fz` — це вниз. Див. [правила знаків](/uk/elements/conventions).

## Результати

### Чому немає кнопки «Розрахувати»?

Модель розраховується автоматично після кожної зміни. Якщо результати не з'являються, модель поки що не можна розв'язати — розділ [Усунення проблем](/uk/reference/troubleshooting) перелічує, що перевірити.

### Чому мій прогин трохи відрізняється від формули?

EduBeam використовує балки Тимошенка, тож прогини враховують деформацію зсуву. Для гнучких стрижнів різниця значно менша за 1 %. Подробиці та розібрані порівняння — у розділі [Перевірка результатів вручну](/uk/guide/verification).

### Наскільки точні результати? Чи потрібно більше елементів?

Для лінійного статичного розрахунку балковий елемент точний під підтримуваними типами навантажень, тож одного елемента на стрижень достатньо. Додаткові вузли потрібні лише там, де ви хочете опору, шарнір, зміну перерізу чи вузол для прикладання навантаження.

### Де перелічені реакції?

У вікні перегляду — як стрілки зі значеннями (увімкніть **Реакції** в налаштуваннях відображення). Кінцеві зусилля елементів і переміщення вузлів — у вкладці **Результати**.

## Файли та обмін

### Як поділитися моделлю?

**Поділитися моделлю** → **Копіювати посилання**. Посилання містить усю модель. Отримувачі одержують власну редаговану копію; спільної роботи в реальному часі немає.

### Чи можна вбудувати модель на мій сайт або у слайди?

Так — додайте `&viewer=1` до посилання для обміну й помістіть його в `<iframe>`. Див. [Вбудувати перегляд лише для читання](/uk/essentials/import-export#вбудувати-перегляд-лише-для-читання).

### Чи можна експортувати зображення або таблиці?

Поки що ні. Для зображень використовуйте знімок екрана, а для чисел — копіюйте текст таблиці. Проголосуйте за цю функцію на [GitHub](https://github.com/janvorisek/edubeam/issues).

### Чи можна генерувати моделі програмно?

Так. Файл проєкту — це звичайний JSON в одиницях SI (див. [опис формату](/uk/essentials/import-export#формат-проєкту)), який можна відкрити через *Відкрити проєкт* або перетягуванням.
