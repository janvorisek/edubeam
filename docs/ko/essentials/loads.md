# 하중

모든 하중은 **하나의 하중 케이스**에 속하며 함께 작용합니다. 여러 경우를 비교하려면 각각을 프로젝트 파일이나 공유 링크로 저장하십시오.

## 한 줄로 보는 부호 규약 {#sign-convention-in-one-line}

전체 **x**축은 오른쪽을, 전체 **z**축은 **아래**를 향합니다. 따라서 양의 `Fz`나 `fz`는 아래 방향의 중력형 하중이고, 양의 모멘트 `My`는 화면에서 반시계 방향으로 돕니다. 자세한 내용은 [좌표계 및 부호 규약](/ko/elements/conventions)에 있습니다. [y 위 좌표축](/ko/elements/conventions#y-up-axes)에서는 연직 방향의 이름과 부호가 뒤집혀 중력은 음의 `Fy`가 됩니다.

## 절점 하중 {#nodal-loads}

*하중* 탭 → **절점 하중 추가**, 또는 절점 클릭 → **하중 추가**. **힘/모멘트**를 선택합니다.

| 항목 | 의미 | 단위 |
| --- | --- | --- |
| `Fx` | 수평력(오른쪽이 양) | 힘 단위 |
| `Fz` | 연직력(아래가 양) | 힘 단위 |
| `My` | y축에 대한 모멘트(반시계 방향이 양) | 모멘트 단위 |

![절점 하중 추가. 입력하는 동안 미리보기에 방향이 표시됩니다.](/screenshots/ko/loads-nodal.webp){.shot-md}

성분은 항상 **전체** 좌표계 기준입니다. 한 절점에 절점 하중을 여러 개 가할 수 있으며, 하중은 합산되고 겹쳐서 그려집니다.

### 강제 변위(지점 침하) {#prescribed-displacements-support-settlements}

같은 대화 상자에서 **강제 변위**를 선택하거나, 지점이 있는 절점 클릭 → **강제 변위 지정**. 입력 항목이 다음과 같이 바뀝니다.

| 항목 | 의미 | 단위 |
| --- | --- | --- |
| `Dx` | 강제 수평 변위 | 변위 단위 |
| `Dz` | 강제 연직 변위(아래가 양) | 변위 단위 |
| `Ry` | 강제 회전각 | rad |

지점만 움직일 수 있으므로 그 절점에서 **구속된** 자유도에만 값을 입력할 수 있습니다. 각 절점에는 강제 변위가 최대 하나만 있습니다. 두 번째를 추가하지 말고 기존 것을 편집하십시오. 정정 구조물에서 지점 침하는 변위만 일으키고 부재력은 생기지 않습니다. 부정정 구조물에서는 둘 다 생깁니다.

## 요소 하중 {#element-loads}

*하중* 탭 → **요소 하중 추가**, 또는 요소 클릭 → **하중 추가**. **하중 유형**을 고르면 입력하는 동안 대화 상자가 요소 위의 하중을 미리 보여 줍니다.

### 등분포하중 {#uniformly-distributed-load}

| 항목 | 의미 | 단위 |
| --- | --- | --- |
| `fx` | x 방향 단위 길이당 하중 | 힘 / 길이 |
| `fz` | z 방향 단위 길이당 하중 | 힘 / 길이 |
| **LCS** | 체크: `fx`, `fz`가 요소의 국부 좌표축 방향으로 작용, 해제: 전체 좌표축 방향으로 작용 | – |

**LCS**는 기본으로 체크되어 있습니다. 왼쪽에서 오른쪽으로 그린 수평 요소에서는 국부 좌표축과 전체 좌표축이 같으므로 차이가 없습니다. 경사 부재에서는 차이가 납니다.

- **부재에 수직인** 하중(서까래에 작용하는 풍하중)은 LCS를 **체크**한 `fz`입니다.
- 부재 길이 1 m당 **연직** 하중(자중)은 LCS를 **해제**한 `fz`입니다.
- *수평* 투영 길이 1 m당 연직 하중(적설하중)은 직접 입력할 수 없습니다. 먼저 부재의 경사각 $\alpha$에 대해 $\cos\alpha$를 곱한 뒤 연직 하중으로 입력하십시오.

### 사다리꼴 분포하중 {#trapezoidal-load}

| 항목 | 의미 |
| --- | --- |
| `f1x`, `f1z` | **시작** 절점에서의 하중 크기 |
| `f2x`, `f2z` | **끝** 절점에서의 하중 크기 |

하중 크기는 요소의 시작에서 끝까지 선형으로 변합니다. 삼각형 분포하중은 `f1z = 0`입니다. 사다리꼴 분포하중은 항상 **요소의 국부 좌표축** 방향으로 작용하며(LCS 체크박스가 고정됨), 수평 요소에서는 전체 좌표축과 같습니다.

### 집중하중 {#concentrated-load}

요소를 **따라** 어디에나 가할 수 있는 집중 힘이나 모멘트로, 절점을 추가할 필요가 없습니다.

| 항목 | 의미 |
| --- | --- |
| `Fx`, `Fz`, `My` | 힘과 모멘트 성분 |
| **시작 절점 기준 하중 위치** | 시작 절점으로부터의 거리, `0 ≤ a ≤ L` |
| **LCS** | 국부 좌표축 기준 성분 |

전단력도는 하중 위치에서 `Fz`만큼 불연속으로 변하고, 휨모멘트도는 그곳에서 꺾입니다. 그 위치의 모멘트 값에는 자동으로 레이블이 붙습니다. 집중 모멘트 `My`를 가하면 대신 휨모멘트도가 불연속으로 변합니다.

### 온도 하중 {#temperature-load}

| 항목 | 의미 |
| --- | --- |
| **ΔT<sub>c</sub>**, 축방향 온도 변화 | 단면 전체의 균일한 온도 변화로, 신장량 $\alpha\,\Delta T_c\,L$을 일으킵니다 |
| **ΔT<sub>b</sub> − ΔT<sub>t</sub>**, 온도 차 | 하연 온도에서 상연 온도를 뺀 값으로, 곡률 $\alpha\,(\Delta T_b - \Delta T_t)/h$를 일으킵니다 |

온도 하중에는 재료의 **α**와 단면의 **높이 h**가 쓰입니다. 양의 `ΔTb − ΔTt`(하연이 더 따뜻함)는 하연을 늘이므로, 요소는 중력 하중을 받는 보처럼 아래로 처집니다. 정정 구조물에서 온도는 변위만 일으키지만, 구속(고정단, 연속성, 여분의 부재)이 있으면 부재력이 생깁니다.

## 하중 편집과 삭제 {#editing-and-removing-loads}

- 모든 하중은 *하중* 탭에 한 행씩 있으며, 그 자리에서 성분과 LCS 플래그를 편집할 수 있습니다. 하중은 *절점* 표와 *요소* 표에도 칩으로 표시됩니다.
- 뷰어에서 하중을 **더블클릭**하거나, 클릭한 뒤 **하중 편집**을 선택하면 편집 대화 상자가 열립니다.
- 하중을 선택하고 <kbd>Delete</kbd>를 누르거나 표의 ×를 누릅니다.
- 절점이나 요소에 붙은 하중은 그 절점이나 요소와 함께 삭제되고, 복사해 붙여 넣을 때도 함께 복사됩니다.

![하중 탭: 하중마다 한 행이며 성분을 그 자리에서 편집할 수 있습니다](/screenshots/ko/loads-table.webp)

## 지원하지 않는 기능 {#what-is-not-available}

- **하중 케이스와 하중 조합.** 하중 케이스는 하나뿐입니다.
- **자중.** LCS를 해제한 등분포하중 $f_z = \rho\,g\,A$로 입력하십시오. IPE 200의 경우 7850 × 9.81 × 0.00285 ≈ 0.22 kN/m입니다.
- 경사 부재에 **전체 좌표축 기준 사다리꼴 분포하중**.
