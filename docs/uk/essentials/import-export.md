# Імпорт, експорт та обмін

Усе в <Edubeam /> відбувається у вашому браузері. Нічого не завантажується на сервер — посилання для обміну буквально містить модель.

## Зберегти проєкт

**Меню ☰ → Зберегти проєкт** або <kbd>Ctrl</kbd>+<kbd>S</kbd> завантажує `project.json`. Він містить вузли, елементи, матеріали, перерізи, навантаження, розмірні лінії та версію застосунку, яка його записала. Перейменовуйте файл як завгодно.

## Відкрити проєкт

- **Меню ☰ → Відкрити проєкт** або <kbd>Ctrl</kbd>+<kbd>O</kbd>, потім виберіть файл `.json`, або
- **перетягніть файл у будь-яке місце вікна застосунку**.

Відкриття замінює поточну модель (разом із матеріалами та перерізами). Спершу скористайтеся **Зберегти проєкт**, якщо хочете її зберегти.

## Поділитися посиланням

**Поділитися моделлю** (🔗 на панелі застосунку або в меню ☰) відкриває діалог *Поділитися моделлю за URL*:

- **Копіювати посилання** — копіює посилання в буфер обміну (або клацніть у полі).
- **Відкрити посилання** — відкриває його в новій вкладці, щоб перевірити, що побачить отримувач.
- **Поділитися через системний діалог** — на телефонах і планшетах передає посилання системному меню «Поділитися».

Посилання має вигляд `https://run.edubeam.app/?model=…` і кодує всю модель (вузли, елементи, властивості, навантаження). Той, хто його відкриє, отримує точну копію для локального редагування; зміни **не** синхронізуються назад — надішліть нове посилання, коли модель зміниться. Дуже великі моделі дають дуже довгі посилання; для них краще поділитися файлом JSON.

## Вбудувати перегляд лише для читання

Додайте `&viewer=1` до посилання для обміну (або `?viewer=1` до будь-якої URL застосунку), щоб відкрити модель у **режимі перегляду**: панель застосунку, нижня панель, скасування/повторення та панель налаштувань приховані, залишається лише полотно з поточною моделлю. Вставте цю URL в `<iframe>`, щоб вбудувати живу масштабовану модель у конспект лекцій чи вебсторінку:

```html
<iframe src="https://run.edubeam.app/?viewer=1&model=…" width="100%" height="400"></iframe>
```

Сторінка [Приклади](/uk/examples/) побудована саме так — кожна картка є посиланням із параметром `?model=`.

## Параметри URL

| Параметр | Ефект |
| --- | --- |
| `model=<дані>` | Завантажити закодовану модель, вписати її в екран, а потім прибрати параметр з адресного рядка. |
| `lang=<код>` | Перемкнути мову інтерфейсу (`en`, `cs`, `de`, `fr`, `es`, `pt`, `pl`, `cn`, `th`, `uk`, `ru`). |
| `viewer=1` | Режим перегляду лише для читання (див. вище). |

## Автоматичне збереження

Поточна модель і ваші налаштування зберігаються в локальному сховищі браузера після кожної зміни й відновлюються, коли ви повертаєтеся, — навіть після закриття браузера. Це зручність, а не резервна копія: вона прив'язана до одного профілю браузера на одному пристрої, і очищення даних сайту її видаляє. Зберігайте важливу роботу як файл проєкту.

## Формат проєкту

`project.json` — це звичайний читабельний JSON:

```json
{
  "edubeam": true,
  "version": "1.0.6",
  "domain": {
    "materials": [ { "label": "1", "e": 210000000000, "g": 81000000000, "alpha": 0.000012, "d": 7850 } ],
    "crossSections": [ { "label": "1", "a": 0.00285, "iy": 1.943e-5, "h": 0.2, "k": 1 } ],
    "nodes": [ { "label": "1", "coords": [0, 0, 0], "bcs": [0, 2] }, … ],
    "elements": [ { "label": "1", "nodes": ["1", "2"], "mat": "1", "cs": "1", "hinges": [false, false] } ],
    "loadCases": [ … ]
  }
}
```

Усі значення зберігаються в **одиницях SI** (м, Н, Па, рад) незалежно від одиниць відображення. Граничні умови використовують ідентифікатори ступенів вільності `0 = Dx`, `2 = Dz`, `4 = Ry`. Оскільки формат простий, моделі можна генерувати скриптом чи електронною таблицею й відкривати через **Відкрити проєкт**. Формат не версіонується як стабільний API, тож перевіряйте поле `version`, якщо автоматизуєте роботу з ним.
