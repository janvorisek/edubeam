# Клавиатура, мышь и сенсорный экран

Сочетания клавиш работают, пока фокус находится в окне просмотра. При вводе в ячейке таблицы или в диалоге они игнорируются; сначала щёлкните по холсту.

## Клавиатура {#keyboard}

| Сочетание | Действие |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Отменить |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Повторить |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Сохранить проект (скачать JSON) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Открыть проект |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Экспорт изображения |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Выделить всё |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Скопировать выделение (узлы, элементы и их нагрузки) |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Вставить: «призрак» копии следует за курсором; щёлкните, чтобы разместить её, или введите смещение Δx, Δz в плашке и нажмите **Вставить** |
| <kbd>Delete</kbd> | Удалить выделение |
| <kbd>Esc</kbd> | Отменить текущий режим мыши, закрыть обзор, снять выделение или выйти из ячейки таблицы |
| <kbd>Enter</kbd> | Подтвердить ячейку таблицы |
| <kbd>F</kbd> | Вписать в экран |
| <kbd>C</kbd> | Центрировать |
| <kbd>G</kbd> | Показать/скрыть сетку |
| <kbd>S</kbd> | Включить/выключить привязку к сетке |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Увеличить / уменьшить |

На Mac используйте <kbd>Cmd</kbd> там, где указано <kbd>Ctrl</kbd>.

## Мышь {#mouse}

| Действие | Результат |
| --- | --- |
| Щелчок | Выделить узел, элемент, нагрузку или размерную линию и открыть её панель |
| Протягивание по пустому холсту | Прямоугольник выделения |
| Перетаскивание узла | Переместить узел (при включённой привязке — по сетке) |
| Щелчок в режиме мыши | Поставить узел либо начать или продолжить ломаную элементов |
| Двойной щелчок по нагрузке | Редактировать нагрузку |
| Правый щелчок | Меню холста: Добавить узел, Добавить элемент, Добавить размер, Образмерить элемент (над элементом), Изменить, Копировать, Вставить, Удалить |
| <kbd>Ctrl</kbd> (<kbd>Cmd</kbd> на Mac) + «Добавить узел» / «Добавить элемент» в меню холста | Разместить мышью вместо диалога |
| Протягивание средней или правой кнопкой | Панорамирование (см. *Настройки → Управление и горячие клавиши*) |
| Колесо | Масштабирование к курсору |
| Наведение на объект | Подсказка с перемещениями, свойствами или значениями нагрузки |

На тачпаде прокрутка двумя пальцами масштабирует. Чтобы панорамировать, нажмите и тяните двумя пальцами (это перетаскивание правой кнопкой).

## Сенсорный экран {#touch}

| Жест | Результат |
| --- | --- |
| Касание | Выделить и показать сведения об объекте и действия с ним |
| Касание в режиме мыши | Поставить узел или продолжить элемент |
| Нажать на узел и тянуть | Переместить узел |
| Перетаскивание одним пальцем в другом месте | Панорамирование |
| Сведение и разведение пальцев | Масштабирование |
| Нажать и удерживать на холсте | Меню холста |
| Кнопка **Выделение рамкой** (справа вверху), затем перетаскивание | Прямоугольник выделения |

## Панели объектов {#object-panels}

Щелчок по объекту открывает рядом с ним панель со сведениями о нём и следующими действиями:

| Объект | Действия |
| --- | --- |
| Узел | Добавить нагрузку · Опоры узла (символ опоры, Dx / Dz / Ry, угол локальной системы координат узла) · Задать перемещение (у опёртого узла) · Удалить |
| Элемент | Редактировать элемент (узлы и шарниры, материал, сечение) · Добавить нагрузку · Матрица жёсткости · Удалить |
| Узловая нагрузка или нагрузка на элемент | Редактировать нагрузку · Удалить |
| Размерная линия | Изменить (координаты) · Развернуть размер · Удалить |
