# 节点与支座

节点是模型中的点。单元连接节点；支座和节点荷载附着在节点上。

## 坐标

每个节点都有以当前长度单位表示的 **X** 和 **Z** 坐标。x 轴指向右，**z 轴在屏幕上指向下**——因此一根从地面向上的柱子是从 `Z = 0` 到 `Z = −3`，而不是 `+3`。网格角落的坐标轴指示器显示当前的方向。参见[坐标系与符号约定](/zh/elements/conventions)。

## 添加节点

| 方式 | 操作 |
| --- | --- |
| **对话框** | *节点*标签页 → **添加节点**，或在画布上右键 → *添加节点*。输入 X 和 Z。 |
| **鼠标** | *节点*标签页 → **通过鼠标添加**（或在画布菜单中选择 *添加节点* 时按住 <kbd>Ctrl</kbd>），然后在画布上点击。每次点击添加一个节点；按 <kbd>Esc</kbd> 结束。 |
| **绘制单元时** | 在 *添加单元 → 通过鼠标添加* 模式下，点击空白画布会创建一个新节点并将其连接。 |
| **复制粘贴** | 选中节点（和单元），<kbd>Ctrl</kbd>+<kbd>C</kbd>、<kbd>Ctrl</kbd>+<kbd>V</kbd>，然后点击副本应放置的位置。 |

标签自动分配（`1`、`2`、…），可以在表格中重命名。

### 吸附

开启**吸附到网格**（<kbd>S</kbd> 或 **S** 标记）后，用鼠标放置和拖动的节点会落在**网格吸附步长**的整数倍上（默认 `0.1 m`，可在 *设置 → 视图设置 → 网格* 中更改）。关闭吸附可自由放置，或者事后在表格中输入精确坐标。

### 在已有单元上放置节点

添加节点时如果点击位置距离某个单元约 0.1 m 以内，EduBeam 会询问你的意图：

- **连接到结构** —— 该单元被拆分成两段（`1a` 和 `1b`），外端的铰会被保留，分布荷载会在两段之间划分。这是添加中间支座或加载点最快的方法。
- **放置独立节点** —— 节点创建在单元之上，但不与它连接。

## 编辑节点

- **表格：**就地编辑标签、X 和 Z。
- **拖动：**在视图中移动节点（可撤销）。在触摸屏上，长按节点开始移动。
- **编辑节点对话框：**在一处设置坐标、支座和局部坐标系角度，并实时预览支座符号。
- **删除：**表格中的垃圾桶图标、节点弹出菜单中的 *删除*，或选中后按 <kbd>Delete</kbd>。删除节点会同时删除附着在它上面的单元和荷载。

## 支座

支座就是一组被约束的自由度（DOF）。每个节点有三个自由度：

| 自由度 | 含义 |
| --- | --- |
| **Dx** | 沿 x 的平动（水平） |
| **Dz** | 沿 z 的平动（竖向） |
| **Ry** | 绕 y 的转动（平面内转动） |

在*节点*标签页的**受约束自由度**列、选中节点的**节点支座**弹出菜单或 *编辑节点* 对话框中勾选复选框。视图中绘制的符号由约束组合决定：

| 约束 | 支座 | 符号 |
| --- | --- | --- |
| Dx + Dz + Ry | 固定端（固支） | 带阴影的块 |
| Dx + Dz | 固定铰支座 | 三角形 |
| Dz | 竖向可动铰支座（可水平滑动） | 带滚轴的三角形 |
| Dx | 水平可动铰支座（可竖向滑动） | 旋转的滚动支座 |
| Dz + Ry | 定向支座（竖向导向） | 带滚轴的夹持块 |
| Dx + Ry | 定向支座（水平导向） | 旋转的夹持块 |
| Ry | 仅约束转动 | 转动约束符号 |
| 无 | 自由节点 | — |

每个被约束的自由度都会计算——并绘制——一个支座反力。

::: tip 桁架节点
桁架杆件是两端**端部铰接**都被释放的梁单元（参见[单元](/zh/essentials/elements#端部铰接)）。桁架节点通常采用固定铰支座（Dx + Dz）；如果与某节点相连的所有单元在该端都是铰接的，请**不要**约束该节点的 Ry，否则该节点的转角没有定义。
:::

### 倾斜（斜向）支座

在节点弹出菜单或 *编辑节点* 对话框中设置**节点局部坐标系角度**（角度制，−180…180）。节点的局部坐标轴按该角度旋转，支座自由度在旋转后的坐标系中解释，因此 30° 斜坡上的可动铰支座就是 `Dz` 加上局部坐标系角度 `30`。支座符号相应旋转，支座反力也按旋转后的方向报告。

### 稳定性

求解器至少需要总共**三个被约束的自由度**，且结构不能是机构。支座缺失或不足会产生错误 *Model needs at least 3 constrained DOFs…*（目前仅以英文显示），或者干脆没有结果。参见[故障排除](/zh/reference/troubleshooting)。

## 节点荷载与沉降

力、力矩和位移约束（支座沉降）都施加在节点上——参见[荷载](/zh/essentials/loads#节点荷载)。

## 尺寸标注

在画布上右键 → **添加标注**，即可在两点之间绘制尺寸标注线。端点拖近节点时会吸附到节点；选中标注线后可用**编辑**输入坐标，或用**翻转标注**把文字放到另一侧。尺寸标注仅用于展示，会随项目一起保存。
