# 手算校核

<Edubeam /> 是养成每位工程师都需要的习惯的好地方：永远不要相信一个自己无法大致复现的数字。本页给出经典情形的闭合解公式，并展示应用对它们的计算结果，你可以自己建立每个模型并进行比较。

除非另有说明，所有算例使用同一钢截面：$E = 210\,000$ MPa，$G = 81\,000$ MPa，$A = 28.5$ cm²，$I_y = 1943$ cm⁴，$h = 200$ mm，$k = 1$（IPE 200）。

$$EI = 210 \times 10^9 \cdot 1.943 \times 10^{-5} = 4.080 \times 10^6\ \text{Nm}^2$$

::: tip 为什么数值略有差异
EduBeam 使用 **Timoshenko** 梁，在经典 Euler–Bernoulli 弯曲挠度之上增加了剪切挠度 $\Delta w_s$。在静定情形下，转角、支座反力和内力不受影响。对细长杆件，附加项非常小；下表明确列出了它。
:::

## 两杆桁架

两根杆件分别从 `(0, 0)` 和 `(4, 0)` 处的固定铰支座出发，相交于 `(2, −2)`（顶点在上方 2 m 处），两杆都勾选**两端的端部铰接**，顶点处作用竖向荷载 $F = 20$ kN（向下，即 `Fz = 20`）。

每根杆件倾角 45°，长度 $L = 2\sqrt{2}$ m。由对称性，每杆承受

$$N = -\frac{F}{2 \sin 45^\circ} = -14.14\ \text{kN (压力)}$$

每个支座承担 10 kN 竖向反力和 ±10 kN 水平反力。查看 **N (x)** 图层和支反力。

## 简支梁上的温度梯度

$L = 8$ m，$\Delta T_b - \Delta T_t = -10$ K（顶部较热），$\alpha = 12 \times 10^{-6}$，$h = 0.2$ m。

梁可以自由弯曲，因此**没有内力**；曲率为

$$\kappa = \frac{\alpha\,(\Delta T_b - \Delta T_t)}{h} = \frac{12 \times 10^{-6} \cdot (-10)}{0.2} = -6 \times 10^{-4}\ \text{m}^{-1}$$

跨中挠度为 $\kappa L^2 / 8 = -4.8$ mm（向上）。现在约束两端的 `Ry`：曲率被阻止，整跨出现常值弯矩 $M = EI\kappa = 2.45$ kNm。

## 位移约束

取上面的[一端固支一端铰支梁](#一端固支一端铰支梁承受均布荷载)，去掉荷载，在可动铰支座处施加 `Dz = 10 mm` 的位移约束（支座沉降）。把悬臂梁端部向下推 $w$ 所需的力为 $R = 3EIw/L^3 = 0.567$ kN，固端弯矩为 $RL = 3.40$ kNm。再把均布荷载加回来，结果按线性叠加。

## 自行校核的技巧

- 始终留意**单位标记**；大多数差异都来自单位错误。
- 学习矩阵位移法时，用**刚度矩阵**窗口把单个单元与[理论手册](/zh/elements/beam)进行对照。
- 从**结果**标签页和悬停提示中读取精确数值，而不是从图形标签读取——后者经过舍入。
- 用**分享模型**把校核过的模型交给同事或老师。
