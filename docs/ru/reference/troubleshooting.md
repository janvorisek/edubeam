# Решение проблем

## Результаты не рисуются

Результаты появляются, только когда модель можно решить. Проверьте по порядку:

1. **Есть ли красное предупреждение в области просмотра?** *Материалы не определены.* / *Сечения не определены.* → добавьте их. *Model has N error(s)* → нажмите **Show details** и исправьте каждый пункт (см. таблицу ниже). Сообщения решателя пока показываются на английском.
2. **Хватает ли опор?** Решателю нужно не менее трёх закреплённых степеней свободы *и* отсутствие механизмов. Балка на двух подвижных опорах (Dz + Dz) имеет только две и уезжает; рама на одних шарнирах без связей может быть механизмом даже при множестве опор. Добавьте где-нибудь `Dx` или `Ry` на одной из опор.
3. **Соединены ли элементы?** Два узла с одинаковыми координатами — это всё равно два разных узла. Удалите лишний и соедините заново либо ставьте узлы на элементы через **Соединить с конструкцией**.
4. **Шарниры повсюду?** Узел, у которого все элементы шарнирные и нет закрепления `Ry`, имеет неопределённый поворот. Снимите один шарнир или закрепите `Ry` в этом узле.
5. **Абсурдные числа** (перемещения в миллионы) означают, что система почти механизм; такие результаты EduBeam скрывает. Ищите пропущенную опору или почти нулевую жёсткость (`E`, `A` или `Iy`, случайно введённые как 0 или не в тех единицах).

## Сообщения об ошибках

Сообщения из **Show details** (диалог *Cannot solve model*); они пока показываются только на английском:

| Сообщение | Смысл / исправление |
| --- | --- |
| *Model needs at least 3 constrained DOFs to be stable in 2D analysis.* | Добавляйте опоры, пока в сумме не будет закреплено не менее трёх степеней свободы. |
| *Element X references missing node / material / cross section Y.* | Объект, на который ссылается элемент, удалён (обычно через отредактированный вручную JSON). Назначьте его заново в таблице *Элементы*. |
| *Element X must reference exactly 2 nodes.* | Повреждённый элемент в импортированном файле; удалите и создайте заново. |
| *Nodal load / Prescribed displacement #n references missing node Y.* | Удалите нагрузку или перенаправьте её на другой узел. |
| *Element load #n references missing element Y.* | Удалите нагрузку. |
| *Solver failed due to an internal model inconsistency…* | Общая ошибка; отмените последний шаг или сохраните файл и [сообщите о проблеме](https://github.com/janvorisek/edubeam/issues). |

Предупреждения (диалог *Model warnings*) расчёт не останавливают: *Element X references the same node at both ends* (элемент нулевой длины — удалите его) и *… contains invalid values* (нагрузка с нечисловым компонентом — отредактируйте её).

## Результаты выглядят неправильно

| Симптом | Вероятная причина |
| --- | --- |
| Нагрузки направлены вверх | Глобальная ось **z направлена вниз**, поэтому положительные `Fz`/`fz` направлены вниз. Отрицательные значения — вверх. См. [правила знаков](/ru/elements/conventions). |
| Прогиб в 1000 раз больше или меньше | Путаница в единицах: `E` введён в Па при единице МПа или `Iy` в см⁴ при единице м⁴. Проверьте плашку единиц в правом нижнем углу области просмотра. |
| Прогиб чуть больше, чем по формуле из учебника | Деформация сдвига по Тимошенко. Увеличьте коэффициент сдвига сечения (или возьмите более гибкий стержень), чтобы приблизиться к значениям Эйлера–Бернулли. См. [Проверка результатов вручную](/ru/guide/verification). |
| Эпюра моментов «не с той стороны» | Сторона — лишь условность рисования; знак читайте по подписям: положительный означает растяжение нижних волокон. |
| Эпюры огромные / крошечные | Чисто визуальный эффект — отрегулируйте **Масштаб результатов** в *Настройки → Настройки просмотра*. |
| Нагрузка в локальных координатах направлена не туда | Локальная ось x элемента идёт от *начального* узла к *конечному*. Используйте **Поменять порядок узлов** или измените знак. |
| Температурная нагрузка ничего не делает | Статически определимые системы свободно деформируются от температуры без внутренних усилий. Проверьте, что α ≠ 0, а для перепада — что задана высота сечения h. |

## Проблемы интерфейса

| Симптом | Исправление |
| --- | --- |
| Горячие клавиши не работают | Сначала щёлкните по холсту — клавиши игнорируются, пока фокус в текстовом поле. |
| Не получается панорамировать | По умолчанию панорамирование — средней/правой кнопкой мыши; измените это в *Настройки → Управление и горячие клавиши*. На тачпаде используйте два пальца или переключите настройку на *Правая кнопка*. |
| Модель пропала после обновления | Об обновлении, сбрасывающем хранилище, сначала сообщает диалог; отмените его и сохраните проект перед обновлением. |
| Не тот язык | *Настройки → Язык и локаль* или добавьте `?lang=ru` к URL. |
| Настройки не сохраняются | Локальное хранилище заблокировано (приватное окно, строгий режим приватности). Настройкам и автосохранению оно необходимо. |

## Сообщить об ошибке

Создайте [GitHub issue](https://github.com/janvorisek/edubeam/issues), указав браузер и ОС, что вы ожидали и — самое полезное — **ссылку на модель** или **JSON проекта**, воспроизводящий проблему.
