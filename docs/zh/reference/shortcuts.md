# 键盘与鼠标

键盘快捷键在视图获得焦点时有效——在表格单元格或对话框中输入时会被忽略。

## 键盘

| 快捷键 | 操作 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 撤销 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | 重做 |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | 保存项目（下载 JSON） |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | 打开项目 |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | 全选 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | 把所选内容（节点、单元、荷载）复制到 EduBeam 的剪贴板 |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | 粘贴：副本的虚影跟随光标；左键点击放置 |
| <kbd>Delete</kbd> | 删除所选内容 |
| <kbd>Esc</kbd> | 取消当前鼠标模式、清除选择、离开表格单元格 |
| <kbd>Enter</kbd> | 确认表格单元格 |
| <kbd>F</kbd> | 适配屏幕 |
| <kbd>C</kbd> | 居中显示 |
| <kbd>G</kbd> | 切换网格 |
| <kbd>S</kbd> | 切换吸附到网格 |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | 放大 / 缩小 |

在 macOS 上，凡是标注 <kbd>Ctrl</kbd> 的地方请使用 <kbd>Cmd</kbd>。

## 鼠标

| 操作 | 结果 |
| --- | --- |
| 左键点击 | 选中节点 / 单元 / 荷载 / 尺寸标注并打开它的弹出菜单 |
| 在空白画布上左键拖动 | 框选 |
| 在节点上左键拖动 | 移动节点（开启吸附时吸附到网格） |
| 在 *通过鼠标添加* 模式下左键点击 | 放置节点，或开始 / 继续单元折线 |
| 双击荷载 | 编辑荷载 |
| 在空白画布上右键点击 | 画布菜单：添加节点、添加单元、添加标注、编辑、复制、粘贴、删除 |
| 中键或右键拖动 | 平移（可在 *设置 → 控制与快捷键* 中配置） |
| 滚轮 | 朝光标位置缩放 |
| 悬停 | 显示位移 / 属性 / 荷载数值的提示 |

## 触摸

| 手势 | 结果 |
| --- | --- |
| 轻点 | 选择 |
| 单指拖动 | 平移 |
| 双指捏合 | 缩放 |
| 长按节点 | 开始移动它 |

## 弹出菜单

点击对象会在它旁边打开一个小菜单：

| 对象 | 菜单项 |
| --- | --- |
| 节点 | 添加荷载 · 节点支座（Dx / Dz / Ry、节点局部坐标系角度）· 施加位移约束（如果有支座）· 删除 |
| 单元 | 编辑单元（节点、材料、截面）· 添加荷载 · 刚度矩阵 · 删除 |
| 节点 / 单元荷载 | 编辑荷载 · 删除 |
| 尺寸标注 | 编辑（坐标）· 翻转标注 · 删除 |
