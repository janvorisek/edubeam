# 故障排除

## 没有绘制出结果

只有当模型可以求解时才会显示结果。请按以下顺序检查：

1. **视图中是否有红色提示？** *尚未定义材料。* / *尚未定义截面。* → 添加一个。*Model has N error(s)* → 点击 **Show details** 并逐项修复（见下表）。
2. **支座够吗？** 求解器至少需要三个被约束的自由度*并且*没有机构。放在两个可动铰支座上的梁（Dz + Dz）只有两个约束，会滑走；全部为铰接且没有支撑的刚架即使有很多支座也可能是机构。在某处添加一个 `Dx`，或在某个支座上添加 `Ry`。
3. **单元连接了吗？** 坐标相同的两个节点仍然是两个独立的节点。删除多余的节点并重新连接，或者用**连接到结构**在单元上放置节点。
4. **到处都是铰？** 如果与某节点相连的每个单元都是铰接的，且该节点没有 `Ry` 支座，那么它的转角没有定义。取消一个铰的勾选，或约束该节点的 `Ry`。
5. **荒谬的数值**（位移达到数百万）意味着结构几乎是机构；EduBeam 会隐藏此类结果。检查是否缺少支座，或某个刚度接近零（`E`、`A` 或 `Iy` 不小心输入为 0 或单位错误）。

## 错误消息

来自 **Show details**（*Cannot solve model* 对话框）的消息。求解器消息目前仅以英文显示：

| 消息 | 含义 / 修复方法 |
| --- | --- |
| *Model needs at least 3 constrained DOFs to be stable in 2D analysis.* | 添加支座，直到总共至少有三个自由度被约束。 |
| *Element X references missing node / material / cross section Y.* | 被引用的对象已被删除（通常是手工编辑 JSON 文件导致）。在*单元*表格中重新分配。 |
| *Element X must reference exactly 2 nodes.* | 导入文件中的单元已损坏；删除并重新创建。 |
| *Nodal load / Prescribed displacement #n references missing node Y.* | 删除该荷载或重新指定作用位置。 |
| *Element load #n references missing element Y.* | 删除该荷载。 |
| *Solver failed due to an internal model inconsistency…* | 一般性故障；撤销上一步，或保存文件并[报告问题](https://github.com/janvorisek/edubeam/issues)。 |

警告（*Model warnings* 对话框）不会阻止求解：*Element X references the same node at both ends*（零长度单元——删除它）和 *… contains invalid values*（某个荷载含有非数值分量——编辑它）。

## 结果看起来不对

| 现象 | 可能原因 |
| --- | --- |
| 荷载朝上 | 整体 **z 轴向下**，因此正的 `Fz`/`fz` 是向下的。负值朝上。参见[符号约定](/zh/elements/conventions)。 |
| 挠度大了或小了 1000 倍 | 单位混淆——单位是 MPa 却以 Pa 输入了 `E`，或单位是 m⁴ 却以 cm⁴ 输入了 `Iy`。检查视图右下角的单位标记。 |
| 挠度比教科书公式略大 | Timoshenko 剪切变形。增大截面的剪切系数（或使用细长杆件）即可接近 Euler–Bernoulli 的值。参见[手算校核](/zh/guide/verification)。 |
| 弯矩图画在"错误"的一侧 | 画在哪一侧只是绘图约定；请从标签读取符号——正值表示下侧受拉（下缘纤维受拉）。 |
| 图形巨大 / 极小 | 纯视觉问题——在 *设置 → 视图设置* 中调整**结果缩放**。 |
| 局部坐标系荷载方向反了 | 单元的局部 x 轴从*起始*节点指向*终止*节点。使用**交换节点顺序**或改变符号。 |
| 温度荷载没有效果 | 静定结构在温度作用下自由变形而不产生内力。检查 α ≠ 0，对于梯度部分还要检查截面高度 h 是否已设置。 |

## 界面问题

| 现象 | 修复方法 |
| --- | --- |
| 快捷键无效 | 先点击画布——当文本框获得焦点时按键会被忽略。 |
| 无法平移 | 默认使用鼠标中键/右键平移；可在 *设置 → 控制与快捷键* 中更改。在触控板上用双指，或把设置改为*右键*。 |
| 更新后我的模型不见了 | 会重置存储的更新会先在对话框中通知；请选择取消，先保存项目再更新。 |
| 语言不对 | *设置 → 语言与区域*，或在 URL 后添加 `?lang=cn`。 |
| 设置更改不生效 | 本地存储被阻止（隐私窗口、严格隐私模式）。设置和自动保存都需要它。 |

## 报告错误

在 [GitHub issue](https://github.com/janvorisek/edubeam/issues) 中说明浏览器和操作系统、你期望的结果，以及——最有用的——一个能复现问题的**分享链接**或**项目 JSON**。
