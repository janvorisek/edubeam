# 坐标系与符号约定

<Edubeam /> 中大多数“错误”结果，其实都是符号约定带来的意外。下面列出的就是求解器实际使用的约定。

## 整体坐标轴 {#global-axes}

- **x** —— 水平方向，向**右**为正。
- **z** —— 竖直方向，在屏幕上**向下**为正。
- **y** —— 平面外的坐标轴（按右手坐标系指向观察者）。转角和力矩都绕 y 轴。

网格角落的坐标轴指示器显示 x（红色）和 z（绿色）。因此，如果柱底位于 `Z = 0`，那么 3 m 高柱顶部的节点为 `Z = −3`。

## 自由度 {#degrees-of-freedom}

每个节点有 `Dx`、`Dz`（平动）和 `Ry`（转动）。正的 `Dz` 是向下的位移；正的 `Ry` 在屏幕上是**逆时针**转动。位移约束和输出的节点结果采用相同的符号。

## 荷载 {#loads}

| 荷载 | 正方向 |
| --- | --- |
| `Fx`、`fx`、`f1x`… | +x（向右；开启 LCS 时沿单元局部 x 轴） |
| `Fz`、`fz`、`f1z`… | +z（**向下**；开启 LCS 时沿局部 z 轴） |
| `My` | 屏幕上逆时针 |
| `ΔTc` | 升温（伸长） |
| `ΔTb − ΔTt` | 下缘纤维比上缘更热 |

因此重力荷载是**正**的 `fz`，把左侧柱推向右方的风荷载是正的 `fx`。

## 单元局部坐标轴 {#element-local-axes}

局部 **x** 轴从起始节点指向终止节点；局部 **z** 轴与之垂直，由整体坐标轴旋转单元角度 $\alpha$ 得到。对于从左向右画的水平单元，局部坐标轴与整体坐标轴重合。在*单元*表格中使用**交换节点顺序**可以使方向反转。

## 内力 {#internal-forces}

| 物理量 | 正值表示 |
| --- | --- |
| **N** | 受拉 |
| **V<sub>z</sub>** | 梁理论中的常用符号：重力荷载作用下的简支梁，V 在左支座处为正，在右支座处为负 |
| **M<sub>y</sub>** | **正弯矩**——下缘（+z）纤维受拉。重力荷载作用下的简支梁跨中弯矩为正；自由端受集中荷载的悬臂梁在根部为负弯矩 |

## 端力（单元结果表格） {#end-forces-element-results-table}

`X12, Z12, M12` 在起始节点处作用于单元，`X21, Z21, M21` 在终止节点处作用于单元，均在**局部**坐标系中，正方向与局部坐标轴和 `My` 相同。它们是节点作用在单元上的力，即 $\mathbf{f} = \mathbf{K}_l\,\mathbf{u}_l - \mathbf{f}_{eq}$，其中 $\mathbf{f}_{eq}$ 是单元荷载的等效节点荷载。交于某个节点的所有单元的端力之和，与该节点处的节点荷载和支反力相平衡。

## 支反力 {#reactions}

每个受约束的自由度都有一个支反力，并在节点坐标系中给出（如果设置了节点局部坐标系角度，则按该角度旋转）。视图中的支反力箭头指向支座推动结构的方向。

## y 向上的坐标轴 {#y-up-axes}

**设置 → 坐标系 → x 向右，y 向上**会把你输入和读取的所有内容切换到教科书常用的坐标系：**x** 向右，**y** 向上，**z** 指向观察者。模型、已保存的文件和图形保持不变；只有数值和名称会改变：

| 物理量 | z 向下（默认） | y 向上 |
| --- | --- | --- |
| 竖向坐标 | `Z` | `Y`，符号相反 |
| 竖向荷载、位移、支反力、端力 | `Fz`、`fz`、`Dz`、`Z12`… | `Fy`、`fy`、`Dy`、`Y12`…，符号相反 |
| 转角和力矩 | `Ry`、`My` | `Rz`、`Mz`，符号相同（逆时针为正） |
| 支座角度 α | 顺时针量取 | 逆时针量取，符号相反 |
| 内力 N、V、M | | 不变，内力图的画法相同 |

因此重力荷载是**负**的 `fy`，3 m 高柱的顶部为 `Y = 3`。

## 单位 {#units}

求解器内部采用国际单位制（m、N、Pa、rad、K）。显示单位只影响你输入和读取的内容；修改显示单位绝不会改变模型。
