# キーボード・マウス・タッチ

キーボードショートカットは、ビューアにフォーカスがあるときに使えます。表のセルやダイアログに入力している間は無視されるので、先にキャンバスをクリックしてください。

## キーボード {#keyboard}

| ショートカット | 操作 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 元に戻す |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | やり直し |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | プロジェクトを保存（JSON をダウンロード） |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | プロジェクトを開く |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | 画像をエクスポート |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | すべて選択 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | 選択内容（節点、要素とそれらの荷重）をコピー |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | 貼り付け：コピーの半透明の像がカーソルに付いてくるので、クリックして配置するか、バナーにオフセット Δx、Δz を入力して**貼り付け**を押します |
| <kbd>Delete</kbd> | 選択内容を削除 |
| <kbd>Esc</kbd> | 現在のマウスモードの取り消し、ツアーを閉じる、選択の解除、または表のセルを離れる |
| <kbd>Enter</kbd> | 表のセルの入力を確定 |
| <kbd>F</kbd> | 画面に合わせる |
| <kbd>C</kbd> | 中央に表示 |
| <kbd>G</kbd> | グリッド表示の切替 |
| <kbd>S</kbd> | グリッドスナップの切替 |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | ズームイン / ズームアウト |

Mac では、<kbd>Ctrl</kbd> の代わりに <kbd>Cmd</kbd> を使ってください。

## マウス {#mouse}

| 操作 | 結果 |
| --- | --- |
| クリック | 節点、要素、荷重、寸法線を選択し、そのパネルを開く |
| キャンバスの何もない所をドラッグ | 範囲選択の矩形 |
| 節点をドラッグ | 節点を移動（スナップがオンならグリッドにスナップ） |
| マウスモードでクリック | 節点を配置、または要素の折れ線を開始・継続 |
| 荷重をダブルクリック | 荷重を編集 |
| 右クリック | キャンバスのメニュー：節点を追加、要素を追加、寸法線を追加、要素の寸法線（要素の上で）、編集、コピー、貼り付け、削除 |
| キャンバスのメニューで <kbd>Ctrl</kbd>（Mac では <kbd>Cmd</kbd>）+ 節点を追加 / 要素を追加 | ダイアログではなくマウスで配置 |
| 中ボタンまたは右ボタンでドラッグ | パン（*設定 → 操作とショートカット*を参照） |
| ホイール | カーソルに向かってズーム |
| オブジェクトにマウスを重ねる | 変位、特性、荷重の値を示すツールチップ |

トラックパッドでは、2 本指のスクロールでズームします。パンするには、2 本指でクリックしてドラッグします（右ボタンでのドラッグ）。

## タッチ {#touch}

| ジェスチャー | 結果 |
| --- | --- |
| タップ | 選択し、オブジェクトの詳細と操作を表示 |
| マウスモードでタップ | 節点を配置、または要素を継続 |
| 節点を押してドラッグ | 節点を移動 |
| それ以外の場所を 1 本指でドラッグ | パン |
| ピンチ | ズーム |
| キャンバスを長押し | キャンバスのメニュー |
| **矩形選択**ボタン（右上）を押してからドラッグ | 範囲選択の矩形 |

## オブジェクトのパネル {#object-panels}

オブジェクトをクリックすると、その横にパネルが開き、詳細と次の操作が表示されます。

| オブジェクト | 操作 |
| --- | --- |
| 節点 | 荷重を追加 · 支点条件（支点記号、Dx / Dz / Ry、節点の LCS 角度） · 強制変位を設定（支点のある節点で） · 削除 |
| 要素 | 要素を編集（節点とヒンジ、材料、断面） · 荷重を追加 · 剛性マトリクス · 削除 |
| 節点荷重または要素荷重 | 荷重を編集 · 削除 |
| 寸法線 | 編集（座標） · 寸法線を反転 · 削除 |
