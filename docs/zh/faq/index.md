# 常见问题

## 一般问题

### EduBeam 是什么？

一款免费、开源、基于浏览器的平面梁、刚架和桁架求解器，面向希望获得即时反馈的学生、教师和工程师。参见[简介](/zh/guide/introduction)。

### 真的免费吗？需要账号吗？

是的，不需要。打开 [run.edubeam.app](https://run.edubeam.app/?lang=cn) 就可以开始建模。没有账号，没有安装程序，也没有使用限制。源代码在 [GitHub](https://github.com/janvorisek/edubeam) 上。

### 支持哪些浏览器和设备？

任何当前版本的 Chrome、Edge、Firefox 或 Safari。平板和手机也可以使用（轻点、拖动平移、捏合缩放、长按移动节点），但鼠标和键盘会让建模快得多。

### 可以离线使用吗？

EduBeam 是一个渐进式网页应用（PWA）：加载一次后无需网络也能继续工作，浏览器可能会提示安装它。有新版本时，会先弹出对话框询问再更新。

### 我的数据存在哪里？

只在你的浏览器里。模型从不发送到服务器；分享链接*就是*模型本身。参见[导入、导出与分享](/zh/essentials/import-export)。

## 建模

### 如何设置固定端 / 固定铰支座 / 可动铰支座？

勾选自由度复选框：**Dx + Dz + Ry** = 固定端，**Dx + Dz** = 固定铰支座，**Dz** = 可动铰支座。所有组合及其符号列在[节点与支座](/zh/essentials/nodes-supports#支座)中。

### 如何建立桁架？

使用梁单元，并在*单元*标签页中为每根杆件勾选**两端的端部铰接**。荷载施加在节点上。参见[单元](/zh/essentials/elements#端部铰接)。

### 如何在刚架中设置铰？

在需要释放弯矩的那一侧，勾选该单元的**端部铰接**。在一个节点处只对*一个*单元设置铰接，只会释放那个单元。

### 如何在梁的中间添加支座或集中荷载？

用 *通过鼠标添加* 在梁上添加一个节点并选择**连接到结构**——梁会被一分为二。如果只需要集中荷载，甚至不需要节点：使用带位置参数的**集中荷载**单元荷载。

### 可以施加自重吗？

不能自动施加。请以均布荷载 $f_z = \rho g A$ 的形式输入。

### 可以模拟斜向支座吗？

可以——为节点设置**节点局部坐标系角度**，它的自由度随后在旋转后的坐标系中解释。

### 有荷载工况或组合吗？

没有，只有一个荷载工况。请把每种工况分别建模并保存或分享。

### 为什么我的荷载朝上？

因为整体 z 轴指向**下**：正的 `Fz` 是向下的。参见[符号约定](/zh/elements/conventions)。

## 结果

### 为什么没有"求解"按钮？

模型在每次更改后自动求解。如果没有出现结果，说明模型还无法求解——[故障排除](/zh/reference/troubleshooting)列出了需要检查的内容。

### 为什么我的挠度与公式略有不同？

EduBeam 使用 Timoshenko 梁，因此挠度包含剪切变形。对细长杆件，差异远小于 1 %。详情和对比算例见[手算校核](/zh/guide/verification)。

### 结果有多精确？需要更多单元吗？

对线性静力分析，梁单元在所支持的荷载类型下是精确的，因此每根杆件一个单元就够了。只有在需要支座、铰、截面变化或需要一个节点来施加荷载的位置才需要额外节点。

### 支座反力在哪里列出？

在视图中以带数值的箭头显示（在显示设置中启用**支反力**）。单元端力和节点位移在**结果**标签页中。

## 文件与分享

### 如何分享模型？

**分享模型** → **复制链接**。链接包含整个模型。接收者会得到自己的可编辑副本；没有实时协作。

### 可以把模型嵌入到我的网站或课件中吗？

可以——在分享链接后添加 `&viewer=1` 并放入 `<iframe>`。参见[嵌入只读查看器](/zh/essentials/import-export#嵌入只读查看器)。

### 可以导出图片或表格吗？

暂时不行。图片请用截图，数值请复制表格文字。可以在 [GitHub](https://github.com/janvorisek/edubeam/issues) 上为该功能投票。

### 可以通过程序生成模型吗？

可以。项目文件是以 SI 单位表示的简单 JSON——参见[格式说明](/zh/essentials/import-export#项目文件格式)——可以用 *打开项目* 或拖放打开。
