# บทนำ

<Edubeam /> เป็นเครื่องมือ **วิเคราะห์โครงสร้าง 2 มิติ** ฟรีที่ทำงานบนเบราว์เซอร์ ใช้ได้กับคาน โครงข้อแข็ง และโครงถัก คุณวาดโครงสร้าง ใส่จุดรองรับและแรงกระทำ แล้วตัวคำนวณไฟไนต์เอลิเมนต์จะคำนวณใหม่ทั้งหมดทันทีที่คุณเปลี่ยนแปลงอะไรก็ตาม ไม่มีปุ่ม *คำนวณ* ไม่ต้องติดตั้ง และไม่ต้องมีบัญชี

[เปิด EduBeam](https://run.edubeam.app/?lang=th){target="_blank"} ในแท็บใหม่ แล้วทำตาม [เริ่มต้นใช้งานด่วน](/th/guide/quick-start) ไปพร้อมกัน

![โครงข้อแข็งสามจุดหมุนใน EduBeam: แรงกระทำสีส้ม แรงปฏิกิริยาสีม่วง โมเมนต์ดัดสีแดง และรูปร่างที่เสียรูปสีเทา](/screenshots/th/hero.webp)

## การเข้าใช้งานครั้งแรก {#your-first-visit}

เมื่อเปิดแอปครั้งแรก กล่องต้อนรับจะถามว่าคุณอยากเริ่มอย่างไร และต้องการใช้หน่วยและแกนแบบใด ทั้งสองอย่างเปลี่ยนภายหลังได้ใน [การตั้งค่า](/th/essentials/units-settings)

![กล่องต้อนรับ](/screenshots/th/welcome.webp){.shot-lg}

- **พาชมแอป** จะแนะนำเมนู ปุ่มเลิกทำและทำซ้ำ ปุ่มของโปรแกรมดู ตัวเลือกการแสดงผล ตาข่ายและหน่วย และแถบด้านล่าง ทีละส่วน
- **วาดคานแรกของคุณ** เป็นแบบฝึกพร้อมคำแนะนำ 7 ขั้น คุณจะวาดคานด้วยเมาส์ ใส่จุดรองรับ ใส่แรงกระทำ และอ่านผลลัพธ์ การ์ดเล็ก ๆ ที่มุมจอจะบอกว่าต้องทำอะไรต่อ
- **เปิดตัวอย่าง** จะเปิดแกลเลอรีของโมเดลสำเร็จรูป

ทั้งสามตัวเลือกมีอยู่ใน **เมนู ☰** ด้วย คุณจึงกลับมาใช้ได้ทุกเมื่อ

![วาดคานแรกของคุณ: การ์ดคำแนะนำอยู่ที่มุมจอตลอดขณะที่คุณทำงาน](/screenshots/th/first-beam-task.webp)

## EduBeam ทำอะไรได้บ้าง {#what-it-does}

| ด้าน | ความสามารถ |
| --- | --- |
| **โครงสร้าง** | คาน คานต่อเนื่อง โครงข้อแข็ง และโครงถักในระนาบ (x–z) ที่ประกอบจากโหนดและองค์ประกอบคาน Timoshenko แบบ 2 มิติ จุดหมุนที่ปลายเปลี่ยนชิ้นส่วนใดก็ได้ให้เป็นชิ้นส่วนโครงถัก |
| **จุดรองรับ** | หมุด ล้อเลื่อน ยึดแน่น แบบเลื่อน และการยึด `Dx`, `Dz`, `Ry` ในทุกรูปแบบ เลือกได้จากสัญลักษณ์ จุดรองรับแบบเอียงกำหนดด้วยมุมของโหนด การทรุดตัวของจุดรองรับ |
| **แรงกระทำ** | แรงและโมเมนต์ที่โหนด การให้ค่าการกระจัด แรงกระจายสม่ำเสมอและแรงกระจายรูปสี่เหลี่ยมคางหมู แรงและโมเมนต์แบบจุดบนชิ้นส่วน และอุณหภูมิแบบสม่ำเสมอหรือแบบแปรผันตามความลึก |
| **หน้าตัด** | ไลบรารีวัสดุและหน้าตัด (มาตรฐานยุโรปและสหรัฐฯ) และตัวแก้ไขรูปหลายเหลี่ยมที่คำนวณ $A$, $I_y$, $I_z$, $I_{yz}$ แกนหลัก และรัศมีไจเรชันให้กับรูปร่างใดก็ได้ |
| **ผลลัพธ์** | รูปร่างที่เสียรูป แรงตามแนวแกน **N** แรงเฉือน **V** โมเมนต์ดัด **M** แรงปฏิกิริยา การกระจัดที่โหนด แรงปลายขององค์ประกอบ และเมทริกซ์ความแข็งขององค์ประกอบ |
| **การวิเคราะห์** | การวิเคราะห์สถิตเชิงเส้นกับกรณีโหลดเดียว ผลลัพธ์แม่นตรงสำหรับโมเดลเชิงเส้น จึงไม่ต้องแบ่ง mesh ให้ละเอียดขึ้น เมื่อโครงสร้างคำนวณไม่ได้ EduBeam จะบอกเหตุผลและแสดงภาพเคลื่อนไหวว่าโครงสร้างเคลื่อนที่ได้อย่างไร |
| **ไฟล์** | บันทึกและเปิดโปรเจกต์เป็น JSON แชร์ทั้งโมเดลเป็นลิงก์ ส่งออกภาพวาดเป็น PNG หรือ SVG และผลลัพธ์เป็น CSV โมเดลที่เพิ่งถูกแทนที่จะถูกเก็บไว้ให้เรียกคืนได้ ข้อมูลทั้งหมดอยู่บนอุปกรณ์ของคุณ |
| **หน่วย** | SI หรือระบบอเมริกันในคลิกเดียว หรือตั้งแต่ละปริมาณแยกกัน แกนเป็นได้ทั้ง x ไปทางขวา z ชี้ลง หรือ x ไปทางขวา y ชี้ขึ้น |

## สิ่งที่ยังทำไม่ได้ (ในตอนนี้) {#what-it-does-not-do-yet}

รู้ข้อจำกัดไว้ก่อนช่วยประหยัดเวลา:

- **2 มิติเท่านั้น** ไม่มีพฤติกรรมนอกระนาบ ไม่มีโครงข้อแข็ง 3 มิติ
- **สถิตเชิงเส้นเท่านั้น** ไม่มีผลลำดับที่สอง (P–Δ) ไม่มีการโก่งเดาะ ไม่มีพลศาสตร์ ไม่มีพฤติกรรมพลาสติก
- **กรณีโหลดเดียว** ไม่มีการจัดหมู่แรงกระทำ (load combination) หรือ envelope ให้สร้างโมเดลแต่ละกรณีแยกกัน แล้วบันทึกเป็นไฟล์หรือลิงก์แชร์ของแต่ละกรณี
- **ไม่คิดน้ำหนักตัวเอง** หากต้องการ ให้ใส่เป็นแรงกระจายบนชิ้นส่วน
- **ไม่มีการตรวจสอบการออกแบบ** EduBeam ให้แรงภายในและการกระจัด ส่วนการตรวจสอบตามมาตรฐานการออกแบบเป็นหน้าที่ของคุณ

หากฟีเจอร์ที่ยังไม่มีสำคัญกับคุณ [เปิด issue](https://github.com/janvorisek/edubeam/issues) ได้เลย

## เหมาะกับใคร? {#who-is-it-for}

- **นักศึกษา** ที่เรียนกลศาสตร์โครงสร้างและอยากได้ผลตอบกลับทันทีสำหรับการคำนวณมือ ดู [ตรวจสอบผลลัพธ์ด้วยการคำนวณมือ](/th/guide/verification)
- **ผู้สอน** ที่สาธิตสดบนโปรเจกเตอร์ว่าจุดรองรับ จุดหมุน และแรงกระทำเปลี่ยนแรงภายในอย่างไร ได้ใน 13 ภาษา ดู [สอนด้วย EduBeam](/th/guide/teaching)
- **วิศวกร** ที่ต้องการตรวจสอบความสมเหตุสมผลอย่างรวดเร็ว ก่อนเปิดโปรแกรมเดสก์ท็อปที่หนักกว่า

## โครงสร้างของคู่มือนี้ {#how-this-guide-is-organised}

1. **เริ่มต้นใช้งาน** หน้านี้ [เริ่มต้นใช้งานด่วน 10 นาที](/th/guide/quick-start) และ [ตัวอย่าง](/th/examples/) สำเร็จรูป
2. **บทเรียน** โมเดลที่สมบูรณ์ตั้งแต่ต้นจนจบ ตรวจสอบด้วยการคำนวณมือ: [โครงข้อแข็งสามจุดหมุน](/th/tutorials/three-hinged-frame) และ [โครงถักในระนาบ](/th/tutorials/truss)
3. **การสร้างโมเดล** หนึ่งหน้าต่อหนึ่งส่วนประกอบของโมเดล: [ส่วนติดต่อผู้ใช้](/th/essentials/user-interface) [โหนดและจุดรองรับ](/th/essentials/nodes-supports) [องค์ประกอบ วัสดุ และหน้าตัด](/th/essentials/elements) [แรงกระทำ](/th/essentials/loads) และ [หน่วยและการตั้งค่า](/th/essentials/units-settings)
4. **ผลลัพธ์** วิธี [อ่านแผนภาพและตาราง](/th/essentials/results) และวิธี [ตรวจสอบผลลัพธ์](/th/guide/verification)
5. **ไฟล์และการแชร์** [โปรเจกต์ ลิงก์แชร์ การส่งออกรูปภาพและ CSV](/th/essentials/import-export) และ [การสอนด้วย EduBeam](/th/guide/teaching)
6. **ข้อมูลอ้างอิง** [แป้นพิมพ์ เมาส์ และระบบสัมผัส](/th/reference/shortcuts) [การแก้ปัญหา](/th/reference/troubleshooting) และ [คำถามที่พบบ่อย](/th/faq/)
7. **คู่มือทฤษฎี** [ข้อตกลงเรื่องเครื่องหมาย](/th/elements/conventions) และสูตรขององค์ประกอบ [คาน](/th/elements/beam) และ [โครงถัก](/th/elements/truss)

ไอคอน **?** ในแอปจะเปิดหน้าที่ตรงกันของคู่มือนี้ในภาษาของคุณ

## ภาษา {#languages}

อินเทอร์เฟซมีให้เลือกเป็น English, Čeština, Deutsch, Español, Français, Polski, Português, Русский, Türkçe, Українська, हिन्दी, ไทย และ 汉语 EduBeam เลือกภาษาตามเบราว์เซอร์ของคุณ เปลี่ยนได้ใน **การตั้งค่า → ภาษาและภูมิภาค** หรือเปิดแอปด้วยพารามิเตอร์ `?lang=` เช่น [run.edubeam.app/?lang=th](https://run.edubeam.app/?lang=th){target="_blank"}
