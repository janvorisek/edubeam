# समस्या निवारण

::: tip त्रुटि संदेश अंग्रेज़ी में हैं
सॉल्वर के त्रुटि और चेतावनी संदेश (जैसे *Cannot solve model*, *Model has N error(s)*, **Show details**) ऐप में अभी केवल अंग्रेज़ी में दिखते हैं, इसलिए नीचे उन्हें मूल रूप में उद्धृत किया गया है।
:::

## कोई परिणाम नहीं बनता

परिणाम तभी दिखते हैं जब मॉडल हल किया जा सके। इस क्रम में जाँचें:

1. **क्या व्यूअर में लाल चेतावनी है?** *No materials defined* / *No cross sections defined* → एक जोड़ें। *Model has N error(s)* → **Show details** पर क्लिक करके हर आइटम ठीक करें (नीचे की तालिका देखें)।
2. **पर्याप्त आधार?** सॉल्वर को कम से कम तीन अवरुद्ध DOFs *और* कोई यंत्र (mechanism) न होना चाहिए। दो रोलरों पर बीम (Dz + Dz) में केवल दो हैं और वह सरक जाता है; सभी पिन वाला और बिना ब्रेसिंग का फ्रेम कई आधारों के बावजूद यंत्र हो सकता है। कहीं एक `Dx` जोड़ें, या किसी एक आधार पर `Ry`।
3. **क्या अवयव जुड़े हैं?** एक ही निर्देशांक पर दो नोड फिर भी दो अलग नोड हैं। भटका हुआ नोड हटाकर दोबारा जोड़ें, या **Connect to structure** से नोड को अवयवों पर रखें।
4. **हर जगह हिंज?** जिस नोड का हर अवयव हिंज वाला हो और जिस पर `Ry` आधार न हो, उसका घूर्णन अपरिभाषित है। एक हिंज हटाएँ या उस नोड पर `Ry` अवरुद्ध करें।
5. **बेतुकी संख्याएँ** (लाखों में विस्थापन) का अर्थ है कि संरचना लगभग यंत्र है; EduBeam ऐसे परिणाम छिपा देता है। कोई छूटा हुआ आधार या लगभग-शून्य दृढ़ता (`E`, `A` या `Iy` गलती से 0 या गलत इकाई में दर्ज) खोजें।

## त्रुटि संदेश

**Show details** (*Cannot solve model* संवाद) के संदेश:

| संदेश | अर्थ / समाधान |
| --- | --- |
| *Model needs at least 3 constrained DOFs to be stable in 2D analysis.* | आधार तब तक जोड़ें जब तक कुल कम से कम तीन DOFs अवरुद्ध न हों। |
| *Element X references missing node / material / cross section Y.* | संदर्भित इकाई हटा दी गई है (आमतौर पर हाथ से संपादित JSON फाइल के कारण)। *Elements* तालिका में उसे दोबारा निर्दिष्ट करें। |
| *Element X must reference exactly 2 nodes.* | आयातित फाइल में भ्रष्ट अवयव; उसे हटाकर दोबारा बनाएँ। |
| *Nodal load / Prescribed displacement #n references missing node Y.* | भार हटाएँ या उसका लक्ष्य बदलें। |
| *Element load #n references missing element Y.* | भार हटाएँ। |
| *Solver failed due to an internal model inconsistency…* | सामान्य विफलता; अंतिम चरण पूर्ववत करें या फाइल सहेजकर [रिपोर्ट करें](https://github.com/janvorisek/edubeam/issues)। |

चेतावनियाँ (*Model warnings* संवाद) हल को नहीं रोकतीं: *Element X references the same node at both ends* (शून्य-लंबाई अवयव—उसे हटाएँ) और *… contains invalid values* (गैर-संख्यात्मक घटक वाला भार—उसे संपादित करें)।

## परिणाम गलत लगते हैं

| लक्षण | संभावित कारण |
| --- | --- |
| भार ऊपर की ओर कार्य करते हैं | वैश्विक **z नीचे की ओर** है, इसलिए धनात्मक `Fz`/`fz` नीचे की ओर है। ऋणात्मक मान ऊपर की ओर। देखें [परिपाटी](/hi/elements/conventions)। |
| विक्षेप 1000× बहुत बड़ा या छोटा | इकाई की गड़बड़—`E` Pa में दर्ज जबकि इकाई MPa है, या `Iy` cm⁴ में जबकि इकाई m⁴ है। व्यूअर के निचले-दाएँ इकाइयों की चिप जाँचें। |
| विक्षेप पाठ्यपुस्तक सूत्र से थोड़ा बड़ा | Timoshenko अपरूपण विरूपण। Euler–Bernoulli मानों के करीब आने के लिए काट का अपरूपण गुणांक बढ़ाएँ (या पतला सदस्य लें)। देखें [परिणामों की हाथ से जाँच](/hi/guide/verification)। |
| आघूर्ण आरेख "गलत" तरफ़ है | तरफ़ केवल आरेखन की परिपाटी है; चिह्न लेबलों से पढ़ें—धनात्मक का अर्थ सैगिंग (निचले तंतु में तनाव)। |
| आरेख बहुत बड़े / बहुत छोटे | केवल दृश्य—*Settings → Viewer settings* में **Results scale** समायोजित करें। |
| स्थानीय-निर्देशांक भार गलत दिशा में | अवयव का स्थानीय x उसके *प्रारंभिक* से *अंतिम* नोड की ओर जाता है। **Swap nodes** का उपयोग करें या चिह्न पलटें। |
| तापीय भार कुछ नहीं करता | निर्धार्य संरचनाएँ तापमान के अधीन बिना आंतरिक बलों के मुक्त रूप से विरूपित होती हैं। जाँचें कि α ≠ 0 है और, प्रवणता वाले भाग के लिए, काट की ऊँचाई h सेट है। |

## इंटरफ़ेस की समस्याएँ

| लक्षण | समाधान |
| --- | --- |
| शॉर्टकट काम नहीं करते | पहले कैनवास पर क्लिक करें—टेक्स्ट फ़ील्ड फ़ोकस में हो तो कुंजियाँ अनदेखी रहती हैं। |
| पैन नहीं हो पाता | पैन डिफ़ॉल्ट रूप से मध्य/दाएँ माउस बटन से होता है; इसे *Settings → Controls & Shortcuts* में बदलें। ट्रैकपैड पर दो उँगलियों का उपयोग करें या सेटिंग को *Right button* पर बदलें। |
| अपडेट के बाद मेरा मॉडल गायब हो गया | स्टोरेज रीसेट करने वाला अपडेट पहले संवाद में घोषित होता है; उसे रद्द करके अपडेट से पहले प्रोजेक्ट सहेजें। |
| गलत भाषा | *Settings → Language & Locale*, या URL में `?lang=en` जोड़ें। |
| सेटिंग्स के बदलाव टिकते नहीं | लोकल स्टोरेज अवरुद्ध है (निजी विंडो, सख्त गोपनीयता मोड)। सेटिंग्स और ऑटोसेव को इसकी आवश्यकता है। |

## बग रिपोर्ट करना

ब्राउज़र और OS, आपकी अपेक्षा, और—सबसे उपयोगी—समस्या को दोहराने वाला **साझा लिंक** या **प्रोजेक्ट JSON** देते हुए एक [GitHub issue](https://github.com/janvorisek/edubeam/issues) खोलें।
