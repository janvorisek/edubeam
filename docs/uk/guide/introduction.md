# Вступ

<Edubeam /> — це безкоштовний браузерний інструмент для **розрахунку плоских (2D) стрижневих конструкцій**: балок, рам і ферм. Ви креслите конструкцію, додаєте опори й навантаження, а скінченноелементний розв'язувач перераховує все тієї ж миті, коли ви щось змінюєте — без кнопки «Розрахувати», без встановлення, без облікового запису.

[Запустіть EduBeam](https://run.edubeam.app/?lang=uk){target="_blank"} у новій вкладці та виконуйте кроки [Швидкого старту](/uk/guide/quick-start).

## Що він уміє

| Область | Можливості |
| --- | --- |
| **Конструкції** | Плоскі (x–z) балки, нерозрізні балки, рами та ферми з вузлів і 2D балкових елементів Тимошенка. Кінцеві шарніри перетворюють будь-який стрижень на стрижень ферми. |
| **Опори** | Будь-яка комбінація закріплених `Dx`, `Dz`, `Ry` у вузлі → защемлення, шарнірно-нерухома, шарнірно-рухома опора, ковзне защемлення… Похилі опори через кут локальної системи координат вузла. |
| **Навантаження** | Вузлові сили та моменти, задані переміщення (осідання опор), рівномірно розподілені й трапецієподібні навантаження (у глобальній чи локальній системі), зосереджені навантаження вздовж елемента, а також рівномірний та градієнтний температурний вплив. |
| **Результати** | Деформована форма, поздовжня сила **N**, поперечна сила **V<sub>z</sub>**, згинальний момент **M<sub>y</sub>**, опорні реакції, переміщення вузлів, кінцеві зусилля елементів і матриця жорсткості кожного елемента. |
| **Розрахунок** | Лінійний статичний розрахунок для одного випадку навантаження. Результати точні для лінійної моделі (згущення сітки не потрібне). |
| **Файли** | Збереження/відкриття проєктів у JSON, передавання всієї моделі через URL, вбудовування перегляду лише для читання. Усе залишається на вашому пристрої. |
| **Одиниці** | Незалежний вибір одиниць довжини, площі, моменту інерції площі, маси, сили, моменту та напруження (метричні й імперські). |

## Чого він (поки що) не вміє

Знати обмеження наперед — значить заощадити час:

- **Лише 2D** — жодної роботи з площини, жодних просторових рам.
- **Лише лінійна статика** — без ефектів другого порядку (P–Δ), без стійкості, динаміки та пластичності.
- **Один випадок навантаження** — немає комбінацій навантажень чи обвідних епюр. Моделюйте кожен випадок окремо (збережіть кожен як окремий файл або посилання).
- **Без власної ваги** — за потреби задайте її як розподілене навантаження.
- **Без перевірок за нормами** — EduBeam дає внутрішні зусилля й переміщення; перевірки за нормами лишаються за вами.

Якщо вам бракує певної функції, [створіть issue](https://github.com/janvorisek/edubeam/issues).

## Для кого це?

- **Студентам**, які вивчають будівельну механіку й хочуть миттєво перевіряти ручні розрахунки. Див. [Перевірка результатів вручну](/uk/guide/verification).
- **Викладачам**, які показують, як опори, шарніри та навантаження змінюють внутрішні зусилля — наживо, на проєкторі, будь-якою з 11 мов.
- **Інженерам**, яким потрібна швидка перевірка перед запуском важчого настільного пакета.

## Мови

Інтерфейс доступний мовами: English, Čeština, Deutsch, Español, Français, Polski, Português, Русский, Українська, ไทย та 汉语. EduBeam визначає мову з налаштувань браузера; змінити її можна в **Налаштування → Мова та локаль** або відкривши застосунок із параметром `?lang=`, наприклад [run.edubeam.app/?lang=uk](https://run.edubeam.app/?lang=uk){target="_blank"}.
