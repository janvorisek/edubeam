# 疑难解答

## 没有绘制任何结果 {#no-results-are-drawn}

只有当模型可以求解时，才会显示结果。请按以下顺序检查：

1. **阅读视图左上角的消息。**
   - *尚未定义材料* / *尚未定义截面*：用**新增**按钮添加一个。
   - 蓝色的**需要支座**标记：模型只是尚未完成。请添加支座。指向该标记，会以虚线轮廓显示结构仍可如何运动。
   - **红色消息**：有地方出错了。它会指出问题所在；如果有多个问题，则显示*模型有 N 个错误。* 点击**显示详情**，逐项修正（见下表）。相关的节点或铰会在画布上被圈出。
   - **黄色消息**：警告。模型仍然已经求解；你可以将其隐藏。
2. **支座够吗？** 求解器至少需要三个受约束自由度，并且支座必须能够固定结构。放在两个滑动铰支座上的梁（Dz + Dz）只有两个约束，会滑走。请在某处加一个 `Dx`，或在一个支座处加 `Ry`。
3. **单元连接上了吗？** 坐标相同的两个节点仍然是两个独立的节点。删除多余的那个并重新连接，或用**连接到结构**把节点放在单元上。
4. **铰太多了？** 柱两端都设铰，或者没有斜杆的铰接方框，都会形成机构。EduBeam 会圈出这些铰并显示其运动。
5. **刚度为零？** `E`、`A` 或 `Iy` 误输入为 0，或单位错误，会使结构的一部分几乎无阻力地运动。EduBeam 会将其报告为*不稳定*。

## 消息 {#messages}

**显示详情**会打开一个对话框，标题为*无法求解模型*（错误）、*尚不能求解*（仍需支座）或*模型警告*。其中的**疑难解答**链接指向本页。

### 尚需完成 {#still-needed}

| 消息 | 含义 / 解决方法 |
| --- | --- |
| *结构需要支座才能求解。* | 受约束自由度总数少于三个。请添加支座。 |
| *结构中一个独立部分（节点 …）的受约束自由度少于 3 个，可以自由运动。* | 模型分成了几块，其中一块处于悬空状态。请将其连接或为其设置支座。 |

### 错误 {#errors}

| 消息 | 含义 / 解决方法 |
| --- | --- |
| *结构的支座数量足够，但无法将其固定：结构仍可…* | 支座全部平行，或其作用线交于一点。虚线轮廓会显示运动；请改变其中一个支座的方向。如果只有某一块受影响，同样的消息会指明是*独立部分*。 |
| *支座能够固定结构，但它仍是机构：杆件可绕节点 … 处的铰转动。* | 铰使杆件之间可以相对转动，例如两根柱顶都设铰的框架，或没有斜杆的铰接方框。请去掉一个铰，或添加杆件或支座。 |
| *结构不稳定：以下自由度几乎没有抵抗即可运动：节点 …* | 接近机构，或刚度接近于零。请检查支座、铰，以及 `E`、`A` 和 `Iy` 的数值。 |
| *结构为机构：刚度矩阵奇异。* | 有某个部分可以自由运动，而上述检查没有发现。请检查每个部分是否至少有三个约束，以及铰是否导致某根杆件可以自由转动。 |
| *单元 … 引用了不存在的节点 / 材料 / 截面 …* | 被引用的对象已被删除，通常发生在手动编辑过的 JSON 文件中。请在*单元*表格中重新指定。 |
| *单元 … 必须恰好引用 2 个节点。* | 导入文件中有损坏的单元。删除并重新创建它。 |
| *节点荷载 / 位移约束 #n 引用了不存在的节点 …* | 删除该荷载，或为其指定一个节点。 |
| *单元荷载 #n 引用了不存在的单元 …* | 删除该荷载。 |
| *由于模型内部不一致，求解失败……* | 一般性的失败。撤销上一步，或保存文件并[报告问题](https://github.com/janvorisek/edubeam/issues)。 |

### 警告 {#warnings}

模型仍然已经求解，但请检查以下内容：

| 消息 | 含义 / 解决方法 |
| --- | --- |
| *节点 … 未与任何单元相连，求解器将忽略该节点。* | 多余的节点。删除它，或将其连接。 |
| *节点 … 设有支座，但没有单元与之相连，因此该支座不承受任何力。* | 支座设在了多余的节点上。 |
| *单元 … 的两端引用了同一个节点。* | 长度为零的单元。删除它。 |
| *节点荷载 / 位移约束 #n 包含无效数值。* | 某个分量不是数字。编辑该荷载。 |

## 结果看起来不对 {#results-look-wrong}

| 现象 | 可能的原因 |
| --- | --- |
| 荷载向上作用 | 整体坐标 **z 轴指向下**，因此正的 `Fz`/`fz` 向下。负值指向上。见[符号约定](/zh/elements/conventions)。使用 y 向上的坐标轴时则正好相反。 |
| 挠度大了或小了 1000 倍 | 单位混淆：单位为 MPa 时以 Pa 输入了 `E`，或单位为 m⁴ 时以 cm⁴ 输入了 `Iy`。请检查视图右下角的单位标记。 |
| 挠度略大于教科书公式 | Timoshenko 剪切变形。增大截面的剪切系数，或使用细长杆件，即可接近 Euler–Bernoulli 值。见[手算校核结果](/zh/guide/verification)。 |
| 符号看起来“不对” | 请根据标签而不是内力图所在的一侧读取符号。正弯矩表示下缘受拉。*单元结果*中的端力遵循单元局部坐标轴，而不是 N-V-M 约定。 |
| 两根相同的柱剪力符号相反 | V 的符号跟随各单元的方向。交换其中一根的节点顺序再比较。 |
| 出现 `4 · 10¹` 这样的数字 | 这是科学计数格式。在*设置 → 语言与区域 → 数字格式*中选择*自动*。 |
| 内力图过大或过小 | 纯属视觉效果。在*设置 → 视图设置*中调整**结果缩放**。 |
| 局部坐标系中的荷载方向反了 | 单元的局部 x 轴从*起始*节点指向*终止*节点。交换节点顺序，或改变符号。 |
| 倾斜杆件上的荷载不对 | **LCS** 默认勾选，因此 `fz` 垂直于杆件作用。要施加竖向荷载，请取消勾选。 |
| 温度荷载不起作用 | 静定结构在温度作用下自由变形，不产生内力。请检查 α ≠ 0；对于温度梯度，还要检查是否设置了截面高度 h。 |

## 界面问题 {#interface-issues}

| 现象 | 解决方法 |
| --- | --- |
| 快捷键没有反应 | 先点击画布：文本框获得焦点时，按键会被忽略。 |
| 无法平移 | 默认用鼠标中键或右键平移；可在*设置 → 控制与快捷键*中更改。在触控板上，双指滚动用于缩放；用双指点按并拖动即可平移。 |
| 我的模型不见了 | 打开链接、文件或示例，以及清空结构时，旧模型都会被保留：**☰ → 最近的结构**，或 <kbd>Ctrl</kbd>+<kbd>Z</kbd>。 |
| 语言不对 | *设置 → 语言与区域*，或在地址后加上 `?lang=cn`。 |
| 设置修改无法保存 | 本地存储被阻止了（无痕窗口、严格隐私模式）。设置、自动保存和“最近的结构”都需要本地存储。 |

## 报告 bug {#reporting-a-bug}

提交一个 [GitHub issue](https://github.com/janvorisek/edubeam/issues)，写明你的浏览器和操作系统、你预期的结果，以及最有用的：能够复现问题的**分享链接**或**项目文件**。
