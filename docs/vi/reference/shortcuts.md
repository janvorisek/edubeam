# Bàn phím, chuột và cảm ứng

Phím tắt hoạt động khi vùng hiển thị đang được chọn (có focus). Chúng bị bỏ qua khi bạn đang gõ trong ô bảng hoặc hộp thoại; hãy nhấp vào khung vẽ trước.

## Bàn phím {#keyboard}

| Phím tắt | Thao tác |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Hoàn tác |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Làm lại |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Lưu dự án (tải xuống JSON) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Mở dự án |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Xuất hình ảnh |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Chọn tất cả |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Sao chép phần đang chọn (nút, phần tử và tải trọng của chúng) |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Dán: bóng mờ của bản sao đi theo con trỏ; nhấp để đặt, hoặc nhập độ dời Δx, Δz trên thanh thông báo rồi nhấn **Dán** |
| <kbd>Delete</kbd> | Xóa phần đang chọn |
| <kbd>Esc</kbd> | Hủy chế độ chuột hiện tại, đóng hướng dẫn tham quan, bỏ chọn, hoặc thoát khỏi ô bảng |
| <kbd>Enter</kbd> | Xác nhận ô bảng |
| <kbd>F</kbd> | Vừa màn hình |
| <kbd>C</kbd> | Căn giữa |
| <kbd>G</kbd> | Bật/tắt lưới |
| <kbd>S</kbd> | Bật/tắt bắt dính lưới |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | Phóng to / thu nhỏ |

Trên máy Mac, dùng <kbd>Cmd</kbd> ở những chỗ ghi <kbd>Ctrl</kbd>.

## Chuột {#mouse}

| Thao tác | Kết quả |
| --- | --- |
| Nhấp | Chọn nút, phần tử, tải trọng hoặc đường kích thước và mở bảng của nó |
| Kéo trên vùng trống của khung vẽ | Khung chọn hình chữ nhật |
| Kéo một nút | Di chuyển nút (bắt dính vào lưới khi bật bắt dính) |
| Nhấp trong chế độ chuột | Đặt nút, hoặc bắt đầu hay vẽ tiếp một chuỗi phần tử |
| Nhấp đúp vào tải trọng | Sửa tải trọng |
| Nhấp chuột phải | Menu khung vẽ: Thêm nút, Thêm phần tử, Thêm kích thước, Ghi kích thước phần tử (khi trỏ vào phần tử), Sửa, Sao chép, Dán, Xóa |
| <kbd>Ctrl</kbd> (<kbd>Cmd</kbd> trên Mac) + Thêm nút / Thêm phần tử trong menu khung vẽ | Đặt bằng chuột thay vì qua hộp thoại |
| Kéo bằng nút giữa hoặc nút phải | Kéo màn hình (xem *Cài đặt → Điều khiển và phím tắt*) |
| Con lăn | Thu phóng về phía con trỏ |
| Trỏ vào một đối tượng | Chú thích với chuyển vị, đặc trưng hoặc giá trị tải trọng |

Trên bàn di chuột (trackpad), cuộn bằng hai ngón sẽ thu phóng. Để kéo màn hình, nhấp và kéo bằng hai ngón (tương đương kéo bằng nút phải).

## Cảm ứng {#touch}

| Cử chỉ | Kết quả |
| --- | --- |
| Chạm | Chọn, và hiện thông tin cùng các thao tác của đối tượng |
| Chạm trong chế độ chuột | Đặt nút hoặc vẽ tiếp phần tử |
| Nhấn vào nút rồi kéo | Di chuyển nút |
| Kéo một ngón ở chỗ khác | Kéo màn hình |
| Chụm hai ngón | Thu phóng |
| Nhấn giữ trên khung vẽ | Menu khung vẽ |
| Nút **Chọn bằng khung** (góc trên bên phải), rồi kéo | Khung chọn hình chữ nhật |

## Bảng đối tượng {#object-panels}

Nhấp vào một đối tượng sẽ mở một bảng bên cạnh nó với thông tin chi tiết và các thao tác sau:

| Đối tượng | Thao tác |
| --- | --- |
| Nút | Thêm tải trọng · Gối tựa tại nút (ký hiệu gối, Dx / Dz / Ry, góc LCS của nút) · Chuyển vị cưỡng bức (với nút có gối tựa) · Xóa |
| Phần tử | Sửa phần tử (nút và khớp, vật liệu, tiết diện) · Thêm tải trọng · Ma trận độ cứng · Xóa |
| Tải trọng nút hoặc tải trọng phần tử | Sửa tải trọng · Xóa |
| Đường kích thước | Sửa (tọa độ) · Lật kích thước · Xóa |
