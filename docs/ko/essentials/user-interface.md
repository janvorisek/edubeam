# 사용자 인터페이스

<Edubeam />은 세 영역으로 나뉩니다. 위쪽의 **앱 바**, 가운데에서 그림을 그리는 **뷰어**, 그리고 객체 종류마다 표가 있는 **하단 바**입니다. 무엇이 어디에 있는지 알면 사용 설명서의 나머지 내용도 쉽게 이해할 수 있습니다.

![인터페이스의 각 부분, 번호는 아래 목록과 같습니다](/screenshots/ko/ui-overview.webp)

1. **☰ 메뉴**: 열기, 저장, 공유, 내보내기, 예제와 안내 투어.
2. **앱 바 버튼**: 구조물 지우기와 모델 공유.
3. 모델의 모든 변경에 대한 **실행 취소 / 다시 실행**.
4. **뷰어 버튼**: 가운데 맞춤, 화면에 맞추기, 표시 옵션 토글.
5. **표시 옵션**: 어떤 결과와 모델 요소를 그릴지 선택합니다.
6. **그리드, 스냅, 십자선, 단위.**
7. **하단 바 탭**: 절점, 요소, 하중, 재료, 단면, 결과.
8. 열린 탭의 **표**. 모든 값을 편집할 수 있습니다.

::: tip 둘러보기
**☰ → 둘러보기**를 선택하면 앱 안에서 이 부분들을 하나씩 짚어 줍니다.
:::

![둘러보기의 표시 옵션 단계](/screenshots/ko/tour.webp)

| **구조물 지우기** | 확인 후 모든 절점, 요소, 하중을 삭제합니다. 체크박스 두 개로 재료와 단면도 함께 삭제할 수 있습니다. <kbd>Ctrl</kbd>+<kbd>Z</kbd>로 모델을 되돌릴 수 있으며, 모델은 최근 구조물에도 보관됩니다. |

## 뷰어 {#viewer}

캔버스에서 모델을 그리고 살펴봅니다. 앱의 다른 부분은 모두 여기서 선택한 것을 따라갑니다.

### 캔버스의 버튼 {#buttons-on-the-canvas}

- **왼쪽 위:** **실행 취소**와 **다시 실행**(<kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>). 추가, 편집, 드래그, 삭제, 지우기를 포함해 모델의 모든 변경을 되돌릴 수 있습니다.
- **오른쪽 위:** **가운데 맞춤**(<kbd>C</kbd>), **화면에 맞추기**(<kbd>F</kbd>), 그리고 표시 옵션을 보이거나 숨기는 ⚙ 버튼. 터치스크린에는 **영역 선택**도 있습니다.
- **오른쪽 아래:** **G**는 그리드를, **S**는 그리드 스냅을 켜고 끕니다. 십자선 버튼은 눈금자에 포인터 위치를 표시하고, **단위 칩**은 설정의 *언어 및 지역*을 엽니다.

### 표시 옵션 {#display-options}

![뷰어 버튼과 표시 옵션](/screenshots/ko/ui-display-settings.webp){.shot-lg}

기본으로 열려 있는 두 줄의 체크박스입니다.

- **결과:** *변형 형상*, *N (x)*, *V<sub>z</sub> (x)*, *M<sub>y</sub> (x)*, *반력*. 변형 형상, M, 반력은 처음부터 체크되어 있습니다.
- **모델:** *지점*, *하중*, *절점 이름*, *요소 이름*.

**설정 더 보기**는 전체 [설정](/ko/essentials/units-settings)을 *뷰어 설정*에서 엽니다.

### 화면 이동 {#navigating}

| 동작 | 마우스 | 터치 |
| --- | --- | --- |
| 확대/축소 | 마우스 휠(커서 방향으로), <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | 두 손가락 벌리기/모으기 |
| 화면 이동 | **가운데 또는 오른쪽** 버튼으로 드래그(*설정 → 조작 및 단축키* 참고) | 한 손가락으로 드래그 |
| 화면에 맞추기 / 가운데 맞춤 | <kbd>F</kbd> / <kbd>C</kbd> 또는 오른쪽 위 버튼 | 오른쪽 위 버튼 |

### 선택과 편집 {#selecting-and-editing}

절점, 요소, 하중, 치수선을 **클릭**하면 선택됩니다. 그 옆에 세부 정보와 하중 추가, 지점 설정, 편집, 강성 행렬 보기, 삭제 등 알맞은 작업이 있는 패널이 열립니다. 절점을 클릭하면 하단 바도 절점 탭으로 바뀝니다.

<div class="shots">

![절점: 하중 추가, 지점 설정, 강제 변위 지정](/screenshots/ko/ui-node-menu.webp)

![요소: 편집, 하중 추가, 강성 행렬](/screenshots/ko/ui-element-menu.webp)

</div>

- **빈 캔버스에서 드래그**하면 선택 사각형이 그려집니다. 사각형 안의 절점, 요소, 그 하중과 치수선이 모두 선택됩니다. <kbd>Delete</kbd>를 누르면 모두 삭제되고, <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd>로 다른 곳에 복사할 수 있습니다.
- **절점을 드래그**하면 이동합니다. 스냅이 켜져 있으면 그리드에 맞춰집니다. 연결된 요소와 그 하중도 함께 따라옵니다.
- **하중을 더블클릭**하면 편집할 수 있습니다.
- 무엇이든 **포인터를 올리면** 툴팁이 나타납니다. 절점은 변위와 회전각을, 요소는 재료와 단면을, 하중은 값을 보여 줍니다. 터치스크린에서는 대신 탭하면 선택 패널에 같은 정보가 나타납니다.

![절점에 포인터를 올리면 변위와 회전각이 표시됩니다](/screenshots/ko/ui-hover.webp){.shot-sm}

**캔버스를 마우스 오른쪽 버튼으로 클릭**하면(터치스크린에서는 길게 누르면) 캔버스 메뉴가 열립니다. *절점 추가*나 *요소 추가*를 고를 때 <kbd>Ctrl</kbd>을 누르고 있으면 대화 상자 대신 마우스로 배치합니다. 요소 위에서는 메뉴에 *요소에 치수 추가*도 있습니다.

![캔버스 메뉴](/screenshots/ko/ui-canvas-menu.webp){.shot-sm}

모든 단축키는 [키보드, 마우스 및 터치](/ko/reference/shortcuts) 페이지에 있습니다.

### 모델을 해석할 수 없을 때 {#when-the-model-cannot-be-solved}

뷰어 왼쪽 위에 메시지가 나타납니다.

- **새로 추가** 버튼과 함께 *정의된 재료가 없습니다* / *정의된 단면이 없습니다*.
- 모델이 단지 아직 완성되지 않았을 때는 작은 파란색 **지점 필요** 칩.
- 무언가 잘못되었을 때는 모든 문제를 나열하는 **자세히 보기**가 있는 **빨간색 메시지**.

구조물이 아직 움직일 수 있으면 EduBeam이 점선 윤곽으로 구조물을 흔들어 보이고, 원인이 되는 절점이나 힌지에 원을 그립니다. 메시지에 포인터를 올리면 움직임을 다시 볼 수 있고, 눈 모양 버튼으로 숨길 수 있습니다.

![B와 C에 힌지가 있는 라멘은 메커니즘입니다: EduBeam이 어떻게 움직이는지 보여 줍니다](/screenshots/ko/ui-mechanism.webp)

![자세히 보기는 각 문제를 도움말과 함께 나열합니다](/screenshots/ko/ui-diagnostics.webp){.shot-lg}

[문제 해결](/ko/reference/troubleshooting)에서 모든 메시지를 설명합니다.

## 하단 바 {#bottom-bar}

탭 6개가 있으며, 탭마다 도구 모음과 편집 가능한 표가 있습니다. 탭에는 모델에 있는 각 종류의 객체 수가 표시됩니다. 오른쪽의 **?**는 열린 탭을 설명하고, 일부 열 제목 옆의 **?**도 그 열을 설명합니다. 탭 줄을 위아래로 드래그해 바의 크기를 바꾸거나, 오른쪽 버튼으로 최소화할 수 있습니다.

| 탭 | 도구 모음 | 표 |
| --- | --- | --- |
| **절점** | 절점 추가(대화 상자), 절점 추가(마우스) | 이름, 좌표, **구속 자유도**(지점 기호, Dx, Dz, Ry, 지점 각도 α), 하중, 편집, 삭제 |
| **요소** | 요소 추가(대화 상자), 요소 추가(마우스) | 이름, 유형, 절점(교환 버튼 포함), 재료, 단면, **단부 힌지**, 하중, 강성 행렬, 삭제 |
| **하중** | 절점 하중 추가, 요소 하중 추가 | 유형, 대상, 편집 가능한 성분, 편집, 삭제 |
| **재료** | 재료 추가, 재료 라이브러리 | 이름, E, G, α<sub>T</sub>, 삭제 |
| **단면** | 단면 추가, 단면 라이브러리, 다각형 단면 | 형상, 이름, A, I<sub>y</sub>, h, k, 형상 편집, 삭제 |
| **결과** | 절점 결과, 요소 결과, CSV 내보내기, 복사 | 절점별 변위와 회전각 또는 요소별 단부력 |

셀은 그 자리에서 편집합니다. 클릭하고 값을 입력한 다음 <kbd>Enter</kbd>를 누릅니다(셀을 벗어나려면 <kbd>Esc</kbd>). 값은 [현재 단위](/ko/essentials/units-settings)로 표시되고 입력됩니다.

## 뷰어 위의 탭 {#tabs-above-the-viewer}

**뷰어**는 캔버스를 보여 줍니다. **설정**은 설정을 전체 화면으로 보여 주므로 색상이나 단위를 바꾼 뒤 다시 전환해 효과를 확인할 수 있습니다. 단위 칩과 *설정 더 보기*는 같은 설정을 모델 위의 대화 상자로 엽니다.

## 플로팅 창 {#floating-windows}

**강성 행렬**(요소 패널이나 요소 표에서)은 전체 좌표계 기준 요소의 6 × 6 강성 행렬을 창으로 엽니다. 캔버스 메뉴의 **편집**은 현재 선택 항목의 표를 엽니다. 창은 제목 표시줄을 드래그해 옮기고 ×로 닫습니다.
