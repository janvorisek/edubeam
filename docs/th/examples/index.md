# ตัวอย่าง

การ์ดทุกใบด้านล่างคือโมเดลที่คำนวณแล้วและโต้ตอบได้ คลิกเพื่อเปิดใน <Edubeam /> พร้อมการตั้งค่าครบถ้วนที่แก้ไขได้ทันที แล้วลองลากโหนด เปลี่ยนแรงกระทำ หรือติ๊กจุดหมุน และดูแผนภาพเปลี่ยนตาม

## แบบฝึกหัดแนะนำ {#suggested-exercises}

- **คานอินดีเทอร์มิเนท**: ยกเลิกการติ๊ก `Ry` ที่ปลายยึดแน่นเพื่อให้เป็นคานรองรับธรรมดา โมเมนต์ที่กึ่งกลางช่วงเพิ่มขึ้นเท่าไร?
- **คานยื่น**: เปรียบเทียบการโก่งตัวที่ปลายกับ $FL^3/3EI$ (ดู [ตรวจสอบผลลัพธ์ด้วยการคำนวณมือ](/th/guide/verification)) แล้วลด $I_y$ ลงครึ่งหนึ่งในแท็บ *หน้าตัด*
- **โครงถัก Pratt**: จุดต่อในตัวอย่างนี้เป็นแบบแข็งเกร็ง ติ๊กจุดหมุนทั้งสองปลายของทุกชิ้นส่วนเพื่อให้เป็นโครงถักจริง แล้วเปรียบเทียบแรงตามแนวแกน จากนั้นลบชิ้นส่วนทแยงออกหนึ่งชิ้น: โครงถักยังตั้งอยู่ได้หรือไม่?
- **คานต่อเนื่องสามช่วง**: คานนี้มีจุดรองรับที่ปลายทั้งสองเท่านั้น ติ๊ก `Dz` ที่โหนดภายใน B และ C เพื่อให้เป็นคานต่อเนื่อง แล้วดูโมเมนต์ลบเกิดขึ้นเหนือจุดรองรับ
- **กรณีแรงกระทำของโครงข้อแข็ง**: ติ๊กจุดหมุนทั้งสองปลายของคานเพื่อจำลองจุดต่อคาน-เสาแบบหมุด หรือเปลี่ยนจุดรองรับด้านขวาจากล้อเลื่อนเป็นหมุด
- **แรงกระทำเนื่องจากอุณหภูมิ**: ยึด `Dx` ที่จุดรองรับทั้งสองข้าง แล้วดูแรงตามแนวแกนเกิดขึ้น

## บทเรียนพร้อมตัวอย่างการคำนวณ {#worked-tutorials}

- [โครงข้อแข็งสามจุดหมุน](/th/tutorials/three-hinged-frame): แรงปฏิกิริยา N, V และ M ตรวจสอบด้วยการคำนวณมือ
