# कीबोर्ड और माउस

कीबोर्ड शॉर्टकट तब काम करते हैं जब व्यूअर फ़ोकस में हो—तालिका कोशिका या संवाद में टाइप करते समय वे अनदेखे रहते हैं।

## कीबोर्ड

| शॉर्टकट | क्रिया |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | पूर्ववत करें (Undo) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | पुनः करें (Redo) |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | प्रोजेक्ट सहेजें (JSON डाउनलोड) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | प्रोजेक्ट खोलें |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | सब कुछ चुनें |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | चयन (नोड, अवयव, भार) को EduBeam के क्लिपबोर्ड पर कॉपी करें |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | पेस्ट: प्रति की छाया कर्सर के साथ चलती है; रखने के लिए बायाँ क्लिक करें |
| <kbd>Delete</kbd> | चयन हटाएँ |
| <kbd>Esc</kbd> | वर्तमान माउस मोड रद्द करें, चयन साफ़ करें, तालिका कोशिका छोड़ें |
| <kbd>Enter</kbd> | तालिका कोशिका की पुष्टि करें |
| <kbd>F</kbd> | सामग्री को स्क्रीन पर फिट करें |
| <kbd>C</kbd> | सामग्री केंद्रित करें |
| <kbd>G</kbd> | ग्रिड टॉगल करें |
| <kbd>S</kbd> | ग्रिड-स्नैप टॉगल करें |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | ज़ूम इन / आउट |

macOS पर जहाँ <kbd>Ctrl</kbd> लिखा है वहाँ <kbd>Cmd</kbd> का उपयोग करें।

## माउस

| क्रिया | परिणाम |
| --- | --- |
| बायाँ क्लिक | नोड / अवयव / भार / विमा रेखा चुनें और उसका पॉपओवर मेनू खोलें |
| खाली कैनवास पर बायाँ ड्रैग | रबर-बैंड चयन |
| नोड पर बायाँ ड्रैग | नोड खिसकाएँ (स्नैप चालू हो तो ग्रिड पर बैठता है) |
| *Add using mouse* मोड में बायाँ क्लिक | नोड रखें, या अवयव की बहुभुजी रेखा शुरू / जारी करें |
| भार पर डबल-क्लिक | भार संपादित करें |
| खाली कैनवास पर दायाँ क्लिक | कैनवास मेनू: Add node, Add element, Add dimension, Edit, Copy, Paste, Delete |
| मध्य या दायाँ ड्रैग | पैन (*Settings → Controls & Shortcuts* में बदला जा सकता है) |
| व्हील | कर्सर की ओर ज़ूम |
| होवर | विस्थापन / गुण / भार मानों वाला टूलटिप |

## टच

| इशारा | परिणाम |
| --- | --- |
| टैप | चुनें |
| एक उँगली से ड्रैग | पैन |
| पिंच | ज़ूम |
| नोड को देर तक दबाना | उसे खिसकाना शुरू करें |

## पॉपओवर मेनू

किसी वस्तु पर क्लिक करने से उसके पास एक छोटा मेनू खुलता है:

| वस्तु | आइटम |
| --- | --- |
| नोड | Add load · Node supports (Dx / Dz / Ry, Nodal LCS angle) · Prescribe displacement (यदि आधार हो) · Delete |
| अवयव | Edit element (नोड, सामग्री, काट) · Add load · Stiffness matrix · Delete |
| नोडीय / अवयव भार | Edit load · Delete |
| विमा रेखा | Edit (निर्देशांक) · Flip dimension · Delete |
