# 荷载

所有荷载都属于**同一个荷载工况**并同时作用。要比较不同方案，请把每个方案分别保存为项目文件或分享链接。

## 一句话符号约定

整体坐标 **x** 指向右，整体坐标 **z** 指向**下**。因此整体坐标系中正的 `Fz` 或 `fz` 是向下的、重力方向的荷载；正的力矩 `My` 在屏幕上为逆时针。详见[坐标系与符号约定](/zh/elements/conventions)。

## 节点荷载

*荷载*标签页 → **添加节点荷载**，或点击节点 → **添加荷载**。选择**力/力矩**：

| 字段 | 含义 | 单位 |
| --- | --- | --- |
| `Fx` | 水平力（+ → 向右） | 力的单位 |
| `Fz` | 竖向力（+ → 向下） | 力的单位 |
| `My` | 绕 y 的力矩 | 弯矩单位 |

分量始终在**整体**坐标系中。对话框中的实时箭头预览显示合力的方向和大小。同一节点上允许有多个节点荷载，它们简单叠加。

### 位移约束（支座沉降）

在同一对话框中选择**位移约束**（或点击有支座的节点 → **施加位移约束**）。字段变为：

| 字段 | 含义 | 单位 |
| --- | --- | --- |
| `Dx` | 施加的水平位移 | 长度单位 |
| `Dz` | 施加的竖向位移（+ → 向下） | 长度单位 |
| `Ry` | 施加的转角 | rad |

只能为该节点上**被约束**的自由度输入数值——只有支座才能被移动。每个节点只能有一个位移约束；请编辑它而不是再添加一个。在静定结构中，沉降只产生位移而不产生内力；在超静定结构中两者都会产生。

## 单元荷载

*荷载*标签页 → **添加单元荷载**，或点击单元 → **添加荷载**。选择**荷载类型**；对话框会实时预览荷载在单元上的样子。

### 均布荷载

| 字段 | 含义 | 单位 |
| --- | --- | --- |
| `fx` | 沿 x 的单位长度荷载 | 力 / 长度 |
| `fz` | 沿 z 的单位长度荷载 | 力 / 长度 |
| **局部坐标系** | 勾选后 `fx`、`fz` 按单元局部坐标轴解释 | – |

最常见的情形是竖向重力荷载：`fz > 0`，局部坐标系关闭。对于倾斜杆件，**垂直于杆件**的荷载（例如作用在斜梁上的风荷载）是**开启**局部坐标系的 `fz`；按*水平*投影每米计的竖向荷载无法直接输入——请先把它换算成按杆件长度每米计。

### 梯形分布荷载

| 字段 | 含义 |
| --- | --- |
| `f1x`、`f1z` | **起始**节点处的集度 |
| `f2x`、`f2z` | **终止**节点处的集度 |

集度在两端之间线性变化。三角形荷载就是 `f1z = 0`。梯形荷载始终在**单元局部坐标系**中（局部坐标系复选框被锁定为开启）；对于水平单元，局部与整体的 z 轴重合，因此这只对倾斜杆件有影响。

### 集中荷载

作用在单元**沿长度方向**某处的集中力或力矩——不需要额外节点。

| 字段 | 含义 |
| --- | --- |
| `Fx`、`Fz`、`My` | 力 / 力矩分量 |
| **距起始节点的荷载位置** | 距起始节点的距离，`0 ≤ a ≤ L` |
| **局部坐标系** | 分量按局部坐标轴解释 |

剪力图在荷载位置突变 `Fz`，弯矩图在该处出现折点；该处的弯矩值会自动标注。

### 温度荷载

| 字段 | 含义 |
| --- | --- |
| **ΔT<sub>s</sub>** – 轴向温度变化 | 整个截面的均匀温度变化 → 伸长 $\alpha\,\Delta T_s\,L$ |
| **ΔT<sub>b</sub> − ΔT<sub>t</sub>** – 下缘减上缘纤维温度 | 沿截面高度的温差 → 曲率 $\alpha\,(\Delta T_b - \Delta T_t)/h$ |

温度荷载使用材料的 **α** 和截面**高度 h**。正的 `ΔTb − ΔTt`（下缘更热）使单元向上拱起。在静定结构中温度只产生位移；约束（固定端、连续性、多余杆件）会把它转化为内力。

## 编辑与删除荷载

- 荷载在*节点* / *单元*表格中以小标签的形式显示，在*荷载*标签页中以行的形式显示，可在此就地编辑分量（以及局部坐标系标志）。
- 在视图中**双击**荷载，或点击它并选择**编辑荷载**，即可打开编辑对话框。
- 选中荷载并按 <kbd>Delete</kbd>，或使用垃圾桶图标。
- 附着在节点或单元上的荷载会随其一起删除，复制粘贴时也会随其一起复制。

## 尚不支持的功能

- **荷载工况与组合** —— 只有一个工况。
- **自重** —— 以均布荷载输入：$f_z = \rho\,g\,A$（例如 IPE 200：7850 × 9.81 × 0.00285 ≈ 0.22 kN/m）。
- 倾斜杆件上的**整体坐标系梯形荷载**。
