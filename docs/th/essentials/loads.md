# แรงกระทำ

แรงกระทำทั้งหมดอยู่ใน **กรณีแรงกระทำเดียว** และกระทำพร้อมกัน ถ้าต้องการเปรียบเทียบหลายสถานการณ์ ให้บันทึกแต่ละสถานการณ์เป็นไฟล์โปรเจกต์หรือลิงก์แชร์แยกกัน

![แรงกระทำทุกประเภทบนคานต่อเนื่องคานเดียว: แรงที่โหนด แรงแผ่กระจายสม่ำเสมอ แรงแผ่กระจายรูปสี่เหลี่ยมคางหมู แรงกระทำเป็นจุด แรงกระทำเนื่องจากอุณหภูมิ และการทรุดตัวของจุดรองรับ](/screenshots/th/loads-overview.webp)

## ข้อตกลงเรื่องเครื่องหมายในบรรทัดเดียว {#sign-convention-in-one-line}

แกนรวม **x** ชี้ไปทางขวา และแกนรวม **z** ชี้ **ลง** `Fz` หรือ `fz` ที่เป็นบวกจึงเป็นแรงทิศลงแบบแรงโน้มถ่วง และโมเมนต์ `My` ที่เป็นบวกหมุนทวนเข็มนาฬิกาบนหน้าจอ รายละเอียดอยู่ใน [ระบบพิกัดและข้อตกลงเรื่องเครื่องหมาย](/th/elements/conventions) เมื่อใช้ [แกน y ชี้ขึ้น](/th/elements/conventions#y-up-axes) ชื่อและเครื่องหมายของปริมาณแนวดิ่งจะกลับกัน: แรงโน้มถ่วงคือ `Fy` ที่เป็นลบ

## แรงกระทำที่โหนด {#nodal-loads}

แท็บ *แรงกระทำ* → **เพิ่มแรงกระทำที่โหนด** หรือคลิกโหนด → **เพิ่มแรงกระทำ** เลือก **แรงและโมเมนต์**:

| ช่อง | ความหมาย | หน่วย |
| --- | --- | --- |
| `Fx` | แรงแนวนอน (บวกไปทางขวา) | หน่วยแรง |
| `Fz` | แรงแนวดิ่ง (บวกทิศลง) | หน่วยแรง |
| `My` | โมเมนต์รอบแกน y (บวกทวนเข็มนาฬิกา) | หน่วยโมเมนต์ |

![เพิ่มแรงกระทำที่โหนด ตัวอย่างแสดงทิศทางขณะที่คุณพิมพ์](/screenshots/th/loads-nodal.webp){.shot-md}

ส่วนประกอบของแรงอยู่ในระบบพิกัด **รวม** เสมอ โหนดหนึ่งรับแรงกระทำที่โหนดได้หลายรายการ ซึ่งจะรวมกันและวาดซ้อนกัน

### การกระจัดที่กำหนด (การทรุดตัวของจุดรองรับ) {#prescribed-displacements-support-settlements}

ในกล่องโต้ตอบเดียวกันเลือก **การกระจัดที่กำหนด** หรือคลิกโหนดที่มีจุดรองรับ → **กำหนดการกระจัด** ช่องต่าง ๆ จะเปลี่ยนเป็น:

| ช่อง | ความหมาย | หน่วย |
| --- | --- | --- |
| `Dx` | การกระจัดแนวนอนที่กำหนด | หน่วยการกระจัด |
| `Dz` | การกระจัดแนวดิ่งที่กำหนด (บวกทิศลง) | หน่วยการกระจัด |
| `Ry` | มุมหมุนที่กำหนด | rad |

ใส่ค่าได้เฉพาะ DOF ที่ **ถูกยึด** ที่โหนดนั้น เพราะเฉพาะจุดรองรับเท่านั้นที่เลื่อนได้ แต่ละโหนดมีการกระจัดที่กำหนดได้ไม่เกินหนึ่งรายการ ให้แก้ไขรายการเดิมแทนการเพิ่มรายการที่สอง ในโครงสร้างดีเทอร์มิเนท การทรุดตัวทำให้เกิดการกระจัดแต่ไม่เกิดแรงภายใน ส่วนในโครงสร้างอินดีเทอร์มิเนทจะเกิดทั้งสองอย่าง

## แรงกระทำบนเอลิเมนต์ {#element-loads}

แท็บ *แรงกระทำ* → **เพิ่มแรงกระทำบนเอลิเมนต์** หรือคลิกเอลิเมนต์ → **เพิ่มแรงกระทำ** เลือก **ประเภทแรงกระทำ** กล่องโต้ตอบจะแสดงตัวอย่างแรงบนเอลิเมนต์ขณะที่คุณพิมพ์

### แรงแผ่กระจายสม่ำเสมอ {#uniformly-distributed-load}

| ช่อง | ความหมาย | หน่วย |
| --- | --- | --- |
| `fx` | แรงต่อความยาวตามแกน x | แรง / ความยาว |
| `fz` | แรงต่อความยาวตามแกน z | แรง / ความยาว |
| **LCS** | ติ๊ก: `fx`, `fz` กระทำตามแกนท้องถิ่นของเอลิเมนต์ ไม่ติ๊ก: ตามแกนรวม | – |

**LCS** ติ๊กไว้เป็นค่าเริ่มต้น บนเอลิเมนต์แนวนอนที่วาดจากซ้ายไปขวา แกนท้องถิ่นและแกนรวมตรงกัน จึงไม่ต่างกัน แต่บนชิ้นส่วนเอียงจะต่างกัน:

- แรง **ตั้งฉากกับชิ้นส่วน** (แรงลมบนจันทัน) คือ `fz` โดย **ติ๊ก** LCS
- แรง **แนวดิ่ง** ต่อเมตรของความยาวชิ้นส่วน (น้ำหนักตัวเอง) คือ `fz` โดย **ไม่ติ๊ก** LCS
- แรงแนวดิ่งต่อเมตรของ *ภาพฉายแนวนอน* (หิมะ) ใส่โดยตรงไม่ได้ ให้คูณด้วย $\cos\alpha$ ก่อน โดย $\alpha$ คือความลาดของชิ้นส่วน แล้วใส่เป็นแรงแนวดิ่ง

### แรงแผ่กระจายรูปสี่เหลี่ยมคางหมู {#trapezoidal-load}

| ช่อง | ความหมาย |
| --- | --- |
| `f1x`, `f1z` | ความเข้มที่โหนด **เริ่มต้น** |
| `f2x`, `f2z` | ความเข้มที่โหนด **ปลาย** |

ความเข้มเปลี่ยนแบบเชิงเส้นจากต้นถึงปลายเอลิเมนต์ แรงแผ่กระจายรูปสามเหลี่ยมคือ `f1z = 0` แรงแผ่กระจายรูปสี่เหลี่ยมคางหมูกระทำตาม **แกนท้องถิ่นของเอลิเมนต์** เสมอ (ช่อง LCS ถูกล็อก) บนเอลิเมนต์แนวนอนจะเหมือนกับแกนรวม

### แรงกระทำเป็นจุด {#concentrated-load}

แรงหรือโมเมนต์แบบจุดที่ตำแหน่งใดก็ได้ **ตาม** เอลิเมนต์ โดยไม่ต้องเพิ่มโหนด

| ช่อง | ความหมาย |
| --- | --- |
| `Fx`, `Fz`, `My` | ส่วนประกอบของแรงและโมเมนต์ |
| **ตำแหน่งแรงกระทำจากโหนดเริ่มต้น** | ระยะจากโหนดเริ่มต้น `0 ≤ a ≤ L` |
| **LCS** | ส่วนประกอบตามแกนท้องถิ่น |

แผนภาพแรงเฉือนกระโดดเท่ากับ `Fz` ที่ตำแหน่งแรง และแผนภาพโมเมนต์หักมุมที่ตำแหน่งนั้น โดยค่าโมเมนต์ที่จุดนั้นจะติดป้ายให้อัตโนมัติ ส่วน `My` แบบจุดจะทำให้แผนภาพโมเมนต์กระโดดแทน

### แรงกระทำเนื่องจากอุณหภูมิ {#temperature-load}

| ช่อง | ความหมาย |
| --- | --- |
| **ΔT<sub>c</sub>** การเปลี่ยนแปลงอุณหภูมิตามแนวแกน | การเปลี่ยนแปลงสม่ำเสมอทั่วทั้งหน้าตัด ทำให้ยืดออก $\alpha\,\Delta T_c\,L$ |
| **ΔT<sub>b</sub> − ΔT<sub>t</sub>** ผลต่างอุณหภูมิ | เส้นใยล่างลบเส้นใยบน ทำให้เกิดความโค้ง $\alpha\,(\Delta T_b - \Delta T_t)/h$ |

แรงกระทำเนื่องจากอุณหภูมิใช้ **α** ของวัสดุและ **ความสูง h** ของหน้าตัด `ΔTb − ΔTt` ที่เป็นบวก (ด้านล่างร้อนกว่า) ทำให้เส้นใยล่างยืดออก เอลิเมนต์จึงแอ่นตัวลงเหมือนคานที่รับแรงโน้มถ่วง ในโครงสร้างดีเทอร์มิเนท อุณหภูมิทำให้เกิดเพียงการกระจัด การยึดรั้ง (ปลายยึดแน่น ความต่อเนื่อง ชิ้นส่วนเกินจำเป็น) จะเปลี่ยนให้เป็นแรงภายใน

## การแก้ไขและการลบแรงกระทำ {#editing-and-removing-loads}

- แรงกระทำแต่ละรายการเป็นหนึ่งแถวในแท็บ *แรงกระทำ* ซึ่งแก้ไขส่วนประกอบและค่า LCS ได้ในที่ แรงกระทำยังแสดงเป็นป้ายในตาราง *โหนด* และ *เอลิเมนต์* ด้วย
- **ดับเบิลคลิก** แรงกระทำบนหน้าจอแสดงผล หรือคลิกแล้วเลือก **แก้ไขแรงกระทำ** เพื่อเปิดกล่องโต้ตอบแก้ไข
- เลือกแรงกระทำแล้วกด <kbd>Delete</kbd> หรือใช้ × ในตาราง
- แรงกระทำที่ติดอยู่กับโหนดหรือเอลิเมนต์จะถูกลบไปพร้อมกัน และถูกคัดลอกไปพร้อมกันเมื่อคัดลอกและวาง

![แท็บแรงกระทำ: หนึ่งแถวต่อหนึ่งแรงกระทำ แก้ไขส่วนประกอบได้ในที่](/screenshots/th/loads-table.webp)

## สิ่งที่ยังไม่มี {#what-is-not-available}

- **กรณีแรงกระทำและการจัดหมู่แรงกระทำ** มีเพียงกรณีแรงกระทำเดียว
- **น้ำหนักตัวเอง** ใส่เป็นแรงแผ่กระจายสม่ำเสมอโดยไม่ติ๊ก LCS: $f_z = \rho\,g\,A$ สำหรับ IPE 200: 7850 × 9.81 × 0.00285 ≈ 0.22 kN/m
- **แรงแผ่กระจายรูปสี่เหลี่ยมคางหมูในแกนรวม** บนชิ้นส่วนเอียง
