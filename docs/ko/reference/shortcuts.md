# 키보드, 마우스 및 터치

키보드 단축키는 뷰어에 포커스가 있을 때 작동합니다. 표의 셀이나 대화 상자에 입력하는 중에는 무시되므로 먼저 캔버스를 클릭하십시오.

## 키보드 {#keyboard}

| 단축키 | 동작 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 실행 취소 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | 다시 실행 |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | 프로젝트 저장(JSON 다운로드) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | 프로젝트 열기 |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | 이미지 내보내기 |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | 모두 선택 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | 선택 항목(절점, 요소와 그 하중) 복사 |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | 붙여넣기: 사본의 윤곽이 커서를 따라다니며, 클릭해 배치하거나 배너에 오프셋 Δx, Δz를 입력하고 **붙여넣기**를 누릅니다 |
| <kbd>Delete</kbd> | 선택 항목 삭제 |
| <kbd>Esc</kbd> | 현재 마우스 모드 취소, 둘러보기 닫기, 선택 해제, 또는 표의 셀 벗어나기 |
| <kbd>Enter</kbd> | 표의 셀 입력 확정 |
| <kbd>F</kbd> | 화면에 맞추기 |
| <kbd>C</kbd> | 가운데 맞춤 |
| <kbd>G</kbd> | 그리드 켜기/끄기 |
| <kbd>S</kbd> | 그리드 스냅 켜기/끄기 |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | 확대 / 축소 |

Mac에서는 <kbd>Ctrl</kbd> 대신 <kbd>Cmd</kbd>를 쓰십시오.

## 마우스 {#mouse}

| 동작 | 결과 |
| --- | --- |
| 클릭 | 절점, 요소, 하중, 치수선을 선택하고 패널 열기 |
| 빈 캔버스에서 드래그 | 선택 사각형 |
| 절점 드래그 | 절점 이동(스냅이 켜져 있으면 그리드에 맞춰짐) |
| 마우스 모드에서 클릭 | 절점 배치, 또는 요소 폴리라인 시작이나 이어 그리기 |
| 하중 더블클릭 | 하중 편집 |
| 마우스 오른쪽 버튼 클릭 | 캔버스 메뉴: 절점 추가, 요소 추가, 치수 추가, 요소에 치수 추가(요소 위에서), 편집, 복사, 붙여넣기, 삭제 |
| 캔버스 메뉴에서 <kbd>Ctrl</kbd>(Mac에서는 <kbd>Cmd</kbd>) + 절점 추가 / 요소 추가 | 대화 상자 대신 마우스로 배치 |
| 가운데 또는 오른쪽 버튼 드래그 | 화면 이동(*설정 → 조작 및 단축키* 참고) |
| 휠 | 커서 방향으로 확대/축소 |
| 객체에 포인터 올리기 | 변위, 속성, 하중 값을 보여 주는 툴팁 |

트랙패드에서는 두 손가락 스크롤로 확대/축소합니다. 화면을 이동하려면 두 손가락으로 클릭한 채 드래그합니다(오른쪽 버튼 드래그).

## 터치 {#touch}

| 제스처 | 결과 |
| --- | --- |
| 탭 | 선택하고 객체의 세부 정보와 작업 표시 |
| 마우스 모드에서 탭 | 절점 배치 또는 요소 이어 그리기 |
| 절점을 누른 채 드래그 | 절점 이동 |
| 다른 곳에서 한 손가락 드래그 | 화면 이동 |
| 두 손가락 벌리기/모으기 | 확대/축소 |
| 캔버스를 길게 누르기 | 캔버스 메뉴 |
| **영역 선택** 버튼(오른쪽 위) 누른 뒤 드래그 | 선택 사각형 |

## 객체 패널 {#object-panels}

객체를 클릭하면 그 옆에 세부 정보와 다음 작업이 있는 패널이 열립니다.

| 객체 | 작업 |
| --- | --- |
| 절점 | 하중 추가 · 지점 조건(지점 기호, Dx / Dz / Ry, 절점 좌표계 각도) · 강제 변위 지정(지점이 있는 절점) · 삭제 |
| 요소 | 요소 편집(절점과 힌지, 재료, 단면) · 하중 추가 · 강성 행렬 · 삭제 |
| 절점 하중 또는 요소 하중 | 하중 편집 · 삭제 |
| 치수선 | 편집(좌표) · 치수 뒤집기 · 삭제 |
